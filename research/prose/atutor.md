ATutor is a learning management system for developing and managing online courses. A site is installed by extracting the files on a web server and following the browser-based installer, or by cloning the repository into the document root first. The [installation guide](https://atutor.github.io/atutor/docs/installation) describes both routes.

## Worth knowing

The project's repository states that ATutor is no longer supported for users and asks developers who want to maintain it to request collaborator access.
