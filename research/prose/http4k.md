http4k is a Kotlin toolkit for serving and consuming HTTP services. Its core library provides a base HTTP implementation and server and client implementations based on the JDK classes, and further modules add servers, clients, serverless support, templating and other capabilities. An application is mounted into a running server, so it runs as a long-lived process. The [quickstart](https://www.http4k.org/quickstart/) declares the modules as Gradle dependencies from Maven Central artifacts.

## Worth knowing

Most of the repository is under Apache 2.0, but the `pro/` directory, files that carry the http4k Commercial License notice and the `org.http4k.pro` artifacts fall under that commercial license. The Enterprise edition is a subscription, and the Pro modules are licensed per developer seat. From 1 October 2026, releases reach Maven Central about quarterly, while maven.http4k.org keeps its normal cadence.
