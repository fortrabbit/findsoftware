ts-rest is a TypeScript library that defines an API contract shared by client and server, with type-safe client and server helpers. It is installed from npm as @ts-rest/core, and its quickstart describes that package as the core, with a basic fetch-based client. The project's FAQ compares it with tRPC. The same repository holds adapters for Express, Nest, Fastify, Next and React Query.

The homepage says the contracts can use Standard Schema validators, naming Zod, Valibot and ArkType, and that the library can generate OpenAPI documents.

## Worth knowing

The project is no longer maintained, as its README and homepage state. Both say that forks are welcome, and the repository is archived.
