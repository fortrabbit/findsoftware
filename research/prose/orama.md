Orama is a JavaScript search library for full-text, vector and hybrid search. The [OramaJS product page](https://orama.com/products/oramajs) describes it as one library that runs in the browser, on a server or at the edge, and it is installed with npm or imported as a browser module from a CDN. The [docs](https://docs.orama.com/docs/orama-js) and the repository hold the reference for its API.

OramaSearch, Inc. maintains the library. The company also runs a managed service, Orama Cloud, which its [cloud docs](https://docs.orama.com/docs/cloud) describe as Orama run at scale and managed.

## Worth knowing

The company's homepage now presents Metis, an enterprise AI platform, with the search library as one product beside it. The product page and the repository are the library's own reference.
