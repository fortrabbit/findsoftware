Inkline is a UI component library for Vue.js 3, published on npm as @inkline/inkline. Its documentation covers setup with Vite.js, Nuxt, Webpack.js, a manual install, and a CDN build, and the init command in the Vite.js and Nuxt guides generates the configuration file and updates the project. The [about page](https://www.inkline.io/docs/about) says it is officially maintained by Alex Grozav.

## Worth knowing

The homepage announces a paid edition, Inkline Pro, that is not released yet. The repository moved from the inkline organization to uxfront-com, and its default branch now holds a rewrite with the earlier codebase archived in a folder.
