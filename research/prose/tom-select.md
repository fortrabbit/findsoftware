Tom Select is a framework-agnostic JavaScript control that combines a text box with a select box. It is a fork of selectize.js, which the project's README names.

A page adds Tom Select through the npm package or a script tag from jsDelivr. The [configuration settings](https://tom-select.js.org/docs) are documented on the project site, and the source is on [GitHub](https://github.com/orchidjs/tom-select).
