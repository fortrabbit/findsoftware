Phosphor Icons is an icon family of open-source SVG icons. The core package holds the raw SVG files, grouped by weight, together with a catalog that lists each icon's name, categories, tags and the version it was published in. The framework packages for the web, React, Vue and other platforms are separate packages that the family publishes alongside it, and the core package serves as a dev dependency in the build of some of them.

## Worth knowing

Framework and build tooling may need custom type declarations before it can import the SVG files from the core package directly.
