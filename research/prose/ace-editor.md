Ace is an embeddable code editor written in JavaScript that runs in the browser. A page loads the prebuilt files, either copied into the project or served from a CDN. It is the successor of the Mozilla Skywriter (Bespin) project and is maintained as the primary editor for Cloud9 IDE. The prebuilt files are published from the [ace-builds repository](https://github.com/ajaxorg/ace-builds), which holds generated files only and takes no issues; reports go to the main repository.
