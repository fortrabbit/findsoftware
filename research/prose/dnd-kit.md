dnd kit is a drag and drop toolkit for the web, built as a framework-agnostic core with adapters for React, Vue, Svelte and Solid. The React adapter is the package the quickstart installs with npm. The repository is a monorepo that holds the core, the DOM layer, the adapters and several helper packages.

## Worth knowing

The earlier @dnd-kit/core line is still published, and the docs keep it under a legacy selector with a migration guide from it.
