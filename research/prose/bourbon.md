Bourbon is a Sass library of mixins and functions, installed from RubyGems as the bourbon gem or from npm, and used from Sass stylesheets. Using it needs a Sass compiler. Its homepage describes it as a lightweight Sass tool set. The repository is written in Ruby because it ships the gem's command-line wrapper, and the library's own files are Sass.

## Worth knowing

The project is discontinued. The homepage says it is no longer maintained, and the README records its deprecation as of September 2024 and links a thoughtbot blog post on replacing its helpers with native CSS. The repository is archived on GitHub, and no successor project is named.
