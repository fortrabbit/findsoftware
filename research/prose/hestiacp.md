HestiaCP is a web control panel for Debian and Ubuntu servers. Its README says it gives administrators a web and a command line interface for deploying and managing web domains, mail accounts, DNS zones and databases from one dashboard. The README states that it is based on the VestaCP project.

It is installed with an install script and manages MariaDB, MySQL or PostgreSQL databases. The community-run Hestia Control Panel project maintains it, and translations of the web interface are community-contributed.

## Worth knowing

The docs state that the panel must be installed on top of a fresh operating system installation to work properly.
