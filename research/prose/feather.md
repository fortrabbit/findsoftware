Feather is a collection of SVG icons, each designed on a 24x24 grid, and its npm package, feather-icons, adds a JavaScript interface to them. In the browser, a feather.replace() call swaps elements that carry a data-feather attribute for their icon. In Node, the feather.icons object returns each icon as data with a toSvg() method that returns an SVG string. The icons can also be used as plain SVG files or from a sprite file, as the [README](https://github.com/feathericons/feather#readme) describes, and a Figma component library is available.

## Worth knowing

The README's related projects section links framework wrappers such as react-feather and vue-feather-icons. They are separate projects with their own packages.
