SEED Design is the design system for Daangn products, and this repository holds its React, Lynx and CSS packages. The README says the React and Lynx packages share one token source. The [React guide](https://seed-design.io/react) describes installing the npm packages @seed-design/react and @seed-design/css, and a CLI for setting up the project.

## Worth knowing

The documentation is written in Korean only. The NOTICE file reserves the brand resources, such as the logo and the name, as assets of 주식회사 당근마켓, usable for non-commercial purposes unless the company agrees otherwise.
