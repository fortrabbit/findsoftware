Core dna is a hosted platform for content management, eCommerce, multi-site orchestration and forms. Core dna Group Pty Ltd maintains the platform. Each site has its admin area at /cdna-admin, with live preview, preset and custom roles, and several brands can run on one instance.

Developers read and write through a REST API. Sign-in uses OAuth 2 on the platform, and external authenticators for Google, Microsoft and Facebook are listed in the single sign-on documentation.

## Worth knowing

Nothing is installed by the client: the repository holds templates and front-end assets, and the platform runs as a hosted service.
