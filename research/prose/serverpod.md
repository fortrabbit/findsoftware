Serverpod is a Dart server framework for Flutter apps. The [quickstart](https://docs.serverpod.dev/quickstart) installs the serverpod_cli package with the Dart package manager, and the serverpod command creates and starts a project. The framework is published on pub.dev as serverpod, and its built-in web server is based on Relic. Its ORM queries Postgres or SQLite with Dart.

Serverpod Cloud is a managed hosting platform for Serverpod apps, and the project also documents self-hosting with Docker, Terraform or your own infrastructure.
