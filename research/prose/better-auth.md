Better Auth is a framework-agnostic authentication and authorization framework for TypeScript. Its database support covers SQLite, PostgreSQL, MySQL and MSSQL, plus a MongoDB adapter. An SSO plugin supports OpenID Connect, OAuth 2.0 and SAML 2.0, and an admin plugin covers user management, including user roles. Server code can call the endpoints as regular functions, and the docs describe them as REST API endpoints. An OpenAPI reference plugin documents the endpoints, and an internationalization plugin translates error messages. The repository is a monorepo, and the npm package sits in one of its packages.

## Worth knowing

Better Auth announced on its homepage and blog that it is joining Vercel. A managed dashboard, Better Auth Infrastructure, sits beside the open-source framework and has its own pricing; the pricing page says the framework itself is free and open source. The enterprise pages list SSO, SCIM and directory sync as features of the managed service.
