Zox is a service-oriented web framework written in TypeScript. The README installs the core with one npm command and adds features as separate npm packages: server-side React rendering through zox-react, Handlebars templates through zox-handlebars and GraphQL through zox-graphql-ws. The framework covers server rendering, single-page React apps and static site generation.
