CKEditor 4 is a WYSIWYG HTML editor loaded as a JavaScript file on a web page. The script comes from npm, a CDN or a manual download, and a call with the id of an element turns that element into a rich-text area. The README lists a plugin repository and localizations with right-to-left support.

The project states that CKEditor 4 reached end of life. The [homepage](https://ckeditor.com/ckeditor-4/) says it is considered end-of-life software, and the README names CKEditor 5 as the upgrade route. The newest releases are a long-term support line available under commercial terms, with a license key.

## Worth knowing

The open source terms end with the last open source release. The LICENSE file for the older versions names the GPL, LGPL and MPL, at the choice of the user. The newest line is available only under the Extended Support Model terms.
