MetaBake is the mbake command-line tool, a bundler and builder for sites written in Pug. Its README says it can be used to build static websites and custom elements, and it runs a watcher that rebuilds on file changes with livereload.

The tool is installed globally with npm.

## Worth knowing

The GitHub LICENSE file and the npm package declare different licenses, so the terms depend on which copy is used. The project's own website is not reachable at the address on npm.
