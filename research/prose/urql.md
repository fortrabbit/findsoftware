urql is a GraphQL client for JavaScript apps, built around an exchange pipeline that customizes its behavior. Bindings for React, Preact, Vue, Solid and Svelte sit on a shared core, and the core can be used directly in Node.js.

## Worth knowing

The project's [comparison page](https://raw.githubusercontent.com/urql-graphql/urql/main/docs/comparison.md) sets urql against Apollo Client and Relay. The core and the bindings are separate packages in one repository.
