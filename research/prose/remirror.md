remirror is a React toolkit for building text editors on ProseMirror. Its docs describe it as a wrapper library for ProseMirror that adds React and ProseMirror integration. The README also lists collaborative editing through yjs or prosemirror-collab.

## Worth knowing

The README opens by stating that remirror is in maintenance mode and is not recommended for new projects. It keeps fixing critical bugs and names [ProseKit](https://prosekit.dev) as the editor to use for new projects.
