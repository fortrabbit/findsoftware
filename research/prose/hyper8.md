Hyper8 is a static site generator for video publishing. It builds a complete static website from video files and is used through a desktop application with a built-in graphical editor, or through a command line tool. A site is stored as plain text files and folders, so there is no database, and the output is a folder of static files that can be uploaded to a web host. The graphical editor can deploy over FTP or SFTP/SSH. Simon Repp develops it on Codeberg. The [documentation](https://hyper8.org/docs/) describes the site directory format.
