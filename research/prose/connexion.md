Connexion is a Python framework that builds an API from an OpenAPI or Swagger specification. The framework validates requests and responses against the specification. It is installed with pip. The quickstart runs an application with uvicorn during development, and recommends gunicorn with uvicorn workers in production. Connexion is maintained by Robbe Sneyders and Ruwan Lambrichts.

## Worth knowing

The FlaskApp class leverages Flask, which is a separate framework, so an application built with that class also uses Flask.
