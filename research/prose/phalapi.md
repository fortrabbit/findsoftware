PhalApi is a PHP framework for building API services. A project is created with `composer create-project phalapi/phalapi`, and the web server's site root is set to the project's public directory.

The company 广州果创网络科技有限公司 states on the project's homepage that it maintains PhalApi long term. The project dates from 2015.

## Worth knowing

The documentation is in Chinese. The homepage describes the 1.x line as archived and no longer updated, and the 2.x line as the current one, which this record covers. The license is stated differently by different files: Apache 2.0 on the homepage, GPL-3.0+ in composer.json.
