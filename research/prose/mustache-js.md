mustache.js renders Mustache templates in JavaScript, in web browsers and in Node.js, and has no dependencies. Templates use tags for variables, sections, inverted sections, comments and partials, and the library renders them against a view object that holds the data. Mustache.render takes the template and the view, and Mustache.parse caches a parsed template for later renders. A command line tool ships in the same npm package and renders a JSON view into a template file.
