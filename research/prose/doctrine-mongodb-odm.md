Doctrine MongoDB ODM is an object document mapper for PHP that maps PHP objects to MongoDB documents. The [introduction](https://www.doctrine-project.org/projects/doctrine-mongodb-odm/en/stable/reference/introduction.html) says the library is installed with Composer and that its ORM integration lets ORM entities and documents relate to each other. The Doctrine Project maintains it.

## Worth knowing

The library needs the MongoDB PHP extension installed and enabled, as the same introduction states.
