Stacks is Stack Overflow's design system, a CSS and JavaScript pattern library. Its JavaScript components are provided as Stimulus controllers. The [usage guide](https://stackoverflow.design/system/develop/using-stacks) explains how to include it in other projects, by an npm install or from a CDN build.

## Worth knowing

The guide says the CDN stylesheet should not be considered production-ready and that production use should pin a version through a package manager. The repository also holds a Svelte implementation of the library as a separate package.
