Oat is an HTML and CSS UI component library with zero dependencies and a few Web Components for dynamic parts. The usage page describes three ways to add it: a CDN link from unpkg, an npm install of @knadh/oat, or a download of the CSS and JavaScript files.

The project's [extensions page](https://oat.ink/extensions/) lists third-party extensions. The author, Kailash Nadh, publishes it from a personal GitHub account, and its license names him as the copyright holder.

## Worth knowing

The unscoped npm name oat belongs to an unrelated package, so the install command uses the scoped name @knadh/oat.
