Dimples is a static site generator written in Ruby and published as the dimples gem on RubyGems. Its README calls it an absurdly simple, incredibly inflexible static site generator, and its LICENSE names Daniel Bogan as the copyright holder. The README links no installation or usage documentation, and the RubyDoc page for the gem holds only API reference, so the steps to build a site are not recorded.

## Worth knowing

The gem has versions published after the last commit on the repository's default branch, so the repository may not show the source of the released gem.
