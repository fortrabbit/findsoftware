shadcn-svelte is a Svelte port of shadcn/ui. A CLI adds components and their dependencies to the project, so the component code sits in the project's own source tree. The [CLI documentation](https://shadcn-svelte.com/docs/cli) describes the add command for this.

## Worth knowing

The components are copied into the project rather than imported from a package, so the project holds the code it runs. The homepage credits shadcn for the original and says the Svelte version was ported by its maintainers.
