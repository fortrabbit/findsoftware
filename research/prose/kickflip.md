Kickflip is a static site generator built on Laravel Zero, which provides its command-line interface and lets it use Laravel's Blade as the primary renderer. The [getting started guide](https://kickflip.lucidinternets.com/docs/getting-started) describes it as a Laravel-based framework for static content websites. Content lives in a source directory, and a build generates static HTML from it. Node.js and npm are also needed, because the starter project compiles assets with Laravel Mix and uses ShikiJS for syntax highlighting.

## Worth knowing

The repository is archived and read only. The Packagist record flags the package as abandoned.
