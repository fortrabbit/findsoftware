LavaLust is a PHP framework built on the MVC pattern. It is installed by cloning its GitHub repository or downloading the default branch as an archive, and the web server is pointed at the project root. The [documentation](https://lavalust.netlify.app/) is the project's full reference.

## Worth knowing

The project is distributed from GitHub, and no Packagist package exists for it, so Composer cannot install it by name.
