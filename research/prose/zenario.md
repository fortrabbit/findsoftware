Zenario is a content management system with an administration mode inside the application, a permissions system for what administrators can do, and multilingual features built into the core. The self-hosted release is downloaded as an archive and set up with a web installer, or installed through the Softaculous auto installer, on an Apache server with PHP and MySQL.

## Worth knowing

Tribal Limited also runs OnZenario, a hosted service, next to the self-hosted download.
