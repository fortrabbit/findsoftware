Djot is a light markup syntax. It derives most of its features from CommonMark and adds definition lists, footnotes, tables, math, attributes that can be applied to any element, and more. The homepage lists implementations in JavaScript, Lua, Prolog, Rust, Go and PHP, and shows converting GitHub-flavored Markdown to djot with the official JavaScript implementation and pandoc.

## Worth knowing

The homepage says the syntax is not completely stable and that minor changes are expected, while the official JavaScript implementation is complete and ready for use.
