GraphQL.NET is an implementation of GraphQL for .NET. Its README describes it as an implementation of GraphQL, a query language and execution engine, in .NET. The core package, GraphQL, is installed from NuGet.

The license names Joseph T. McBride, Ivan Maximov and Shane Krueger, and the project is maintained by them and other contributors. The repository also holds separate NuGet packages for serialization, document caching, DataLoader and dependency injection.
