MediumEditor is a vanilla JavaScript library that adds an inline formatting toolbar, styled after the one on medium.com, to editable elements of a web page. The project calls itself a clone of that toolbar and says no additional frameworks are required. It can be installed from npm or Bower, loaded from a CDN, or downloaded and attached as files. Wrappers for specific frameworks are written by other people and listed on the project's wiki, so framework support comes from those projects.

## Worth knowing

The README opens with a request for people to help maintain the project.
