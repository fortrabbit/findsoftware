Outstatic is a content management system for Markdown and MDX files stored in a GitHub repository. Editors write in a visual dashboard, and each saved change is committed to the repository as a file, so the site deploys with its content. The self-hosted form installs as an npm package in a Next.js app, and the dashboard is served from a route in that app. There is no database to set up.

## Worth knowing

The license is the Functional Source License, which converts to Apache 2.0 on the second anniversary of each version's release. The [pricing page](https://outstatic.com/pricing) describes a hosted dashboard at outstatic.com. Hosted projects need a Pro subscription to save and publish content, and Pro adds social login, roles and AI-assisted writing.
