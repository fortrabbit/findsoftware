Fulcro is a library for building single-page full-stack web applications in Clojure and ClojureScript, built on React. The [developer's guide](https://book.fulcrologic.com/) builds the browser code with shadow-cljs and sets up a server with Ring and http-kit. A JDK is among its prerequisites. Add the Maven coordinate to a Clojure project, or start from the fulcro-template project the README names.

## Worth knowing

A Fulcro application has a browser part compiled to JavaScript and a Clojure server part. The project offers consulting for companies that use Fulcro; the site does not present it as a paid edition of the library.
