Rolldown bundles JavaScript and TypeScript modules into bundles for applications and libraries. It is written in Rust and offers a Rollup-compatible API and plugin interface. It is installed with npm as a development dependency, and a build step runs it from a config file or a package.json script.

The [getting started guide](https://rolldown.rs/guide/getting-started) recommends using Rolldown through Vite for most applications. The README describes the project as intended to serve as the bundler used in Vite, and names VoidZero as the company behind it.
