Docpress is a Node.js command-line tool that generates a documentation website from Markdown files, starting at a project's README and optionally adding pages from a docs folder. It is installed with npm. A serve command runs a local server with live reload, and a build command writes the site to a folder. A guide in the project's docs describes updating a GitHub Pages branch automatically.

## Worth knowing

The README says the project is still under heavy development and a preview.
