Faker is a JavaScript library that generates fake but realistic data for testing and development. It runs in the browser or in Node.js, and it is installed as a development dependency with a package manager. The [guide](https://fakerjs.dev/guide/) covers installation and usage.

The LICENSE file says the project is based on faker.js, the original package by Marak Squires and contributors. The [team update](https://fakerjs.dev/about/announcements/2022-01-14.html) says the original package was deleted from npm, and it names the maintainers.

## Worth knowing

The unscoped npm package named faker is a separate project, so the install uses the scoped name @faker-js/faker.
