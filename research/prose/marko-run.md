Marko Run is an application framework for Marko. Its [README](https://github.com/marko-js/run/blob/main/packages/run/README.md) describes server-side rendering and says an application can be built to run in Node, Deno, Netlify, Cloudflare or as a static site. It installs from npm as @marko/run.

## Worth knowing

The README marks the project as in BETA.
