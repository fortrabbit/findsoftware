Plyr is a JavaScript media player that adds its own controls to HTML5 video and audio, and to YouTube and Vimeo embeds. A page keeps the standard media element markup, and a script creates a player on a selector. Controls are configured through markup and options, with translatable control labels, and the README lists streaming playback through hls.js, Shaka and dash.js.

## Worth knowing

Plyr is discontinued. Its README and homepage say it is deprecated and receives security updates only, and they name Video.js 10 for new projects, with a migration guide from Plyr.
