Vapor is a web framework for Swift, used to write backends, web apps, APIs and HTTP servers in Swift. It is built on Apple's SwiftNIO. Projects are created with the Vapor Toolbox or from a template repository, and the application runs as a server process. The Leaf templating language generates HTML pages and emails. The docs cover PostgreSQL, MySQL, SQLite and MongoDB drivers.

## Worth knowing

The Toolbox template requires a newer Swift than the install page states for Vapor itself. The docs also present the next major line as an alpha pre-release, not a stable release.
