Remix Icon is an icon set of neutral-style system symbols that can be imported with npm, loaded from a CDN or downloaded and added to a project. The Remix Icon License allows use of the icons in products, and it bars selling them as a standalone product or using them to build a competing icon library.

## Worth knowing

The npm package declares Apache-2.0, while the README names the Remix Icon License v1.0, so the two license statements disagree.
