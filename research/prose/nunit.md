NUnit is a unit-testing framework for .NET languages. The framework is distributed as a NuGet package, and the project's installation page also shows the dotnet new template and the Visual Studio project dialog as ways to start a test project.

The project calls itself the NUnit Project, a member of the .NET Foundation, and is run by a core team.

## Worth knowing

NUnit 2 is a different product with its own documentation, and the repository's oldest tags belong to it. Earlier releases used the NUnit license rather than MIT.
