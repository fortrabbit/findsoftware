Vuestic UI is an open-source Vue component library of ready-to-use frontend components, maintained by Epicmax. It is installed with npm as `vuestic-ui`, following the [installation guide](https://ui.vuestic.dev/getting-started/installation), or created with `create-vuestic`, a scaffolder that sets up a Vuestic Admin, create-vue or Nuxt project with the library in place. The project site describes it as an MIT-licensed UI framework with i18n integration for localizing apps.
