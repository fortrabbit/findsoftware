Simple.css is a CSS framework that styles plain semantic HTML. It is mostly classless, so plain HTML can be integrated with it directly. The stylesheet is added to a page either by linking the CDN-hosted file in the head of the HTML or by installing the simpledotcss package from npm, and the [getting started guide](https://github.com/kevquirk/simple.css/wiki/Getting-Started-With-Simple.css) walks through both routes. Kev Quirk is named as the author in the license, which is MIT.
