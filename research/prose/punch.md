Punch is a web publishing framework that runs on Node.js. It builds pages from Mustache templates with inheritable layouts and partials, and it reads page contents from JSON and Markdown. The `punch generate` command renders every page and copies the assets into an `output` directory, which is the static site that gets served.

Punch publishes that directory to Amazon S3 or to a custom server over SFTP. A development server previews changes while the site is edited.
