ttag is a JavaScript localization library that marks strings with ES6 tagged templates and reads translations in the style of GNU gettext. A project installs it from npm and wraps its strings in tagged templates, and the README names the separate ttag-cli package for po file handling. The README says the library is designed to work with babel-plugin-ttag. The [quickstart](https://ttag.js.org/docs/quickstart.html) runs a script under Node.js.
