DevExtreme is a suite of JavaScript UI components for Angular, React, Vue and jQuery, published by Developer Express Inc. The React installation guide installs the devextreme core package from npm together with devextreme-react, the React wrapper. The repository is public on GitHub, and its license file refers readers to the licensing page instead of naming a license.

## Worth knowing

Commercial applications need a 12-month subscription, because the licensing page says a license is required per developer for commercial software. A 30-day trial is offered. The buy page offers several subscription tiers that bundle DevExtreme with other DevExpress products, and the [pricing page](https://js.devexpress.com/Buy/) lists them.
