pgweb is a web-based explorer for PostgreSQL databases, written in Go and distributed as a precompiled binary. The [README](https://github.com/sosedoff/pgweb/blob/main/README.md) shows it started with the `pgweb` command, and a browser then works with the database. The [project page](https://sosedoff.github.io/pgweb/) calls it a cross-platform client, and the [installation page of the wiki](https://github.com/sosedoff/pgweb/wiki/Installation) names a Docker image and a Homebrew formula alongside the binaries on GitHub Releases.

## Worth knowing

The README and the project page give different minimum PostgreSQL versions.
