Teutonic CSS is a CSS framework for responsive websites and web applications, built on CSS variables and CSS Grid. Its source is a set of SCSS modules; the minified stylesheet can be included from a CDN and customized through the variables, without any JavaScript.

## Worth knowing

The README marks the framework as retired: it is no longer continued as of May 2023, and the GitHub repository is archived. It targets modern browsers only, with no Internet Explorer support.
