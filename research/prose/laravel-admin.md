laravel-admin is an administrative interface builder for Laravel that helps build CRUD backends from a few lines of code. It is added to a Laravel application with Composer as the encore/laravel-admin package, and its [documentation](https://laravel-admin.org/docs/en/) describes the setup.

## Worth knowing

The documentation says the author does not have much time to maintain the project, and that support covers only the long-term-support version of Laravel.
