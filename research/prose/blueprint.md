Blueprint is a toolkit of React components and CSS for building web interfaces. Each package ships a stylesheet and ES modules that export React components, and the core package is installed with npm or pnpm alongside React and React DOM. Palantir Technologies develops it as an open source project, in a monorepo that also publishes icons, tables, select and date components.

## Worth knowing

The project's own README says it is optimized for complex, data-dense interfaces in desktop applications that run in modern browsers, and that it is not a mobile-first toolkit. The icon set is a separate package that a project imports alongside the core stylesheet.
