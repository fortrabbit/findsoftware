openid-client is an OAuth 2 and OpenID Connect client library for JavaScript, written in TypeScript. An application uses it to talk to an authorization server through the authorization code flow and the other grants its README lists. It runs on Node.js and Deno, and the README also names browsers and Cloudflare Workers among the runtimes it is designed for.

## Worth knowing

The library is a client API for authorization servers, not a server. By default it only allows HTTPS endpoints.
