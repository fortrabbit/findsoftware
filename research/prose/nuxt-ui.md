Nuxt UI is a library of accessible, typed Vue components built on Reka UI, Tailwind CSS and Tailwind Variants. It works as a module in Nuxt and as a Vite plugin in plain Vue apps. The install command adds the package from npm as @nuxt/ui next to Tailwind CSS.

The homepage says color mode, i18n and typography are already wired in. The repository belongs to the nuxt organization, and the copyright line in its license names Nuxt.
