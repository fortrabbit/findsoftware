Nette is a family of standalone components for PHP 8. Its application package, nette/application, is a component-based MVC layer, and views are written in Latte, the templating system the project's documentation describes. A new project starts from the nette/web-project skeleton, as the [installation guide](https://doc.nette.org/en/installation) describes.

## Worth knowing

The license page states that "Nette Framework" is a registered trademark and asks users not to put "Nette" in a project name or top-level domain name.
