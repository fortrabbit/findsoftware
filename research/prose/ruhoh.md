Ruhoh is a Ruby tool for building a static blog, distributed as the ruhoh gem and added to a project through a Gemfile entry with bundler. The repository README describes it as a universal static blog API.

## Worth knowing

The homepage no longer serves the project, and the README's quick start points to that homepage, so the repository README and gemspec are the only sources left. The README names only Ruby 1.9 and 2.0 as supported.
