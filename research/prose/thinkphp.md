ThinkPHP is a PHP web framework. The trademark and copyright belong to 上海顶想信息科技有限公司, as the [README](https://github.com/top-think/framework/blob/8.x/README.md) and the project homepage state. A new application is created with Composer from the topthink/think skeleton, which requires the topthink/framework package.

## Worth knowing

The README is written in Chinese. GitHub reports no license for the repository, while the README and composer.json state Apache-2.0.
