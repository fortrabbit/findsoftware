PGlite is a WebAssembly build of PostgreSQL, packaged as a TypeScript and JavaScript library. An application imports it from npm, or from a CDN in the browser, and runs a Postgres database inside the browser, Node.js, Bun or Deno. The data can live in memory, in the file system under Node and Bun, or in IndexedDB in the browser. The about page also offers it as an alternative to a full local Postgres for development.

## Worth knowing

Electric DB Inc., which develops PGlite, also runs a hosted cloud for its sync services. That cloud is a separate product from PGlite.
