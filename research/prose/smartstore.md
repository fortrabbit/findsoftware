Smartstore is an eCommerce platform built on ASP.NET Core. It supports several stores and several languages, has a backend for managing the shop, and manages permissions through an access control list with inheritance. Razor views render the application, and Liquid templates handle emails and campaigns. A RESTful Web API exposes store data, and the data is kept in SQL Server, MySQL, PostgreSQL or SQLite. The [developer guide](https://docs.smartstore.com/developer) documents building it from source or as a Docker image.

SmartStore AG, a German company, maintains the project. Smartstore 5 and later is a port of Smartstore.NET 4, and an installation of Smartstore.NET 4.2 can be upgraded to it.

## Worth knowing

The Community Edition is released under the AGPL. The Premium Edition and the Enterprise B2C and B2B editions sit beside it and are sold on request, and the editions page also offers a rental solution alongside the Premium Edition.
