Pothos is a GraphQL schema builder for TypeScript. The schema is defined in code, and the builder is extended through plugins, which are listed in the [plugin catalog](https://pothos-graphql.dev/docs/plugins). The core package lives in a monorepo with those plugins, and the [getting started guide](https://pothos-graphql.dev/docs) builds a schema with Node.js and serves it with GraphQL Yoga.

## Worth knowing

The project was published as GiraphQL before the rename to Pothos, and the [migration guide](https://pothos-graphql.dev/docs/migrations/giraphql-pothos) covers the change for code that still uses the old names.
