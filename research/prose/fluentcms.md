FluentCMS is a content management system built with ASP.NET Core and Blazor, with an admin dashboard for managing content. It serves content through a REST API and can be run as a headless CMS. The project supports LiteDB and MongoDB as databases, and its README names roles, multiple sites and multi-language content among its features. Momentaj created the project.

## Worth knowing

The default branch is v2, a rewrite that its README marks as pre-alpha and says runs nothing yet. This record describes the dev branch, the line that the project says receives security fixes only. The project also states that there is no migration path from that line to v2.
