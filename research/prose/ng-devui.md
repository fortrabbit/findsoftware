DevUI, published as ng-devui on npm, is an Angular UI component library based on the DevUI Design system. A project installs it with npm and adds the package's stylesheet to its angular.json file. The copyright line in the license names DevUI as the holder, and the project is published from the DevCloudFE organization on GitHub under the MIT License.

## Worth knowing

The README, the npm manifest and the homepage state different Angular versions as supported.
