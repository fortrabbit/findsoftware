SvelteUI is a Svelte component library, described in its README as components, actions, utilities and animations. The repository is a monorepo of packages, and the core package holds the components. The installation guide in the docs source installs @svelteuidev/core together with @svelteuidev/composables, with npm or yarn, and the README states that the library is SvelteKit and SSR compatible.

## Worth knowing

The README calls its roadmap a work in progress toward a first stable release. The README names an npm package under a different scope from the one the install guide uses, so the install guide is the reference for what to install.
