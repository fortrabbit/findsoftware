new.css is a classless CSS framework that styles plain HTML elements directly, so a page written with only HTML uses it without class names. It installs from npm or loads from a CDN, and the [usage guide](https://newcss.net/usage/) shows the stylesheet link. Brendan Hersh maintains the project in the xz organization on GitHub, and the usage guide links the project's Discord server for questions.

## Worth knowing

The npm package is published as @exampledev/new.css, not as new.css, so the install command must use the scoped name. The project also runs a second address, new.css.site, that serves the same pages.
