Picnic CSS is a stylesheet that styles native HTML elements directly, so they need no presentation classes. The project's own term for this approach is invasive. The stylesheet is available from a CDN, from npm and from Bower, and the SCSS source lets a site set its own variables before import. The README names Milligram, PureCSS, Bootstrap and Min as alternatives.

## Worth knowing

The README says the approach is difficult to drop into a project that already exists. Its stated support covers IE11 and newer.
