ContentChef is a hosted headless CMS. Authors manage content in a web app, and developers define content structures with a schema language and retrieve content through APIs that the project documents as Swagger. Byte-Code S.p.A operates the service, and the company's office address is in Italy.

The service is offered in four plans, and the plans set users, spaces, media storage, API calls and bandwidth.

## Worth knowing

The API reference is a Swagger UI, and the record does not name the API style beyond that. Webhooks are listed as a Team plan feature. Preview before release and scheduled visibility dates are described on the features page.
