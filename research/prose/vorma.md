Vorma is a Go framework that uses Vite for the frontend, where an app can be written with React, Solid or Preact. A new project starts with `npm create vorma@latest`, which needs Go and Node on the developer's machine. The backend is a Go program that serves the application and server-renders the HTML entry page on a visitor's first request. A production build compiles that program into one binary, which usually embeds the static assets.

## Worth knowing

The README says the APIs are still evolving and that releases before the first stable major may contain breaking changes.
