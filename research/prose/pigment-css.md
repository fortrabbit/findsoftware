Pigment CSS is a zero-runtime CSS-in-JS library from MUI. It lets styles sit beside components and moves them into CSS files at build time. It is installed from npm as @pigment-css/react, and a plugin for Next.js or Vite runs the extraction during the build. The README presents the library as a successor to Emotion and styled-components, and says components made with its styled API can be used with React Server Components by default.

## Worth knowing

The maintainers paused work on Pigment CSS and say so in a status post on the repository and in a blog post, where the project is listed as on hold. The repository description calls it an alpha phase project on hold. None of the pages says the project has ended.
