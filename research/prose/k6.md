Grafana k6 is a load-testing tool that runs scripts written in JavaScript or TypeScript on an engine written in Go. Scripts set thresholds and ramp virtual users through stages, and the README says they can run on the command line, in CI, or across a Kubernetes cluster. The tool sends HTTP, WebSocket, gRPC and browser traffic, and extensions add new protocols and use cases.

Grafana Labs also offers Grafana Cloud k6, a hosted service that runs tests and analyzes their results, with free and paid plans. The k6 Studio desktop app, which generates scripts from a browser recording, is a separate product.
