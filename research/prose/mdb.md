MDB UI Kit is a Material Design component kit for Bootstrap 5 and plain JavaScript that extends Bootstrap. It installs from npm, from a CDN or as a zip package. The documentation also tells a reader to choose components and copy them into the project. The MDB CLI, with the MDBGO service behind it, is a separate install route that includes free hosting. The [installation guide](https://mdbootstrap.com/docs/standard/getting-started/installation/) lists the routes.

## Worth knowing

A paid MDB PRO subscription sits beside the free kit, and the installation guide refers to it.
