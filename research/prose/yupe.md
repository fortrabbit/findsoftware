Yupe is an open source engine for online shops, blogs and business sites, built on the Yii 1.x framework. It is split into modules, and the README says to use only the ones a project needs. The admin interface is built on Twitter Bootstrap.

The [installation guide](https://brain.yupe.ru/books/yupe-web/page/ustanovka-i-zapusk-yupi) describes installing through Composer, through Git or from an archive.

## Worth knowing

The README and the [documentation](https://docs.yupe.ru) are in Russian.
