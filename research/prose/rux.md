rux is a Go web framework and router for HTTP applications, installed with go get under its module path. Its server package runs a production server with graceful shutdown and health endpoints, and the render package leaves the choice of template engine to the application.

## Worth knowing

The current major line is a clean-room rewrite, and the README links a [migration guide](https://github.com/gookit/rux/blob/master/docs/MIGRATION-v1-to-v2.md) for its breaking changes from the earlier line.
