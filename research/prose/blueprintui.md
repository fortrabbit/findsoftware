Blueprint UI is a collection of UI components, themes and layout utilities for building user interfaces. Its components are built as Web Components, which the [getting-started page](https://blueprintui.dev/getting-started.html) says lets them work in a variety of frameworks and libraries. The components install from npm as `@blueprintui/components`, and the same page describes loading them from a CDN. Crylan Software LLC publishes the project from a monorepo.
