Syncfusion Essential JS 2 is a suite of JavaScript UI components written in TypeScript. The install guide names one umbrella npm package that holds every control, and it also describes one npm package per control. The source is public in the GitHub repository, under the vendor's license.

## Worth knowing

The license is proprietary. A paid license is required for possession or use, and a free Community License covers only organizations under a revenue limit and a developer limit. The public source does not make the suite open source.
