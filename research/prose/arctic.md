Arctic is a collection of OAuth 2.0 clients for popular providers, installed from npm. It is built on the Fetch API and describes itself as runtime-agnostic.

## Worth knowing

The project is discontinued. Its author deprecated the npm package in July 2026 and states that the project has not been worked on for nearly a year. The homepage and the README point to example code in the repository to replace the package, and no replacement package is named.
