TOAST UI Editor is a JavaScript component that lets a page edit Markdown documents in a Markdown mode or a WYSIWYG mode. Its chart and syntax-highlight plugins render with TOAST UI Chart and Prism.js. It is installed from npm, or loaded from the NHN Cloud CDN.

## Worth knowing

The README states that the project is no longer maintained and that its repository is archived, and that no new features or bug fixes will be released. A release published after that notice is on npm and on GitHub, but the notice is the project's own statement about its status.
