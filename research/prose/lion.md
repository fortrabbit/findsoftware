Lion is a white-label, open-source, framework-agnostic component library for building a design system, with its components written on Lit. It is published on npm as @lion/ui and installed with npm. ING Bank NV publishes it, and the project opened its code in 2020.

The repository is a monorepo. @lion/ui is the package the get-started guide installs, and the other packages in the same repository are published separately.

## Worth knowing

The library is below 1.0.0. Its versioning page says that for versions below 1.0.0, minor upgrades may contain breaking changes.
