Micronaut is a JVM framework for applications written in Java, Kotlin or Groovy. The core team maintains it under a project lead, and the Micronaut Foundation supports that work. New projects are created with the `mn create-app` command of the Micronaut CLI or with the Micronaut Launch generator, and applications can include locale-specific resource bundles for translated messages.
