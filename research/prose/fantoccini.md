Fantoccini is a Rust crate that drives a web browser through the WebDriver protocol. Code uses it to open pages, find elements by CSS selector or link text, click them, fill in and submit forms, read the page source, and send raw HTTP requests that carry the browser's cookies.

The examples assume a WebDriver-compatible process, such as geckodriver, is already running on port 4444. The crate is published on crates.io, and its source is a GitHub repository with Jon Gjengset as the copyright holder.
