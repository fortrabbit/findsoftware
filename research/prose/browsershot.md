Browsershot converts a web page to an image or PDF from PHP code. The README says the conversion runs through Puppeteer, which drives a headless version of Google Chrome, so a PHP app depends on Node and Puppeteer for the browser work. It is installed with Composer, and the [installation page](https://spatie.be/docs/browsershot/v4/installation-setup) of its documentation covers the setup.

## Worth knowing

The rendering needs Node and the Puppeteer package on the machine that runs the PHP code. The [requirements page](https://spatie.be/docs/browsershot/v4/requirements) names the minimum versions.
