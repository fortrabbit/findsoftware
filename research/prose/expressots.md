ExpressoTS is a TypeScript framework for server-side Node.js applications, built around a dependency injection container that wires controllers, use cases and providers through modules. Its HTTP server is Express.js by default, through an Express adapter. A project is created with the CLI, for example `npx @expressots/cli new`, and the [deployment guide](https://doc.expresso-ts.com/docs/guides/deployment) describes packaging an app as a container. ExpressoTS Studio, a local development tool, runs alongside the app during development.

## Worth knowing

GroundZero is named on the project's site as an official deploy partner. It is a hosted platform run by another company, not part of the project, and the record does not cover it.
