Nightwatch.js runs tests on Node.js and controls browsers through the W3C WebDriver API. Its README lists end-to-end, component and API tests among its uses, and the [comparison page](https://nightwatchjs.org/guide/comparison-with-leading-frameworks.html) sets it beside Cypress and Playwright. The [quick start](https://nightwatchjs.org/guide/quickstarts/create-and-run-a-nightwatch-test.html) says tests can run on the developer's machine or on a cloud machine. A migration guide from Protractor adds Nightwatch to Angular projects through an Angular schematic.

## Worth knowing

The cloud grids the docs name, BrowserStack and Sauce Labs, are third-party services that the tests connect to. BrowserStack is also the company that maintains the project.
