Grafana is an open source application for querying, visualizing, alerting on and exploring metrics, logs and traces. It runs as a server and keeps its users, data sources and dashboards in a database. The [installation guide](https://grafana.com/docs/grafana/latest/setup-grafana/installation/) lists Docker, Debian packages, a binary archive and a Helm chart. A dashboard panel can be shared as an iframe that another website embeds. Sign-in works through OAuth2 providers and LDAP. The UI language is set by a configuration option.

## Worth knowing

Grafana Enterprise adds commercial features such as enterprise data source plugins, reporting and enhanced access control. Grafana Cloud is a fully managed platform hosted by Grafana Labs, and panel embedding and anonymous access are not available there.
