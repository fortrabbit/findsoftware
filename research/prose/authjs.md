Auth.js is an authentication library for JavaScript web frameworks, published on npm as next-auth. The installation page starts with Next.js and also covers Qwik, SvelteKit and Express. The README names built-in database adapters for MySQL, MariaDB, PostgreSQL, Microsoft SQL Server, MongoDB and SQLite.

## Worth knowing

The project says it is now part of Better Auth. Its README recommends that new projects start with Better Auth unless a specific feature gap applies, such as stateless session management without a database. Existing Auth.js users can keep using it, and security patches continue. The stable next-auth v4 line is in maintenance mode, and the installation page installs the v5 beta.
