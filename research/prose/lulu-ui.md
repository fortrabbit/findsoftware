LuLu UI is a front-end component library of CSS and JavaScript files, published by Yuewen Group. A page can load its files from a CDN, and a project can install the lu2 package from npm. The project has five themes, and the one it names as actively maintained is Edge.

The project has no version numbers. Its npm releases are named by publish date.

## Worth knowing

The README says the Modern and Peak themes have stopped being maintained. Its documentation is in Chinese.
