Oracle Content Management is a cloud-based content hub from Oracle Corporation for managing content and delivering it across channels. Its documentation has a Headless CMS section that describes using the service as a headless content management system, and an API section that lists REST APIs, among them the REST API for Content Delivery.

## Worth knowing

The service has a Starter tier with a limited feature set, and a Premium Edition that the Starter page describes as the way to get the full feature set and a larger number of users and other items.
