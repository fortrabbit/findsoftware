Querydsl is a Java framework that builds type-safe, SQL-like queries through a fluent API, where the README contrasts this with writing queries as inline strings or XML files. It targets several backends, including JPA, MongoDB and SQL, and the README's tutorials also cover Lucene, collections and JDO. Releases come from public Maven repositories.

## Worth knowing

The project's own site answers only over plain HTTP, so this record links no homepage. The CHANGELOG says the 5.0.0 release targets Java 8 minimally.
