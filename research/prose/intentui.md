Intent UI is a collection of accessible React components whose source sits in the project once added. The [installation guide](https://intentui.com/docs/getting-started/installation) describes adding files with the shadcn CLI and a manual route that copies the source by hand. The components are built with React Aria Components and Tailwind CSS, and the source is MIT-licensed under Irsyad A. Panjaitan.

## Worth knowing

A separate Design product sells templates, blocks and starter kits under a one-time paid license at design.intentui.com.
