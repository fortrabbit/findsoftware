Apache Sling is a Java framework for RESTful web applications that maps HTTP request URLs to resources in an extensible content tree. This record covers the Sling Starter, the repository that produces feature artifacts for the Feature Launcher. The getting-started page starts Sling from a Docker image, a feature archive or a Karaf distribution, and once started it serves requests. The starter runs Sling on an Oak SegmentStore or on an Oak MongoDB DocumentStore, and the MongoDB option needs a MongoDB server.

## Worth knowing

The starter is not meant to be a production-ready setup and is aimed at experimenting with and learning Sling. The getting-started page was last changed in 2022, and the scripting page lists HTL and JSP among the template languages.
