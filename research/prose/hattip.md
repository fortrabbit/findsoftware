Hattip is a set of JavaScript packages for building HTTP server applications, written in TypeScript. A handler receives a context object with a standard Request and returns a standard Response, following the Fetch API, and adapters let the same handler run on several platforms, among them Node.js, Bun and Cloudflare Workers. An adapter also lets a Hattip handler run inside an Express application, according to the [README](https://github.com/hattipjs/hattip/blob/main/readme.md).
