Grape is a Ruby framework for building REST-like APIs. Grape APIs are Rack applications, and the README names mounting them in a Rails or Sinatra application as ways to serve them. It is installed with `bundle add grape`. The project's documentation is on [rubydoc.info](https://www.rubydoc.info/gems/grape), and questions go to a Google group named on the project's website.

## Worth knowing

The default branch of the repository describes a 4.1.0 release as the stable documentation, while 4.0.1 is the release the README names as current. The record follows the RubyGems stable version, which is 4.0.1.
