Knock is a hosted notification service. A managed API and dashboard send in-app and out-of-app product notifications, and the API reference describes the API as REST-ful, with SDKs.

## Worth knowing

The [pricing page](https://knock.app/pricing) places custom roles, translation support, SAML 2.0 SSO and audit logs on the Enterprise plan, while Google SSO appears on every plan. Pricing counts each message delivered to one user on one channel, with monthly amounts included in each plan, and a Free plan needs no credit card.
