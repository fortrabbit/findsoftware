DropInBlog is a hosted blog platform that adds a blog to a website that already exists. A site adds the blog with an HTML embed snippet or with an app for a site builder or store platform. Custom sites can instead fetch the blog through an API and SDK packages for Next.js, Astro, React and Laravel. Authors write in the admin panel, and an account can use predefined roles or custom permission sets.

Function Company LLC owns and operates the service, and the company says it launched the platform in 2015.

## Worth knowing

No free plan is offered; the trial lasts seven days. The API returns either rendered HTML or structured JSON, and its reference does not name a REST or GraphQL style.
