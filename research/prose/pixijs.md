PixiJS is a 2D rendering library for the web. Its renderers use WebGL or WebGPU, and the content it draws runs in any modern browser on desktop and mobile devices. It is added to a project from npm, or as a browser build from a CDN. The quick start scaffolds a new application with `npm create pixi.js`, which needs Node.js.

## Worth knowing

PixiJS runs in browsers by default. Running it in a Web Worker, Node.js or another non-browser environment means setting a custom adapter first.

The homepage describes PixiJS 3D as an extension, not a fork. This record covers the 2D library only.
