NelmioApiDocBundle is a Symfony bundle that produces OpenAPI documentation for an application's REST API. It reads PHP attributes, including Swagger-Php attributes, along with Symfony route requirements, and it describes models through the Symfony serializer, the JMS serializer or form types. The [documentation on symfony.com](https://symfony.com/bundles/NelmioApiDocBundle) also describes a sandbox for trying the API interactively.

The README states that the bundle also runs under FrankenPHP worker mode and other long-running workers.
