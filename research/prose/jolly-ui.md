Jolly UI is a copy-and-paste collection of React Aria Components styled with Tailwind CSS. The project says it is not a component library and describes itself as an add-on to shadcn/ui: its components take the shadcn/ui designs and rebuild them on React Aria Components, so they can sit beside existing shadcn/ui components. The [installation guide](https://www.jollyui.dev/docs/installation) offers copy-and-paste or the shadcn CLI. The code is MIT-licensed, and James Shopland is the copyright holder.

## Worth knowing

The repository has no tagged release and no registry package, so a reader copies from the default branch.
