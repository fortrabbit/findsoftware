Hyperf is a PHP CLI framework whose applications run as persistent processes on the Swoole or Swow coroutine engine. The [installation guide](https://github.com/hyperf/hyperf/blob/master/docs/en/quick-start/install.md) starts new projects from the hyperf/hyperf-skeleton package with Composer. The README says MySQL, Redis and other common clients are provided as coroutine clients.

## Worth knowing

Because the process stays running, the installation guide says to stop it and start it again after code changes.
