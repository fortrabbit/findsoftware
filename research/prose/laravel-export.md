Laravel Export is a Laravel package by Spatie that turns a Laravel application into a static site bundle. It is added with Composer, and the export runs inside the Laravel application, so building the bundle needs a PHP runtime even though the output is static files. The [README](https://github.com/spatie/laravel-export/blob/main/README.md) says the bundle can be uploaded to any host, with no full server to manage. Spatie bvba maintains the package.
