Adobe Experience Manager as a Cloud Service is Adobe's hosted edition of Experience Manager. Its documentation describes a cloud-native service with Adobe-managed content delivery through a built-in CDN, autoscaling, and Cloud Manager for CI/CD. Authors work in a web-based interface with a Page editor, a Universal Editor and a Content Fragment editor. Structured content in Content Fragments can be consumed by any app over HTTP using GraphQL, so the product can serve as a headless CMS.
