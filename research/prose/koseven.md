Koseven is a PHP framework forked from Kohana, compatible with PHP 7, and its homepage describes it as the successor of the Kohana framework. The source is on GitHub, and the project is installed by cloning the repository or downloading its archive. The Koseven Team is named as the maintainer in the license agreement. Third-party modules are listed on the project's [modules page](https://koseven.dev/modules).

## Worth knowing

The [README](https://github.com/koseven/koseven/blob/master/README.md) says the project is archived, with no active development, no guaranteed compatibility with PHP 8 and later, and no guaranteed security fixes. The GitHub repository is archived and the Packagist package is marked abandoned. The homepage still describes the framework as maintained by its contributors; the record follows the README, the archive flag and the Packagist flag.
