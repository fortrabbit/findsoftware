Enterprise Commerce is a Next.js storefront template from Blazity that uses Shopify for product data and Algolia as a middle layer for fetching and search. The template is installed by cloning the repository and running yarn in starters/shopify-algolia, and the README names one-click deployment to Vercel.

## Worth knowing

The template needs a Shopify store with a Storefront API token and an admin app, and an Algolia account. The repository has no release tags.
