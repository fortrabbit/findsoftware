NSwag is a Swagger and OpenAPI toolchain for .NET, ASP.NET Core and TypeScript. It generates OpenAPI documents and client code, and the same toolchain is available from C# code as NuGet packages, from npm and as a dotnet tool.

The repository is a monorepo: its stars and contributors count the whole toolchain, and the NuGet figure is taken from the NSwag.Core package. A separate product, Apimundo, is built on NSwag and has its own site.
