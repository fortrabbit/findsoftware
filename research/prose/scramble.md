Scramble is a Laravel package that generates OpenAPI documentation for an application's API from its code. A documentation UI served by the application displays the generated document, and an export command writes it to a file.

## Worth knowing

Scramble PRO is a paid edition, sold per license, that adds documentation for Spatie's Laravel Data and Laravel Query Builder packages. By default the documentation routes are served only in the local environment, and a gate can change that.
