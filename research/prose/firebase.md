Firebase is Google's hosted platform for web and mobile apps. Its services cover user sign-in, databases, file storage, hosting, cloud functions and messaging, and apps reach them through SDKs. The administration of a project runs in the Firebase console.

Firebase Authentication supports SAML and OpenID Connect, and the pricing page prices that support per monthly active user. The Firebase Authentication service is run only from US data centers, according to the privacy page.

## Worth knowing

The Spark plan includes no-cost usage, and a Blaze pay-as-you-go plan is offered beside it. The pricing page sets the amounts and the limits. Firebase is a hosted service, so an application that uses it depends on Google's infrastructure.
