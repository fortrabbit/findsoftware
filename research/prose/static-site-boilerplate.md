Static Site Boilerplate is a starter project for building static websites. It runs a local development server that reloads the browser when files change, and a production build that lints, concatenates and minifies HTML, styles and scripts, optimizes images, and generates a sitemap.xml and robots.txt. Favicons for web, Apple and Android devices are generated from one source image. The README says the build can be deployed by FTP or to Netlify.
