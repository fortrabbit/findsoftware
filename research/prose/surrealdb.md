SurrealDB is a multi-model database that runs as a standalone database service clients connect to. The [installation guide](https://surrealdb.com/docs/surrealdb/installation) describes one install script for every platform, and the server is also available as a Docker image and through Homebrew on macOS.

## Worth knowing

The core database code is under the Business Source License 1.1, which bars use of the Licensed Work as a Database Service until a fixed change date, after which that code moves to the Apache License 2.0. A self-hosted Enterprise edition, priced on request, is offered beside the engine, and SurrealDB Cloud runs the database as a managed service.
