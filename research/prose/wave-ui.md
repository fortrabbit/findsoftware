Wave UI is a UI framework for Vue.js, distributed through npm as the wave-ui package. The README gives the install command and links the [demo and documentation site](https://antoniandre.github.io/wave-ui), which hosts the component documentation.

## Worth knowing

The README describes the project as an emerging framework, and the older Vue.js line has its own npm tag. The repository has tags but no GitHub release pages; new versions are published to npm.
