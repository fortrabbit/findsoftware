Bootstrap CMS is a content management system written in PHP and built on Laravel and Sentry. It is installed with Composer through the `graham-campbell/bootstrap-cms` package, and the project's README describes it as a PHP CMS powered by Laravel.

## Worth knowing

The GitHub repository is archived and read-only, and the Packagist package that the install command names is marked abandoned. The repository has no stable release: its GitHub releases are all alpha prereleases. The README still says the project is maintained by Graham Campbell, in the present tense.
