syntect is a Rust library that highlights source code using Sublime Text syntax definitions. A Rust program adds it as a crate from [crates.io](https://crates.io/crates/syntect), and its [API documentation](https://docs.rs/syntect) is on docs.rs.

The built-in output is colored HTML pre tags or 24-bit ANSI terminal escape sequences. Highlighting can use one of two regex engines, the default oniguruma or a pure Rust fancy-regex mode.

## Worth knowing

The README says the maintainer considers the project mostly complete, still maintains it and reviews pull requests, and that it is not under heavy development.
