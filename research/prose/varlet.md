Varlet is a Vue component library based on Material Design 2 and 3, for mobile and desktop web apps. It installs from npm as `@varlet/ui`. The [quickstart](https://github.com/varletjs/varlet/blob/dev/packages/varlet-ui/docs/quickstart.en-US.md) also describes a CDN build, `varlet.js`, which carries all the styles and logic of the library.

The varletjs organization on GitHub maintains the project.

## Worth knowing

The quickstart calls the library mobile first, and desktop use needs a separate adapter package. The README lists server-side rendering support, and a first-party Nuxt module covers automatic import in Nuxt projects.
