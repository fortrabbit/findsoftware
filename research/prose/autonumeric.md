AutoNumeric formats numbers and currencies as the user types them into an input element, using predefined options for many international formats or custom options of its own. It also works on most text elements with a contenteditable attribute. It is a standalone JavaScript library with no dependencies, installed with npm or Yarn or loaded in a page with a script tag from a CDN, and its documentation is published on the project site.

## Worth knowing

The docs call the mobile Android Chrome browser only partly supported.
