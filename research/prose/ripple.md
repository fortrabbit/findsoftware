Ripple is a TypeScript UI framework whose components live in `.tsrx` files and use its own JSX-like templating language. The project's docs describe Ripple as built on TSRX, a superset of TypeScript. The framework is installed from npm, and the project's comparison page sets it against React, Solid and Svelte.

Ripple renders on the client only with `mount()`, or on the server with `render()` from `ripple/server`. A prerender step can also write HTML for marked routes as static files.

## Worth knowing

The project's libraries page says Ripple is not production ready and may have breaking changes at any moment.
