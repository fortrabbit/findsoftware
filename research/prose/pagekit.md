Pagekit is a content management system built with Symfony components and Vue.js, written in PHP. The README offers a release archive: the extracted folder is copied to a web server, and the installer runs in the browser. YOOtheme GmbH develops the project.

## Worth knowing

The GitHub repository is archived and the Packagist package is flagged abandoned, so no further changes are expected from the project. The homepage and the documentation site no longer resolve, so the README is the only documentation read for this record.
