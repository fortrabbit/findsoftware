MailerSend is a hosted transactional email service, run by MailerSend, Inc. Applications send mail through its RESTful email API or its SMTP relay, and its developer documentation describes it as a transactional email system built for developers. Its compare page presents it as an alternative to Amazon SES and Brevo, among others.

The company's terms name a New York address, and the security page places the service's data storage center in the European Union.

## Worth knowing

Sending depends on the vendor's hosted service, not on software the user installs. The homepage names role-based access and single sign-on without naming the protocol.
