facil.io is a C library for evented network services, usable from C++ as well. It is distributed as a header file that is copied into a project, and it includes a mini-framework for web applications with an HTTP, WebSocket and Pub/Sub server and Mustache template rendering. The project's site describes the current line as a single-header C core with an IO reactor, HTTP, Pub/Sub and TLS.

## Worth knowing

An older line, labeled legacy on the site, is the classic evented framework with HTTP, WebSockets, Pub/Sub and Redis, kept in a separate repository with its own documentation.
