protomaps-leaflet adds vector basemap rendering and labels to Leaflet, so a Leaflet map can draw a basemap from vector tiles instead of raster images. The tiles come from a PMTiles file on storage or from a tile endpoint. The package is installed with npm or loaded with a script tag. The README describes it as an alternative to MapLibre GL JS, with support for right-to-left writing systems.

## Worth knowing

The README and the docs say the library is in maintenance mode. New features are not added, and the project recommends it only for legacy Leaflet-based systems. For all other use cases it names MapLibre GL JS.
