Framework X is a PHP micro framework for building web applications and APIs, and it uses ReactPHP for its event-driven architecture. It is installed with Composer and can run in two ways: behind an existing PHP stack, where the web server starts PHP for each request, or as an always-on process that systemd keeps running, as the [deployment guide](https://framework-x.org/docs/best-practices/deployment/) describes.

The project is maintained by clue·engineering, which the project names as the company behind it.

## Worth knowing

The project is on a pre-1.0 release line.
