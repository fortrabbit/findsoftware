Formspree is a hosted form backend. A form on a site sends its submissions to a Formspree endpoint, and the service stores them, filters spam and then runs the actions the form owner sets, such as notification emails, auto-responses, redirects and integrations. The homepage says any client that can send an HTTP request can use it, and the help center covers building forms, plugins and a Forms API. The service runs on Amazon Web Services in the United States.

## Worth knowing

The open source server that the GitHub repository of the same name once held is archived, and its description says the source code is not available, so the service cannot be installed from that code. Plans set monthly submission limits, and each plan allows a different number of team members to sign in separately.
