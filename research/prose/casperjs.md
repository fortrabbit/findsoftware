CasperJS is a navigation scripting and testing utility for PhantomJS and SlimerJS. Scripts drive a browser engine: the install guide requires PhantomJS, and SlimerJS is an experimental alternative engine. The install guide gives npm, Homebrew, git and an archive download as routes.

The GitHub repository is archived, and its description says the project is no longer actively maintained. The project's own documentation site and homepage no longer show the project, so the install guide is read from the docs folder of the repository.
