Kendo UI is a library of user interface widgets for jQuery, published by Progress Software Corporation. The commercial package is the npm package @progress/kendo-ui. Kendo UI Core is the open-source subset of the widgets and features, published on npm as kendo-ui-core and kept in a public GitHub repository. The Core subset depends on jQuery.

The docs describe the library as browser-based. Both npm packages are documented, and the Core README adds a pre-built zip download and the Kendo CDN. The [documentation](https://docs.telerik.com/kendo-ui/getting-started/introduction) covers getting started and the components.

## Worth knowing

Only Core is licensed under the Apache License 2.0. The commercial edition adds features under a commercial license. Formal support goes to customers with a commercial license, while Core is supported by its community. The Kendo UI brand also includes Angular, React and Vue libraries, which this record does not describe.
