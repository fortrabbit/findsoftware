Poole is a Markdown-driven static website generator written in Python. It takes the files in an input folder and builds a static site from them. Pages can embed Python code in their source files.

The project is on sourcehut, and the [README](https://hg.sr.ht/~obensonne/poole/raw/README.md) describes the install steps, which clone the repository or download a tarball and run make. Patches and questions go to a mailing list.

## Worth knowing

The repository has no tagged release, and its last commit is several years old.
