Bleach is a Python library that sanitizes HTML. It escapes or strips markup and attributes that are not on an allowed list, so untrusted HTML can be cleaned before it is used. It is installed from PyPI with pip.

The Mozilla Foundation holds the copyright on the code under the Apache License 2.0. The [documentation](https://bleach.readthedocs.io/en/latest/) carries the project's end-of-maintenance note.

## Worth knowing

The maintainer has ended the project. The README says Bleach is no longer maintained and will not get future releases, and the GitHub repository is archived.
