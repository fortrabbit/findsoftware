Saber is a static website generator built on Vue.js and webpack. Each file in its pages folder with a .js, .vue or .md extension becomes a page, and layout components wrap the page content. The build writes static HTML to a public folder that any static HTTP server can serve. The docs describe locale folders such as cn for translated versions of a site.

## Worth knowing

The repository is archived on GitHub. The documentation describes the project as in beta stage.
