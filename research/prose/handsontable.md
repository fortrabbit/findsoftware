Handsontable is a JavaScript data grid that looks and feels like a spreadsheet. A page adds an empty container element to its HTML and creates the grid on it, after installing the package from npm or loading the files from a CDN. The [installation guide](https://handsontable.com/docs/javascript-data-grid/installation/) covers both routes and the framework versions for React, Angular and Vue. The project publishes its own code under two proprietary licenses rather than an open-source license, so the configuration takes a license key.

## Worth knowing

The non-commercial license covers research, private study and evaluation, and the software license page says a project connected with commercial activity may not enter production under it. Commercial use needs a commercial license agreement, which the project sells through its sales team. The code was released under the MIT license up to version 6.2.2, and the later versions use the two proprietary licenses.
