RSpec is a behavior-driven development framework for Ruby. Its README describes four parts that live in one monorepo: rspec-core provides the structure for writing executable examples and the spec runner, rspec-expectations and rspec-mocks cover expectations and test doubles, and rspec-support holds shared helpers. The documentation says the parts can be used independently with other testing tools such as Cucumber or Minitest.

## Worth knowing

The rspec-core repository is archived, and its README points to the monorepo for new issues and releases. The rspec-rails gem, for testing Rails applications, is a separate gem.
