Vitto is a static site generator built with Vite that renders pages with the Vento templating engine. It is created with `npm create vitto@latest`, generates fully static sites for any hosting, and uses Pagefind for built-in search. The project is maintained by Aris Ripandi, and its source is on GitHub under the riipandi account.

## Worth knowing

The README sets a minimum Node.js version for the project. The homepage says the site is optimized for Cloudflare Pages, and the other deployment pages on the site could not be read, so the README is the only installation source.
