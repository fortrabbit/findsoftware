Carew is a static site and blog generator written in PHP, forked from Balrog. Pages and blog posts are Markdown files that start with a YAML front matter block, and Twig layouts render them into HTML. The project is installed with Composer through a boilerplate project, and its build command fills a web directory that any static web server can host.

## Worth knowing

The [README](https://github.com/carew/carew/blob/master/README.md) states that the project is dead and suggests another static site generator instead. The repository is archived on GitHub, and the Packagist package is marked abandoned.
