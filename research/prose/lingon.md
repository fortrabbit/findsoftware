Lingon is a build tool for single-page JavaScript applications, with a development server and Gulp plugins as file processors. The lingon command starts the development server, and lingon build builds once and quits. The tool is installed with npm.

Its [usage documentation](https://github.com/spotify/lingon/blob/master/docs/USAGE.md) walks through all features.

## Worth knowing

The README states that the project is no longer used at Spotify and has been discontinued, and the repository is archived on GitHub.
