Plasmic is a visual builder for React. Pages and components are designed in Plasmic Studio and loaded into a codebase through loader packages, such as the one for Next.js.

The repository is a monorepo. Its packages are under the MIT license, and the platform directory that holds the Studio code is under the AGPL.

## Worth knowing

The sources read do not show whether the Studio can run on a user's own server, so the record is a stub until a self-hosting guide is read. The loader packages are installable from npm, so the open question concerns the editor only.
