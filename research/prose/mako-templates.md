Mako is a template library whose non-XML syntax compiles each template into a Python module, so a template runs as Python code in the process that renders it. The homepage calls it an embedded Python language, close to Python Server Pages. Templates can inherit from a base template, define reusable defs and blocks, use namespaces and cache their output. The [usage guide](https://docs.makotemplates.org/en/latest/usage.html) covers file-based templates, template lookup and integrations with WSGI, Pygments and Babel.

Security reports go through the Tidelift program.
