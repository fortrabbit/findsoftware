Barf is a Go framework for building JSON-based web APIs, with a name its README expands as "Basically A Remarkable Framework". The README names REST and GraphQL based architectures as the styles it is for, and its examples keep the standard net/http request and response types in route handlers. The copyright line in the license names Perfection Loveday.

## Worth knowing

The project has no website of its own, so the [README](https://github.com/opensauceryafrica/barf/blob/main/readme.md) is the only documentation page the project names.
