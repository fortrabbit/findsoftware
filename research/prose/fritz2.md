fritz2 is a Kotlin library for building reactive web apps, with a set of headless components. It is added to a Kotlin multiplatform Gradle project from Maven Central, and the app is mounted into an ordinary HTML page that includes the script built from the Kotlin/JS target.

## Worth knowing

Development moved to a new GitHub organization, and the original repository is archived with a notice pointing to it. The newest releases are release candidates, and the highest stable release predates the move.
