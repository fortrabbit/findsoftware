Directus 8 is the version 8 line of Directus, a database API that wraps custom SQL databases with REST and GraphQL endpoints. The repository holds a monorepo of the version 8 application, and its `api` folder contains the PHP code. The README describes a `build.sh` script that builds the archive into a ready-to-use bundle.

## Worth knowing

The README states that this version is end-of-life and has been deprecated and superseded by the latest version on directus/directus. The repository is archived and read-only on GitHub.
