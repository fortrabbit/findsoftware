MDEx is an Elixir library that parses Markdown and renders it to HTML, Phoenix HEEx, JSON and other formats. Its HEEx output is for Phoenix LiveView, and the README lists HEEx components and expressions among its features.

The [module documentation](https://mdex.hexdocs.pm/MDEx.html) is hosted on hexdocs for the package. Plugins are separate Hex packages, which the README links one by one.
