JBake is a Java-based static site and blog generator. It bakes AsciiDoc, Markdown and HTML content into a static website, with templates written in Freemarker, Groovy, Thymeleaf, Jade or Pebble. The bake command builds the site, and content can be kept in Dropbox, CVS, SVN, Git or elsewhere. It installs from a binary distribution, through SDKMAN or Homebrew, or as an official Docker image, and it runs on a Java runtime. The [reference manual](https://jbake.org/docs/latest/) covers installation, project structure and usage. The JBake Team maintains it.
