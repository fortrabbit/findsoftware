WP Emerge is a PHP micro framework that adds MVC tooling to WordPress development. It is installed with Composer, as the [quickstart](https://github.com/htmlburger/wpemerge-docs/blob/master/framework/quickstart.md) in the docs repository describes. Its source is in the [htmlburger/wpemerge repository](https://github.com/htmlburger/wpemerge), and the README names htmlBurger as the team behind it.
