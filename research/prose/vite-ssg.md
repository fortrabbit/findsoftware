vite-ssg generates static HTML for Vue 3 applications built on Vite. It is installed from npm as a development dependency and run as the build step of a Vue project. The repository is maintained by Anthony Fu and hosted under the antfu-collective organization on GitHub, where the [README](https://github.com/antfu-collective/vite-ssg/blob/main/README.md) documents the setup.

## Worth knowing

The README states the library is ESM-only.
