Normalize.css is a single stylesheet that makes browsers render HTML elements more consistently, and it keeps useful browser defaults where many CSS resets remove them. Its README explains what the code does for the elements it normalizes, and the package is installed from npm as normalize.css or downloaded as a file from the project's site. The source is in the necolas repository on GitHub, and the LICENSE names Nicolas Gallagher and Jonathan Neal as copyright holders.

## Worth knowing

The README lists the browsers the stylesheet targets, including Internet Explorer, and names the cases where browsers stay inconsistent. The project publishes no GitHub releases, so its version comes from the npm package.
