Angular Material is the Material Design component library for Angular applications. The Angular team at Google builds it, and its Component Dev Kit (CDK) is published from the same repository. The [getting-started guide](https://raw.githubusercontent.com/angular/components/main/guides/getting-started.md) installs it with the Angular CLI command ng add, which asks for a prebuilt or custom theme and for global typography, then adds the Roboto font and the Material Symbols icon font to the page.

## Worth knowing

The README says Angular Material and the CDK follow the same support and release policy as the Angular framework. The team supports the two most recent versions of the major browsers.
