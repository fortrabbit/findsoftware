SitecoreAI is a cloud-native SaaS content management system from Sitecore. Editors build and publish pages in a no-code visual page builder with live preview, and one control center manages unlimited sites and brands. Front ends in Next.js, Angular or .NET Core read published content through a GraphQL delivery API, and the REST API manages sites. Sites from a Sitecore XM/XP installation can be migrated in.

Sitecore A/S, based in Denmark, maintains the product.

## Worth knowing

Authentication and user creation are managed by the Sitecore Cloud Portal. The on-premises Sitecore Experience Platform is a different product.
