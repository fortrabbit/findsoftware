Spike is a static site generator built on webpack, with plugins that transform HTML, CSS and JavaScript. It is installed globally with npm, and a site is built with `spike compile`. The local development server is powered by Browsersync.

## Worth knowing

The README states that the project is currently unmaintained. The command line tool collects anonymous usage data by default, and `spike analytics disable` turns that off. The docs say Carrot Creative sponsors the project.
