Effect is a TypeScript library with typed errors, dependency injection, concurrency, scheduling and schema validation. It is published on npm as `effect` and runs on Node.js, Deno and Bun, according to its installation guide. The repository is a monorepo that also holds integration packages, among them platform services for the browser, SQL clients and provider packages for AI services. The MIT license names Effectful Technologies Inc as the copyright holder, and the documentation is on [effect.website](https://effect.website/docs/v4/onboarding).
