Kuma UI is a library of headless UI components for React. Its styling is zero-runtime CSS extraction, which the project's docs describe as build-time extraction. A project installs @kuma-ui/core from npm and adds a plugin for Next.js or Vite, and the install guide says the library is compatible with React 18 and later.

The repository holds several packages, with one release tag per package. The npm package named kuma-ui is an unrelated project. The license file names poteboy as the copyright holder.
