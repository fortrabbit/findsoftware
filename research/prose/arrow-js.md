ArrowJS is a reactive UI library whose templates are `html` tagged template literals. The [documentation](https://arrow-js.com/docs.md) describes it as a reactive UI framework built around JavaScript primitives, and the core package needs no build step.

The core package can be installed from npm, loaded from a CDN or imported directly in the browser. A scaffolder sets up an app with server-side rendering and hydration, and a separate sandbox package runs Arrow code in a WebAssembly sandbox.
