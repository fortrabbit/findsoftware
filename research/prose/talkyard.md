Talkyard is open-source discussion software that combines a forum with question-and-answer topics, team chat and comments for a blog. A self-hosted installation runs with Docker on a single server, following the talkyard-prod-one repository, and one installation can host several communities.

The vendor, Debiki, also provides hosting for Talkyard.

## Worth knowing

The homepage presents the software as a coworker discussion forum, with blog comments as a second use.
