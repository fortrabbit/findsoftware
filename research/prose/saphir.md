Saphir is an HTTP server framework for Rust, written with async and await. The project describes its goal as giving low-level control over the web stack, as hyper does, without building everything from scratch. It is added to a project as a Cargo dependency, and the copyright line in its MIT license names Richer Archambault.

## Worth knowing

The crate's latest major version has no matching release on GitHub, and the install example in the crate documentation shows an older version than the registry's latest.
