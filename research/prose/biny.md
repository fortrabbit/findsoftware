Biny is a model-view-controller framework for PHP web applications, published by Tencent on GitHub. The [project wiki](http://www.billge.cc) documents it. Templates are PHP files with a .tpl.php extension, and database access goes through the mysqli extension for MySQL.

## Worth knowing

The wiki and the release's composer.json differ on the PHP requirement, and the record follows the release. The composer.json describes the project as a modernized fork and names no upstream project, so the record names none. No Composer package is on Packagist, and the pages read do not document an installation method.
