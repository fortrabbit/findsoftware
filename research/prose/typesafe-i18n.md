typesafe-i18n is an internationalization library for TypeScript and JavaScript. A generator writes definitions and wrapper functions from the base locale, so translation keys and their arguments are typed. At runtime the translation function injects arguments, formats them and finds the correct plural form, and locales can load asynchronously.

Adapters for Angular, React, Solid, Svelte, Vue and Node.js are separate packages in the same repository. The [README](https://github.com/codingcommons/typesafe-i18n) serves as the documentation.
