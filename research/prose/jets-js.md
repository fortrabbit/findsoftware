Jets.js is a native CSS search library that filters a list or table already rendered in the page. It generates one CSS rule from the search term, and the browser hides the items that do not match. The homepage describes the case where the list is rendered on the backend and filtered in the browser. The search term can be set from a text field, a select or a call in code. The library is installed from npm, Bower or a CDN, or downloaded from the repository.

## Worth knowing

The releases are published to npm; the GitHub repository has no release entries. The package name jets differs from the project name.
