Ignite UI for Angular is a component library for Angular applications, published by Infragistics, Inc. and installed from npm, with the Angular CLI's ng add, or through its own CLI. The package is dual-licensed: the components named in its license file are available under the MIT license, and every other part is under the Infragistics Commercial License.

## Worth knowing

The [product page](https://www.infragistics.com/products/ignite-ui-angular) says the 50+ open-source components are free to ship commercially and that a license is needed when an application uses the grid, charts or Dock Manager. The npm package declares its license as "SEE LICENSE IN LICENSE", so the license file, not the package metadata, is the source for which parts are open source.
