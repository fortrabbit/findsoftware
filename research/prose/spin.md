Spin is a command-line tool that starts a project's Docker Compose development environment and deploys the same kind of containers to servers with Docker Swarm. A developer installs it with a shell script, through Composer or through npm, and runs it from the project directory with Docker Desktop installed. Server Side Up, a brand of 521 Dimensions LLC, maintains it in the serversideup GitHub organization, and questions go to the maintainers' Discord and to GitHub Discussions.

## Worth knowing

The tool runs only on the developer's machine. Production containers run in Docker Swarm on servers the user provides or has Spin provision. A paid Laravel template from the same company is a separate product and is not part of this tool.
