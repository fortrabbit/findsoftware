Wired Elements is a set of basic UI elements with a hand-drawn look, built with RoughJS and Lit. The package is installed from npm as `wired-elements` or loaded as an ES module from unpkg. The [docs folder](https://github.com/rough-stuff/wired-elements/tree/master/docs) describes the properties, events and CSS properties of each element. Preet Shihn maintains the project, which sits in the rough-stuff GitHub organization.
