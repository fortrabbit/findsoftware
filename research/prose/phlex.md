Phlex is a Ruby gem for writing HTML and SVG views as Ruby classes, so the markup and the Ruby code that feeds it live in the same language. The project describes it as a standalone library with zero dependencies. Most users add it to a Rails application through the phlex-rails gem, which the install step names. Phlex output is rendered on the server.

## Worth knowing

Phlex uses BreakVer rather than SemVer, so the first number of its version marks breaking releases.
