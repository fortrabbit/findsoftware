Thaw is a component library for Leptos, a Rust web framework, and its README describes the components as based on Fluent Design. A project can add the thaw crate with cargo add, or start from the thaw-template repository with cargo-generate, which creates a starter project for Leptos. The crate is published on crates.io, and the README links the documentation and a Discord server.

The documentation describes locale settings for the Calendar and DatePicker components.
