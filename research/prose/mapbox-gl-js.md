Mapbox GL JS is a JavaScript library for interactive, customizable vector maps in the browser. It takes map styles that follow the Mapbox Style Specification, applies them to vector tiles and renders them with WebGL. The [get-started guide](https://docs.mapbox.com/mapbox-gl-js/guides/get-started/) describes adding it to a page from a CDN script or with npm.

## Worth knowing

The library is installable, but using it requires a Mapbox account, and the overview page's examples pass an access token. The license applies the Mapbox terms of service and allows use only with Mapbox products through a Mapbox account. Releases before the license change were under a BSD license, and MapLibre GL JS forked from that line.
