mdui provides Material Design 3 (Material You) components for a project's pages, built with Web Components. Its install guide recommends npm and says the same files can be included directly from a CDN. Components default to English, and the docs describe functions for configuring other languages. zdhxiong maintains it.

## Worth knowing

The README says development is under way on mdui v3, based on the Material 3 Expressive specification, and that v2 keeps receiving fixes and features in the meantime. No v3 release is listed, so this record tracks the v2 line.
