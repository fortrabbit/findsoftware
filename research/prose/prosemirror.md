ProseMirror is a toolkit of modules for building rich-text editors on the web, maintained by Marijn Haverbeke. The core modules hold the document model, the editor state and its transactions, the view that shows that state as an editable element in the browser, and the transforms that record changes so they can be replayed. Further modules provide basic editing commands, key bindings, undo history, input macros, collaborative editing and a simple document schema.

The project develops the modules in its own Forgejo organization, and the [guide](https://prosemirror.net/docs/guide/) explains how the modules relate. Questions go to the [forum](https://discuss.prosemirror.net/).

## Worth knowing

The project is open source, and its homepage asks commercial users to help fund its maintenance. The project states support for post-2020 versions of Firefox, Chrome, Safari and Edge.
