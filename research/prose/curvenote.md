Curvenote is a command line tool on npm for scientific and technical documents written in MyST Markdown and Jupyter Notebooks. It previews a project as a website while the author writes, exports it to PDF, LaTeX, Word and JATS, and publishes it to Curvenote as a site or as a submission to a venue. The [install page](https://curvenote.com/docs/cli/installing) gives the npm command, and the [CLI overview](https://curvenote.com/docs/cli) describes the commands.

## Worth knowing

Curvenote also runs a hosted platform, the Scientific Content Management System, and the README names curve.space as a hosting service for sites. Building and previewing work without an account, but signing in is needed to deploy or submit.
