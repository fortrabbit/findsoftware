Scroll is a plain-text language and a command line app that builds static blogs, websites and other text files from Scroll files. The Scroll files, the static files and the generated HTML sit together in one folder, which is checked into version control. The command line app is written in JavaScript and runs on Node.js, and it is installed from GitHub with npm.

## Worth knowing

Scroll is installed on the machine where the site is written, and the output is static files that any web server can serve. The FAQ says the project is published to the public domain.
