Lunr-Core is a full-text search library for .NET, ported from Lunr.js. The [README](https://github.com/bleroy/lunr-core) describes it as a small search library for use in small applications.

The README says the library is compatible with lunr.js, so an index file prepared with Lunr-Core on the server can be read by lunr.js on the client.

## Worth knowing

The README has no rendered install section, because its installation text sits in a comment, and it lists documentation as work still to do.
