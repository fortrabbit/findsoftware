PHPFusion is a content management system written in PHP. It keeps its content in a MySQL database and ships with an administration panel and multilingual support.

Installation starts with uploading the files to the web host, as the [installation guide](https://github.com/PHPFusion/docs/blob/master/phpfusion-9-documentation/4-installation.md) describes. A web installer then sets up the site, and the guide says to create a MySQL database first.

## Worth knowing

The docs say that removing the PHPFusion copyright notices requires a purchased license.
