Node Sass is a Node.js binding to LibSass, the C implementation of the Sass stylesheet language, and lets Node.js code compile Sass files to CSS. The package is installed with npm and is written in C++. The source is on GitHub under the sass organization.

## Worth knowing

The README states that the project has reached end of life and points projects to Dart Sass. The npm package is deprecated in favor of sass or sass-embedded, and the repository is archived.
