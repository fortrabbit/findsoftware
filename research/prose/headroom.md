Headroom.js hides a page's header while the user scrolls down and shows it again on scroll up. It is written in JavaScript and has no dependencies. A page creates a Headroom instance for a header element and calls its init method; CSS classes for the pinned and unpinned states move the header in and out of view. The [documentation site](https://wicky.nillia.ms/headroom.js/) lists the methods, including freeze and unfreeze, which stop and resume the scroll response. It has a pure JavaScript API plus an optional jQuery plugin and AngularJS directive. The package is installed from npm or yarn, or loaded from unpkg.com for script tags.
