Brill CMS is a React application written in TypeScript that runs in the browser. The client recorded here is built with `yarn build`, and the Brill Server, a separate Spring Boot application in its own repository, serves the build as a web server and listens for HTTP requests on a port.

## Worth knowing

The project's website did not answer when this record was written, so its developer guide could not be read, and the record stays a stub until it does. Part of the framework is under the Brill Software Enterprise Edition License, which needs a paid license, and the rest is under the MIT license.
