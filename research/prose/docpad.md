DocPad is a Node.js static site generator, first released in 2011, that builds websites from files with layouts, metadata and plugins. It stores content as plain files, with no database to install. Static output can be deployed to any web server, and its built-in server handles dynamic pages that change on each request.

## Worth knowing

The project's site says DocPad should be considered archived, and that its final releases wrapped up the project. The repository is not archived on GitHub, and the npm package is not deprecated.
