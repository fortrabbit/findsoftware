Plesk is a control panel that administers web, DNS and mail services through a browser interface. When a user creates a website in Plesk, the panel passes the request to Apache or IIS, which adds the virtual host. The deployment guide installs it with the Plesk installer script on a Linux server, and the requirements page also lists Windows Server.

Plesk supports MySQL, MariaDB and PostgreSQL, and its pricing page lists an MSSQL module. Its features page describes user roles and subscriptions for each user or user group, and its migrator imports from cPanel, Confixx, DirectAdmin and more.
