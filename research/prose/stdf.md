STDF is the Svelte component library of the Any TDF family, a set of mobile web component libraries that share one design system. The components are built on Tailwind CSS and are added to an existing Svelte project with bun, which installs the stdf package from npm. A scaffolding tool, create-any-tdf, sets up a new project.

The React and Vue libraries, RTDF and VTDF, are published from the same repository as STDF, together with a shared core.

## Worth knowing

The Any TDF family has its own site at any-tdf.dev. The repository was moved from another GitHub account, so older links may point to the former location.
