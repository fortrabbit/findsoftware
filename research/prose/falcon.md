Falcon is a Python framework for building REST APIs and microservices. The [installation guide](https://falcon.readthedocs.io/en/stable/user/install.html) says Falcon is installed with pip and needs a WSGI server to serve an app, and the [homepage](https://falconframework.org/) describes it as a Python web API framework for app backends and microservices.

Falcon has no dependencies outside the Python standard library, according to the homepage. It runs under CPython 3.9 and later, per the installation guide.

## Worth knowing

The homepage describes Falcon as an Apache-licensed community project, built and supported by volunteers, with Kurt Griffiths as original creator and primary maintainer.
