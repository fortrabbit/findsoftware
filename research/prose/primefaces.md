PrimeFaces is a UI component library for Jakarta Faces, written in Java. It is distributed as the org.primefaces:primefaces artifact on Maven Central, and its tag library is documented in a [VDL reference](https://primefaces.github.io/primefaces/vdldoc/). Components are added to a Jakarta Faces application as a Java library, and the project publishes a showcase of its components.

## Worth knowing

The README says PrimeTek handed the project over to the open-source community, which now maintains it, and that PrimeTek no longer offers its PrimeFaces PRO edition to new customers. Commercial support is offered by the project lead through neroe.org. The README also sets a support policy in which the last line that supports the javax namespace is supported for longer than the others.
