Thumbor is a Python image service that crops, resizes and filters images on demand. Each transformation is set by parameters in the request path. It runs as an HTTP server and installs with pip, from Debian and Ubuntu packages, or from an official Docker image on GitHub Container Registry. Images can be loaded from and stored in files, HTTP sources, Redis and MongoDB. The copyright line in its license names Globo.com as the maintainer, and the code is MIT licensed.
