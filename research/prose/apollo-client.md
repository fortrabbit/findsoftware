Apollo Client is a GraphQL client library for JavaScript that fetches, caches and modifies remote and local application data. Its core package, @apollo/client, holds the in-memory cache, local state management, error handling and a React-based view layer, and the install guide adds the graphql and rxjs packages beside it. Apollo Graph, Inc. maintains the library, and its repository is a monorepo that holds several packages.

## Worth knowing

The documentation focuses on React, while the library also serves other view layers that the project lists as community integrations, among them Vue, Angular and Svelte.
