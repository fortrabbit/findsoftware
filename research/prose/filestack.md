Filestack is a hosted upload, transformation and delivery API built by Filestack, Inc., part of the Idera group It includes a file picker for the browser upload step. The project publishes SDKs for JavaScript, React, Angular, Python, PHP and Java.

By default, uploaded files go to an internally managed S3 bucket, and customers can connect their own cloud storage instead.

## Worth knowing

Filestack runs as a hosted service, so an application depends on the service for its uploads and stored files. A free plan is offered beside paid plans.
