Miniblog.Core is a blog engine for ASP.NET Core, written in C# and published by Mads Kristensen. It is distributed as a .NET template package on NuGet, which is installed with dotnet new install and called from the command line to create a blog project.

## Worth knowing

The README says the maintainer accepts pull requests but is not actively working on the project. The NuGet package was last uploaded in 2017. The NuGet page for version 1.0.3 carries a notice of a critical-severity vulnerability. The live demo the README links does not resolve.
