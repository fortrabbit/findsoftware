Shiny is an R package for building interactive web applications in R. It is installed from CRAN with `install.packages("shiny")`, and the source is developed in the rstudio/shiny repository on GitHub.

The Shiny Server admin guide says the open source Shiny Server manages R processes that run Shiny applications, for deployment on-premises. Posit also runs hosted services for Shiny apps, Shinyapps.io and Posit Connect Cloud, and sells Posit Connect, a commercial platform for deploying on-premises or in a VPC.

## Worth knowing

The hosted services and Posit Connect are Posit's own products beside the open-source package, and their plans and terms are not part of the package's license.
