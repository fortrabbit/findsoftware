Pagic is a static site generator that renders Markdown and TSX pages to static HTML. It is powered by Deno and React, and it is installed from deno.land with deno install. Each page is pre-rendered to HTML, and once the page has loaded it runs as a single-page application. The [documentation](https://pagic.org/docs/introduction.html) is on the project's site.

## Worth knowing

The install docs name Deno, and no npm package is recorded as the install path.
