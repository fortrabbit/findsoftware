Mermaid is a JavaScript diagramming and charting tool. Diagrams are written as text in a Markdown-inspired syntax and rendered by the library in the page. The README shows flowchart, sequence, Gantt, class, state and pie diagrams, among others, each with a text example. A web page loads Mermaid from a CDN with a script tag, or an application installs it from npm.

## Worth knowing

The README warns that diagram text taken from outside users can carry scripts that run when the diagram is shown. For sites with external users it describes a sandboxed rendering level that blocks script in diagrams, at the cost of some interactive functionality.

The live editor and the command line interface are separate projects.
