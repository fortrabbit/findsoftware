Apprise is a Python package with a matching command line tool. Its service URLs share one format, so one call can reach many services. Python applications send notifications from within their code, and scripts, cron jobs and CI runs use the command line tool. The [installation guide](https://appriseit.com/getting-started/installation/) lists pip, uv, an RPM package and a Docker image as ways to install it. Applications in other languages can send requests to the Apprise API, a separate HTTP server that routes the message. Chris Caron maintains the project.
