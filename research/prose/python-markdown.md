Python-Markdown is a Python implementation of John Gruber's Markdown that converts Markdown text to HTML. The project says it is almost completely compliant with that reference implementation. A command line script is included beside the library, and the package bundles extensions for features such as tables, footnotes and abbreviations. A public Extension API is available for writing others. The [documentation](https://python-markdown.github.io/) covers installation, the library and the extensions.

## Worth knowing

The project's documentation states that it is not a CommonMark implementation and does not try to be.
