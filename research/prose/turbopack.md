Turbopack is an incremental bundler for JavaScript and TypeScript, written in Rust and built into Next.js, where the docs name it the default bundler. It has no release or package of its own and ships with Next.js; the [Next.js Turbopack reference](https://nextjs.org/docs/app/api-reference/turbopack) documents it as part of the framework.

## Worth knowing

Because Turbopack lives in the Next.js repository, the stars, version, release date and npm download figures on this page are Next.js's and measure adoption of the framework.
