fluent-rs is the Rust implementation of Project Fluent, a localization system for natural-sounding translations. The repository is a workspace of crates, and the crate recorded here is the umbrella crate fluent, the one the README presents for use. The crate is published on crates.io, and its copyright notice names Mozilla.

## Worth knowing

The crate's changelog calls one earlier release a "safe harbor" release made before non-Mozilla community maintainers were brought on. The project's [Fluent category on the Mozilla Discourse](https://discourse.mozilla.org/c/fluent) is where discussion takes place.
