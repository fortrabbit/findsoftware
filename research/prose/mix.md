MixPHP is a PHP framework built for command-line mode. Its HTTP support covers Swoole, Swow, WorkerMan, PHP-FPM and the built-in CLI server. New projects are created with Composer from skeleton packages, one each for web pages, APIs, command-line programs, WebSocket services and gRPC services, as the [README](https://github.com/mix-php/mix/blob/master/README_EN.md) shows. The project is maintained by the Mix PHP organization on GitHub.
