Programmable Search Engine is a Google service for creating a search engine over chosen websites. The search engine is configured in the Control Panel, and its results are shown either on a Google-hosted results page or through a search element embedded in a web page. The [developer overview](https://developers.google.com/custom-search/docs/overview) describes the Custom Search JSON API, which offers a free daily query allowance.

## Worth knowing

The Custom Search JSON API is closed to new customers, and Google's own pages state a discontinuation date for it. The Custom Search Site Restricted JSON API has stopped serving traffic, and Google's pages name Agent Search as the replacement for site search.
