Live Preview is an extension for Visual Studio Code that hosts a local web server in the workspace, so HTML files can be previewed through it. The preview opens in the editor or in an external browser. The extension is installed from the Visual Studio Marketplace under the identifier `ms-vscode.live-server`, and the [repository](https://github.com/microsoft/vscode-livepreview) holds its source under the MIT license.

## Worth knowing

The README opens with a warning that the extension is still under development.
