TDesign Vue Next is a UI component library for Vue 3 from the TDesign project. A project installs the tdesign-vue-next npm package, registers components such as Button on its Vue app, and imports the stylesheet from the package's es/style folder. The package can also be loaded as a script from a CDN, and the TDesign documentation in the Tencent/tdesign repository describes the differences between its bundles. The documentation describes internationalization with a locale package passed to the config provider.
