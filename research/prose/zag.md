Zag is a set of framework-agnostic UI component logic built on finite state machines. Each component is a machine package, such as the tooltip package named in the [installation guide](https://zagjs.com/overview/installation), used with an adapter for the framework in the project. Adapters exist for React, Vue 3, Svelte and Solid.js. The machines are headless and unstyled, so the project supplies its own markup and styling. The README says Zag grew out of building Chakra UI.
