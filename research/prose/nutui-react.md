NutUI React is a component library of mobile user-interface components built on React, in the JD style, for H5 pages and mini programs. Its getting-started guide in the repository describes installing it from npm as @nutui/nutui-react, and the library supports multiple languages.

The repository belongs to the jdf2e organization, and the npm package names jdcfe as its author. The next major line is published as betas on npm, and the newest stable release is on the previous line.

## Worth knowing

The npm latest tag points to a beta, so an install without a version pins a prerelease.
