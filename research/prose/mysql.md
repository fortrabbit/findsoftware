MySQL is an SQL database server developed by the MySQL team at Oracle. The source code is in one repository, and its [INSTALL file](https://raw.githubusercontent.com/mysql/mysql-server/trunk/INSTALL) describes a build from the source distribution and points to pre-built packages on the vendor's download pages.

## Worth knowing

Release numbers are calendar versions, so the newest release has no major number. A separate long-term support line runs beside the innovation releases.
