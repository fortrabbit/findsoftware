Stastic is an online editor for Jekyll websites. A user runs the Stastic installer, which copies the editor into the /admin folder of a Jekyll site, and then edits pages, posts, navigation and settings in the browser. The content is kept in the GitHub repository of the site, and GitHub Pages hosts the site as a static website.

The about page says the editor plugs into Jekyll sites, and the installer offers themes from a curated list. The project offers professional support and custom development on request.

## Worth knowing

The source code is not public, so the editor cannot be inspected or built from source. Both the repository and the published pages depend on GitHub.
