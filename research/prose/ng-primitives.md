Angular Primitives is a headless UI library for Angular, published as ng-primitives on npm. The homepage describes its primitives as unstyled and accessible, and the library ships as one package with an entry point for each primitive. It installs with the Angular CLI or with npm. Ashley Hunter, the npm package author, maintains the project in the ng-primitives organization on GitHub.

## Worth knowing

The releases are still pre-1.0, and the docs say that major versions will follow Angular's major versions from the first 1.0 release onward. The compatibility table in the README lists the Angular majors each release line supports.
