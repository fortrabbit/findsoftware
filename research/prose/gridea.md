Gridea is a desktop client for writing blog posts in Markdown and building them into a static website. It runs on Windows, macOS and Linux. Posts live as files in a local source folder, which the FAQ says can be synced between devices with a file-sync service.

The [quick start](https://open.gridea.dev/gridea-start/) describes publishing the built site to GitHub Pages, Coding Pages or a server over SFTP. For GitHub Pages it needs an access token and a repository for the built files.

## Worth knowing

Hexo posts are imported by copying the Markdown files into the posts folder by hand. The categories Hexo used are dropped, because Gridea has only tags.
