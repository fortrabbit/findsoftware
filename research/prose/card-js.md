Card is a JavaScript library that draws an animated credit card beside a credit card form. The card is drawn with CSS, so the page needs no images. The library adds its own CSS when its script is included in the page, and a single `new Card(...)` call names the form and the container where the card appears.

The README also gives a jQuery form of the same call, and a `messages` option for translated labels. Installation is by npm, by Bower or by including the script file in the page.
