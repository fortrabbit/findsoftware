Bludit builds websites and blogs without a database: content is kept in JSON files, so a web server with PHP is all it needs. The release archive is uploaded to the server, and content is written in Markdown or HTML in the admin area. The [documentation](https://docs.bludit.com) covers installation, and plugins are listed in the [plugin directory](https://plugins.bludit.com).

## Worth knowing

Some plugins, such as White Labeling and Backup Manager, belong to Bludit PRO, which comes with a paid Patreon tier. The PRO page states no license for them.
