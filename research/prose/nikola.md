Nikola is a static website and blog generator written in Python. It takes content in reStructuredText, Markdown, IPython notebooks or HTML and builds a site of HTML files and assets that can be hosted on any web server. Blogs are a supported use, and themes can be written in Mako or Jinja2. Plugins extend the generator, and the project lists them in a plugin index. Nikola is installed with pip, and the development server is started with nikola serve. Roberto Alsina and others hold the copyright.
