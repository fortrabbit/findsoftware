FastEndpoints is a framework for building REST APIs on ASP.NET, installed with dotnet add package FastEndpoints. The [homepage](https://fast-endpoints.com/) names ASP.NET Minimal APIs and MVC as the alternatives it is set against.

The repository describes the framework as one for ASP.NET 8 and newer.

## Worth knowing

The NuGet package has a beta of the next major version published after the latest stable release. GitHub carries that beta only as tags, not as a release.
