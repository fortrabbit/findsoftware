JSON Server is a Node.js command-line tool that serves a JSON file as a REST API. The data sits in a `db.json` or `db.json5` file that the server is started with.

## Worth knowing

The README documents the v1 beta, which it describes as usable but open to breaking changes. The stable line is the 0.17 series, which the README links from its beta notice. The beta's package requires a newer Node than the stable line, so the minimum runtime on this record is the stable line's and not the beta's.
