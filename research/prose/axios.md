axios sends HTTP requests from the browser and from Node.js. The [getting-started guide](https://axios.rest/pages/getting-started/first-steps) shows installs with npm, pnpm, yarn, bun and Deno, and a script tag that loads it from jsDelivr with a pinned version.

## Worth knowing

Two release lines are published, the current one and an older one. The npm package's default tag points to the current line. The older line still publishes releases, and HeroDevs, a third-party provider, offers security updates for it as paid extended support.
