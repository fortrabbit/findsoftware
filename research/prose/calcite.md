Calcite Design System is Esri's set of design resources for building web applications, and its core is a library of web components built with Lit. The homepage lists a UI kit, icons, color schemes and the component library side by side. The components can be installed from npm or loaded with a script tag from a CDN, and they cover localization including right-to-left content.

## Worth knowing

Calcite is tied to an ArcGIS account. The get-started page lists a free ArcGIS Online or ArcGIS Location Platform account as a prerequisite, and the [licensing page](https://developers.arcgis.com/calcite-design-system/resources/licensing/) says it is available with an ArcGIS Online, ArcGIS Enterprise or ArcGIS Location Platform account, subject to the Esri Master Services Agreement. The source code is public, but the package is licensed under the Esri Master License Agreement, and its LICENSE file sends readers to that agreement's use restrictions.
