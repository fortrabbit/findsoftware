TriTan CMS is a content management system and framework written in PHP, run on Apache or Nginx. It stores its content in a schemaless database library that keeps files on the server, and it offers an admin area and a REST API. The README gives the installation as a zip download, followed by composer install and a cron job on the server.

## Worth knowing

The README says the project is no longer maintained and has been replaced by Devflow, a separate project. The GitHub repository is archived. The project's own website no longer answers, so the documentation the README links cannot be reached.
