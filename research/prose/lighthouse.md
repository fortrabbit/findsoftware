Lighthouse is an open-source tool from Google that audits web pages and web apps for performance, accessibility, SEO and best practices. It runs in Chrome DevTools, as a Chrome extension named in its README, through a Node command-line tool installed from npm. The project is maintained by Google LLC.

## Worth knowing

Lighthouse runs locally and audits a page with a Chrome browser installed on the machine. The README says reports are not sent to a remote server.
