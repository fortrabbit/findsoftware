CherryPy is a Python framework that its README calls an object-oriented HTTP framework. It is installed with pip or from a source checkout, and the [deployment guide](https://docs.cherrypy.dev/en/latest/deploy.html) says it stands on its own as an application server. The CherryPy Team maintains it, and it is distributed under a BSD license.

## Worth knowing

The homepage still says it runs on Python 2.7 and 3.5, while the install page lists Python 3.9 through 3.13 and PyPI declares 3.6 or later.
