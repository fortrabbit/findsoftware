Formly builds Angular forms from field configurations written as JSON-style objects. The [README](https://github.com/ngx-formly/ngx-formly/blob/main/README.md) says it is built on top of Angular Reactive Forms, and the [getting-started guide](https://github.com/ngx-formly/ngx-formly/blob/main/docs/getting-started.md) lists the setup steps.

## Worth knowing

The UI themes, such as Bootstrap, Material, Ionic and PrimeNG, are separate packages that the install guide lists by name, so a project adds a theme package next to the core.
