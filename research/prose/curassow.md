Curassow is a Swift HTTP server that uses the pre-fork worker model: a master process, called the arbiter, manages child worker processes that handle requests independently. It exposes a Nest-compatible interface, so an application written for a Nest-compatible web framework can run behind it. The documentation compares it to Python's Gunicorn and Ruby's Unicorn. It is installed as a dependency through the Swift Package Manager.

## Worth knowing

The register lists projects with a release in the last four years. Curassow has none, so the record is listed as a stub. The repository sits under an organization named kylef-archive, but GitHub does not flag it as archived and no page says the project has ended.
