Docz turns MDX files into a documentation site for React code, built on GatsbyJS. It is added to a project as an npm package, and the MDX files are the source of the pages. A development server serves the site locally, and the build output consists of static assets only.

## Worth knowing

The repository is archived. React and react-dom are not installed with Docz and must be added to the project separately. The docz.site address now serves an unrelated page.
