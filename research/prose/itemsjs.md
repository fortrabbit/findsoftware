ItemsJS is a JavaScript library that builds a faceted search engine from an array of JSON objects the application passes in. It filters the items by facet values, searches them by text, sorts them and returns them in pages, and it can take the matching identifiers from an external full-text engine instead. The library is installed from npm or loaded as a script in the browser, and its README says it works on both the backend and the frontend.

## Worth knowing

The README names MiniSearch and Lunr as integrations for full-text search. The project has no website of its own, so its documentation lives in the repository README and the docs folder beside it.
