SVGO is a Node.js library and command-line application for optimizing SVG files. It can be used as a command-line application, as a Node.js library, as a browser bundle loaded through a build tool or from a CDN, and as a webpack loader that optimizes SVG imports. The npm package installs the command-line application globally or into a project, and its docs list yarn and pnpm as install routes as well.

## Worth knowing

The browser bundle runs in the visitor's browser, while the command-line application and the Node.js library run on the developer's machine or in a build step. The source code is MIT-licensed; the site states that its content and assets are under CC-BY-4.0, which is a separate license.
