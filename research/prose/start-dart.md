Start is a web framework for Dart, modeled on Sinatra. An application starts a server with `start()` and registers handlers for GET, POST, PUT and DELETE routes, plus WebSocket handlers on the same server. Routes take named placeholders, and a folder of static files can be served from the same server.

## Worth knowing

The latest version on pub.dev is labeled as incompatible with Dart 3, and its SDK constraint stops below Dart 3. The last commit on the repository is from 2021.
