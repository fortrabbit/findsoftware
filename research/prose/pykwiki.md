PyKwiki is a static site generator for blogs and wikis, written in Python. Pages are written in Markdown and rendered with Jinja2 templates, and the `pykwiki cache` command turns them into HTML files in a docroot folder that a web server such as Apache can serve. Styling uses Sass, and the docs describe a static keyword search that runs in JavaScript, so the site needs no server-side code. The project is installed with pip.
