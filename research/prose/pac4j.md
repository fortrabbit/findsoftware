pac4j is a Java security library that adds authentication and authorization to Java web applications. The README describes one API for OpenID Connect, SAML, CAS, OAuth, JWT and LDAP that works with any Java framework, with integrations for frameworks such as Spring Boot, Jakarta EE, Play and Vert.x. Apereo CAS, Apache Syncope and Apache Knox embed it. The [documentation](https://www.pac4j.org/docs/index.html) is on the project's own site.

## Worth knowing

According to the homepage, the Lagom and Akka HTTP integrations are archived and the Pippo integration is inactive.
