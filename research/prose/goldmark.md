goldmark is a Markdown parser for Go that follows the CommonMark specification. It parses a document into a syntax tree and renders it to HTML, and it is extensible through extensions listed in the README.

## Worth knowing

The default branch holds the v2 line, whose module path differs from the earlier v1 line, which remains on the tags. The README's maintenance policy covers bug and security fixes for the latest major version and the one before it.
