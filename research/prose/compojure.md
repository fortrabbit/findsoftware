Compojure is a routing library for Ring, the Clojure library for web applications. It composes a web application from small route definitions, so each part of the routing can be written separately and combined. The library is added as a Maven dependency in a deps.edn or Leiningen project, and the [PaaS Platforms](https://github.com/weavejester/compojure/wiki/PaaS-Platforms) wiki page describes running Compojure applications on standalone servers and on Java platform services. The project has no website of its own; its documentation is the GitHub wiki. James Reeves maintains it.
