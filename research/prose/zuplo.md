Zuplo is a hosted API gateway, maintained by Zuplo, Inc. The homepage presents it as the unified gateway for APIs and AI, covering authentication, rate limits, spend caps and audit for calls to APIs, LLMs and MCP servers.

The managed service runs across more than 300 edge locations. A Self-Hosted option runs on the customer's own Kubernetes cluster and installs with a single Helm chart. The GitHub repository under the zuplo name holds examples and tooling, not the gateway's own code.

## Worth knowing

The free tier covers 100K requests a month. Single sign-on and role-based access are available on an Enterprise agreement, and the pricing page says teams that need them must take that agreement.
