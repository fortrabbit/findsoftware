Routify is a router for Svelte applications. Routes come from the file structure and from page metadata, and the introduction in the docs describes it as Svelte-based. It can render on the client, on the server and as prerendered pages, and a new project is created with npm init routify@latest. The LICENSE names Team Routify as the copyright holder.

## Worth knowing

The render modes page of the docs marks server rendering and static generation as experimental. The npm package named routify belongs to a different project under GPL-3.0-or-later; Routify's own package is @roxi/routify.
