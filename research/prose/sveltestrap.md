Sveltestrap is a set of Svelte components that implement Bootstrap components without Bootstrap's JavaScript or jQuery. It is installed from npm next to the svelte package. The [README](https://github.com/sveltestrap/sveltestrap/blob/main/README.md) describes adding the Bootstrap stylesheet with a link tag, an import or the bundled Styles component.

## Worth knowing

Bootstrap's styles are not part of the package. The README says Bootstrap components do not come with Bootstrap styles preloaded, so the stylesheet is a separate dependency the project's users add.
