Passage is a static site generator written in PHP. Content is Markdown files kept in a directory structure the author chooses. Templates are plain PHP files. Running the PHP build script in `_engine` writes the finished HTML to `_site`, so the live site needs only a web space that serves files.

## Worth knowing

The repository has no tagged release and no LICENSE file. The GPLv3 license rests on the License section of the README alone.
