Muleify is a command-line static site generator and asset compiler for websites, installed globally with npm. It runs on Node.js. Files are processed by extension and sub-extension, and the [README](https://github.com/xeaone/muleify/blob/master/README.md) describes the commands, including a serve mode with single-page application support.

## Worth knowing

The repository has no GitHub release or tag; the npm package is the only published release.
