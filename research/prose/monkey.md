Monkey is an HTTP server for Linux, written in C, that runs as a standalone web server. It has a plugin-oriented architecture. The [README](https://raw.githubusercontent.com/monkey/monkey/master/README.md) gives the CMake build steps.

The project's own site is a GitHub Pages site that still shows an older release, and its [documentation page](https://monkeywebserver.com/documentation/) covers the 1.6 and 1.5 lines. The current documentation is kept in a separate repository.

## Worth knowing

The repository is the current source for the code, and the site describes older versions. Readers who need documentation for the current release should check the documentation repository as well as the site.
