Earmark is a Markdown converter written in pure Elixir. It turns Markdown into HTML and is meant to be called as a library, although the project also describes a command-line build of the same code. Output generation is pluggable.

## Worth knowing

The GitHub repository is archived, which ends the record as discontinued, although the Hex package still publishes releases. The README warns that Earmark does not sanitize unsafe Markdown and says not to use it on untrusted input.
