Hookstate is a state management library for React. Global state is created with the hookstate function and local state with the useHookstate function, and nested and scoped state use the same API. The core package is installed from npm and, according to the getting-started page, has no external or peer dependencies except React. Extensions are separate packages. The source is a monorepo that holds the core, the extensions, the docs and the demo applications, and Andrey Konstantinov maintains it.
