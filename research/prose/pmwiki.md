PmWiki is a wiki engine written in PHP that stores all its data in flat files, so it needs no MySQL or other database. It is installed by extracting the archive and opening its pmwiki.php script in a browser, which then creates the wiki.d directory that holds the pages. Extensions called recipes add features and are listed in the PmWiki Cookbook. The [installation page](https://www.pmwiki.org/wiki/PmWiki/Installation) covers the steps.
