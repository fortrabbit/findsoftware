FormatJS is a set of JavaScript libraries for internationalization, built on ICU MessageFormat, Unicode CLDR and the ECMA-402 Intl APIs. Its installation guide describes the libraries as helping set up internationalization in any project. The React binding is react-intl, installed with npm, and the [runtime requirements page](https://formatjs.github.io/docs/guides/runtime-requirements/) gives the minimum Node.js version for it.

The repository is a monorepo that also holds Rust crates, Python bindings and a native Hermes SDK. Vue and Svelte bindings are separate npm packages. The documentation includes migration guides from i18next and Lingui. The license files of the packages name Oath Inc. as the copyright holder.

## Worth knowing

Stars and contributor counts describe the whole monorepo, not react-intl alone.
