Longclaw is an e-commerce extension for the Wagtail CMS. It adds products, orders, shipping and statistics to a Wagtail site, and they are managed from the Wagtail admin. The project exposes a REST API. A new site starts from a project created with the longclaw start command, and the README names Stripe, Braintree and PayPal as payment backends.

## Worth knowing

The README says the package is being upgraded for newer Django and Wagtail versions and that the project is looking for maintainers. The latest release dates from 2019.
