Onsen UI is an open source framework for building hybrid apps and progressive web apps with components that look native on each platform. The core library is pure JavaScript on top of Web Components and is framework agnostic. Binding packages connect it to React, Angular, Vue and AngularJS, and community packages cover Aurelia and Ember. Components come in flat (iOS) and Material (Android) designs and are styled per platform by default.

The core library is installed with npm or loaded from a CDN. The copyright line in its license names Asial Corporation.

## Worth knowing

The npm package carries the most recent published build of the core library; the GitHub release list stops at an earlier version.
