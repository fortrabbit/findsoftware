Suave is a web server and library for F#, with HTTP handlers composed from small functions. It runs on .NET and is added to a project with the dotnet add package command.

The [deployment guide](https://suave.io/docs/deployment.html) shows the server run as a standalone published application, in a Docker container or as a systemd service, and a separate package renders DotLiquid templates. The site says Suave is created and maintained by Ademar Gonzalez.
