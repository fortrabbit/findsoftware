Spectrum Web Components is a library of web components that implements Adobe's Spectrum design system. The components are built on LitElement and are designed to work with any web framework, or with none. The repository is a monorepo for the project's packages. The [getting-started guide](https://opensource.adobe.com/spectrum-web-components/getting-started/) recommends a theme element alongside the component elements.

## Worth knowing

The bundle package, which contains every element, is described on the same guide as not for production use.
