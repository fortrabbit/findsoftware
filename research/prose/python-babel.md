Babel is a Python library for internationalizing and localizing Python applications, with an emphasis on web-based ones. Its documentation describes two parts: tools to build and work with gettext message catalogs, and a Python interface to the Common Locale Data Repository (CLDR) for localized names, numbers and dates.

On Python versions without the standard library zoneinfo module, pytz must be installed for timezone support. The project's [documentation](https://babel.pocoo.org/en/latest/) covers both parts.
