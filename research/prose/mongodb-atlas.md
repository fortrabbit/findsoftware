MongoDB Atlas is the managed cloud service from MongoDB, Inc. for MongoDB databases. Clusters deploy onto Amazon Web Services, Google Cloud and Microsoft Azure, as the [cloud providers reference](https://www.mongodb.com/docs/atlas/reference/cloud-providers/) lists them.

Access is organized by roles at the organization and project level. The [user roles reference](https://www.mongodb.com/docs/atlas/reference/user-roles/) describes which actions each role allows.

The self-hosted server that Atlas runs on its own infrastructure is the separate MongoDB record.
