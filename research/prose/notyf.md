Notyf is a vanilla JavaScript library for toast notifications, with no dependencies. It ships ES6, CommonJS, UMD and IIFE bundles and TypeScript typings, so it works with a bundler or from plain script tags. Developers can define their own toast types and render custom HTML inside a toast, and the repository holds recipes for Angular, React, Aurelia, Vue and Svelte, which are integration notes and not separate bindings.

## Worth knowing

The README says Notyf does not sanitize message content, so HTML messages need sanitizing or must not carry user-generated content.
