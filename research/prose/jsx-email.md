JSX email is a set of React components and helpers for writing email templates in JSX or TSX. The components absorb the compatibility differences between email clients, so a template is written as React code and rendered to an HTML string that an email provider can send.

The command-line tool includes a preview server and a compatibility check. The documentation lists the email providers the rendered HTML can go to, among them AWS SES, Nodemailer, Postmark, Resend and SendGrid. The source is a monorepo. The project calls itself community-driven, with no corporate sponsorship.

## Worth knowing

Pro Templates, a set of paid email templates sold from pro.jsx.email, is a separate product from the open source library.
