Kobalte is a set of unstyled UI components and primitives for SolidJS. Unstyled means the components supply behavior and accessibility without visual styles, so a project brings its own CSS or uses the separate styling packages the repository publishes. A project installs @kobalte/core with npm, pnpm, yarn, bun or deno. The package declares solid-js as a peer dependency, so the project supplies Solid itself. A locale provider component passes the locale and layout direction to the child components.

The [documentation](https://kobalte.dev/docs/core/overview/getting-started) is on kobalte.dev. Fabien Marie-Louise created the project, and the code is MIT licensed.
