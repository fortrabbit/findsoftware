Got is an HTTP request library for Node.js with a promise API and a stream API. It retries failed requests by default and supports advanced timeouts, pagination, RFC 7234 caching, proxies and Unix domain sockets, along with hooks, instances and plugins. Responses can be validated against a Standard Schema, and the package ships TypeScript types.

## Worth knowing

The package is native ESM and provides no CommonJS export. The README names Ky, by the same people, as the option that also works in the browser.
