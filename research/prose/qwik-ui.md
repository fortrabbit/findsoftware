Qwik UI is a component library for Qwik, in two kits. The headless kit provides components with no default styles, and the project manages their ARIA attributes, focus and keyboard handling. The styled kit is a design system of copy-paste, reusable components built on the headless kit; a command-line tool added to the project generates them.

The installation page covers the headless kit as an npm package and gives guides for Qwik City and Astro. The docs say the components suit a static marketing page, a server-rendered store or a client-rendered dashboard, and that Qwik UI decides for each function whether it runs on the server or the client.

## Worth knowing

The docs say the project is in its beta phase and expect breaking changes until the first stable release.
