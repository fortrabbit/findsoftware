Fine Uploader is a pure-JavaScript, browser-based file upload library. It offers image previews, drag and drop, progress bars and uploads to S3 and Azure storage. The getting-started tutorial documents three routes: npm, a download of the built files from GitHub releases, and a build from the source repository.

## Worth knowing

The README says the project is no longer maintained and has been effectively shut down, and the GitHub repository is archived. The documentation site named in the README does not resolve, so the docs link points to the tutorial in the repository.
