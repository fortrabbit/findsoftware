Akita is a state management library for JavaScript applications. Its docs describe a store that holds the state and a query that reads it, and the project's site says Akita is built on RxJS. The package is installed from npm with npm or yarn.

## Worth knowing

The README says the library is not maintained anymore and advises against using it. The GitHub repository is archived. The README recommends Elf, a newer state management library, which is not described here.
