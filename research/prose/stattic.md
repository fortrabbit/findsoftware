Stattic is a static site generator written in Python that converts Markdown content into static HTML websites using Jinja2 templates. Content lives in Markdown files with YAML frontmatter, and a `stattic.yml` file holds the site settings. The package is installed with pip or from a clone of the repository, and the `stattic` command builds the site into an `output` directory. Optional features in the README include RSS and sitemap generation, image conversion to WebP and asset minification.
