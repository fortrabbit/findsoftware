Hextra is a theme for Hugo that styles documentation, blog and other static websites with Tailwind CSS. Hugo builds the site, so a Hextra project is a Hugo project: the theme is added as a Hugo module or as a Git submodule, and setup needs Hugo (extended version), Git and Go installed. The [getting-started guide](https://imfing.github.io/hextra/docs/getting-started/) also points to a starter template whose GitHub Actions workflow deploys the built site to GitHub Pages. Because Hugo generates static websites, the output can go to any static host. Hextra supports Hugo's multilingual mode. The project is maintained by Xin.
