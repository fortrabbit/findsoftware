Bloggrify is a Nuxt layer for blogs, built on Nuxt Content. Content is Markdown files, and the layer adds pre-configured SEO modules, an RSS feed and integrations for analytics, newsletters and comments. The [installation guide](https://bloggrify.com/introduction/installation) creates a Nuxt application and adds the core package. The site is built as static files with `npm run generate`, and the output folder is deployed to a hosting provider.

## Worth knowing

The README lists a free theme next to two themes marked paid.
