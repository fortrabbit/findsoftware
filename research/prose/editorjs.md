Editor.js is a block-style editor that saves its content as JSON instead of HTML, with each block provided by a separate plugin. Developers install the `@editorjs/editorjs` package from npm or Yarn, load it from the jsDelivr CDN, or copy the file into their project, as the [getting-started guide](https://editorjs.io/getting-started/) describes. The editor has an internationalization API that localizes its core UI texts and those of its plugins through a messages dictionary. The project is written in TypeScript and maintained by CodeX, named in the copyright line of its license.
