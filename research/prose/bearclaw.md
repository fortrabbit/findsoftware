bearclaw is a static site generator written in Go that converts Markdown files into HTML. It is downloaded as a program and run from any folder. Markdown goes in, and the README says the HTML that comes out is ready for GitHub Pages or a personal server.

Plugins are HTML documents, delivered as zip files in a plugins folder and inserted into a Markdown page with a plugin comment.

## Worth knowing

The homepage named in the repository answers over plain HTTP only, so it is not linked here.
