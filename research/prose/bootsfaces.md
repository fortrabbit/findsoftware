BootsFaces is a JSF framework for building responsive enterprise web applications, based on Bootstrap and jQuery UI. It is a Java library published to Maven Central and added to a project's Maven or Gradle build file, as the [quick-start page](https://www.bootsfaces.net/quick-start.jsf) shows. That page names Glassfish, WildFly/JBoss and TomEE as the application servers it is tested on. The source is on GitHub under the Apache License.

## Worth knowing

The README says the project is not maintained actively, and a new version depends on a contributor's pull request. The quick-start page still describes the older Java EE and JSF stack, while the README requires Jakarta EE for the current release.
