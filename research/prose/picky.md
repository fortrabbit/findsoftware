Picky is a Ruby search library and server for semantic text search. Its indexes can be kept in memory as JSON files on disk, in Redis, or in SQLite. A running Picky server loads its in-memory indexes when it starts and removes them from memory when it stops. The gems are installed with gem install, and the generators produce a running server and client as a starting point. Florian Hanke maintains the project, and the documentation source sits in the repository.

## Worth knowing
