Content Hub ONE is a hosted content platform from Sitecore A/S for building and delivering content of any type to any channel. Business users manage content in the product's interface, and developers reach it through a GraphQL Preview and Delivery API and a REST Content Management API. The developer docs also describe a Client SDK, a command line interface and a starter kit for building a website.

Localization works through locales that an administrator creates, with localizations attached to each content item. What the Home page menu shows depends on the role a user has been assigned.

## Worth knowing

The product page that used to present Content Hub ONE now redirects to a page for SitecoreAI DAM, a digital asset management capability within SitecoreAI. The Content Hub ONE documentation is still published separately.
