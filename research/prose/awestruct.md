Awestruct is a Ruby framework for creating static HTML sites, inspired by Jekyll. Pages are written in lightweight markup such as AsciiDoc, Markdown or Textile, with Slim or Haml templates, and site-specific data is loaded from YAML files.

The generator is a Ruby program, so the machine that builds the site needs a Ruby installation. The output is static HTML, and the [deployment guide](https://awestruct.github.io/deployment/) lists GitHub Pages, an rsync and ssh server, and Amazon S3 as destinations.
