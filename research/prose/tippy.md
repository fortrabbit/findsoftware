Tippy.js is a JavaScript library that shows tooltips, popovers, dropdowns and menus next to an element on a web page. It is installed from npm, or loaded from unpkg with the core CSS that comes with the default unpkg import. The README names an official React wrapper as a separate package and an unofficial Ember wrapper, and neither is part of the library itself.

## Worth knowing

The GitHub repository is archived, so the source is no longer changed there. The npm package is not marked deprecated.
