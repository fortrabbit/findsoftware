Radix Icons is an icon set from the Radix project, designed by the WorkOS team. Each icon is published as a React component in the npm package @radix-ui/react-icons; the install page tells users to add the package from npm and import the icons they use by name into a React project.

The source lives in a GitHub repository, which is the source of the package the install page names. Its releases list is older than the npm package, so the npm registry is where the current release shows.
