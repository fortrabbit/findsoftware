Splinter is a Python API for scripting web browsers, most often in tests. It sits on top of existing browser automation tools such as Selenium and gives one interface for finding page elements and interacting with them, so the same script can run against different back ends. The back ends include Selenium for real browsers, and zope.testbrowser, the Django test client and the Flask test client for headless runs.

## Worth knowing

The minimum Python version the docs name is older than the versions listed in the package metadata, and the metadata itself states no Python requirement, so a reader should check the minimum against the version they install.
