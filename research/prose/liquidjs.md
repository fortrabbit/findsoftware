LiquidJS implements the Liquid template language in JavaScript and TypeScript. It can be used from Node.js, in browsers and from the command line. Its documentation describes compatibility with the Ruby implementation as a priority, so templates written for Shopify themes and Jekyll sites should work, apart from Shopify's business-logic tags and filters, which are meant to be plugins. Async operation is first-class.

## Worth knowing

The setup page says legacy browsers such as IE and Android UC may need a Promise polyfill.
