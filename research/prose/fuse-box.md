FuseBox is a bundler for JavaScript and TypeScript projects. It is installed with npm and configured in code, and the configuration can enable a development server. The project's README names a Slack workspace for discussion, which the record does not link.

## Worth knowing

The GitHub repository is archived. The README opens with a notice that the project has limited support and is used at the user's own risk. The domain in the repository metadata serves an unrelated site, so the record has no homepage.
