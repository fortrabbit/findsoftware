changedetection.io is a web application that watches web pages and reports when their content changes. It is written in Python and serves its user interface on port 5000 after a Docker or pip install. Watches, tags and notifications can also be managed through a REST API, and alerts go out through the Apprise library, which the README names as its notification layer.

## Worth knowing

The project's homepage sells a hosted subscription, operated by Web Technologies s.r.o.
