PostCSS is a tool for transforming CSS with JavaScript plugins. It is installed from npm and used through its JavaScript API, and its README also describes running it from the command line or npm scripts through a separate CLI package. It can compile a CSS string in the browser.

The [plugins list](https://github.com/postcss/postcss/blob/main/docs/plugins.md) in the repository names the plugins built on it, and the README says there are more than 200. The copyright holder named in the LICENSE is Andrey Sitnik, under the MIT License.
