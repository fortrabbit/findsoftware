UI5 Web Components provides custom HTML elements that follow the SAP Fiori design language. An application imports the component modules it uses from npm, and the browser registers each element when its module runs. SAP SE creates and maintains the project as part of the UI5 product family, and the homepage names Angular, React, OpenUI5 and Vue among the frameworks it works with.

## Worth knowing

The project states there is no CDN, so the components reach a page only through a bundled application. The docs site also keeps a legacy version line, separate from the current one.
