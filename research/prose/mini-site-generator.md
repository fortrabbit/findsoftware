Mini Site Generator is a static site generator in which each page is a JavaScript file named index.page.js that exports a function returning a string. The msg command saves each returned string as an HTML file of the same name. The [README](https://github.com/ijmccallum/Mini-Site-Generator/blob/master/readme.md) shows installing the package into a project or globally for use on the command line, and passing source and output folders with a flag.

## Worth knowing

The package has no GitHub release, and its npm page is the only published release.
