Sheetson is a hosted service that exposes a Google Sheet through a REST API. Its docs describe every Google Sheet as a database and each tab as a table, and the data stays in the user's sheet, which the API reads and writes. The service has no admin panel of its own, so the spreadsheet is the editing interface. Its comparison page names SheetDB, Sheety, Sheet.best, Sheet2API and Sheetsu.

## Worth knowing

The data stays in Google Sheets, so the sheet remains the source of every value the API returns.
