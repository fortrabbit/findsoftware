Tabler Icons is a set of SVG icons published as npm packages. The base package holds the raw SVG files, and framework packages in the same repository provide components for the same icons, among them React, Vue, Svelte, SolidJS, Astro and Angular. The icons are MIT-licensed.

## Worth knowing

A premium package of icons is sold next to the free set under a personal and commercial license. The homepage describes the free set as an open-source project and asks for an optional payment to support it.
