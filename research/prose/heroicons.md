Heroicons is a set of hand-made SVG icons from the team behind Tailwind CSS. The icons can be copied from the [website](https://heroicons.com/) as inline SVG markup, or installed from npm. The project also publishes first-party React and Vue packages that import each icon as a component.

## Worth knowing

The [README](https://github.com/tailwindlabs/heroicons) says the project accepts bug fixes but not new icons or support for other frameworks such as Svelte or SolidJS, and encourages others to publish their own icon libraries and framework packages.
