Joy UI is a React component library from MUI that follows a lightly opinionated design direction called Joy Design. It is installed with npm, pnpm or yarn, and the install command adds Emotion packages beside it. The [Joy UI documentation](https://mui.com/joy-ui/getting-started/) sits on the MUI website, and the source is in the material-ui monorepo on GitHub, which holds Material UI as well.

## Worth knowing

The project's own documentation says Joy UI is in beta and that its development is on hold. It also says the maintainers may not be able to respond to issues or pull requests in a timely manner.
