Kotsu is a starter kit for building static websites, with Nunjucks templates, Sass and a Webpack build. Its build writes static pages, and its Continuous Delivery guide serves the build folder from an nginx container. Local work runs with `npm start`, which the README gives for live coding, and i18n is handled through node-gettext. The kit runs on Node.js.

## Worth knowing

The repository is archived on GitHub, and the homepage named in the package metadata no longer resolves. The README describes the documentation as work in progress.
