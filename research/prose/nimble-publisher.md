NimblePublisher is an Elixir library that reads Markdown files from a directory and passes each file to a build function, which returns the entries as a module attribute. Each file can start with a map of metadata, and syntax highlighting uses Makeup highlighters chosen in the configuration. It is added to a project as a Mix dependency. Dashbit is the organization that owns the repository, and the documentation is published on HexDocs.

## Worth knowing

The repository has no LICENSE file. The Apache-2.0 license is stated in `mix.exs` and on the Hex package.
