ReactPage is an editor for web content, written in React, that lets content editors arrange components a developer supplies on a page. Content can be edited in several languages. Its README says it was formerly known as ORY Editor, and that the original library was created by aeneasr and ory.

## Worth knowing

The README opens with a notice that the project is looking for maintainers. An open issue on the repository says its author no longer has a project that uses ReactPage and could not keep maintaining it.
