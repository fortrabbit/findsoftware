Umi is a framework for building React applications, with routing based on React Router 6 and support for server-side rendering and static site generation. The [getting-started guide](https://umijs.org/en-US/docs/guides/getting-started) creates a project with create-umi, and the build writes to a dist directory that the guide says to deploy to a server.

The introduction describes the framework as plugin-based, with Umi itself composed of plugins.
