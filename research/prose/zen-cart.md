Zen Cart is an e-commerce application written in PHP for running an online shop. It is installed by uploading its files to a web server and then running the built-in installer, and the store owner's admin interface is part of the application.

A global group of shop owners develops and maintains it. The [plugin library](https://www.zen-cart.com/plugins) lists plugins contributed by the community, and the [documentation](https://docs.zen-cart.com) covers store owners and developers.

## Worth knowing

The [requirements page](https://docs.zen-cart.com/user/first_steps/server_requirements/) labels the latest release the final version of its line and lists the next line as in development.
