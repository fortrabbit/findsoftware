Skeleton Svelte is the Svelte component package of Skeleton, a design system built on Tailwind CSS. It is installed with npm next to the core Skeleton package, and the [SvelteKit install guide](https://skeleton.dev/docs/svelte/get-started/installation/sveltekit) covers setup. The components are maintained in a monorepo shared with the other Skeleton packages, and the Skeleton Labs organization maintains the project under the MIT license.

## Worth knowing

The Svelte package needs Svelte 5 and Tailwind CSS 4, which the documentation gives as the minimum tooling.
