neobrutalism components is a collection of components in a neobrutalism style, built on shadcn/ui and Base UI for React and Tailwind. Components are not installed from an npm package. They are published as a registry that the shadcn CLI can read, or they are copied into a project from the component pages.

Each component page links to the matching shadcn docs page where one exists. The docs say that the variants differ from the default shadcn components. A direction component passes a left-to-right or right-to-left reading direction to the Base UI components.

## Worth knowing

The repository has no tagged release, so its listing date is the newest commit on the default branch. The docs also say that a component page without a CLI command is installed by hand.
