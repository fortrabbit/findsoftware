ExDoc generates documentation for Erlang and Elixir projects from their API docs. Its README states that the HTML output is accessible offline and that ExDoc also produces Markdown and EPUB. An Elixir project adds ExDoc as a Mix dependency, or installs it as an escript with `mix escript.install`, and builds the documentation with `mix docs`. Erlang projects can use it through Rebar3 from Erlang/OTP 24. The project is maintained by The Elixir Team.

## Worth knowing

The README says documentation generated by ExDoc must include a visible link to the ExDoc repository on each rendered page, and that the generated contents fall under the licenses of the projects used to render them.
