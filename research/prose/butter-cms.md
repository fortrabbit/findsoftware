ButterCMS is a hosted headless content management system. Editors work in a dashboard, and content is delivered through a REST API whose endpoints the [API documentation](https://buttercms.com/docs/api/) describes. The features page describes a live preview of changes before they go live, roles, locale permissions and multi-site management.

ButterCMS runs as a managed service on Heroku and AWS, per its pricing page. The GitHub organization publishes API clients for several languages; none of them is the service itself.

## Worth knowing

Single sign-on is listed as an available add-on on the pricing page. The [pricing page](https://buttercms.com/pricing) also says a free start is possible with paid upgrades.
