Rodauth is an authentication framework for Ruby, loaded as a Roda plugin. It is designed to work in any Rack application and offers both an HTML and a JSON API for its authentication features. The README says it is built using Roda and Sequel but can be used with other web frameworks and database libraries.

## Worth knowing

The project's pages name Devise, Authlogic and Sorcery as other Ruby authentication frameworks and describe them as Rails-specific. Rails integration comes from the separate rodauth-rails gem, which the documentation lists.
