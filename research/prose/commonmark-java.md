commonmark-java is a Java library that parses Markdown according to the CommonMark specification into a tree of nodes, and renders that tree to HTML or back to Markdown. A visitor can inspect or change the tree before it is rendered. Extensions such as tables, task list items and front matter ship as separate artifacts and are added to the parser and renderer builders as a list.

## Worth knowing

The README says that for 0.x releases the API "is not considered stable yet and may break between minor releases". The library works on Android on a best-effort basis.
