Moq is a mocking library for .NET. A test creates a mock of an interface or a class, sets up its members with lambda expressions and verifies the calls made to it. The README says Moq uses Castle DynamicProxy internally to intercept those calls. The [quickstart examples](https://github.com/devlooped/moq/wiki/Quickstart) in the wiki show the API. The copyright holders named in the license text of the stable release are Clarius Consulting, Manas Technology Solutions, InSTEDD and contributors.

## Worth knowing

The default branch holds the upcoming major version, and its README says the current stable release is on another branch. The stable release and the default branch carry different license texts.
