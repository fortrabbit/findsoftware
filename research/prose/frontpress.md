FrontPress is an AngularJS front-end template for a WordPress site. It reads content through the WordPress REST API and renders it in the browser as a single-page app. It is installed with npm, Bower or a script from cdnjs. The author is recorded in the LICENSE as Teles.

## Worth knowing

The repository is archived on GitHub, and the project has no homepage of its own. The wiki pages the README links say the documentation is under construction. By default the homepage of a FrontPress site runs on a hash route, `/#!/`.
