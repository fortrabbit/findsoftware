Fancyapps UI is a toolkit of JavaScript components: Fancybox is a lightbox, Carousel is a slider, and Panzoom adds panning and zooming to HTML content. The package is installed from npm as @fancyapps/ui, or loaded from a CDN, as the [installation guide](https://fancyapps.com/fancybox/get-started/installation/) describes for Fancybox.

The Fancybox guide says the library can be used with frameworks such as React and Vue, or with plain JavaScript. The components ship in one package.

## Worth knowing

Every installation needs a valid paid license, whatever the project type, and the [pricing page](https://fancyapps.com/pricing/) lists Single, Extended and Business licenses. The repository holds the built distribution and type declarations, and no source folder.
