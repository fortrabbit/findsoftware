Symfony CLI is a terminal tool for Symfony applications. It creates new Symfony projects and runs a local web server for them with HTTPS support, and the docs list management of multiple PHP versions and Docker integration among its features. The README describes it as a tool for development on a local machine, and the CLI also integrates with Symfony Cloud, the hosted platform that runs on Upsun.

## Worth knowing

The download page lists the CLI next to Symfony Cloud, which is a hosted service; the CLI itself is the open source part, and the install routes cover shell installers, Homebrew, system package managers, a Docker image and direct downloads.
