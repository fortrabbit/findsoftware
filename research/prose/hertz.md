Hertz is a Go HTTP framework from the CloudWeGo project. It was originally a fork of fasthttp. A project is set up as a Go module, and the `hz` command-line tool, installed with `go install`, generates code. The server listens on an address once started, as the getting-started guide shows. CloudWeGo has no separate project domain for Hertz, so its homepage is the CloudWeGo docs site, which hosts the Hertz documentation.
