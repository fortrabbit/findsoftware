Mastra is a TypeScript framework for building AI agents and applications. A new project is created with `npm create mastra@latest`, and the framework's core package is `@mastra/core`.

The [Mastra documentation](https://mastra.ai/docs) describes the framework. The home page states that Mastra applications can be deployed to any Node.js-compatible environment, and it names Mastra Cloud as a deploy target. The repository is a monorepo, and its core license is Apache 2.0.

## Worth knowing

Code in the `ee/` directories is under the Mastra Enterprise Edition License, which the license file describes as source-available and not open source. The [pricing page](https://mastra.ai/pricing) lists an Enterprise edition with licensed self-hosted features next to the open source framework.
