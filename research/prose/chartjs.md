Chart.js is a JavaScript charting library that draws charts on an HTML5 canvas. A page can install it from npm for use with a bundler, or load a built file from a CDN. The docs say the GitHub download contains no prebuilt files, so the npm and CDN routes are the ones they describe for use. The docs also describe using it in Node.js for server-side generation of plots, with an npm canvas package such as node-canvas or skia-canvas.

## Worth knowing

The homepage calls the project community maintained, and the copyright line names Chart.js Contributors rather than a company.
