Enzyme is a JavaScript testing utility for React, published on npm as `enzyme`. It renders components for tests, lets a test find and traverse the output, and simulates events on it. The README's examples use Mocha and Chai, and its LICENSE names Airbnb, Inc. and contributors as copyright holders.

The README lists official adapters for React 16 and earlier, and names community adapters for Preact and Inferno.

## Worth knowing

The official adapters the README lists stop at React 16.
