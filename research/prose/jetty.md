Jetty is a web server and servlet container written in Java. Webtide is the company that develops it with support services as its funding, and the Eclipse Foundation hosts the project and holds the Eclipse Jetty trademark.

Jetty's operations guide describes installing it as a standalone server that deploys web applications. The download page offers zip and tgz archives, and the project's artifacts are published to Maven Central under the org.eclipse.jetty group, so Java projects can depend on them directly.
