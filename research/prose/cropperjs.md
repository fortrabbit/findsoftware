Cropper.js is a JavaScript image cropper that the project describes as a series of web components for image cropping. It is installed from npm as cropperjs. The repository is a monorepo, and the package the install guide names is one of its packages.

The project is licensed under MIT and maintained by Chen Fengyuan.

## Worth knowing

The default branch of the repository is the 2.x line. The 1.x line is kept on its own branch of the same repository.
