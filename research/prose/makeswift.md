Makeswift is a hosted visual builder for websites that run as Next.js apps. Marketers design pages and layouts in the builder, and the developer's app renders the React components through the @makeswift/runtime package, which the installation guide adds with npm. The command npx makeswift@latest init creates the app and links it to a Makeswift site.

Makeswift, Inc. is part of the group of companies that Commerce operates, according to its privacy policy.

## Worth knowing

The site runs either on Makeswift's default host or on a custom host the developer manages. The REST API reference describes management of sites, locales and pages.
