unite cms is a headless content management system built on Symfony that serves content through a GraphQL API. The repository holds a Composer project that depends on four bundles: core, Doctrine ORM mapping, admin interface and media handling. Franz Wilding is named as copyright holder.

## Worth knowing

The README states that there is no active development on the project, because its authors now focus on internal products. The documentation site named in the README shows only a placeholder, and the README says the docs for the current version are still under development.
