RunCloud is a hosted control panel for servers. Users connect servers they run at a cloud provider or on their own hardware, then manage web applications and databases on them from the RunCloud dashboard. The docs name NGINX and OpenLiteSpeed as web servers and PHP as the application runtime, and they cover MySQL and MariaDB databases. Teams can share a workspace, where roles define the permissions assigned to team members.

## Worth knowing

The panel itself runs on RunCloud's side. It installs an agent on each server the user connects.
