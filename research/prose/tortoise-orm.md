Tortoise ORM is an asyncio ORM for Python that maps model classes to SQL databases. Its README describes it as an Object-Relational Mapper with a Django-like API, and it is installed with pip, with extras for each database client. The package includes a migration framework and a command-line tool, and the [project docs](https://tortoise.github.io/) benchmark it against Piccolo, another Python ORM.

The source is on [GitHub](https://github.com/tortoise/tortoise-orm).

## Worth knowing

The docs call the project young and say breaking changes are to be expected.
