WOW.js is a JavaScript library that reveals elements with CSS animations as the user scrolls down a page. The repository is a fork of an earlier project, made to keep the library under the MIT license.

## Worth knowing

The npm package carries a deprecation notice on every published version, saying it is deprecated in favour of AOS (Animate On Scroll). The [README](https://github.com/graingert/WOW/blob/master/README.md) calls the deprecation temporary and tells readers to ignore the warning if they cannot use AOS.
