Grav Blackhole is a plugin for Grav CMS that writes a static HTML copy of a Grav website. It is installed through the Grav Package Manager or by unzipping the repository into the plugins folder. The generate command takes the URL of a live Grav site and writes the copy to an output path, and it can run from the command line or from the Grav Admin Panel.

## Worth knowing

The README says absolute URLs must be enabled in Grav System Configuration. The repository is archived and read only, and the README names no successor.
