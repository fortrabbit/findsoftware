NutUI is a Vue component library of mobile user-interface components in the JD style. Its README describes it as a library for H5 pages and mini-program development, and it is published on npm as @nutui/nutui.

The installation guide on the project's documentation site covers an npm install and a CDN script. The repository belongs to the jd-opensource organization, and the copyright line in its license names the JD front-end team.

## Worth knowing

The npm latest tag points to a beta release, so an install without a version pins a prerelease. The README lists server-side rendering as experimental.
