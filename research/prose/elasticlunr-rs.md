elasticlunr-rs is a partial port of elasticlunr.js to Rust, written to generate search indexes compatible with the JavaScript library. The README example adds documents with named fields to an index and writes the index out as JSON. Its crate is published on crates.io, and its source is on GitHub.

## Worth knowing

The README says the library is passively maintained to support existing users, and it names other libraries for new users to consider. Installation steps are not in the README or on docs.rs, so the record stays a stub until they are found.
