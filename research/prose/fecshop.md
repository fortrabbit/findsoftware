FecMall is an e-commerce system written in PHP on the Yii2 framework. The project was previously named Fecshop. It uses MySQL by default and can switch to MongoDB through the admin configuration. It has an admin area, and it is installed from a downloaded package with the web installer.

The [installation guide](https://www.fecmall.com/doc/fecshop-guide/develop/cn-2.0/guide-fecshop-2-graphical-install.html) also covers Docker and an Nginx or Apache domain configuration. Extensions are listed on the [app market](http://addons.fecmall.com).

## Worth knowing

The project's pages say its open-source development is complete. The same site sells several products under a paid license, and those are separate from the open-source system.
