DOM Testing Library is a JavaScript package for testing DOM nodes, the elements a page renders. Its queries look up nodes the way a user finds them on the page, and it installs from npm as a development dependency. The [documentation](https://testing-library.com/docs/dom-testing-library/intro/) sits within the wider Testing Library family.

## Worth knowing

The README says the DOM nodes can be simulated with jsdom, which Jest provides by default, or taken from a browser. Framework bindings such as React Testing Library are separate packages built on this one.
