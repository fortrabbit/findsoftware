Doctrine ORM is an object-relational mapper for PHP that provides transparent persistence for PHP objects. It sits on top of the Doctrine DBAL, as its README states. The [installation chapter](https://www.doctrine-project.org/projects/doctrine-orm/en/3.7/reference/configuration.html) shows Composer as the install route and a bootstrap that passes a DBAL connection to the entity manager. The Doctrine Project maintains it.
