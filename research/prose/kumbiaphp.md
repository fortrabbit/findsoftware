KumbiaPHP is an MVC framework for PHP that its homepage describes as a web and application framework in Spanish. The [installation guide](https://github.com/KumbiaPHP/Documentation/blob/master/en/to-install.md) has users download the compressed release and extract it, and a [second guide](https://github.com/KumbiaPHP/Documentation/blob/master/en/installing-kumbiaphp-apache-nginx.md) sets it up behind Apache or Nginx. The manual is available in Spanish and English.

## Worth knowing

Both installation guides describe the setup as a testing environment on a local server and say it is not recommended for applications deployed to production.
