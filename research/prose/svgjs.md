SVG.js is a JavaScript library for manipulating and animating SVG graphics, with no dependencies. Its source is in the svgdotjs organization on GitHub, and its documentation is on the [project site](https://svgjs.dev/docs/3.2/).

It can also run in Node.js. SVG.js ships no DOM of its own there, so the [Node.js page](https://svgjs.dev/docs/3.2/node-js/) has you register a DOM implementation such as svgdom first. A plugins page lists add-ons for the library.
