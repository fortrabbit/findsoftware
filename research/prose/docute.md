Docute is a documentation site generator with no build step. A JavaScript file fetches Markdown files and renders them as a single-page application in the browser, so a site is an HTML file plus Markdown documents served as static files from any host. It is built on Vue, and bundler use starts with an npm install. Multi-language sites are set up with a folder per language.

## Worth knowing

The README states that the project is no longer actively maintained, and the repository is archived. The list of official plugins lives in a separate repository.
