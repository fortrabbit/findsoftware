ScrollMagic is a JavaScript library for reacting to the reader's scroll position. The README names the GSAP and VelocityJS animation frameworks as optional companions, and the [documentation](https://scrollmagic.io/docs/index.html) covers the API.

## Worth knowing

The README says ScrollMagic v2 is no longer actively maintained and has been replaced by ScrollMagic 3.0, which is in beta.
