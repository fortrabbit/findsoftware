Vibe Design System is the official UI resource of monday.com for application development in React.js. Its core package, `@vibe/core`, is a component library that installs with npm or yarn. The repository also holds the packages for icons, testing, codemods and an MCP server.

The project is maintained by monday.com Ltd., which is headquartered in Israel.

## Worth knowing

The README says Vibe 3 receives only critical bug fixes and Vibe 2 is no longer maintained.
