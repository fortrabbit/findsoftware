Apollo Server is a GraphQL server that is added to a new or existing Node.js app. Its docs list Express, Fastify, AWS Lambda, Azure Functions and Cloudflare among the apps it runs in, so it runs inside a long-running server or is invoked per request, depending on that app.

## Worth knowing

The older npm package named apollo-server holds earlier major versions. That package is deprecated on npm, and the docs list those versions as end-of-life. This record covers the @apollo/server package.
