Zend Framework 1 Future is a community continuation of Zend Framework 1, a PHP framework. The README says the Zend Framework community has continued to work and build on ZF1, and the GitHub repository forks the upstream zendframework/zf1. It is installed with `composer require shardj/zf1-future` or by cloning the repository with git. The README points to the [original Zend manual](https://framework.zend.com/manual/1.12/en/manual.html) for documentation.

## Worth knowing

The upstream zendframework/zf1 repository is archived, and its description says the project reached end of life on 2016-09-28. The README says newer PHP versions can bring incompatibilities.

The license is stated two ways. GitHub reads BSD-3-Clause from the LICENSE file, and the README says the files are released under the Zend Framework license.
