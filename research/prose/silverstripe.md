Silverstripe CMS is a PHP content management system built on the Silverstripe Framework. A project is created with Composer from the installer template and runs on a web server, with content authors working in a browser-based interface.

The [server requirements](https://docs.silverstripe.org/en/6/getting_started/server_requirements/) name MySQL and MariaDB as the supported databases, and the [Composer guide](https://docs.silverstripe.org/en/6/getting_started/composer/) covers the create-project command.

## Worth knowing

PostgreSQL, SQL Server and SQLite are available only through third-party modules that the requirements page lists as community supported.
