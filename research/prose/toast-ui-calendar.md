TOAST UI Calendar is a JavaScript calendar component that shows schedules in monthly, weekly and daily views, and lets visitors drag and resize a schedule. It is installed from npm as a plain JavaScript component, and a creator can also load it from the NHN Cloud CDN. React and Vue wrappers are published as separate packages from the same repository.

## Worth knowing

The GitHub repository is archived, so the project is no longer developed there. The library applies Google Analytics and sends the hostname of the page that loads it, unless the creator turns that off as the getting-started guide describes.
