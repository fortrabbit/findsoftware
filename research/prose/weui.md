WeUI is a UI framework and stylesheet that reproduces the look of WeChat's native interface for mobile web pages. The WeChat Design Team designed it. A page loads the stylesheet from a CDN link, or the package is installed from npm as `weui`. The copyright holder is THL A29 Limited, a Tencent company, and the [documentation wiki](https://github.com/Tencent/weui/wiki) covers the installation routes.

## Worth knowing

The MIT license covers WeUI, but LICENSE.txt states that the third-party components it lists carry different license terms, so the terms of each component apply to that component.
