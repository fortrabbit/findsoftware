Twind generates the CSS for Tailwind-style utility classes while the page runs. The install page names the @twind/core npm package, and a CDN script is offered as an alternative. It is available as a global browser script and can be used directly in the browser. The project's comparison page sets it against tailwindcss, and the homepage describes feature parity with Tailwind. Sascha Tandel is named as the maintainer on npm.

## Worth knowing

The npm package named twind is deprecated and points users to @twind/core, which is the package the install page names.
