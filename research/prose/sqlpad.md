SQLPad is a web app for writing and running SQL queries against many databases and visualizing the results. Users sign in with one of two roles, and the docs describe sign-in through Google OAuth, OpenID Connect, SAML and LDAP. The Docker image is the route the project documents for running it, and building from the git repository with Node.js is the other.

## Worth knowing

The README heading says the project is archived and recommends forking it. The docs introduction says the project is in maintenance mode and will not be transferred to another owner.
