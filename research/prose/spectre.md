Spectre.css is a CSS framework with base styles for typography and elements, a flexbox layout system, and pure CSS components and utilities. A page includes the compiled stylesheet with a link tag, loads it from a CDN, or installs it with a package manager. The [installation guide](https://picturepan2.github.io/spectre/getting-started/installation.html) lists these routes, and the project's custom version page describes compiling a modified build with Sass or SCSS.

## Worth knowing

The project says it supports Internet Explorer 10 and later. Its maintainer describes the project as a side project and asks for donations through PayPal and Patreon.
