Cloudrexx is a content management system written in PHP. It has a content manager backend, multilingual websites with a fallback language, and user groups with individual access rights. The source is published as the open source project cloudrexx-oss on Bitbucket under the GNU Affero General Public License. The `cx env init` command sets up a local environment in Docker containers, and the [development documentation](https://dev.cloudrexx.com) describes the local setup.

## Worth knowing

Cloudrexx AG also sells Cloudrexx as a hosted service, and its documentation says the product does not require any installation in that form. The documented way to run the open source code is the local Docker environment. The newest tag in the repository dates from 2021, while its default branch was last updated in 2026.
