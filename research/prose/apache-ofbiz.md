Apache OFBiz is a Java suite of business applications, built on a framework with an entity engine, a service engine and a widget-based user interface. Its applications cover ERP, CRM and e-commerce, and they include administrator interfaces for the back office and for accounting. The Apache Software Foundation maintains it. The source is built with the Gradle wrapper, and the server then runs until it is stopped. The README describes setting up an external database such as MySQL or PostgreSQL.

## Worth knowing

OFBiz needs a full Java Development Kit on the machine that runs it. The README also documents a Docker setup.
