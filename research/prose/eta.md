Eta is an embedded JavaScript template engine written in TypeScript, with Ben Gubler as copyright holder. Templates use JavaScript inside `<% %>` tags, and the engine works inside Node, Deno and the browser. In Deno it is imported from JSR, and in browsers the core build is imported as a module script. Its homepage names EJS as the engine it is an alternative to.

## Worth knowing

The quickstart says the current release line is ESM-only. The README credits parts of the code to EJS, which is licensed under Apache-2.0.
