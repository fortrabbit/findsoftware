Flowershow publishes Markdown files and folders as websites, for docs, knowledge bases and wikis. Content goes up through a Go command line tool named `fl`, and the sites are served from a hosted address on flowershow.app. The web application is a Next.js app in a TypeScript monorepo, and the README describes a local development setup. Datopian maintains it.

## Worth knowing

The repository documents a hosted deployment on Vercel, Neon and Cloudflare R2, and no self-hosting guide for the web application. The record is a stub until the docs say whether one exists. Custom domains, removed branding and search sit in the hosted service's paid plan.
