Eclipse Vert.x is a toolkit for building reactive applications on the JVM. The project describes itself as a toolkit, not a framework. Applications are written in Java and add Vert.x with Maven or Gradle, and the Vert.x Web module adds the web layer: server-side template rendering with several template engines, and user, role and permission authorization. Separate client modules cover PostgreSQL, MySQL, MSSQL, Oracle, DB2, MongoDB and Redis.

## Worth knowing

The Get started guide states a JDK minimum, while the core manual says some features, such as virtual threads, need a newer Java release.
