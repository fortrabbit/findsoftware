Percona Server for MySQL is a database server that the [product page](https://www.percona.com/mysql/software/percona-server-for-mysql) describes as a drop-in replacement for MySQL Community Edition, with all applications and data fully compatible. Percona LLC maintains it under GPLv2 and sells support separately. It installs from Percona's APT, DNF and YUM repositories, from binary tarballs, or as a Docker image, and the server is started automatically after a package install. The [8.4 documentation](https://docs.percona.com/percona-server/8.4/index.html) and the [9.7 documentation](https://docs.percona.com/percona-server/9.7/index.html) cover two release lines side by side.
