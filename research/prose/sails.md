Sails is a web framework for Node.js that follows the MVC pattern and is built on Express. It ships blueprints that help start a backend without writing code, uses EJS views by default, and its data layer supports MySQL, PostgreSQL, MongoDB and Redis.

Apps are installed with npm and started with the sails command. For production, the [deployment guide](https://sailsjs.com/documentation/concepts/deployment) keeps the server running as a Node process and recommends a tool such as pm2 or forever to keep it up.

## Worth knowing

The legal page names two offerings beside the open source framework: a hosted platform called Treeline IDE and a support service called Sails Flagship. This record describes the framework only.
