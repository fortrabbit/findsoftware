imagemin is a Node.js library for minifying image files and image data. Its main function takes file paths or glob patterns and an optional destination folder, and passes each file through the plugins listed in the options; the buffer function does the same for image data in memory. The optimization is done by plugins, which the [README](https://github.com/imagemin/imagemin/blob/v9.0.1/readme.md) links through an npm keyword search.

A separate package, imagemin-cli, provides a command line tool for the module, as the README's Related section states.
