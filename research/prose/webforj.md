webforJ is a Java framework for building the user interface of a web application in Java. Apps are scaffolded from Maven archetypes or with the startforJ wizard, and they deploy as a WAR to a servlet container such as Jetty or Tomcat, or as an executable JAR with an embedded Tomcat under Spring Boot. Routes can require a role through security annotations, and the framework includes a built-in translation system for localized strings. The framework is MIT-licensed on GitHub and is maintained by BASIS International Ltd., as the company's [imprint](https://webforj.com/imprint/) states.

## Worth knowing

An app that has no license certificate runs with a watermark on its interface. The pricing page lists paid Business (LTS+) and Enterprise (LTS++) plans beside a no-fee plan under the NFTC license, so a reader choosing a commercial setup should read the [pricing page](https://webforj.com/pricing/) for the terms that apply to their use.
