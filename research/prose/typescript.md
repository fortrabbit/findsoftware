TypeScript is a programming language that adds static types to JavaScript. Its compiler, `tsc`, checks typed code and converts it to JavaScript, which runs wherever JavaScript runs. The compiler is installed per project from npm, and MSBuild projects can use a NuGet package or a Visual Studio extension instead. The npm package starts native binaries built for each platform, and its launcher still needs Node.js. Microsoft Corporation publishes the language and its source in the [TypeScript repository](https://github.com/microsoft/TypeScript).

## Worth knowing

The repository's README says code changes there are limited to a small category of fixes, and most bug fixes for the compiler go to the typescript-go repository.
