Griffin is a static site generator written in Java that publishes Markdown posts through Handlebars themes. Its releases are zip files: the zip is unpacked and the `bin` folder is added to the PATH. Posts are written as Markdown files, and the output is written to the folder that the configuration names. An embedded server previews the site. The [wiki](https://github.com/pawandubey/griffin/wiki) is the project's documentation.

## Worth knowing

The wiki's contributing page says Griffin is in early stages of its development.
