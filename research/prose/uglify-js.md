UglifyJS is a JavaScript parser, minifier, compressor and beautifier toolkit, written in JavaScript. It is installed from npm, either as a command-line app that runs on the developer's machine or as a package that Node.js code requires. The source and its [repository](https://github.com/mishoo/UglifyJS) are public, and the copyright line names Mihai Bazon.

## Worth knowing

The project's homepage says its pages are old and describe an earlier major version, and it points readers to the repository for documentation of the current one.
