DatoCMS is a hosted headless content management system with a hosted web app for editors. Content is read through a read-only GraphQL Content Delivery API, and the management API follows the JSON:API specification. Each field can be localized on its own, with fallback locales and locale-based publishing. Official npm packages cover the management API and a command-line tool, and integration guides exist for Next.js, Nuxt, SvelteKit, Astro and React Router.

The open-source repository holds the JavaScript API clients. The service itself is not open source.
