Jahia is a content management and digital experience platform written in Java. Editors work in a visual content editor, and one installation can run several multilingual sites. The supported stack names Apache Tomcat 9.0.x as the application server, with PostgreSQL, MariaDB, MySQL, Microsoft SQL Server or Oracle as the database.

The [Jahia Academy](https://academy.jahia.com/home) holds the tutorials, documentation and downloads. A Docker image for developers provides a trial installation. The company Jahia Solutions Group SA, with its head office in Geneva, Switzerland, maintains the project. Jahia Cloud is the hosted option, and the customer chooses where servers and data are hosted: France, Ireland, North Virginia or Singapore.

## Worth knowing

The repository is licensed under a dual license: Apache 2.0 or the Jahia Sustainable Enterprise License (JSEL). Under JSEL, commercial use takes effect only after a document signed with the company, and the enterprise distributions need a separate written agreement. The pricing page lists Enterprise plans next to the community download. The Docker image gives a 30-day trial, after which the page says to contact Jahia about licensing.
