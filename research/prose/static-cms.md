Static CMS is a content editor for sites whose content lives in a Git repository. It is a single-page React application added to the `/admin` folder of a site built with a static site generator. It can load from a CDN with one HTML file and a configuration file, or be bundled with npm. Its web interface includes rich-text editing, real-time previews and drag-and-drop media uploads, and the docs list GitHub, GitLab, Bitbucket and Gitea backends. It is a fork of Decap CMS, formerly Netlify CMS.

## Worth knowing

The repository is archived. The README says the decision "was made to cease development" and names Decap CMS and Tina CMS as alternatives.
