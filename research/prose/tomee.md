Apache TomEE is a Jakarta EE application server that extends Apache Tomcat and is assembled from a Tomcat zip file. The project ships four flavors, Web Profile, MicroProfile, Plus and Plume, as zip and tar.gz archives. Its Linux service guide runs TomEE as a systemd service. The Apache Software Foundation maintains it under the Apache License.

## Worth knowing

The download page says the project is developed and maintained by unpaid volunteers, and it gives no guarantee that security vulnerabilities will be fixed.
