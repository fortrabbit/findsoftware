Quintype is a hosted platform that its homepage describes as a digital experience platform for publishers. The developer documentation describes its CMS as a headless publishing system with a REST API reference. Editors work in a publishing workspace, can preview stories as they build, and assign roles and permissions to users. The about page names Quintype Technologies Inc. as a media-tech company headquartered in New York. The homepage links comparison pages against WordPress, Drupal, Blox Digital and Naviga.

Malibu, which the developer pages describe as a front-end framework for building sites with Quintype, is documented alongside the platform and is a separate client.

## Worth knowing

No self-hosted install is documented on the pages read, so the platform is used as the vendor's service. The terms name an Indian contracting entity and Indian law.
