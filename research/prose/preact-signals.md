Preact Signals is a state management library in which a signal holds a value and the code that reads the signal updates when the value changes. The [Signals guide](https://preactjs.com/guide/v11/signals/) describes signals as reactive primitives for managing application state. The README says signals integrate into frameworks as built-in primitives: a component reads a signal directly, without selectors or wrapper functions, and re-renders when the value changes. The core library is framework-agnostic, and the Preact and React packages integrate it into those frameworks.

## Worth knowing

The GitHub repository holds several packages, including the Preact and React integrations, so its star count and contributor count cover all of them.
