Swoft is a PHP microservices framework based on the Swoole extension. Its [README](https://github.com/swoft-cloud/swoft/blob/v2.0.11/README.md) describes it as resident in memory and independent of PHP-FPM, with a connection pool for MySQL, Redis and RPC and built-in internationalization support.

## Worth knowing

The project runs as a long-lived process rather than per request, so the host has to keep it running. The homepage and both documentation sites named in the README did not load when checked, so the README is the only project page this record rests on.
