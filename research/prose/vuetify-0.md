Vuetify0 is a headless set of components and composables for Vue, distributed as the @vuetify/v0 npm package. A new project starts from a scaffolding command, and an existing Vue project adds the package with npm install, as the [getting-started guide](https://0.vuetifyjs.com/introduction/getting-started) shows.

A locale provider component covers internationalization, and the project's chat runs on its Discord community.
