SheetJS is a JavaScript library for reading, editing and exporting spreadsheet files in web browsers and on servers. Its source moved from GitHub to its own Git server, and the GitHub repository is a mirror that stops at an older release.

The project installs from its own CDN. The Node.js package is a tarball that a package manager installs from a URL, and the same CDN serves a standalone script for browser script tags, an AMD build and an ExtendScript build. The docs also describe Deno and Bun support as experimental. The npm registry copy of the package is out of date, and the install docs treat the CDN as the authoritative source.

## Worth knowing

A SheetJS Pro edition sits beside the Community Edition; its listed features include cell, column, table and worksheet-level styling.
