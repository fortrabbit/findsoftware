ExpressionEngine is a self-hosted content management system written in PHP. It runs on MySQL or Percona and is installed from a [packaged release](https://github.com/ExpressionEngine/ExpressionEngine/blob/7.dev/README.md), or from the repository with Composer. The [requirements page](https://docs.expressionengine.com/latest/installation/requirements.html) lists what the host needs. Editors work in a control panel, and site pages are built from HTML templates that use ExpressionEngine's own template tags.
