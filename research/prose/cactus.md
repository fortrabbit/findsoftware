Cactus is a Python static website generator that uses the Django template system. The `cactus build` command writes the generated site into a `.build` folder, which the README says can be uploaded to any host, and `cactus serve` runs a small local web server to preview it. The README says the site can be deployed directly to Amazon S3, and it installs with easy_install.

## Worth knowing

The site the README names as the Cactus app site does not resolve, and the GitHub homepage field is empty, so the record is marked stub. The repository has no GitHub release, so the version and release date come from the PyPI package of the same name.
