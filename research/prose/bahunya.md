Bahunya is a classless CSS framework: a page written in semantic HTML is styled without adding framework classes or IDs. Dark is the default theme, a bundled light theme is selected with a `data-theme` attribute on the root element, and CSS custom properties can be overridden for a custom theme. Hakan Alpay created it and credits Tacit and Water.css as inspiration.

The stylesheet is added with one CDN link, which jsDelivr serves from the `dist/` folder committed in the repository. The [README](https://github.com/Kimeiga/bahunya/blob/master/README.md) gives the link, and no npm package exists for it.

## Worth knowing

The project has no tagged release, so the CDN link follows the repository's current files rather than a pinned version.
