Open Server Panel is a portable local web server for Windows that a developer runs on their own machine. It bundles web servers and databases, among them MySQL, MariaDB, PostgreSQL and MongoDB, and a control panel for them. The Windows installer is downloaded from the project's site, which names an individual entrepreneur in Belarus as its operator.

## Worth knowing

The project states two license terms. The repository carries the MIT License, and the site's license agreement grants free use without license fees for an unlimited time. The site describes the project as non-commercial and free of charge; its paid items are voluntary support and a paid download-speed service.
