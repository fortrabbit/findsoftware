Gin is a web framework written in Go. It is added to a Go module with go get and runs its own HTTP listener: router.Run listens on port 8080 by default. HTML pages use Go's html/template package. The [quickstart](https://gin-gonic.com/en/docs/quickstart/) shows the first API route and the run command.

## Worth knowing

The documentation names several hosted platforms that deploy Gin projects, including Railway, Render and Google App Engine; these are third-party services, and the docs also say projects can be self-hosted.
