laminas-db is a PHP database abstraction layer from the Laminas project. It gives an application an object-oriented API for building SQL statements, adapters for several database drivers, result sets, and table and row data gateways. It is installed with Composer and is one of the components of the Laminas project, which the docs site lists under components for enterprise applications.

## Worth knowing

The package is in security-only maintenance mode. Its README calls it feature-complete, so it receives critical security fixes and no new features. The README asks anyone who wants to take on the maintainer role to nominate themselves.
