SolidUI is a collection of components for Solid, written in TypeScript. The project describes its components as re-usable code that a user copies into their own apps, not a package installed as a dependency. The components are built with Kobalte and corvu and styled with Tailwind CSS. The [CLI guide](https://www.solid-ui.com/docs/cli) describes the command that adds components to a project.

## Worth knowing

The project calls itself an unofficial port of shadcn/ui and tremor-raw to Solid. The installation guides have a project set up Tailwind CSS before the CLI runs, so a project that copies a component also takes on the Tailwind setup.
