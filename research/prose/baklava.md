Baklava is Trendyol's design system, built as native web components with [Lit](https://lit.dev). The [README](https://github.com/Trendyol/baklava/blob/v3.5.0/README.md) says they can be used within web frameworks including Vue, React or Angular, and describes loading the library from a CDN with a script and a stylesheet link as the preferred way. The package is also published on npm as `@trendyol/baklava`.

The documentation is a Storybook site, and the repository has a discussion board.
