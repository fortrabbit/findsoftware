Font Awesome is an icon library that a page uses by adding a class for the style and the icon name to an HTML element, such as `fa-solid fa-user`. The icons are delivered as web fonts, SVG files and CSS, and the JavaScript packages place them as SVG. The quick start loads a Kit, a script that Font Awesome serves from its own domain, while the packages page recommends a Kit package for projects that use a package manager. The docs also describe hosting the files on the project's own server.

## Worth knowing

Some styles and icons need a Pro or Pro+ subscription. The docs say Pro+ icons reach a page only through a Kit package, so a project that wants them depends on the hosted Kit service or on a downloaded Kit package. The free icons and the core toolkit are available through npm and the other install routes without a subscription.
