SuperAgent is an HTTP request library that runs in a browser and in Node.js with the same API. The homepage calls it an ajax API that also works with Node.js. Its README says it is extended through plugins, and names several of them.

The README says the project is maintained for Forward Email and Lad. The browser build is published on jsDelivr and unpkg, so a page can load it from a CDN, and the same package installs from npm for a bundled project. The [documentation site](https://forwardemail.github.io/superagent/) shows the request API.
