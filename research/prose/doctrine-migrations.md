Doctrine Migrations is a PHP library for versioning a database schema and deploying changes to it. It is built on top of Doctrine DBAL, and the [introduction](https://www.doctrine-project.org/projects/doctrine-migrations/en/3.9/reference/introduction.html) names two ways to install it: with Composer, or by downloading the PHAR file from the GitHub releases page. The Doctrine Project maintains it.
