ViewUI is a Vue.js component library of UI components for building web application interfaces, published on npm as `view-design`. The repository is the original iView project: its README says the original author continues development and maintenance under the new name. The library is installed with npm or loaded with a script tag for global use, and the [installation guide](https://www.iviewui.com/docs/guide/install-en) is linked from the README.

## Worth knowing

No release has come out in the last four years. The README still describes the project as maintained.
