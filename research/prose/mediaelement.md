MediaElement.js is an HTML5 audio and video player library. It gives the browser's media elements one API, so the same player works for MP4, WebM and MP3 files, for streaming sources such as HLS and DASH, and for embedded players.

The installation guide covers adding the script and stylesheet to a page and the [documentation](https://github.com/mediaelement/mediaelement/tree/master/docs) is kept in the main repository. Extra features live in a separate plugins repository, which the README links.
