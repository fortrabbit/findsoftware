Ember.js is a JavaScript framework for building web applications. It includes a built-in router and Ember Data as its data layer, and a test harness that generates tests for each entity. Apps are created with Ember CLI, which is installed with npm. The production build writes a `dist` folder of browser-ready JavaScript, styles and HTML, which the [quick start guide](https://guides.emberjs.com/release/getting-started/quick-start/) says is ready to upload to a web host.

The core package, ember-source, is maintained by Yehuda Katz, Tom Dale and Ember.js contributors under the MIT license.
