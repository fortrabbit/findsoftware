oauth2-server is a PHP library that implements an OAuth 2.0 authorization server. It lets an application issue access tokens to clients, lets an API check them, and supports the authorization code, client credentials, device authorization, implicit, refresh and resource owner password credentials grants. The README names RFCs 6749, 6750, 7519, 7636 and 8628 as the specifications it implements.

The package is installed with Composer and needs the openssl and json PHP extensions. Alex Bilbie created the library. The README credits Andy Millington as its principal developer and maintainer.

Community integrations named in the README include Drupal's simple_oauth module, Laravel Passport and a Symfony bundle. They sit beside the library in the README, which does not describe them as built on it.
