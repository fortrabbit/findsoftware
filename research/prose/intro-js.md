Intro.js adds step-by-step tours and hints to a page, which highlight elements for the user. The project describes itself as an open source vanilla JavaScript and CSS library, and its documentation lists wrappers for several frameworks, including React, Angular, Ember and Rails.

## Worth knowing

Use in a commercial app, website or plugin needs the project's commercial license, which the project sells as a one-time lifetime license. The open source license is the AGPL.
