tsoa generates an OpenAPI specification and API routes from TypeScript controllers and models, so the types in the code describe the API. The README says parameters and model properties are marked required or optional from their TypeScript types, and that routes are generated for Express, Hapi, Koa and Fastify. Other middleware can be supported with a Handlebars template. The [getting started guide](https://tsoa-community.github.io/docs/getting-started) installs the package with Yarn next to Express, then walks through a tsoa.json configuration and a first controller.
