Zesty.io is a hosted headless and hybrid content management system. Each site is a cloud content instance with its own schema, web views and APIs, and editors manage its content in the Manager UI. Developers read content through a REST Instances API and a GraphQL endpoint set that is switched on in the Manager UI, and an instant API returns read-only JSON. Views are written in Parsley, Zesty's templating language, and WebEngine, a server-side rendering origin, can serve full HTML pages from them. Content can be kept in several languages per instance.

## Worth knowing

Zesty.io is a hosted service. The docs name one deployment variant beyond the shared cloud, a Private Cloud in which customers own and operate portions of the architecture that manage data. Single sign-on is listed on the Enterprise plan only.
