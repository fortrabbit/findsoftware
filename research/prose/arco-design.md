Arco Design is a React UI components library built on the Arco Design system. It is published on npm as @arco-design/web-react, the package the README's install steps name, and can also be loaded from a CDN as a UMD build. Component texts are written in Chinese by default, and other languages are set through the ConfigProvider component.

The README links the [components documentation](https://arco.design/react/docs/overview) and names a Design Lab, a Material Market, an Icon Box and Arco Pro on arco.design beside the library.

## Worth knowing

The Vue library, Arco Design Vue, is a separate repository and package and is not covered by this record.
