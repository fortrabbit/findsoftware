TanStack Store is a reactive data store that is not tied to one UI framework. The core package holds the state, and adapters connect it to the components of a framework so that they update when the state changes. The [installation guide](https://tanstack.com/store/latest/docs/installation) says the store installs with any npm package manager and lists one adapter per framework, including React, Vue, Svelte, Solid, Angular, Preact, Lit and Octane.

## Worth knowing

The React adapter works with ReactDOM only, and the guide says no React Native adapter is offered yet.
