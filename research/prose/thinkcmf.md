ThinkCMF is an open-source content management framework in PHP, built on ThinkPHP, with an app center in its back office. It can run under PHP-FPM, where PHP starts per request, or in a Swoole mode, where a server process keeps running and handles requests. The site is served from the `public/` directory of the installation, with URL rewriting enabled.

The [download page](https://www.thinkcmf.com/download.html) lists Composer, a zip download and Docker as install paths. The README names the Gitee repository as the main one and describes the GitHub repository as an overseas mirror. A Chinese company, 上海耐澄生物科技有限公司, states on the about page that it develops and operates the project.

## Worth knowing

The README calls the next development version unfit for production and points to the latest stable release instead.
