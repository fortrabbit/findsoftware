BlogDown is a markdown blogging platform built with Polymer. It is back-end agnostic and needs no compilation. The README describes installation as unzipping a release archive on a server, and a Docker image is also named. Jam Risser wrote it.

## Worth knowing

The README marks the project as beta and carries notes from a 2026 revival that kept it as a working historical artifact. The demo domain does not resolve, and the README says so. The npm package named blogdown and the R package of the same name are different projects.
