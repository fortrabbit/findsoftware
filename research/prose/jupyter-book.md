Jupyter Book turns Markdown files and Jupyter notebooks into books, documents and websites, and runs the code cells in them during the build. It is built on the MyST Document Engine and installs from PyPI, conda-forge or npm. A build writes a folder of static HTML that any static web host can serve, and the README also names a PDF output. The Jupyter Book Project develops it as an official sub-project of Jupyter, and questions go to its Discord server or its GitHub discussions.

## Worth knowing

The live site needs no runtime, only the machine that runs the build does. The earlier Sphinx-based line of the project is in maintenance mode, according to the project's FAQ, and has its own documentation.
