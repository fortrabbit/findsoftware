Flotiq is a hosted headless CMS operated by Codewave Sp. z o.o., which has its registered seat in Wrocław, Poland. Editors work in a web admin panel with roles for admins, editors and viewers. Developers read content through REST and GraphQL APIs, and plugins extend the panel: official ones include multilingual content and a live preview that shows content updates before publishing. Content from WordPress or Contentful can be moved in with Flotiq CLI commands, and single sign-on through Active Directory is documented for the Enterprise plan.

## Worth knowing

Flotiq is a hosted service. The pricing page describes a custom plan that adds on-premise and hybrid deployment options. API calls are counted per month against the plan, and the free plan has a monthly quota.
