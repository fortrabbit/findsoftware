Phenomic is a website compiler whose renderer and bundler are plugins. The documentation names React and Webpack as examples of each, and the CLI is installed as a local development dependency of the project.

Its output is static files, so any static host can serve it and the server needs no runtime. Content files are read from the filesystem.

## Worth knowing

The repository is archived, and its README opens with a note that the project is deprecated in favor of Next.js. The homepage does not show that note.
