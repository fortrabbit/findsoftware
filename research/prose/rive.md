Rive Web Runtime plays Rive animation files in a web page. It is a JavaScript and WebAssembly runtime library, with a high-level API for hooking up interactions and animations and a low-level API for driving your own render loop.

## Worth knowing

Rive files are authored with the Rive CLI or the Rive Editor, which are separate products from the runtime, and the MIT license covers the runtime only. Writing the file that ships on a site needs a free Rive account, and free exports play a short Rive splash screen.
