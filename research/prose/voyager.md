Voyager is a Laravel admin package that adds BREAD (browse, read, edit, add, delete) operations to a Laravel application, with a media manager and a menu builder. Composer installs it with `composer require tcg/voyager`, and `php artisan voyager:install` completes the setup.

## Worth knowing

The maintainers have archived Voyager, and the README says it "will not be receiving any more updates". The README names Wave, FilamentPHP and Genesis as alternatives. The GitHub repository is archived and the Packagist package is marked abandoned. The README says the package supports Laravel 8 and newer.
