TanStack Table is a headless library for building data grids. It supplies the table logic, and the application supplies the markup, components and styles. The framework-agnostic core package has adapters for React, Preact, Octane, Vue, Solid, Svelte, Angular, Ember, Lit and Alpine, and the [installation guide](https://tanstack.com/table/latest/docs/installation) asks you to install the adapter for your framework with your preferred package manager. The guide also says the core can be used directly to write an adapter for another framework.

The docs describe using the library with TanStack Query for server-side pagination and sorting.
