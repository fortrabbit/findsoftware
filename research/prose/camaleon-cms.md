Camaleon CMS is a content management system for Ruby on Rails, added to a Rails application as a gem and set up with a Rails generator. It works with PostgreSQL, MySQL and SQLite, and it includes an admin interface that its homepage describes as familiar to users coming from WordPress. One installation can serve several sites and several languages, and the CMS has user roles. The [documentation](https://camaleon.website/docs.html) covers installation and configuration, and plugins and themes are published in the project's own stores. Owen Peredo Diaz is named as the author, and the project is under the MIT License.

## Worth knowing

The free core is open source, and the plugin and theme stores also list paid add-ons, such as a visual editor and some themes. The README requires Rails 6.1 or later and ImageMagick.
