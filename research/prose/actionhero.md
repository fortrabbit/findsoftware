Actionhero is a framework for API servers, written in TypeScript and run on Node.js. One application can serve HTTP, WebSocket and other transports, and the project describes it for stateless and stateful applications. The project site names Keryx, at keryxjs.com, as its successor.

## Worth knowing

The application is a long-running Node process, so it needs a host that keeps a server process running rather than one that serves static files.
