Vuex is a state management pattern and library for Vue.js applications. It keeps a centralized store that all components in an application share. The homepage and the README say the official state management library for Vue has changed to Pinia, and that Pinia is now the new default.

## Worth knowing

The maintainers say the current Vuex lines will still be maintained but that new functionality is unlikely, and they highly recommend Pinia for new projects. The README says Vuex and Pinia can be installed in the same project.
