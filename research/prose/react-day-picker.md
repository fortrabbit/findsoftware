React DayPicker is a React component for date pickers, calendars and date inputs. It is published on npm under two names: new projects are told to install @daypicker/react, and the older react-day-picker name remains available for compatibility.

The component relies on date-fns for date handling. Besides localization, its docs cover the ISO 8601, broadcast, Persian, Hijri, Buddhist, Ethiopic and Hebrew calendar systems.
