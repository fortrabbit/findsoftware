aaPanel is a web control panel that runs on a Linux server and manages its websites from a browser. The homepage lists website management, WP Toolkit for WordPress, mail servers, FTP, MySQL, file management and Docker containers. The panel is written in Python and installed with a shell script. The project's installation notes list several interface languages, and its homepage says a cPanel site can be moved to the panel for WordPress sites and SSL certificates.

## Worth knowing

The source is covered by the AAPANEL Open Source License Agreement, which is not a standard open source license. It allows use for profit or non-profit work and changes for personal use, bars publishing modified copies, and bars encrypting or obfuscating the source. Accounts for multiple users and shared hosting are part of the paid Pro edition, which the install page calls the paid version of aaPanel.
