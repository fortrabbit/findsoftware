openapi-typescript generates TypeScript types from an OpenAPI 3.0 or 3.1 schema, read from a local or remote JSON or YAML file. A project imports the generated types for its paths, parameters and responses. The project's homepage describes the output as static types with no runtime cost. The tool runs on Node.js from the command line while a project is developed, and nothing of it runs on the live site.

## Worth knowing

The Node.js version in the introduction is a recommendation of 20.x or higher, not a stated minimum. The repository holds more than one package, so its star count and contributor count cover all of them.
