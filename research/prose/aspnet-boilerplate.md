ASP.NET Boilerplate is an application framework for ASP.NET Core with a layered architecture based on domain-driven design, a module system and multi-tenancy. It is distributed as NuGet packages, the core one being Abp, and the [README](https://github.com/aspnetboilerplate/aspnetboilerplate) lists the packages for each part. Volosoft is named as the maintainer in the MIT license.

## Worth knowing

The [end-of-support page](https://aspnetboilerplate.com/endofsupport) says the framework moves out of active development and receives no updates after May 12, 2026, yet the repository published a release afterwards, so the record is a stub. The same page names ABP.IO as its successor, and ASP.NET Zero, a commercial product built on this framework, is separate.
