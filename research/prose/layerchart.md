LayerChart is a set of Svelte components for building charts. The layers a chart is drawn on can be SVG, Canvas or HTML. The library covers cartesian, radial and polar, hierarchical, graph, geographic and calendar charts, with tooltips, brushing and pan and zoom. The package is installed from npm into a Svelte project. The repository is a monorepo that also holds a companion library, Svelte UX.

## Worth knowing

The library no longer requires Tailwind CSS. Rendering charts to PNG or JPEG images on the server needs a native Node.js canvas library.
