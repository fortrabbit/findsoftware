NgRx is a state management library for Angular applications. The [Store guide](https://github.com/ngrx/platform/blob/main/projects/www/src/app/pages/guide/store/index.md) describes the Store as RxJS powered global state management, inspired by Redux. The repository is a monorepo that also holds the effects, signals, router and devtools packages, and the project says it is community-driven.
