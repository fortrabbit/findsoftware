Mockery is a PHP mock object framework for creating test doubles in unit tests. Its documentation describes it as usable with PHPUnit, PHPSpec or any other testing framework. It is installed as a development dependency with Composer, or by cloning its repository. The project describes itself as a drop-in alternative to PHPUnit's phpunit-mock-objects library and says it can run alongside that library.

## Worth knowing

The README says some of Mockery's internals are private and may change at any time, so a class that is not final, or a method that is not private, is not necessarily part of the API the versioning scheme covers.
