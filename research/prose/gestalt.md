Gestalt is Pinterest's design system. It includes a React component library, which the README says is installed from npm with `npm i gestalt --save`.

The [homepage](https://gestalt.pinterest.systems/) describes the system, and the source is in the [pinterest/gestalt repository](https://github.com/pinterest/gestalt).

## Worth knowing

The repository README opens with a notice that the project is no longer actively maintained and has reached end of life.
