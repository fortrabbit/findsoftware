Clusterize.js shows a large list or table in a scrolling container without placing every row in the page. It keeps the rows near the scroll position in the DOM and adds spacer rows above and below, so the scrollbar matches the full list. Rows can be passed as an array of markup strings, or the markup already on the page can be used. The container can be a table, an ordered or unordered list, or a set of divs. The library is a script with a separate stylesheet, and its homepage is the demo and usage guide.
