Laragon is a development environment for Windows that runs web servers, databases and language runtimes from a portable folder. Everything lives in the Laragon folder, so the setup can be moved to another machine by copying it. The Windows installer is the download on the project's site, and the project's creator is Leo Khoa.

The software is distributed as a binary; the GitHub repository holds the Windows executable and its configuration, not source code. It supports Windows 10 and 11.

## Worth knowing

Laragon is proprietary software. A free tier allows non-commercial use with a reminder, and commercial use requires a paid license. From release 7.x on, the project's README states that a license is required to use Laragon.
