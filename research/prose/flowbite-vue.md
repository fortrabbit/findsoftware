Flowbite Vue is a set of Vue 3 components styled with Tailwind CSS utility classes and the Flowbite plugin. The quickstart installs flowbite next to flowbite-vue, imports the package stylesheet and registers the Flowbite plugin in the CSS file. The license file names Themesberg (Crafty Dwarf LLC) as the copyright holder.

The package also ships a Nuxt module that registers the components and the toast composable and injects the stylesheet, so a Nuxt project needs no import statements for either.

## Worth knowing

The README says the documentation is not finished and points readers to the Flowbite site for component pages. The quickstart and the package manifest give different Node minimums, so check the engines field before a build.
