ClassicPress is a fork of WordPress that leaves out the block editor and keeps the classic editor. The [installation guide](https://docs.classicpress.net/installing/) covers a fresh install on a host with a MySQL or MariaDB database, and the migration of an existing WordPress site to ClassicPress.

## Worth knowing

GitHub states the license as GPL-2.0 and Packagist as GPL-2.0-or-later; the sources do not settle the "or later" clause.
