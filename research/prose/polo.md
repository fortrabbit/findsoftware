Polo is a static site generator written in Go. It reads Markdown content from a source folder, is compatible with Jekyll and Pelican content, and writes the published files to an output folder. A mode with a built-in HTTP server watches the sources for changes and regenerates the site, and the [README](https://github.com/agonzalezro/polo/blob/master/README.md) names `gh-pages` as a deploy target.

It is installed from a binary release or a Docker image, or built from source with glide.
