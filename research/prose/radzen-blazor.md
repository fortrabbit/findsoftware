Radzen Blazor Components is a UI component library written in C# for Blazor apps. It covers data-heavy interfaces such as a data grid, a scheduler, a Gantt chart and a spreadsheet with formulas, plus charts drawn as SVG without a JavaScript charting library, and form, layout and navigation controls. The package is installed from NuGet; the [getting started guide](https://blazor.radzen.com/get-started) then has the app import the namespaces, add a theme stylesheet and a script, register the services in Program.cs, and place the components in razor pages.

The README says the library supports Blazor Server, Blazor WebAssembly and .NET MAUI Blazor Hybrid. The maintainer is Radzen Ltd.

## Worth knowing

The interactive features of the components need an interactive render mode on the component or its container, which the guide names as InteractiveServer, InteractiveAuto or InteractiveWebAssembly. The README lists premium themes, a Studio IDE and a cloud-hosted MCP server as part of the Radzen Blazor Pro subscription.
