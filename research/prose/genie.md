Genie is a full-stack web framework for Julia, aimed at data-centric web apps, backends and APIs. Apps are installed with the Julia package manager and run a built-in web server, which the [deployment guide](https://learn.genieframework.com/framework/guides/deployments/deploying-genie-apps) starts with up() in production mode. Its database layer works with SQLite, MySQL and Postgres. Stipple.jl, a reactive UI package, is built on top of Genie.

## Worth knowing

Genie Builder, a VS Code extension with a no-code UI editor, is sold from the same site with paid licenses. It is a separate product from the MIT-licensed framework.
