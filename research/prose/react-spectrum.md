React Spectrum is a React component library that implements Adobe's Spectrum design system. Its components work with mouse, touch and keyboard, adapt to screen sizes, and include screen reader and keyboard navigation support, according to the getting-started page. The `@adobe/react-spectrum` package is installed with a package manager such as npm or yarn, and an application wraps its components in a `Provider` that sets the theme and locale.

The same repository holds React Aria and React Stately, libraries of unstyled components and state hooks for building a design system of one's own.

## Worth knowing

The components carry the Spectrum look, as the Adobe design system it implements. The README describes React Aria and React Stately as the route for one's own DOM structure and styling.
