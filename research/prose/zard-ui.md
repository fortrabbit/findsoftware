ZardUI is an Angular component library built with TailwindCSS and inspired by shadcn/ui, according to its [about page](https://www.zardui.com/docs/about). Components are added to an Angular project with the zard-cli command, which the CLI README describes as landing the source in the codebase, so each component can be read and changed in place. The components support right-to-left layouts. Setup runs with the `init` command of the CLI.

## Worth knowing

The package @ngzard/ui, which an earlier version of the project published, is deprecated on npm with a notice that it is no longer supported. The install docs name zard-cli, which is the package this record follows.
