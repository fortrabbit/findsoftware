svelte-jsoneditor is a JSON editor component for Svelte, written with Svelte. It edits a document in tree, text and table modes, and the README names its JSON Schema validation, which is built on Ajv.

The README calls it the successor of jsoneditor, the older editor that is written in plain JavaScript. For use outside Svelte, the README points to the separate vanilla-jsoneditor package, a vanilla bundle of the editor that it says can be used in any browser environment and framework. The [web application](https://jsoneditoronline.org) is the project's own demo of the editor.
