youi is a framework for user interfaces and applications in Scala and Scala.js, written for web, mobile and desktop. Its app module joins client and server code in one project: the compiled Scala.js front end is served by a JVM server.

Projects are set up with the youi-plugin for sbt or with the library dependencies declared by hand. The tutorial in the app module, which presumes sbt, is the project's own walkthrough.
