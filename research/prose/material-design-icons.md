Material Design Icons is the icon collection Google publishes for Material Design. It holds two official sets: Material Symbols, the current set, and Material Icons, the classic set. The icons are used through a Google Fonts font, and the repository holds the icon sources.

## Worth knowing

The README says Material Icons has had no updates since 2022 and names Material Symbols as the current set. Google does not maintain an npm package for the repository past its 2016 release; the npm packages the README lists belong to a third party, and Google does not vet them.
