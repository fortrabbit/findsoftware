Adobe Experience Manager is a commercial content management and digital experience platform from Adobe. The on-premise edition is installed by starting a quickstart jar on Java, or by deploying a WAR file to a third-party application server, and the docs describe it as deployed and managed in the customer's own environment. Content lives in a Java Content Repository, which the docs call a hierarchical database, and editors work through a web browser. A Multi Site Manager reuses site content across several sites through live copies.

AEM as a Cloud Service is a hosted offering and is separate from the self-hosted install.
