Vuelidate is a model-based validation library for Vue.js that supports Vue 3 and Vue 2. The core package is installed beside a validators package that holds commonly used rules, and the docs also show a browser build loaded from a CDN for use without a bundler. The [docs site](https://vuelidate-next.netlify.app/) holds the guide and the API reference.

## Worth knowing

The docs say Vuelidate is in LTS mode and name Regle, Vee-Validate and VueForm as form libraries that are actively maintained.
