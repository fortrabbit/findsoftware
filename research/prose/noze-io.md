Noze.io is an attempt to carry the ideas of Node.js over to pure Swift, with evented I/O streams. It is installed from a git clone, built with make or swift build, as the [start page](https://noze.io/start/) describes.

## Worth knowing

The project's homepage says "Consider this deprecated." and names Macro.swift as the more modern version. The README says the project is not recommended for production. The repository carries a copyright line but no license text, so the terms of use are not stated.
