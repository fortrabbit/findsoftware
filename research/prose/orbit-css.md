Orbit is a CSS layout system for elements arranged around a center, such as gauges, dials, knobs, radial menus and watch faces. Authors write plain HTML with a few classes that describe rings, satellites and their content. CSS handles the geometry, and a small runtime keeps numbering, spacing and SVG arcs right as the content changes.

The markup works the same in plain HTML and in frameworks such as React, Vue and Svelte. The project is open source under the MIT License and is maintained by Juan Martín Muda with ZumerLab.
