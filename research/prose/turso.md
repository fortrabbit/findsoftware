Turso Database is an in-process SQL database engine. It runs inside the application that loads it, and the README describes it as compatible with SQLite. It is used from Rust, JavaScript, Python and Go through their package managers, and the CLI installs with a shell script or Homebrew. The [manual](https://github.com/tursodatabase/turso/blob/main/docs/manual.md) is the reference.

## Worth knowing

The README says the rewrite replaces libSQL as the project's intended direction. The company behind the project also runs Turso Cloud, a managed service, and has announced that it is being acquired by Supabase. The project says Turso Database remains open source and in active development.
