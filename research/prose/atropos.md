Atropos is a JavaScript library for 3D parallax hover effects that also work with touch input. The homepage names a JavaScript build, a React build and a Web Component for use with other frameworks.

The [documentation](https://atroposjs.com/docs) lists the browser features it needs: pointer events, CSS 3D transforms and CSS transitions. Projects install it from npm, with a script tag or from a CDN, as the same page describes.
