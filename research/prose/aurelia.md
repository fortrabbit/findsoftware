Aurelia builds applications from components, each a class paired with an HTML template. It targets browser, mobile and desktop applications. New apps are scaffolded with `npx makes aurelia`, and the framework can also run from a plain HTML page without a build step. The [documentation](https://docs.aurelia.io/) covers the framework.

## Worth knowing

The README still describes Aurelia 2 as in beta and says a few more breaking changes to the public API are expected. A [migration guide](https://docs.aurelia.io/migrating-to-aurelia-2/migrating-to-aurelia-2) covers moving Aurelia 1 applications to Aurelia 2.
