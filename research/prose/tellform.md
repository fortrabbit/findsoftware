TellForm is an open source form builder for creating embeddable forms. It is written in JavaScript for Node.js, stores its data in MongoDB, and has an admin panel. Forms can be written in French, English, Spanish, Italian and German. The code is MIT licensed.

## Worth knowing

The project is discontinued. Its repository is archived and its README says the codebase is no longer maintained. The README points to OhMyForm, a fork, as the project to follow.
