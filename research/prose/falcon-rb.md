Falcon is a Rack-compatible HTTP server for Ruby web applications, published as the falcon gem. It runs as a multi-process, multi-fiber server, and its deployment guide states that it can be deployed into production as a standalone application server.

Falcon is built on top of the async gems, separate packages by the same maintainer. It installs with `bundle add falcon` or `gem install falcon`.

## Worth knowing

The maintainer offers priority business support through socketry.io.
