Yoopta Editor is a headless, plugin-based rich-text editor for React, built on Slate.js. The core package is installed from npm together with Slate's peer packages, and the [documentation](https://docs.yoopta.dev/quickstart) walks through a quickstart. Optional packages add a shadcn theme and collaboration through Yjs. Akhmed Ibragimov holds the copyright.

## Worth knowing

The project's own website at yoopta.dev did not answer when checked, so the documentation site is the reference here. The quickstart lists React 18 or later and the Slate peer packages as requirements.
