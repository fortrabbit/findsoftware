Semi Design is a React component library and design system maintained by the Douyin front-end team. The [getting started guide](https://semi.design/en-US/start/getting-started) describes the project as providing ready-to-use React components, and its install step names the package @douyinfe/semi-ui.

## Worth knowing

The main package is for React versions below 19. For React 19 the guide names a separate package, @douyinfe/semi-ui-19, which the examples can use in place of the main package. The getting-started page names a Figma Variant UI Kit.
