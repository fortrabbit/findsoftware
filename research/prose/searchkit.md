Searchkit is a set of search interface components for Elasticsearch and OpenSearch. It is built on Elasticsearch. It works with the instantsearch libraries, and Searchkit supplies the client that sends their requests to the search server. The components are published for React, Vue and Angular, and for plain JavaScript through CDN scripts. The project is maintained by Joseph McElroy.

## Worth knowing

The UI components run in the visitor's browser and need a reachable Elasticsearch or OpenSearch server. A separate Node API package proxies the requests to that server instead.
