Tamagui is a styling and UI library for React that works the same way on React Native and on the web. Its style props and components are typed, and an optimizing compiler handles the build-time work for web and native. The library is written in TypeScript and maintained by Nate Wienert, and the project is hosted under a GitHub organization.

## Worth knowing

Native apps need React Native with the New Architecture enabled, and the install page names a minimum React Native release.
