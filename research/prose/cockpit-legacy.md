Cockpit legacy is the earlier Cockpit codebase, a content management system that can also serve as a headless CMS. Its folder goes into the root of a web project, and an install page in the browser finishes the setup. Content is stored in SQLite or MongoDB.

## Worth knowing

The README opens by saying that development of Cockpit's next iteration moved to a dedicated organization on GitHub, where [Cockpit](https://github.com/Cockpit-HQ/Cockpit) is developed.
