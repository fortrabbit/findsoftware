Vane is a server-side framework for Dart with a built-in middleware system, published as the vane package on pub.dev. The framework serves routes that are declared with annotations, and its README lists built-in MongoDB support.

## Worth knowing

The project's own site, named in the README, does not resolve, so the README and the repository are the only sources for this record. The published package and the repository declare different Dart SDK ranges.
