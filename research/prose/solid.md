Solid is a JavaScript framework for building user interfaces. Its README says it compiles templates to real DOM nodes instead of using a Virtual DOM and updates them with fine-grained reactions, so only the code that depends on changed state reruns. Components can render on the client and on the server.

A project is created with the create-solid scaffolder, which can also set up SolidStart, the full-stack framework that the docs describe separately. Ryan Carniato holds the copyright.

## Worth knowing

A 2.0 line is in release candidates on npm and GitHub. The stable release the record shows comes from the 1.x line.
