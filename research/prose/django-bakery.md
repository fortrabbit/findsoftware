django-bakery is a set of helpers that save every page generated by a database-backed Django site as a flat file. Django's class-based views are at the heart of the approach, and the output can be hosted on a static-file service. It is installed with pip from PyPI.

A local build server lets the output be reviewed before it is published, and the [documentation](https://palewi.re/docs/django-bakery/) names Amazon S3 as the place to publish the files.

## Worth knowing

A flat site has no online database for writes, so user-generated content and complex searches are outside what the output can do.
