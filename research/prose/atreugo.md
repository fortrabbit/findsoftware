Atreugo is a micro web framework for Go, built on top of fasthttp. Its README lists routing with path parameters, route groups, middleware that runs before or after a view, and static file serving. The [docs folder](https://github.com/savsgio/atreugo/blob/master/docs/README.md) of the repository points to the go.dev reference for the server API.

## Worth knowing

The project has no website of its own, so its GitHub repository is the only page it names.
