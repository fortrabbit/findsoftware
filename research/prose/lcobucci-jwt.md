lcobucci/jwt is a PHP library that issues, parses and validates JSON Web Tokens based on RFC 7519. It does not depend on a framework and is installed with Composer into any PHP application. The documentation covers issuing, parsing and validating tokens, configuration, extending the library and rotating keys.

## Worth knowing

The documentation says the project is licensed under the MIT license, while the LICENSE file and the Composer manifest name BSD-3-Clause.
