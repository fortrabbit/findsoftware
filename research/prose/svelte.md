Svelte is a compiler. It takes declarative components and converts them into JavaScript that updates the DOM directly, and it is used to build web applications. The [getting started page](https://svelte.dev/docs/svelte/getting-started) recommends SvelteKit, the official application framework from the Svelte team, and creates a project with npx sv create. Svelte can also be used on its own with Vite through vite-plugin-svelte. In that setup the build writes HTML, JS and CSS files to a dist directory, and Vite is often used this way to build single-page apps.
