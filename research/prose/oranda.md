oranda is a Rust command-line tool that builds a landing page for a software project from its README and project manifest files. Arbitrary Markdown pages can be included. `oranda build` writes the site and `oranda dev` starts a local server that rebuilds on file changes.

The output is HTML, CSS and JavaScript files, and the [hosting guide](https://axodotdev.github.io/oranda/book/hosting.html) describes GitHub Pages and other static hosts as places to publish them.

## Worth knowing

The book introduction says oranda is still beta-quality software and that its configuration format may change.
