Puppertino is a CSS framework that applies Apple's Human Interface Guidelines to web pages, with components for pointer and touch. A page adds one stylesheet from a CDN or installs the package from npm, and the optional vanilla JavaScript helpers are imported per component. The [documentation](https://puppertino.com/) lists the components, and Edgar Pérez maintains it.

## Worth knowing

The framework is plain CSS with no build step and no dependencies, and the README says the CSS in the distribution folder is written by hand. Some components need a JavaScript helper to open, float or drag, and the docs name the helper each component needs.
