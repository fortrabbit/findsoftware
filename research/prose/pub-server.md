pub-server renders a website from Markdown files in a directory. The same command previews the site from a local web server, writes the generated HTML and static files to an output directory, or runs as a web server on a platform such as Heroku. The generator and editor can run in the browser, so people can edit and preview the generated HTML without installing pub-server themselves. The [documentation](https://jldec.github.io/pub-doc/) includes a live example of the editor.
