Beautiful Jekyll is a Jekyll theme for personal websites, blogs and project websites. It is built on top of Jekyll, and the homepage says it is powered by GitHub Pages and Jekyll. The getting-started page gives two routes: forking the repository on GitHub, where GitHub Pages builds the site, or adding the beautiful-jekyll-theme Ruby gem to a Jekyll project. The README says more than 50,000 people use the theme.

## Worth knowing

The README says no support is given for the Ruby gem route. Some extras are sold as sponsor plans on the project's plans page.
