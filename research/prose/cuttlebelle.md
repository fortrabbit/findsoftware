Cuttlebelle is a static site generator that uses React for layouts. Content is written in Markdown or YAML files split into partials, and each partial is assigned its own React layout written in JSX, so content and layout code are kept apart. The CLI is installed from npm and run in a project folder to write the site.

## Worth knowing

The npm package has no stable version: its latest tag is an alpha, and the repository has no GitHub releases or tags.
