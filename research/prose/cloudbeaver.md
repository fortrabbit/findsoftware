CloudBeaver is a web server that provides a browser interface for databases, in its community edition. The server is a Java application, and the web part is written in TypeScript and React. It connects to MySQL, MariaDB, PostgreSQL, SQLite, SQL Server and Oracle, among others.

Administrators manage users and teams from an administration page in the same application. The server runs as a long-lived process that the team deploys on its own host, and the [deployment guide](https://github.com/dbeaver/cloudbeaver/wiki/CloudBeaver-Deployment) documents the Docker image route. The project is licensed under Apache-2.0 and published by DBeaver Corporation.

## Worth knowing

DBeaver Corporation also sells CloudBeaver Enterprise as an annual subscription under its own agreement. The repository holds the community edition.
