Ant Design Mobile is a UI component library of essential UI blocks for building mobile web apps, published to npm as antd-mobile. The documentation FAQ says it supports only the React stack. The README describes its features as CSS-variable theming, components that can be used one at a time, and gesture and animation support. A CodeSandbox template lets a reader try the library in a browser without a local setup.

## Worth knowing

The documentation marks server-side rendering support as experimental and in an initial stage.
