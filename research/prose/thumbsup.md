thumbsup turns a folder of photos and videos into a static gallery website. Each folder of media becomes an album by default, and the tool generates thumbnails, several resolutions of each photo and HTML pages for each album. It is a command-line tool, installed from npm or run as a Docker image, and it needs image and video tools on the machine, such as exiftool and GraphicsMagick. The generated website is fully static and self-contained, so it can be opened from disk or uploaded to any static web server.
