Mailchimp Open Commerce, formerly Reaction Commerce, is a headless commerce platform built with Node.js, MongoDB and GraphQL. The README describes an API-first design with a plugin system, an included admin for orders, and support for several shops in one installation. The project is set up with the reaction-cli command-line tool, which creates API, admin and storefront projects.

## Worth knowing

The repository description reads "Project has been discontinued", and the README's documentation and website links return a not-found page. The repository itself is not archived.
