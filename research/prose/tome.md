Tome turns a Drupal site into static HTML and stores its content as files. Drupal runs only on the developer's machine, and the generated static output is what goes live. The [drupal.org project page](https://www.drupal.org/project/tome) describes it as a static site generator and a static storage system for content, and it is installed with Composer. Composer metadata names Samuel Mortenson and Lee Rowlands as its maintainers.

## Worth knowing

The drupal.org page labels the project minimally maintained, with maintenance fixes only. Some tome.fyi pages describe older Drupal and PHP requirements than the drupal.org project page.
