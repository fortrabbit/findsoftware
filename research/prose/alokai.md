Alokai is a frontend-as-a-service platform for building headless eCommerce storefronts. Its docs describe a set of tools covering UI libraries, integrations, deployment and monitoring, and name Storefront UI as the component library for storefronts. The project is documented at the [Alokai docs](https://docs.alokai.com/).

## Worth knowing

The repository named for this record holds only a README on its default branch, so its source is not public there. The docs describe Cloud, Console and Enterprise offers alongside the tools, and the pricing page lists no prices.
