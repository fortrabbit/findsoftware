Umbraco Heartcore is a headless CMS built on the open-source Umbraco CMS and run by Umbraco in the cloud. Editors work in a serviced backoffice, and developers read content over REST or GraphQL APIs from any frontend, such as websites and apps. The features page describes the Preview API as 1:1 with the Content Delivery API.

The FAQ says Umbraco keeps the backoffice and the APIs up to date, so a team maintains no separate backend codebase. Content can be published in selected languages, and user roles with granular permissions control who can edit what.

## Worth knowing

Heartcore is hosted in the cloud, and the FAQ names no on-premise install for it; content can be sent to on-premise projects instead. Sign-in with an external identity provider such as Azure AD is not possible on the cloud platforms.
