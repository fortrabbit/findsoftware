BalmUI is a set of Material Design components built on Vue 3, which the README describes as a modular and customizable UI library. It ships as one npm package, `balm-ui`, which the [README](https://github.com/balmjs/balm-ui/blob/v10.31.2/README.md) installs with npm or yarn into a project, with the Balm CLI or with script tags from unpkg.

The README says `balm-ui@8` is the line that supports Vue 2.
