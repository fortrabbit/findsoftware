Pines is a collection of UI elements written as HTML, such as modals and tooltips, for projects that use Alpine and Tailwind. An element is copied into a page. The project states that there is no package to install and no build step to configure, and the repository holds the element sources.

## Worth knowing

A page needs Alpine and Tailwind loaded before a copied element works. The How to Use page uses CDN scripts in its example and says the Tailwind CDN should not be used in production. The repository has no release, so its activity is shown by the date of its newest commit on the default branch.
