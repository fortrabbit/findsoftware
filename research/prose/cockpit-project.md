Cockpit is a web-based graphical interface for servers that an administrator opens in a browser to manage a Linux server. It works through the system's own tools, so the command line remains usable beside it.

The [running guide](https://cockpit-project.org/running) installs it from distribution packages and enables the `cockpit.socket` unit.

## Worth knowing

Cockpit administers the server as a whole. Its pages describe no web server or website management.
