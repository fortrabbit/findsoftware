Laravel Nova is an administration panel for Laravel, built by the Laravel team. It provides a full CRUD interface for Eloquent models. It is added to an existing Laravel application as a Composer package from the vendor's private repository, as the [installation guide](https://nova.laravel.com/docs/v5/installation.md) describes.

## Worth knowing

The docs state that Nova's license does not allow public distribution of its source code, and that production use requires a license key and a production URL.
