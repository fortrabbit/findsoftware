react-i18next is the React binding for i18next. Its `Trans` component and `t` function translate text inside React components, and it depends on the i18next package for the translation features.

## Worth knowing

Locize, a translation management service run by the team that builds react-i18next, is a separate product and is not part of this package.

The legacy v9 line is published under the `legacy` npm tag, not the default one.
