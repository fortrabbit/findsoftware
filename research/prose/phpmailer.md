PHPMailer is a PHP library for building email messages and sending them over SMTP, which the README says works without a local mail server. The README lists WordPress, Drupal and Joomla among the open-source projects that use it, and its error messages are translated into over 50 languages.

The project began in 2001 as a SourceForge project and has been developed on GitHub since 2013. The README names Symfony Mailer, Laminas/Mail and ZetaComponents as other libraries to look at.
