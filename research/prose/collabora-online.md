Collabora Online is an open source online editor for text documents, spreadsheets and presentations. It is embedded into other applications through the WOPI protocol, and the server runs as a WebSocket daemon. It can be installed from a Docker image, native Linux packages, a virtual appliance or a Helm chart for Kubernetes. Collabora Productivity Ltd, a division of Collabora, maintains it. Development happens on the project's own Gerrit server, and the GitHub repository holds the issue tracker, the Helm chart, the Docker build and the release artifacts.

## Worth knowing

The collabora/code Docker image is the Development Edition, which the project describes as a rolling release for testing. The supported stable version is sold as a subscription, and the project describes it as the one with tested updates and security fixes. The [SDK documentation](https://sdk.collaboraonline.com/) was behind a bot check when it was read, so its pages are not described here.
