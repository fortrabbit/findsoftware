Dotclear is a blog publishing engine written in PHP. One installation can run several blogs, and each user gets permissions of their own, so a site can be shared between writers and administrators. The installer is started from a quick-install file uploaded to the web space.

The project is run by a French non-profit association. Its documentation, forum, and theme and plugin repositories are on dotclear.org and are written in French.

## Worth knowing

The project's pages state the license two ways: the licence page names the GNU Affero General Public License version 3, and the conditions page names the GPL for the sources.
