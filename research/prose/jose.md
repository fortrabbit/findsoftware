jose is a JavaScript module for JSON Object Signing and Encryption. It covers JSON Web Tokens, JSON Web Signatures, JSON Web Encryption and JSON Web Keys, including key import, export and generation. It has no dependencies and exports tree-shakeable ESM, and its README names Node.js, browsers, Cloudflare Workers, Deno and Bun among the runtimes it works in.

## Worth knowing

The README says some algorithms are available in only some runtimes, and it links one issue per runtime that lists them.
