Imba is a full-stack programming language for the web that compiles to JavaScript. Its README says it replaces Vue or React on the frontend and works with the Node ecosystem on the backend, with a built-in bundler based on esbuild and styles written inside the code. A new project starts with npm create imba, which runs the create-imba scaffolder and offers a client-only application, a full-stack application with an Express server, a module, or a CLI tool.

## Worth knowing

The README says the tooling is still in alpha. The npm latest tag points at a prerelease of the next major line, and the newest stable release on npm predates it.
