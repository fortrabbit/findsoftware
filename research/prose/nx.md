Nx is a monorepo tool for TypeScript and polyglot codebases. It caches the results of tasks whose inputs did not change and runs only the tasks that a change affects. The Nx CLI is installed on a developer's machine with npm, Homebrew, Chocolatey or apt, or a new workspace is created with create-nx-workspace. Narwhal Technologies Inc. publishes it under the MIT License.

## Worth knowing

Nx Cloud is a hosted service next to the open-source CLI. It offers remote caching and CI task distribution, and it has plans of its own, which this record does not list.
