Siema is a carousel written in plain JavaScript that needs no other libraries and ships without styles. The script slides the items of a container element, and it supports right-to-left layouts. It is installed from npm or added to a page with a script tag, and the project's documentation is on GitHub Pages.

## Worth knowing

The maintainer's README says active maintenance of Siema is being discontinued, and invites anyone who wants to continue it to do so. The homepage names Flickity and Swiper for readers who need a more powerful library.
