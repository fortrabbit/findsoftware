JWt is a Java library for building web applications from widgets, and it renders them with Ajax or as plain HTML. Every HTML element has a corresponding widget, and events are handled on the server. The library requires a Servlet container, and Emweb bv develops it.

## Worth knowing

The download page offers the library under the GNU General Public License or under a Commercial License. Under the GPL, the source of an application built with it must be made available to anyone who is given the application to install on their own server; the page says the Commercial License has no such limitations.
