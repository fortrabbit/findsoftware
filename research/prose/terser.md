Terser is a JavaScript minifier and compressor for ES6+ code, distributed on npm. It is installed with `npm install terser -g` for command line use or with `npm install terser` for use from Node.js, and the README also describes loading it in the browser. The README states that terser is a fork of uglify-es that mostly keeps that project's API and command line compatibility. It runs on a developer's machine or inside a build, not on a live site.

## Worth knowing

The package has no GitHub releases of its own. Its repository carries tags, and the npm registry is the source for the latest version.
