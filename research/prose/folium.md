Folium is a Python library that builds interactive Leaflet.js maps from Python data. The data is prepared in Python, and the library places it on a Leaflet map. A map can be shown in a Jupyter notebook or saved as an HTML file. The README says folium builds on the mapping strengths of Leaflet.js. The project is maintained by the folium developers under the python-visualization organization on GitHub, and its [getting started guide](https://python-visualization.github.io/folium/latest/getting_started.html) shows the installation and the first map.
