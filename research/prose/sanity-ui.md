Sanity UI is a React component library, published on npm as @sanity/ui, for building web apps from components, layout primitives and theme tokens. The docs install the package with npm, together with the peer dependencies react, react-dom and styled-components. The repository is a monorepo that also holds a Figma plugin, a Storybook and the docs site; the package sits in its own folder.

## Worth knowing

The docs say the package ships one theme, studioTheme, which is built for use in Sanity products.
