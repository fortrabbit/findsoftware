Crayons is a library of web components published by Freshworks Inc, built with Stencil and described by the project as framework-agnostic. The components follow the UX standards of the Freshworks Design System. The [docs introduction](https://raw.githubusercontent.com/freshworks-oss/crayons/next/www/introduction/readme.md) covers two ways to use it: an npm install and a script loaded from a CDN. The same introduction lists a React wrapper, i18n support and an icon library among the library's features.
