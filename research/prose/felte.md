Felte is a form library that works with plain HTML forms in Svelte, Solid and React. The repository holds the core package for each framework next to the other packages: bindings for Preact and Vue, a vanilla JavaScript package built on web components, validator packages for yup, Zod, Superstruct and Vest, and reporter packages that display validation messages. Svelte projects install the felte package from npm, and the vanilla JavaScript package can also be loaded from a CDN.

## Worth knowing

The Vue binding is marked experimental in the README. The repository has no GitHub releases, so new versions are found on npm. The documentation for the earlier major version is kept at a separate address that the homepage links.
