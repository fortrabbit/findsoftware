wg is a static website generator written in Python. It takes Markdown and uses Jinja2 templates for pages and blog posts. The README gives one command, `python generate.py`, as the whole usage, and the script writes the generated site into a `docs` folder.

## Worth knowing

The script imports mistune and Jinja2, and the repository names neither in a requirements file or an install step. The project has no releases or tags, and the record rests on its README and source.
