DevCycle is a hosted feature flag platform with built-in support for OpenFeature SDKs, so applications can evaluate flags through the OpenFeature interface. Flags are created and managed in the DevCycle dashboard, and an application initializes a DevCycle client SDK with an SDK key for one environment. Access to flags is governed by roles, and SAML single sign-on is offered on the Enterprise plan. DevCycle is now part of Dynatrace, and its terms of service name a Dynatrace Inc. subsidiary as the provider of the service.

## Worth knowing

The SDKs are open source, while the service itself is hosted and has no self-hosted option recorded. Data residency is handled on request rather than as a published choice of region, according to the security page. The free tier is described as always free to start.
