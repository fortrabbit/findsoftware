Athena is a web framework for Crystal, offered as one part of a collection of independent, reusable components that the project's site describes. A project adds the framework to its shard.yml and installs it with shards, following the [getting started guide](https://athenaframework.org/getting_started/). George Dietrich is named in the license's copyright line.

## Worth knowing

All releases of the framework are below version 1.
