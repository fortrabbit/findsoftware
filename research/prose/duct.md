Duct is a server-side framework for Clojure. An application's structure is an immutable data structure that names the components and how they connect, rather than a file tree generated from a template. A project is set up with the Clojure CLI and a deps.edn alias, and the application runs as a long-lived process.

## Worth knowing

The repository first listed for this record, duct-framework/duct, is the old Leiningen template, and its README says it has been deprecated in favor of the project's site. The record stays a stub until the project names one current home.
