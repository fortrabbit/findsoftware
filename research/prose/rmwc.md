RMWC is a React UI kit that wraps Google's Material Components for the web, the library the project names as its base. Each component ships as its own npm package, and the installation guide recommends installing components one at a time rather than the whole kit. Component stylesheets come from the Material Components package and are imported per component.

The project was created by James Friedman. A development team named in the README maintains it.

## Worth knowing

The README warns that the base library is archived and that RMWC will receive no major updates, only essential maintenance. Pull requests are welcome, but the maintainers say they may not have capacity to prioritize them.
