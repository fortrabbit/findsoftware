CapRover is a self-hosted platform as a service, written in TypeScript, that deploys apps and one-click services to Docker containers behind nginx with automatic HTTPS. The server is installed from the caprover/caprover Docker image on a server the user controls, where it keeps running to serve the platform, and the project also publishes a command-line client on npm that the install docs name for managing it.
