YOCaml is a framework for building static site generators, written in OCaml. A site built with it is an OCaml program that describes how its pages are produced.

The project is set up as a dune project with opam dependencies, and the tutorial states that YOCaml is released for OCaml 5.1.0 and later. The tutorial describes statically generated sites as easy to deploy and says a simple static server is enough to serve them.
