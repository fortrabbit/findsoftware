Rellax is a vanilla JavaScript library that moves page elements at different speeds from the rest of the content as the page scrolls, which produces a parallax effect. It selects elements by class name, reads each element's speed from a data attribute, and falls back to a default speed when none is given. Its options cover centering, z-index, horizontal movement and a custom scroll wrapper, and the [demo site](https://dixonandmoe.com/rellax/) shows the effect.

## Worth knowing

The repository has no tags or GitHub releases; versions are published only on npm.
