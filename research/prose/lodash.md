Lodash is a JavaScript utility library of functions for arrays, collections, objects, strings and functions. The full build is one UMD module, and the npm package also offers modular entry points, so single methods can be imported and bundled on their own.

## Worth knowing

The README says the project is moving to a feature-complete maturity stage with support from the Sovereign Tech Agency, and that its governance is being rebooted with a technical steering committee.
