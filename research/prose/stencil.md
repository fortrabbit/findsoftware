Stencil is a compiler that generates web components, more specifically custom elements, from TypeScript, JSX and CSS. The same components can be used with or without a framework, and Stencil can emit framework wrappers for Angular, React and Vue. It also supports prerendering: components and routes are rendered at build time to static HTML, which the client code then hydrates, so the HTTP server only serves static files. A project is scaffolded with the create-stencil command.
