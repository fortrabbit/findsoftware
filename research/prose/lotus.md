Lotus is a pricing and billing engine for SaaS companies, built for custom subscriptions and usage-based plans. Its README presents self-hosting with Docker through a self-host script as the only version. A product's backend sends usage events and subscribes customers to plans through the Lotus SDK or API, as the [getting-started guide](https://github.com/uselotus/lotus/blob/main/docs/overview/getting-started.mdx) shows. Postgres with TimescaleDB holds its data, and a control panel manages plans and subscriptions.

## Worth knowing

The newest tagged release is older than the repository's latest commits, and no page says whether the project is still developed.
