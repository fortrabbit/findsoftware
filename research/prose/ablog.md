ABlog is a Sphinx extension that turns a documentation or personal website project into a blog. It is installed with pip or conda, and the `ablog build` command builds the website as HTML pages into a `_website` folder, so the output is static files. The project is part of the SunPy Project, as its documentation states, and the copyright line of the license names Ahmet Bakan and The SunPy Developers as the holders.
