Million.js is an optimizing compiler for React. Its install docs give two routes: a command-line tool that installs the package and configures the project, and a manual install in which the npm package is added and the compiler is added to the application. Aiden Bai is named as the copyright holder, and Million Software, Inc. appears in the footer of the project's site.

## Worth knowing

Million.js assumes an existing React project, so it does not apply to projects built on other frameworks. The install page lists Node 18 or above as a requirement.
