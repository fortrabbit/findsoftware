imi is a PHP framework for long-connection and distributed microservices. Its README says it runs under PHP-FPM, Swoole, Workerman and RoadRunner, so the same framework can serve requests from a traditional PHP web server or from a long-running process. The README lists MySQL and PostgreSQL among its built-in features, and new projects start from the imiphp/project-http skeleton with Composer.

The README is written in Chinese.
