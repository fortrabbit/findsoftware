ZK is a Java framework for building enterprise web and mobile applications. The user interface is declared in ZUML markup, and the README says Ajax works without JavaScript written by the developer. The [Maven setup guide](https://docs.zkoss.org/zk_installation_guide/maven_setup) lists the editions and the Maven repository, and applications run on a servlet application server such as Jetty or Tomcat, which the deployment pages name.

## Worth knowing

The community edition is under LGPL, while the professional and enterprise editions are premium and have a 60-day evaluation. Versions are published to Maven Central, and the GitHub repository holds one older release.
