Streamlit is a Python framework that turns a script into an interactive web app. An app runs as a Python server.

The package is installed with pip and started with the streamlit run command. Streamlit is published by Snowflake Inc., which also offers Streamlit in Snowflake as a hosted option, and [Streamlit Community Cloud](https://docs.streamlit.io/deploy) is a free platform for deploying an app.

## Worth knowing

Because the app is a Python process that keeps running, hosting it means running that process, not serving files. The hosted options are separate offerings beside the Apache-2.0 package this record describes.
