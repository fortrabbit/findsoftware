Mako is a web bundler based on Rust, published on npm as @umijs/mako. The npm readme gives `npm create mako` as the way to start a project and names the project's site for further information. The package is maintained by Ant UED, as its license states.

## Worth knowing

The project's site could not be read on the check date. The repository now sits under the Utoo organization, whose readme describes a different toolchain and does not name Mako.
