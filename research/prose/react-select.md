React-Select is a select control for React. The README lists a styling API built on emotion, option groups, portal support and animation among its features, and the [docs](https://react-select.com/) cover async and creatable variants.

The project says it was first built for use in KeystoneJS and is funded by Thinkmill and Atlassian. Since the rewrite to TypeScript the source is TypeScript, and the types for earlier releases are published separately under @types.
