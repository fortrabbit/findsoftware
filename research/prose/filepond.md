FilePond is a JavaScript library that turns file inputs on a web page into an upload area. Its core is written in vanilla JavaScript, and the same organization publishes adapters for React, Vue, Svelte, Angular and jQuery as separate repositories. Further features come as plugins, listed in the [plugin directory](https://pqina.nl/filepond/plugins/).

## Worth knowing

The Image Edit plugin is powered by Pintura, a separate commercial image editor from the same company. The GitHub releases end early while the npm package continues, so current versions are found on npm.
