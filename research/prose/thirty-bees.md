thirty bees is a web shop platform in PHP with a storefront and a back office in one installation. It began as a fork of PrestaShop 1.6, and its README says it remains compatible with almost all PrestaShop 1.6 modules. Templates use the Smarty engine, and one admin panel can run several shops. The download page offers a release archive for installation, and the site has a migration path from PrestaShop. Thirty Bees B.V. maintains it, with an address in the Netherlands.

## Worth knowing

The license is stated two ways: the file headers name the Open Software License 3.0, and the repository's LICENSES file contains an MIT notice without saying which files it covers. The [documentation](https://docs.thirtybees.com/) describes an older release line with a different PHP range than the [download page](https://thirtybees.com/download/), which holds the current requirements.
