Bloomreach Content is the hosted content management platform from Bloomreach, Inc. Its Content SaaS documentation describes a Delivery API with REST endpoints for front-end applications and an optional GraphQL API for commerce features. One platform can manage several sites, apps, brands and languages, with multi-country and multilingual channels.

Each environment is placed in a single public cloud region chosen by the customer, initially EU or US-East.

## Worth knowing

The on-premise install guide on the vendor's docs site configures Bloomreach Experience Manager, a related on-premise product, so this product has no self-install guide of its own. Sign-in can use SAML single sign-on, and access is role based, with roles such as Content author, Content editor and Content project admin.
