Mail-in-a-Box is a mail server appliance for one Ubuntu machine. A setup script, run from a clone of its repository, turns a fresh machine into a working mail server with a web control panel, and the control panel can also be driven through a REST API. Joshua Tauberer began the project in 2013, as its homepage states.

## Worth knowing

The pages the project publishes do not show a website or app submitting mail through the box.
