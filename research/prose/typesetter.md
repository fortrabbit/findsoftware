Typesetter is an open-source content management system in PHP that stores pages as flat files and edits them in the browser with a WYSIWYG editor. According to the [README](https://github.com/Typesetter/Typesetter/blob/master/README.md), installation means uploading the extracted release to a web server and completing the installation form in the browser. The download, documentation and forum pages are on the project's own site.
