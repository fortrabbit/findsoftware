Doofinder is a hosted search service for ecommerce stores, operated by Doofinder S.L. from Madrid. A store connects to it through a platform module for a shop system or through the API, and the Doofinder Admin Panel shows the search zone that the store's API calls use.

Doofinder runs in three regional zones: eu1 for Europe, us1 for the United States and ap1 for Asia Pacific. Each API call goes to the host of its zone, and the API answers more than 20 requests per second with a 429 error.

## Worth knowing
