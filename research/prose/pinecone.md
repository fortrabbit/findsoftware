Pinecone is a hosted vector database. Indexes run on Pinecone's cloud and are reached through a REST API and a console, so there is no server to install. Pinecone Systems, Inc. operates the service from San Francisco. Access is managed with roles for users, service accounts and API keys, and a Starter plan is offered for trying out the service and for small applications.

## Worth knowing

Under the Bring Your Own Cloud option, a privately managed Pinecone region runs inside the customer's own AWS, Azure or Google Cloud account. The pricing page lists the plans, and the Starter plan is the only one described as free to start.
