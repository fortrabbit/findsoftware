Scalar's API Reference turns an OpenAPI or AsyncAPI document into interactive API documentation. It works from a single HTML page that loads the JavaScript from a CDN and is given the URL of the API document, or through one of the framework integrations. The project's own pages name Swagger UI and Redoc as tools it can replace. API Documentation Inc., which trades as Scalar, is the company behind it.

## Worth knowing

Scalar also offers hosted documentation as a separate service, with a free plan and paid plans. The API Reference itself is MIT licensed and can be self-hosted.
