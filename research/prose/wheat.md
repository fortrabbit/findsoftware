Wheat is a blogging engine for Node.js that reads a git repository of Markdown articles and presents them as a website. It is published on npm as `wheat` and installed with `npm install wheat`. The [README](https://github.com/creationix/wheat/blob/master/README.markdown) is the project's documentation.

## Worth knowing

Rendering Graphviz graphs from DOT files on the fly needs Graphviz installed separately, as the README states.
