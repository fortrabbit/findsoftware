PrimeReact is a React UI component library that PrimeTek publishes on npm. The [Styled guide](https://primereact.dev/docs/styled/guides/introduction) describes components that come pre-styled with a built-in design system, and the installation guide for the Vite setup adds the @primereact/ui package with a theme package and an icon package. PrimeTek Informatics Bilisim AS maintains it, from Ankara.

## Worth knowing

The current line is distributed as a compiled package under the PrimeUI License and needs a PrimeUI license key. The license offers a free Community License for eligible individuals and organizations and a paid Commercial License per developer. PrimeReact moved into PrimeUI in 2026. The earlier line, PrimeReact 10 and before, is MIT-licensed; its public repository receives security fixes only.
