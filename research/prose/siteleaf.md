Siteleaf is a hosted content management system for static sites, and its homepage says it is compatible with Jekyll themes. Editors work in a cloud editor and write templates in Liquid, and the sites it publishes are generated as static files for Amazon S3, GitHub Pages, FTP or SFTP. Changes can be synced with a GitHub repository. The features page names WordPress, Tumblr, Ghost and Drupal as sources for import. The company is Oak Studios LLC, whose site gives an address in Brooklyn, New York.

## Worth knowing

The editing interface is a hosted service, while the site it publishes is static files.
