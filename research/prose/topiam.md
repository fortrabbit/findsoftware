TOPIAM is an identity and access management server for organizations. It manages organizations, users and user groups, signs users in to connected applications over OAuth 2.0, OpenID Connect, SAML 2.0, JWT, CAS and SCIM 2.0, and can sync identities from LDAP, AD, DingTalk, WeCom and Feishu. The server is written in Java on Spring Boot with MySQL, and the [installation guide](https://www.topiam.cn/docs/deployment/) describes a one-line installer that sets up Docker and runs the service on a Linux server, or a BaoTa panel app. Administrators work in a web console. The copyright notice on the project site names 济南源创网络科技有限公司 as the copyright holder.
