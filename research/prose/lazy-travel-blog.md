Lazy Travel Blog is a Python script that builds a travel blog as one index.html page, linking each place its author visited to an Instagram hashtag. The script is run with `python3 make.py` and asks for place names at the command line, or reads them from an optional JSON file. The README says the finished page can be hosted on any static website host.

## Worth knowing

The repository has no license file, so the terms for reusing the code are not stated.
