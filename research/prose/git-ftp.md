git-ftp is a Python package that uploads files from a Git repository to FTP servers, sending only the files that changed since the last upload. It is installed from PyPI with pip, runs as a `git ftp` command on the machine that holds the working copy, and can be pointed at FTP, FTPS, FTPES or SFTP servers.

## Worth knowing

The project site documents a second, older implementation of the same command as a shell script.
