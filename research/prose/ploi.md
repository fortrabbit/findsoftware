Ploi is a hosted service that manages the servers and sites of its customers. It connects to servers provisioned at cloud providers such as UpCloud, DigitalOcean, Linode, Hetzner, Vultr, AWS EC2 and Scaleway, or to a server the customer brings as a VPS, and it installs the server software on them. The homepage lists one-click installs for Laravel, WordPress, Statamic, Craft CMS, Nextcloud and phpMyAdmin. Ploi is maintained by Ploi, a WebBuilds B.V. product, from the Netherlands, and is hosted in Europe.

## Worth knowing

Ploi runs only as a hosted service. No source code is published, so the software can be used only through the Ploi account. The paid plans are on the [pricing page](https://ploi.io/pricing).
