FlexSearch is a full-text search library for JavaScript that runs in the browser and in Node.js. The default index is held in memory. Persistent indexes can keep the data in IndexedDB in the browser, or in Redis, SQLite, Postgres, MongoDB or ClickHouse on the server. The [documentation](https://github.com/nextapps-de/flexsearch/tree/master/doc) covers document search across several fields of one document. It is installed with npm or loaded as a module from a CDN.
