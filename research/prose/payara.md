Payara Server is a Jakarta EE application server that runs on a Java virtual machine. The community edition is distributed as a ZIP bundle that is unzipped into a directory, as the [getting started guide](https://docs.azul.com/payara-community/general-info/getting-started.html) describes, and it is administered through an Administration Console opened in a browser. The source sits in the [repository](https://github.com/payara/Payara), which also holds Payara Micro Community. Its community documentation is served from Azul's domain.

## Worth knowing

The project's own site now says a new payara.org is coming, and the product pages and documentation sit on Azul's domain, so the record stays hidden until the maintainer of the community edition is confirmed.
