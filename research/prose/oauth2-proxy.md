OAuth2 Proxy is a reverse proxy and static file server that provides authentication. The [documentation](https://oauth2-proxy.github.io/oauth2-proxy/) lists four ways to install it: a prebuilt binary, go install, a Docker image and a Helm Kubernetes manifest. It listens for HTTP clients on an address set in its configuration and can use OpenID Connect providers to check users. The repository was forked from bitly/OAuth2_Proxy, and the project is a series of LF Projects, LLC.
