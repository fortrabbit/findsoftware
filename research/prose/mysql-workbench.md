MySQL Workbench is a graphical tool for working with MySQL servers and databases, made by the MySQL team at Oracle. It runs on the developer's own machine and covers SQL development, data modeling and administration. The [repository](https://github.com/mysql/mysql-workbench) holds the 8.0 line and its release tags.

## Worth knowing

The repository's description calls its 8.0 line end-of-life and points to another repository, mysql-shell-plugins, as the new Workbench.
