NVD3 is a reusable charting library for d3.js. Its README describes adding the nv.d3 stylesheet and script to a page, with the d3.js script loaded before the nv.d3 script. The examples and documentation are on the GitHub Pages site the README names.

## Worth knowing

The homepage named in the repository metadata does not resolve, so the project's own site cannot be checked for its current status. The newest stable release is older than the repository's last push, and the README lists d3.js as a required dependency.
