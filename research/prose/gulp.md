gulp is a JavaScript toolkit for automating a project's build and development workflow. It is installed as a development dependency with npm, and the [quick-start guide](https://gulpjs.com/docs/en/getting-started/quick-start) runs it from a gulpfile.js in the project root through a separate gulp command line utility installed globally. Community plugins cover individual steps, and the [plugin directory](https://gulpjs.com/plugins) lists them.
