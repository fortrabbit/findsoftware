Base Web is the React implementation of Base, a design system built from modern, responsive, living components. The component library is published on npm as baseui, and its documentation is linked from the [README](https://github.com/uber/baseweb/blob/main/README.md).

## Worth knowing

The README carries a maintenance notice: the maintainers are limiting their engagement with the repository while still mirroring their internal development. The project's blog post adds that pull requests are no longer actively reviewed, the issue tracker is closed, and development is driven by Uber's internal needs, while the library stays maintained. Neither says the project has ended.
