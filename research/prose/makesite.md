makesite.py is a Python script that generates a static website and blog from content files and layout files. The README presents the repository as an example site: a fork replaces the content with its own, and the generated output is static files that a hosting service or web server can serve.

## Worth knowing

The README says the project takes no new features such as Jinja templates or YAML front matter; those belong in a fork. Rendering Markdown posts needs the commonmark package.
