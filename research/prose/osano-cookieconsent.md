Cookie Consent is a JavaScript plugin that shows visitors a cookie notice, for sites that need to comply with EU, GDPR and California cookie rules. It is installed with npm, Yarn or Bower, or loaded from jsDelivr. Osano, Inc. maintains the open source code and also offers a hosted consent platform, which the README describes as a separate, free option alongside paid plans.

## Worth knowing

The README on the default branch describes a newer major version that has no release, tag or npm package. The install routes above deliver the published one.
