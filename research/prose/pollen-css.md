Pollen is a configurable library of CSS variables for a design system. The getting-started page says it works without any preprocessor or environment requirements. A command-line build tool reads a configuration file and writes the variables into a stylesheet, which a project includes from npm or from a CDN.

## Worth knowing

The repository has moved. The README badges, the npm metadata and the homepage's GitHub link still name an earlier organization, which now redirects to the repository this record covers. The homepage and README name different maintainers, so the record uses the one the current site names.
