SQLite is a C library that implements a complete SQL database engine. It is an in-process library with no separate server process, so an application links it in rather than connecting to a server. The source code is in the public domain. The [download page](https://sqlite.org/download.html) offers the source as an amalgamation and precompiled binaries for several platforms. The developers are employed by Hipp, Wyrick & Company, Inc. (Hwaci).

## Worth knowing

The project does not accept outside code contributions. Its developers' company sells a warranty of title, which is a legal document and not a different build of the software.
