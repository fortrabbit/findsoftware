Builder.io is a hosted platform made of two products. Code is a visual IDE that generates and edits application code from a team's repositories and design system. Content is a headless CMS with a visual editor, where marketing and content teams build and publish pages and entries that sites and apps read through the Content API and a GraphQL API. Builder.io, Inc. runs both products.

The Content API and the GraphQL API read published content, and the Write API creates and updates it.

## Worth knowing

The service is hosted. No self-hosted installation is described in the docs read for this record, and the self-hosting option on the Enterprise plan connects custom git providers, not a Builder server. Admin, developer, designer and editor roles come with the Team plan; a contributor role, custom roles and single sign-on are Enterprise features.
