Pundit is a Ruby library of helpers for building an authorization system from regular Ruby classes and object-oriented design patterns. It is written for Rails applications: the README walks through a Rails controller and a Rails generator, and the gemspec describes it as authorization for Rails applications.

Varvet, a digital product studio in Sweden, builds and maintains it, and the README says Jonas Nicklas first released it in 2012. The README also lists Flask-Pundit, a Python extension it describes as heavily inspired by Pundit.
