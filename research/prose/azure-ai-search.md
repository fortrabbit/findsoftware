Azure AI Search is a fully managed, cloud-hosted service on Microsoft Azure that connects data to AI, from Microsoft Corporation. It is available through the Azure portal, REST APIs and Azure SDKs, and the [documentation](https://learn.microsoft.com/en-us/azure/search/search-what-is-azure-search) describes its use for search and for retrieval in AI applications. Service-to-service calls authenticate through Microsoft Entra ID.

A Microsoft product page says Azure AI Search is Foundry IQ, and the record stays a stub until that naming question is settled.
