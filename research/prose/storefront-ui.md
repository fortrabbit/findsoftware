Storefront UI is an open-source component library and design system for ecommerce storefronts, published as packages for React and Vue.js. Its components are built to fit a Tailwind CSS workflow. The Vue package is installed with npm or yarn next to Tailwind CSS and its Vite plugin, and the [documentation](https://docs.storefrontui.io/v2/) covers the installation steps. The project also offers copy-pasteable blocks alongside the components.

The library is maintained by Alokai, which formerly operated as Vue Storefront. The code for all packages is in one repository.

## Worth knowing

The Vue and React packages are published separately, so a project installs only the one it uses. The storefrontui.io domain forwards to a product page on the maintainer's site.
