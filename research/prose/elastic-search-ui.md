Search UI is a JavaScript library from Elastic for building search interfaces on top of Elasticsearch or another search API. It is headless: the library holds the search logic and query behavior, and the interface is left to the developer. Built-in React components are available, and the library can also be used with plain JavaScript or another front-end framework. Search state such as queries, filters and paging is kept in the page URL, so a search can be linked directly. Data comes in through connectors, and the docs name Elasticsearch and Elastic Site Search as the connectors they cover.

The core package is installed from npm together with the React packages the docs name for components.

## Worth knowing

The Elastic docs mark the App Search and Workplace Search tutorials as deprecated.
