Litstack is an administration panel package for Laravel that a developer adds to an existing Laravel project with Composer. Its homepage says it extends Laravel models with CRUD functionality, and the admin interface is served at the /admin route by default. The homepage also lists a built-in permission manager for roles and permissions, and says it works with Blade, Livewire or Vue components. The official add-on packages, such as pages and two-factor authentication, are separate packages and not part of this record.

## Worth knowing

The [README](https://github.com/litstack/litstack/blob/3.x/Readme.md) states that the project has been discontinued and is in maintenance-only mode. Litstack needs an existing Laravel project and does not run as a standalone application, as the [documentation](https://litstack.io/docs) states.
