LavinMQ is a message broker written in Crystal. Applications connect to it over AMQP 0.9.1 and MQTT to exchange messages and tasks between parts of a system. It comes as a single binary. The [installation guide](https://lavinmq.com/documentation/installation-guide) covers Debian and Ubuntu packages, Fedora packages, Homebrew, a Docker image and a build from source. The [systemd page](https://lavinmq.com/documentation/systemd) describes running it as a managed service, and the management interface is a browser dashboard to monitor and handle the broker.

The project is maintained by 84codes AB, which describes itself as a Swedish tech company.

## Worth knowing

CloudAMQP runs LavinMQ as a managed instance, which the project's getting-started page names as the hosted option.
