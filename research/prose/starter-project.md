Starter Project is a set of Gulp tasks for Pug templates, Sass stylesheets and JavaScript, installed from npm. The README names Netlify builds as a place where the build task runs.

A second repository, Starter Project CLI, is the one the README names for version 2 of the package. The project's page describes that CLI as the tool that sets up the Gulp environment.

## Worth knowing

The repository is archived, so it no longer receives changes.
