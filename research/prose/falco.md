Falco is a toolkit for building full-stack web applications in F#, built on the components of ASP.NET Core. The [documentation](https://falcoframework.com/docs) says Falco depends only on the base components of .NET and ASP.NET Core. The [get-started page](https://falcoframework.com/docs/get-started.html) installs it with dotnet add package Falco.

Falco includes a native F# view engine, which the homepage lists among its features. The [deployment guide](https://falcoframework.com/docs/deployment.html) describes self-contained and Native AOT executables.

## Worth knowing

The GitHub releases lag behind the NuGet package, which carries the later stable releases and a beta; the record takes its major version and release dates from NuGet.
