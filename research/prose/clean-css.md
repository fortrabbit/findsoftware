clean-css is a CSS optimizer for stylesheets. The [README](https://github.com/clean-css/clean-css/blob/master/README.md) says it runs on Node.js and in browsers, and the install step adds it to a project as a development dependency. Third-party plugins connect it to other build tools, while the command-line tool ships as the separate clean-css-cli package.

## Worth knowing

The README says the project is in maintenance mode. Pull requests are still accepted, and the maintainer intends an occasional bugfix release.
