TallStackUI is a suite of more than 80 Blade components for Laravel applications that use Livewire, Alpine.js and Tailwind CSS. The components are installed with Composer and used inside a Laravel application's views. The project designs them for Livewire, and its documentation says most of them also work outside a Livewire component. Its internal texts are translated through language files. The creator and maintainer is AJ Meireles, and the project is hosted under a GitHub organization.

## Worth knowing

The documentation lists KeyValue, Loading, Reaction, Signature and Upload as components that cannot be used outside a Livewire component. Livewire's script still has to be on the page, because that is where Alpine.js comes from.
