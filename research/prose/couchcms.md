CouchCMS is a content management system for web designers who build from HTML and CSS templates. The designer adds Couch tags to an existing HTML template to make parts of it editable. Editors change those parts in the admin panel, which the project describes as blank to begin with. It is written in PHP and runs under Apache or a compatible web server such as LiteSpeed. The [requirements page](https://docs.couchcms.com/requirements.html) describes installing it by uploading the files over FTP. Webzyme Softwares Pvt. Ltd. maintains the project.

## Worth knowing

The open-source license requires attribution in the source code and a link to the project on the site front-end, unless the author waives the link. A commercial license removes the attribution link and the admin panel branding, and includes one month of support.
