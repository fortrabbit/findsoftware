Phalcon is an open-source web framework delivered as a PHP extension. The README says it is written in Zephir/C, and the [installation docs](https://docs.phalcon.io/latest/installation) say it has to be installed and loaded as a module on the web server. They prefer PIE as the installer and list PECL as deprecated.

The project is maintained by the Phalcon Team, which describes itself as a core team of volunteers.

## Worth knowing

This record covers the stable line in phalcon/cphalcon. The docs also describe a pure PHP line in a separate repository, phalcon/phalcon, which this record does not cover.
