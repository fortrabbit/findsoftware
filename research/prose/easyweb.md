Easyweb is a hosted headless content management system from Sphinxly AB. Content is edited in a web interface on the service, and the [developer introduction](https://www.easyweb.site/developer/easyweb-cms/introduction) describes a REST API that sites use to read the content. The service runs on Easyweb Cloud servers in Sweden. The docs also describe a .NET site template for building a front end on the API.

## Worth knowing

No installable copy of the CMS is documented, so it runs only as the hosted service. The developer introduction says the service is free for personal projects and developers and that commercial projects need a business plan.
