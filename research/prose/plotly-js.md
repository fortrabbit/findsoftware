Plotly.js is a standalone JavaScript data visualization library. A figure is described by data and layout objects and drawn into an element on the page with the newPlot method. The library covers statistical, 3D, scientific, SVG and tile map, and financial charts, and it also powers the Python and R modules named plotly.

## Worth knowing

The npm install guide names plotly.js-dist-min, a distributed bundle, rather than the plotly.js package. The standard bundle includes US and British English, and other localizations are separate files. MathJax is not part of the bundle and has to be loaded separately to render math in plots.
