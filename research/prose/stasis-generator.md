Stasis is a static site generator that compiles Markdown pages into static HTML with Handlebars templates and bundles scripts and styles with Parcel. Its content is kept as Markdown files in the project's source, and it is installed from npm as a project dependency. The maintainer is named in the license as Jonas D.; the GitHub repository belongs to a user account named Gioni06.

## Worth knowing

The [README](https://github.com/Gioni06/stasis-generator/blob/master/README.md) says the project is in alpha status and that its API is likely to change.
