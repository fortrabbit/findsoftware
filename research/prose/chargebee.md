Chargebee is a hosted service for subscription and usage-based billing and for payments, run by Chargebee Inc. It has no documented self-hosted install. Its REST API uses HTTP Basic Auth. The free Starter plan is aimed at single-brand businesses, and the pricing page lists multi-entity management and account hierarchies among the features.

## Worth knowing

The pricing page lists SAML, SCIM and just-in-time provisioning under enterprise access controls. The open source Node.js client library is a separate package from the service. The product documentation is on the [docs site](https://www.chargebee.com/docs/).
