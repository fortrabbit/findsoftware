Uppy is a modular JavaScript file uploader for web browsers, built from npm packages around a core package. Plugins add the parts an app needs: a dashboard interface, file sources such as local disk, remote sources and a webcam, and resumable uploads over tus. The core is framework-agnostic, and the project names official bindings for React, Svelte, Vue and Angular.

## Worth knowing

The packages come from one monorepo, and the registry figures in this record are for @uppy/core alone. The companion server package has its own record. Transloadit, the company that develops Uppy, offers a separate file-processing API that the README names as a partner. The README advises against the Smart CDN bundle for production.
