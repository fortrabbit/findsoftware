Oat++ is an open-source C++ web framework. Its REST layer covers request parameter mapping and Swagger-UI annotations, and the about page lists an ORM framework, a WebSocket framework, object mapping with DTOs and dependency injection. The ORM interfaces live in the main module, and a database adaptor module such as the SQLite or PostgreSQL one is linked in separately. The project describes Oat++ as zero-dependency. It is built from a git clone with CMake, as the [Unix and Linux installation page](https://oatpp.io/docs/installation/unix-linux/) describes, and the docs also cover community-maintained vcpkg and Conan packages.
