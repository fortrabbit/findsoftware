Neutrino is a JavaScript build tool that runs webpack and configures it through presets, so a web or Node.js project can be built from shared configuration instead of a hand-written webpack setup. Presets can be extended for other projects or changed for one project. A project is set up by installing the neutrino package with npm or Yarn together with a middleware package for the kind of project, or by a scaffolding command that creates the project structure. The source is hosted on GitHub by the Neutrino organization.

## Worth knowing

The repository is archived and the npm package is marked as no longer supported. The homepage named in the README no longer leads to the project; the documentation that remains is the copy in the repository.
