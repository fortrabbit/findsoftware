my_py_site is a Python static site and blog generator that renders Jinja2 templates with data from a config.json file. Pages carry YAML front matter, and files in a collections folder are listed to templates.

The README says to clone or download the repository, install requirements.txt with pip and run my_py_site.py. It gives Netlify as a deployment route: fork the repository and add it to Netlify.

## Worth knowing

The repository has no release and no tag, and the README says the documentation is still in progress.
