Comfortable is a hosted headless CMS. Editors manage content in a hosted web interface, and the content is read through a RESTful API. Images are transformed through imgix.

Each content repository is a separate space with its own documents, users and locales. A field can be marked translatable, so each language holds its own value, and a fallback language serves a field where a translation is missing. Users hold one of four roles in a repository, from Owner to Editor, and the Editor role covers only content objects such as documents and assets.

## Worth knowing

The service runs only on Comfortable's cloud. The [pricing page](https://www.comfortable.io/pricing) says it is not possible to run it on your own server. The editor offers drafts and version restore for documents.
