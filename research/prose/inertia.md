Inertia.js is an adapter protocol and a set of client libraries that let a server-side framework drive single-page React, Vue and Svelte apps. The server keeps its routing while the client renders the pages, so the app needs no separate API between the two, and Inertia can also render pages on the server. The Laravel adapter is the official one; adapters for other server frameworks are community projects, according to the [installation guide](https://inertiajs.com/docs/v3/installation), which points to Laravel starter kits as scaffolding for new applications.
