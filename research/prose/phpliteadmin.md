phpLiteAdmin is a web-based admin tool for SQLite databases, written in PHP. The [project site](https://www.phpliteadmin.org/) describes it as a single PHP file that is copied to a directory on a server and opened in a browser. The readme says it supports SQLite3 and SQLite2 databases and is translated into several languages.

## Worth knowing

GitHub reports no license for the repository, so the license comes from the readme's license section. The stable version is named on the project's download page.
