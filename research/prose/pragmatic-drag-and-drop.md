Pragmatic drag and drop is a low-level library that makes the browser's built-in drag and drop safe to use across an application. A small core package handles the drag and drop behavior, and optional packages add pieces on top of it. The core works with any view library, so the same behavior can be wired into components built with any framework. Its [comparison page](https://atlassian.design/components/pragmatic-drag-and-drop/comparison) sets it against several other drag and drop libraries.

## Worth knowing

The optional visual outputs and assistive technology controls follow the Atlassian Design System, and the README says a team can substitute its own components. The GitHub repository is a one-way mirror of Atlassian's internal monorepo that does not accept code contributions, and the packages are published on npm under the `@atlaskit` scope.
