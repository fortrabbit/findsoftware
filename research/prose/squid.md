Squid is a caching proxy for the web that supports HTTP, HTTPS and FTP. Its own site describes it as a server accelerator for websites. The project's FAQ describes starting it in the background as a daemon process.

It can be built from source with configure and make, installed from the packages of an operating system, or downloaded as a binary package for several platforms.

## Worth knowing

The developers support only the latest stable release series. Support for older series may come from distributions or third parties.
