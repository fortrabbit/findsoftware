JSON Forms is a framework for building forms from two schemas: a JSON Schema that describes the data, and a UI schema that describes how the data is shown. The core package is independent of any UI framework. React, Angular and Vue bindings, and renderer sets built on Material UI, Vuetify and Angular Material, come from the same monorepo. The tutorial installs the core package together with the React renderer sets.

## Worth knowing

The core provides a translation function, but the renderer sets are not yet translatable, according to the docs.
