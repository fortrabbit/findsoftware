Vue (Official) is the editor and type-checking tooling the Vue project publishes for Vue single-file components. The repository holds the Vue (Official) VS Code extension, the vue-tsc command line type checker and a language server, all written in TypeScript and based on Volar.js. The extension installs from the VS Code Marketplace, and vue-tsc installs from npm as a development dependency.

## Worth knowing

The Vue documentation names this extension as the recommended editor setup. The same page names Vetur, the earlier official extension for Vue 2, which is a separate project with no record here. The extension was previously published under the name Volar.
