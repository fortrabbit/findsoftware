interact.js adds drag and drop, resizing and multi-touch gestures to elements on a web page, with inertia and snapping for the movement. The homepage says the library does not move anything itself: it provides the pointer event data, and the page decides what feedback users get, whether that is dragging elements, drawing on a canvas or scrolling the page. It works with HTML and SVG, and one API covers touch and mouse events.

## Worth knowing

The project's Pro page lists further features and describes interact.js Pro as still under development.
