Octicons is GitHub's set of SVG icons, shipped as a family of packages for JavaScript, React and Ruby. The core package is a Node.js package with a JavaScript API, the React package provides one component per icon, and the Ruby gems provide a Ruby API along with a Rails helper and a Jekyll plugin. The [code page](https://primer.style/octicons/code/) says the icons are provided as SVGs, with helpers for React and Rails projects.

Each package is installed separately from its registry, so a project takes only the helper it needs. The repository holds all of the packages together. GitHub, Inc. maintains it.

## Worth knowing

The README asks users of the GitHub logos among the icons to follow the GitHub logo guidelines.
