Obelisk is a static site generator for Elixir that builds blog posts and pages from Markdown files in a project directory. Layouts are written in EEx or HAML.

It is added to an Elixir project as a Hex dependency through mix. The README describes a local server for checking the built site.

## Worth knowing

The GitHub repository that the Hex package links to is archived, so the project is recorded as discontinued.
