Windi CSS is a utility-first CSS framework installed from npm as `windicss`. The [integration docs](https://windicss.org/integrations/javascript) show the install step for the JavaScript API. The project's guide calls it an on-demand alternative to Tailwind CSS.

## Worth knowing

The project is sunsetting. Its README and the [sunsetting post](https://windicss.org/posts/sunsetting.html) state that the team no longer has the time to work on it and does not expect new features, while security fixes continue.
