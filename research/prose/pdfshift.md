PDFShift is a hosted API that converts raw HTML or a URL into a PDF document. Requests go to its conversion endpoint with an API key, and the [documentation](https://docs.pdfshift.io/) covers sandbox mode, webhook events, templates, export to an S3 bucket and logs.

The service is operated by SASU PDFShift, a company organized under the laws of France, and has run since 2018. Data of EU customers is stored in French datacenters hosted by OVH.

## Worth knowing

The free plan limits each file to 15 MB, according to the pricing page. The pricing page says every paid plan includes all features.
