WebGUI is a content management system and web application framework written in Perl. Its install instructions ask for a recent Perl and MySQL, a configuration file for each site and an imported database schema, and they launch the application with plackup. Plain Black Corporation is named as the copyright holder, and the code is licensed under the GNU General Public License, version 2.

## Worth knowing

The GitHub repository is archived, and its newest commit on the master branch is dated 2014. The homepage the repository names does not answer over https.
