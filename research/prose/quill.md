Quill is a rich text editor library that a web page embeds. The quickstart initializes the editor from a DOM element, and the homepage describes an API with granular access to the editor's content, changes and events, using JSON as both input and output. Quill loads from a CDN with a script tag, which needs no build step, or installs with npm for projects that use a bundler. The README names Jason Chen and Byron Milligan as its creators and Slab as the company that maintains it.

## Worth knowing
