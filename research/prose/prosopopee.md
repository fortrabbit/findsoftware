Prosopopee is a Python static website generator for picture galleries arranged as sections of a story. Content is managed in YAML files, and the [documentation](https://prosopopee.readthedocs.io/en/latest/) describes installing it with pip3 or a Docker image. Building gallery output needs GraphicsMagick and a video converter such as ffmpeg on the machine. The output is completely static, so it can be hosted anywhere, and a deploy command uploads it with rsync.
