TestNG is a Java testing framework for unit, functional and integration tests. Tests are marked with annotations, and an XML suite file can group them and pass them parameters. The [project site](https://testng.org/) holds the manual and the download instructions.

The docs describe running it from the command line, an Ant task, Maven or Gradle. TestNG can also run existing JUnit tests, and the manual describes converting them to TestNG step by step.

## Worth knowing

Running TestNG needs Java 11 or newer, as the README states for the current release. The docs say that older releases ran on Java 8.
