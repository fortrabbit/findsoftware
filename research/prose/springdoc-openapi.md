springdoc-openapi is a Java library for Spring Boot that generates OpenAPI 3 documentation from an application and serves Swagger UI and Scalar pages for it. Its homepage describes it as a library that automates the generation of API documentation for Spring Boot projects. A project adds one of the library's starter dependencies to its build, and the library's artifacts are hosted on Maven Central. The homepage includes a migration guide for projects that use SpringFox.

## Worth knowing

The homepage says the project is a community project that the Spring team does not maintain. Older Spring Boot lines are kept on separate branches.
