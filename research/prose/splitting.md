Splitting is a JavaScript microlibrary that splits an element into words, characters and child nodes. Each piece is wrapped in a span populated with CSS variables, which lets CSS or a JavaScript animation library address each piece on its own. The guide says the library handles no animation itself: it provides the elements and variables an animation is built from.

## Worth knowing

The license file names Stephen Shaw as the copyright holder, and the README's maintainers table lists a second person.
