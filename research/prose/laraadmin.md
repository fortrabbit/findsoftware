LaraAdmin is an admin panel for Laravel that manages a project's models and their role permissions and generates CRUD screens from them. It is added to a Laravel project with Composer and runs inside that application.

## Worth knowing

The [installation docs](https://laraadmin.com/docs) cover the packaged release line on an early Laravel version. The default branch has turned LaraAdmin into a project template that has no installation page yet, and the README lists user management and workflows as under development.
