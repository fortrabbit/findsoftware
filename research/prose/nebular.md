Nebular is an Angular UI library with themed components, distributed as npm packages. The core package is added to an Angular project with the Angular CLI, which configures it automatically, or installed by hand with its peer packages and a theme stylesheet listed in the project's build configuration.

Authentication, security and date handling are separate npm packages. The security package covers roles and permissions, and the docs list right-to-left support for all components. The build output of a Nebular app is a set of HTML, JavaScript and CSS files, and the deployment guide says no other processing is needed to run them in a browser.

## Worth knowing

The README says the repository is in a state of minimal maintenance. The maintainers focus on keeping the Angular version up to date, and they are not reviewing or merging pull requests or responding to issues at this time.
