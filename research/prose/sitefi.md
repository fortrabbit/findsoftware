SiteFi is a static site generator for F# that builds a blog from Markdown articles with WebSharper. The build writes complete HTML pages into an output folder, ready to deploy to a web server. The repository also holds a Hosted project, an ASP.NET Core application that runs the same blog for self-hosting. Articles can be written in several languages, which adds a language selector to the site. Building needs the Dotnet SDK and Node.

## Worth knowing

The repository has no releases and no tags.
