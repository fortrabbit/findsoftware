Ariakit is an open-source React library of unstyled, accessible components and hooks for building web apps. It ships as the @ariakit/react npm package, which the [getting-started guide](https://ariakit.com/guide/getting-started) installs with a package manager, and the guide also shows a CDN method for development only. The project was previously named Reakit.

The source sits in a monorepo; the figures on this record are for @ariakit/react, the package the guide installs.

## Worth knowing

The repository carries three licenses. The packages are MIT. Recipes that the project marks as Plus are licensed to customers of Ariakit Plus under the Ariakit Plus License, and the website source is proprietary with no license granted. The [README's licensing table](https://github.com/ariakit/ariakit/blob/main/readme.md) lists which path each license covers.
