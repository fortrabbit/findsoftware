Dapper is an object mapper for .NET that extends ADO.NET database connections with methods for running SQL and mapping the results to typed objects. A project adds it as a NuGet library. The repository also ships related packages, including Dapper.Rainbow, a micro-ORM built on Dapper, and Dapper.SqlBuilder, a component for building SQL queries dynamically.

## Worth knowing

The README names Dapper Plus, a separate commercial library, as a major sponsor of the project. Dapper Plus is not part of Dapper.
