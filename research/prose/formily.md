Formily is a form library built around a framework-agnostic core package, @formily/core, which is installed from npm. Bridge packages connect the core to React and to Vue, and the @formily/antd and @formily/next packages wrap Ant Design and Alibaba Fusion components for forms. The source is on GitHub under the alibaba organization, and the copyright holder named in its license is Alibaba Group Holding Limited.
