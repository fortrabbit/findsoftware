howler.js is an audio library for the modern web. It defaults to the Web Audio API and falls back to HTML5 Audio. A Howl object takes sound sources in order of preference and loads the first one that is compatible with the current browser. The [README](https://github.com/goldfire/howler.js/blob/master/README.md) lists npm, Bower, hosted CDNs and a repository clone as ways to get started. James Simpson created it, and the LICENSE names GoldFire Studios, Inc. alongside him.

## Worth knowing

Full browser coverage needs at least two audio formats, and the README names mp3 as the fallback for Internet Explorer.
