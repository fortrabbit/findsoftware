RxDB is a NoSQL database for JavaScript that runs inside the application and keeps data on the client. It replicates with a backend through plugins, with ready-made ones for GraphQL, CouchDB and WebSocket, and it can run embedded in a Node.js process as well. The storage engine underneath can be swapped, among them SQLite and MongoDB.

## Worth knowing

The core is free. A Pro and a Pro Plus tier add commercial plugins, and the SQLite storage is one of them; the core ships only a trial SQLite storage limited to 500 documents.
