OneEntry is a hosted platform that combines a headless CMS, headless e-commerce and backend-as-a-service functions for building digital products. The headless CMS delivers content over APIs to any frontend, and an administration dashboard manages it. Frontends connect through an SDK, an API and an MCP server, which the pages name without stating a protocol.

## Worth knowing

OneEntry is hosted only. The pricing page describes a dedicated installation for each project, with its own database, and no self-hosted install is described on the pages read.
