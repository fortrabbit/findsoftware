NGINX Unit is a universal web application server that runs application code, serves static assets and handles TLS and request routing. The [installation guide](https://unit.nginx.org/installation/) covers official binary packages, a Docker official image, a Homebrew tap, a Node.js module and a build from source, and it shows Unit started as a daemon.

## Worth knowing

The homepage states that NGINX Unit is archived and unmaintained. The GitHub repository is archived too.
