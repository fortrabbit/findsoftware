Opensolr is a hosted service that runs Apache Solr search indexes for websites and apps. A customer creates an index and picks the Solr version and the region it is hosted in; the service provides a web crawler, hybrid search, a RAG API and a hosted search page. The operator is Opensolr SRL, a company registered in Romania.

## Worth knowing

There is no installable server: the indexes run on the provider's infrastructure. The free plan includes a monthly allowance of AI requests.
