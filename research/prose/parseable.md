Parseable is an observability platform for logs, metrics and traces. It ships as a single binary with a web UI, a SQL query layer, and an ingestion API that agents and OpenTelemetry collectors send data to over HTTP. Its data lake keeps telemetry in columnar form, in object storage for the distributed deployment and on a local disk in standalone mode.

## Worth knowing

The open source edition is licensed under the AGPL. An Enterprise plan on a custom price adds features the open source edition does not list, such as multi-tenant clusters and audit logging. A managed cloud is offered with a free trial.
