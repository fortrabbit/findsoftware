next-intl brings translated messages, locale-aware formatting and localized routing to Next.js applications. The [Next.js plugin page](https://next-intl.dev/docs/usage/plugin) describes adding its plugin to the Next.js config. The repository is a monorepo that also holds use-intl, the core library, which covers the parts that do not depend on Next.js.

## Worth knowing

The docs name Crowdin, a separate localization platform, as a companion for managing translations, and the eloqnt CLI as a companion linter for messages. Both are separate products.
