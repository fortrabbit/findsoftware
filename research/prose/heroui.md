HeroUI is a component library for React web and React Native applications, released as open source. According to its homepage, the web library combines React Aria Components with Tailwind CSS v4. It installs with npm, and the [quick-start guide](https://heroui.com/docs/react/getting-started/quick-start) asks for the Tailwind import before the styles package. The project was previously named NextUI, and the footer of its website still reads NextUI Inc.

## Worth knowing

The homepage says teams can use the free packages. HeroUI Pro is a separate paid product that sells additional components, templates and AI tooling under perpetual licenses for each edition.
