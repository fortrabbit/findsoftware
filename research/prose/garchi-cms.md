Garchi CMS is a hosted headless CMS and content operations platform, developed by LumenHarbor Digital Solutions Limited. Content lives in a hosted space: the team edits it in a dashboard and the app reads it over the REST API. The documentation also covers a live editor, in which the page updates as fields change, and content in multiple languages per space.

An MCP server gives AI agents access to the same content through a separate path, and the docs include Node and PHP SDKs and usage guides for Nuxt, Next.js and Laravel.

## Worth knowing

Garchi CMS is a hosted service. A free Sandbox plan needs no card, the plans differ in the limits they set on spaces, items, storage and bandwidth, and the pricing page states that the number of API calls per month is not capped.
