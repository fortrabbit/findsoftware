Hoplon is a ClojureScript library for building single-page web applications. Its elements bind DOM nodes to a Javelin cell graph, so the view follows the cells it reads. The [Get Started guide](https://github.com/hoplon/hoplon/wiki/Get-Started) creates a project with deps-new through the Clojure CLI, and the production build, `npx shadow-cljs release app`, writes static files to `public/` for any hosting provider to serve. Development runs `npx shadow-cljs watch app`. The copyright line names Alan Dipert and Micha Niskin, and the repository belongs to the hoplon organization on GitHub.
