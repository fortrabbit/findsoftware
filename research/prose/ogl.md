OGL is a WebGL library for JavaScript that the project describes as minimal, with a low level of abstraction. It is written as ES modules with no dependencies, and it is installed with npm, loaded from a CDN or downloaded as a zip. The [examples site](https://oframe.github.io/ogl/examples) holds the reference examples.

## Worth knowing

The repository has no LICENSE file. The Unlicense text sits in the README and the license field sits in package.json, and both place the code in the public domain.
