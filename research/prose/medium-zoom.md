medium-zoom is a JavaScript library that zooms an image when it is clicked. It is installed from npm, or loaded with a script tag from a CDN. A React component is also available: the shadcn CLI copies it into a project set up with shadcn/ui and installs the library as a dependency.

## Worth knowing

The shadcn route copies the component source into the project that installs it, so later changes to that copy are made in that project.
