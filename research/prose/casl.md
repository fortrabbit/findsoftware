CASL is a JavaScript authorization library that decides what a given user may access. Its core package runs in browsers and in Node.js, according to the install page, and it installs with npm, Yarn or pnpm. For prototypes the install page also gives a route that loads the package from the esm.sh CDN.

Official integrations for React, Vue and Angular, and for Prisma and Mongoose, ship as separate packages. The Mongoose package is the one the README names for MongoDB.
