ImageOptim is a macOS application that optimizes images. The README describes it as a GUI for lossless image optimization tools. It is downloaded from the project's own page as a binary; the homepage states that it is not in the App Store.

The project also runs the ImageOptim API, a hosted HTTP web service for resizing and compressing images on a server. It has its own sign-up and [pricing page](https://imageoptim.com/api/pricing), separate from the desktop app.

## Worth knowing

The homepage says that PNGOUT is bundled under terms that are not the GPL, so the app's license does not cover that part. The macOS version it needs is stated differently on the download page and in the changelog.
