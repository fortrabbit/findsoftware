WebForms Core is a technology in which server code produces UI commands and WebFormsJS, a JavaScript library, applies them to the HTML page in the browser. The server side is a WebForms class written for the language the application already uses, and the product page lists implementations for C#, Python, Java, PHP, Ruby, Swift, Elixir, Node.js, Go, Rust and AssemblyScript. Elanat publishes it, and both the browser library and the server classes are MIT-licensed. The library is distributed on npm as webformsjs.
