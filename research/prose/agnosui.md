AgnosUI provides each component in headless mode for Angular, React and Svelte, all built from the same factory, and offers Bootstrap-styled versions of the same components. A framework-agnostic core holds each component's data and methods, and a separate package per framework and style builds the markup on top of it.

The [installation guide](https://github.com/AmadeusITGroup/AgnosUI/blob/main/INSTALLATION.md) lists the npm packages: the core, and one headless and one Bootstrap package for each framework. The copyright line names Amadeus s.a.s.
