Iconify is a unified icon framework that works with any icon library. Its icon web component, iconify-icon, takes an icon name as an attribute and loads that icon from the Iconify API when it is rendered in the browser. The component is installed with npm or loaded from a CDN.

## Worth knowing

Icon data comes from the Iconify API at runtime, which the documentation says can be replaced with a self-hosted API. The MIT license covers the software; the README says it does not cover the icons, which carry the licenses of their own icon sets.
