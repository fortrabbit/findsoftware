Magnific Popup is a lightbox and modal dialog plugin for jQuery and Zepto.js. The [documentation and getting started guide](https://dimsemenov.com/plugins/magnific-popup/documentation.html) sits on the maintainer's own site.

## Worth knowing

The README states that the plugin is deprecated and that only critical or security fixes will ship. It points readers to the native dialog element for a basic dialog and to the maintainer's PhotoSwipe library for an advanced image gallery. The MIT license comes with a request not to publish a public WordPress plugin based on it without contacting the maintainer first.
