lighttpd is a web server written in C. Its features include FastCGI, CGI, authentication, output compression and URL rewriting, and its configuration reference names mod_fastcgi, mod_proxy and mod_openssl among its modules. Packages exist for Debian and Ubuntu, Fedora, openSUSE, Gentoo and FreeBSD, and the source builds with automake, cmake, meson or scons. The install guide notes many ways to set it up to run as a daemon.

## Worth knowing

The GitHub repository is a mirror, and its description says the main repository is still on lighttpd.net. The wiki documents the configuration options.
