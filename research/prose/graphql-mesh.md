GraphQL Mesh is a framework for building GraphQL gateways over GraphQL and non-GraphQL sources. Its current documentation describes Mesh Compose, a command-line tool installed from npm that composes the sources into a supergraph file. Hive Gateway or another federation gateway serves the supergraph, so serving is a separate component from the composition step.

The company behind Mesh also makes Hive Gateway and Hive, which are separate products.
