Elm is a functional language that compiles to JavaScript, for building websites and web apps. Programs follow The Elm Architecture. The elm command compiles them either to an index.html file or to a JavaScript file that a custom HTML page loads and starts, and the output is served like any other HTML file.

The compiler is a single executable file, installed from the Mac and Windows installers or downloaded directly. Packages live at package.elm-lang.org. The guide's JavaScript Interop chapter names flags, ports and custom elements for working with JavaScript.
