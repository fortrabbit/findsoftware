Gauge is an open source acceptance testing framework. Its test specifications are written in Markdown, and each step is implemented in a programming language. The docs say step implementations can be written in Java, C#, Python, TypeScript and Golang, and the language runners are plugins. The core is written in Go. The README copyright line names ThoughtWorks, Inc.

## Worth knowing

The README's important note says Gauge's official sponsorship ended, that the core team looks at issues in its spare time with slower response times, and that users should consider Gauge only if they are prepared to adopt and support it on their own.
