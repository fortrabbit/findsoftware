POEditor is a hosted localization platform for translation projects, managed in the vendor's web app. The [API documentation](https://poeditor.com/docs/api) describes a REST API that software connects to. Code Whale Inc. operates the service, which has been available since 2012 in several paid and free plans.

## Worth knowing

The privacy page says all data is stored in data centers in EU countries. The privacy page names Stripe, Inc. in the US as the payment processor that receives name and email. SAML single sign-on is available to organizations on the Enterprise plan.
