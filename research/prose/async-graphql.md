async-graphql is a GraphQL server library written in Rust. It defines schemas with procedural macros and runs on async/await. The README names integrations for Poem, Actix-web, Warp, Rocket and Axum that connect the library to a web server.

Projects add the crate to their Cargo.toml, as the [quickstart](https://async-graphql.github.io/async-graphql/en/quickstart.html) shows. The [book](https://async-graphql.github.io/async-graphql/en/index.html) is the project's documentation.
