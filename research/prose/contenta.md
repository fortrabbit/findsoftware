Contenta CMS is a Drupal 8 distribution that provides a JSON:API content API and demo content for building decoupled applications and websites. The homepage describes it as an API-first Drupal distribution, and the README says it is a content API and CMS based on Drupal 8. Installation is done with a download script and Composer, followed by a Composer script that sets up the database; MySQL is the database named in the install steps, and SQLite is named for the local quick install.

## Worth knowing

The repository is archived. The README opens with "DEPRECATED" and says the project was archived because no one has taken on the maintainer role. The homepage still says Contenta CMS is actively supported by an open community; the archive and the README are the stronger statements, and the record follows them.
