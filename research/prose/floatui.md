Float UI is a collection of UI components and website templates styled with Tailwind CSS. The components are written for React, and the homepage describes a copy-and-paste workflow rather than an installable package. MarsX publishes the source on GitHub.

## Worth knowing

The license is a custom Float UI license, not a standard open source one. It permits building End Products, including sold ones, and forbids distributing the components on their own, inside a website builder, or as themes or starter kits. The README and homepage call the project free and open source.
