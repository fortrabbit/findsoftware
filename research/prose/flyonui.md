FlyonUI is a Tailwind CSS component library that adds semantic class names, so markup can use one short class where Tailwind alone needs a long list of utilities. It also ships JavaScript plugins for interactive components such as accordions, dropdowns and modals. A project installs the package with npm and adds it to its Tailwind CSS configuration with a plugin line.

The docs say FlyonUI offers no CDN support, because its styles are generated on demand for the JavaScript components a project uses.

## Worth knowing

The open-source library is MIT-licensed, and the [license page](https://flyonui.com/license) describes a separate paid tier, FlyonUI Pro, that sells premium components, blocks, templates and Figma files. The root LICENSE file states that components from Preline UI and daisyUI are bundled and remain under their own license terms.
