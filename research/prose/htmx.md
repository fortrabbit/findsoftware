htmx is a browser library that uses HTML attributes to trigger AJAX requests and CSS transitions, and to open WebSocket and Server-Sent Event connections. The [documentation](https://htmx.org/docs/) calls it a browser-oriented library with no dependencies and says it is added with a script tag, without a build system. It is the successor to intercooler.js.

## Worth knowing

The homepage says a newer major line has been released but is not marked as the npm latest version, so that people on the current line are not upgraded by accident.
