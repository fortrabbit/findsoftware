Yii is a component-based PHP framework maintained as two lines. Yii 2 is a monolithic framework, installed from its basic or advanced application templates. Yii3 is a set of independently versioned packages, started from the `yiisoft/app` template, which includes a Docker setup. The two lines differ in code base and install path. Yii3 applications can optionally run under the RoadRunner, Swoole or FrankenPHP application servers. The release-cycle page announces a successor line for Yii 2. Yii Software holds the copyright.

## Worth knowing

Yii 2 follows a published schedule that moves it to security-only support and then ends it.
