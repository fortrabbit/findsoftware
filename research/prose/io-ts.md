io-ts is a TypeScript library for checking data while the program runs, against types the program defines. Each codec describes one type and can decode, encode and type-check values of that type. The stable API is documented in the [module reference](https://gcanti.github.io/io-ts/docs/modules).

The library expects fp-ts to be installed beside it as a peer dependency.

## Worth knowing

The project also ships experimental modules for decoding, encoding, codecs, equality and schemas. The README describes them as backward-incompatible with the stable modules and at risk of changing without notice.
