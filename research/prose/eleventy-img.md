Eleventy Image is a utility that transforms raster and vector images at build time, writing each image in several sizes and formats and producing `img` or `picture` markup. According to its README it is a plugin for the Eleventy static site generator, and its [documentation](https://www.11ty.dev/docs/plugins/image/) also describes a low-level JavaScript API that works independent of Eleventy. It uses the sharp image processor and is published on npm as `@11ty/eleventy-img`.
