Floating UI is a JavaScript library that positions floating elements such as tooltips, popovers and dropdowns next to an anchor. The [getting-started guide](https://floating-ui.com/docs/getting-started) installs it from npm or loads it from a CDN, and names separate packages for vanilla JavaScript, React and React Native, and Vue. A core package serves other platforms, such as canvas. The repository is a monorepo that also holds the project's website.

## Worth knowing

Floating UI forked Popper 2, and the project's [migration guide](https://floating-ui.com/docs/migration) covers moving an existing Popper v2 setup to Floating UI.
