Suncel is a headless CMS for Next.js applications. Developers define reusable content blocks as React components with the @suncel/nextjs package, and editors assemble pages from those blocks in a visual builder. The admin interface is a route that the application adds to itself, and the application reads content through the functions the package provides. The FAQ says the content is stored by Suncel while the Next.js application is hosted by its owner.

The documentation covers a preview route for unsaved pages, a renamable admin path, and multiple locales configured through the Next.js routing settings.

## Worth knowing

Suncel is a hosted service run by FAST WEB, and the documentation describes no self-hosted install. The Enterprise plan offers on-premise installation only on request.
