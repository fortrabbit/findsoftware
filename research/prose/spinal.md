Spinal is a hosted git-based CMS for static site generators. Writers edit content in a WYSIWYG editor, and Spinal connects to a GitHub repository to pull the Markdown content already there and push what writers create, edit and schedule. Roles for administrators, authors and publishers set who can edit and who can publish. The about page describes the company as bootstrapped and remote, headquartered in Amsterdam, with data hosted in the EU.

## Worth knowing

Spinal runs as a service at app.spinalcms.com and the docs describe no self-hosted install. Pushed content reaches the live site only if the site's host rebuilds on each push, which the docs name as a requirement.
