QUnit is a JavaScript testing framework. Its README says it was originally developed for the jQuery project and has since evolved to test any client-side or server-side JavaScript code, with no dependencies. Tests run in browsers, Node.js and SpiderMonkey. In the browser, an HTML file loads qunit.js and qunit.css. In Node.js, the qunit command runs the test files. The project's [plugins page](https://qunitjs.com/plugins/) lists extensions for the framework and its browser interface.
