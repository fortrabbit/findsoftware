Trailblazer is a set of Ruby gems for structuring business logic. Its central piece, the operation, is a service object that runs business code as a sequence of steps with error handling and flow control, and is called through a single entry point. The gems also include form objects, view components and test helpers, and the project describes the set as framework-agnostic, used with Rails, Hanami, Roda, Grape and Sinatra.

The gems are licensed under the LGPL. A separate commercial edition, Trailblazer PRO, adds a web debugger and a BPMN workflow editor under a separate commercial agreement that the project's license text ties to purchase.

## Worth knowing

The PRO features and their agreement are separate from the LGPL gems, so the two sets of terms apply to different parts of a project. The project says Trailblazer 2.1 is long-term supported, and the README names it as the current version.
