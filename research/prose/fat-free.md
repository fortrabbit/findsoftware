Fat-Free Framework, also called F3, is a PHP micro-framework for building web applications. It is installed with Composer as `bcosca/fatfree-core` or downloaded directly, and it ships with a template engine and database support for MySQL, SQLite, MSSQL, PostgreSQL, DB2 and MongoDB. The readme says the framework's files can be kept in a directory the web server cannot reach.

The project is maintained by F3::Factory, which publishes the core library in the [fatfree-core](https://github.com/f3-factory/fatfree-core) repository. The [user guide](https://fatfreeframework.com/3.9/user-guide) is the documentation.

## Worth knowing

The readme states the GPL as the license and says alternative licensing is available for a fee.
