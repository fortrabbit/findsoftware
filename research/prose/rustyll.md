Rustyll is a static site generator written in Rust. It builds sites from Markdown and Liquid templates, and it is compatible with Jekyll sites and themes. The [installation guide](https://rustyll.better-web.org/docs/installation/) installs it as a Rust crate with Cargo or as a Docker image, and the [deployment page](https://rustyll.better-web.org/docs/deployment/) describes the generated output as static.

The project publishes migration guides for moving a site from Jekyll, Hugo, Gatsby, Eleventy, Zola, mdBook, GitBook, MkDocs, Pelican, Slate and Bridgetown. It is a Better Web Initiative project.

## Worth knowing

The main branch names a version that has no release yet, so the newest installable version may differ from the code on the main branch.
