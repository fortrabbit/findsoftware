complexity is a Python static site generator for people who work in HTML. Pages are Jinja2 templates in a project folder, and the generated static site is written to a www folder. JSON data files feed the template context, according to the README. The package is installed with pip, and a lightweight local server starts up to serve the generated site for preview.

## Worth knowing

The README names Python 2.6, 2.7 and 3.3 as the versions it works on, and states no minimum. The project's documentation is hosted on Read the Docs.
