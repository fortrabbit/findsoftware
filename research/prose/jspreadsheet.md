Jspreadsheet CE is a JavaScript data grid component with spreadsheet controls for web applications. It is the open edition of the Jspreadsheet product, which the same company also sells as Jspreadsheet Pro under a commercial license. The project was called Jexcel CE before the rename. Its docs describe use with React, Angular or plain JavaScript, and a dictionary function that replaces the interface texts for other languages.

## Worth knowing

Jspreadsheet Pro adds features this edition lacks, such as real-time collaboration and granular permissions, according to the vendor's site.
