Turf is a JavaScript library for geospatial analysis, with spatial operations, helper functions for creating GeoJSON data and statistics. The homepage says it runs in browsers and Node.js, and the README says the browser bundle combines all of its modules into one file. A project installs the @turf/turf package from npm, or loads the bundle through a script tag or a CDN. The [getting started guide](https://turfjs.org/docs/getting-started) covers each route.

## Worth knowing

The README says Deno and Bun are not officially supported, and that a browser build must transpile and polyfill Turf and its dependencies for the target browsers.
