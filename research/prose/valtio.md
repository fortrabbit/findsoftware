Valtio is a proxy-based state library for JavaScript that works with React and without it. The README says it is not tied to React: an object passed to it becomes a proxy whose changes are tracked, components read a snapshot of that state, and subscribe and subscribeKey handle changes made outside components. The same state works in plain JavaScript, and the README says the library works on Node.js, with Next.js and with other frameworks. The documentation is published on valtio.dev, and the Poimandres collective that maintains the project runs the Discord community the README links.
