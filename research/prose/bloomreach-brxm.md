Bloomreach brXM is a Java content management system. Authors edit content in the CMS with its authoring tools and Channel Manager, and a delivery tier serves that content to headless frontends, including ones built with a single-page application SDK. Projects are generated from a Maven archetype and run on Tomcat with a relational database, as the [system requirements](https://docs.content.bloomreach.com/about/platform-overview/system-requirements) list them.

## Worth knowing

The public repository's default branch holds only a README that points to the release tags, which carry the source. The release policy says the open source versions follow enterprise releases after a 24-month delay, so the newest public tag is behind the current product line. Bloomreach also offers the same product as a hosted service, which the docs describe as Bloomreach Cloud and SaaS.
