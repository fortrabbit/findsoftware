XAMPP is a distribution that packages the Apache web server with MariaDB, PHP and Perl, plus phpMyAdmin and a control panel for starting and stopping the servers. It is meant for setting up a local development server, and the project's installers come from its own site, with the files hosted on SourceForge. The Apache Friends project, which describes itself as a non-profit project, publishes it.

## Worth knowing

XAMPP is a compilation: each product it contains keeps its own license, and the project asks readers to check those licenses before commercial use. The documentation is a set of FAQs rather than a manual.
