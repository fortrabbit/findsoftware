React Flow is a React library for building node-based user interfaces, such as flow editors and diagrams. The project publishes it from a monorepo that also contains Svelte Flow and Vue Flow, together with a shared helper package.

The company behind the project, xyflow, is operated by webkid GmbH. A paid Pro subscription adds Pro examples, prioritized GitHub issues and support from the maintainers. The library itself stays under the MIT license.

## Worth knowing

The README says React Flow shows an attribution link on the canvas, and it asks users who remove the link to subscribe. It also states that the MIT license does not require paying or keeping the attribution.
