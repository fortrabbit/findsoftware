flexmark-java is a Java library that parses Markdown according to the CommonMark specification and renders the result, with HTML as the default output. Extension modules add syntax and output formats, and the README names PDF and DOCX output among them.

The project is a fork of the commonmark-java project. The README says it was written to replace the pegdown parser. The Maven artifact named by the install guide, flexmark-all, includes the core and every module.
