dumi is a static site framework for documenting component libraries, built on Umi. A project is created with `npx create-dumi`, and the [initialization guide](https://d.umijs.org/guide/initialize) asks for Node.js 20 or later. The site supports several languages through a `locales` setting in `.dumirc.ts`, as the [i18n guide](https://d.umijs.org/guide/i18n) describes. The FAQ's deployment section builds the site into a `dist` directory and publishes it to GitHub Pages.

The project is maintained by the UmiJS Team and published under the MIT license.

## Worth knowing

The project's own documentation is written in Chinese only, so the [guide](https://d.umijs.org/guide) and the configuration reference are read in Chinese. The README in the repository is in English and links to the Chinese site.
