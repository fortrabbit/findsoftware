adm-dev-kit is a Node.js static web server and build tool for component-driven website development. It is installed with npm into a project, which then runs its development server and build from Node.js. The README names Node.js, JSPM, Express.js, Browser-Sync and Gulp.js among the tools it is built with.

## Worth knowing

The GitHub repository is archived and was last pushed in 2017, so the record is marked discontinued. The npm package was last published in 2016.
