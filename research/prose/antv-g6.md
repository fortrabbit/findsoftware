G6 is a TypeScript engine for graph visualization, and its install page offers npm and CDN routes. The repository is a monorepo of packages, and the core engine is the npm package the install page names. The license names Alipay.inc as copyright holder, and the site footer names Ant Group Co., Ltd.

## Worth knowing

The site credits the AntV team, the license names Alipay.inc, and the footer names Ant Group Co., Ltd., so the owning entity differs across the sources.
