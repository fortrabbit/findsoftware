SunEditor is a WYSIWYG HTML editor written in JavaScript. A page creates it on a textarea or a div element, and the plugins the page needs are passed in the options, so the features the page enables are the ones it lists. The editor runs in the visitor's browser and is installed from npm or loaded from a CDN.

The [getting-started guide](https://suneditor.com/getting-started) is on the project site, which says the editor works with plain JavaScript, React, Vue, Angular, Svelte and Web Components. The React binding is a separate package in its own repository.

## Worth knowing

The README says an older line on a legacy branch is no longer actively maintained. It also says the editor sanitizes HTML on input, paste and Code View.
