Crank.js is a JavaScript and TypeScript library for building websites and applications, in which components are plain functions, generators and promises, and it works with JSX. The [getting-started guide](https://crank.js.org/guides/getting-started/) installs the core package with npm, and also shows a single HTML file that loads Crank from a CDN and runs in the browser with no bundler.

## Worth knowing

The same guide describes a scaffolded app, set up by the create-crank command, that uses server-side rendering and static output with Shovel.js. That is the scaffolded app's stack and not a feature of the core package.
