Overmind is a state management library for web applications. Its state is kept in a single tree, changes to it are made only in actions, and calls to third-party APIs sit in effects.

The core is installed with npm next to a view package for the framework in use: overmind-react, overmind-vue, overmind-angular or overmind-svelte. Its devtools track what happens in an application, effects included, through a standalone app or a VS Code extension, and a server-side rendering API renders the same configuration on the server.
