Cleave.js formats the text a user types into an input element while they type. It has presets for credit card numbers, phone numbers, dates, times and numerals, and options for custom delimiters, prefixes and block patterns. The main file is added with a script tag or imported as a CommonJS, AMD or ES module. Phone formatting also needs a country addon loaded beside the main file. The package includes ReactJS and AngularJS integrations, and its documentation covers the JavaScript API, options and public methods.

## Worth knowing

The [README](https://github.com/nosir/cleave.js/blob/master/README.md) opens with a deprecation notice. It says the library has been deprecated and points to a newer project, cleave-zen, for anyone who still wants to use it. The repository is not archived, so the status rests on that notice.
