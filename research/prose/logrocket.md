LogRocket is a hosted service for session replay, product analytics and error tracking in web and mobile apps. Client SDKs for web and mobile send the data to the service. LogRocket, Inc. is based in Boston, Massachusetts, and its privacy policy states that data is processed in the United States.

## Worth knowing

Self-hosted deployments run on the customer's own infrastructure and are listed on the pricing page under the Enterprise plan with a link to talk to sales; no install guide is public. Active Directory and SAML single sign-on are set up on request. Roles can be defined within a LogRocket account, and the roles documentation places them on the Pro plan.
