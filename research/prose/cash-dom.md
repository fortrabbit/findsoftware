Cash is a DOM library with a jQuery-style API: a query selector and chainable collection methods for finding and changing elements. It is written for modern browsers and can be loaded from a CDN or installed from npm. Where it implements a jQuery method, the README says the two should be compatible, and the repository includes a migration guide.

## Worth knowing

Cash has no website of its own, so its documentation is the README in the repository. The README says full parity with jQuery is not a goal, so a method that jQuery offers may not be in Cash.
