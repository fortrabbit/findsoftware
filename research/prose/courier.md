Courier is a hosted messaging service that an application calls to send notifications across email, SMS, push, chat and in-app channels. Applications use its REST API or an SDK, and the [documentation](https://www.courier.com/docs/) lists server SDKs for Node, Python, Go, Ruby, Java, PHP and C#, and client SDKs for React, JavaScript, iOS, Android, React Native and Flutter. The company behind it is trycourier.com, Inc.

## Worth knowing

Courier runs only as a managed cloud platform, so there is no self-hosted or on-premise install. An EU datacenter keeps notification data in Europe. The pricing page lists SOC 2, GDPR and HIPAA, and the trust center adds CCPA and PCI DSS.
