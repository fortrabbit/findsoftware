Sprockets is a Ruby library that compiles and serves web assets such as JavaScript, CSS and Sass, with declarative dependency directives between files. It is installed as a gem and depends on Rack. The README says it is usually used through another framework, such as the Rails asset pipeline. Asset files can embed Ruby through ERB.

For production, the README says to generate the assets to a directory on disk and serve them from there, for example with Nginx. Sam Stephenson and Joshua Peek are named as the authors, and the gem is developed in the rails GitHub organization.
