Preline UI is a set of prebuilt UI components, blocks and JavaScript plugins that are styled with Tailwind CSS. It is published by Preline Labs Ltd. as the npm package `preline`.

Installation needs a working Tailwind CSS project, Node and npm, and then `npm i preline`. The [installation guide for HTML and Vite](https://preline.co/docs/frameworks-html-vite.html) covers the JavaScript plugin setup.

## Worth knowing

The free library is released under the MIT License and the Preline UI Fair Use License together. The Fair Use License forbids products that compete with Preline UI and requires attribution when derivative templates or themes are sold. Preline Pro, a separate paid product sold under Pro, Team and Enterprise licenses, is licensed on different terms, and its license forbids redistribution and use in derivative themes or generators.
