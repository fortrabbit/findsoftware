webpack is a module bundler that takes an application's JavaScript, CSS, HTML, WebAssembly and other assets and packs them into output files for browsers, Node.js and other runtimes. It runs on Node.js, and the getting-started guide installs the webpack-cli command-line tool alongside webpack. The OpenJS Foundation holds the copyright on the project. The [getting-started guide](https://webpack.js.org/guides/getting-started/) walks through a first build.
