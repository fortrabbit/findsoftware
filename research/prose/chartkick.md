Chartkick is a Ruby gem that draws a JavaScript chart from one line of Ruby in a view. The gem is added to a Gemfile, and the JavaScript side is set up through the app's asset tooling: Importmap, a JavaScript bundler or Sprockets. The quick start pairs it with Chart.js. The README also covers Sinatra and Padrino, where chartkick.js is downloaded and included by hand.

## Worth knowing

The homepage navigation lists Python, React, Vue and Elixir versions of Chartkick as separate projects.
