MkDocs reads a folder of Markdown files and one YAML configuration file, then writes a completely static HTML site. Themes use Jinja templates, and two built-in themes ship with MkDocs. The MkDocs Team maintains it, and Tom Christie is named as its founder. Plugins and themes are catalogued in a GitHub repository. The [deployment guide](https://www.mkdocs.org/user-guide/deploying-your-docs/) covers GitHub Pages, Read the Docs and any static file host.

## Worth knowing

A discussion on the project's GitHub page announces a new major version developed in a private repository, and a second discussion asks who should maintain MkDocs. mkdocs.org shows no notice about either. PyPI also carries pre-releases of a new major version under the same name, and it is unclear whether they are the documentation tool.
