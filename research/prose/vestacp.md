Vesta Control Panel is an open source hosting control panel for Linux servers, managed through a web interface that is translated into 26 languages and regions. It manages websites, DNS, mail and backups, and works with MySQL and PostgreSQL databases. Users get one of three roles: admin, site manager or user.

The README's main install route downloads an install script from the project's domain and pipes it to bash. A second route clones the repository and runs the installer for the operating system.

## Worth knowing

The README says the project is back under active development, and the homepage announces a next major version as coming soon. The install page calls the current version deprecated while a full rebuild is under way. The project is owned by Outroll.
