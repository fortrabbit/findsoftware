Scorched is a Ruby web framework that the homepage describes as generic, unopinionated and light-weight. It is installed as a gem, and the README says it makes no attempt to hide Rack. The homepage calls it an evolutionary enhancement of Sinatra, and the [documentation](https://github.com/Wardrop/Scorched/tree/master/docs) covers controllers, routing, filters, middleware and views.

Views render through Tilt, so any engine Tilt recognizes, such as ERB or Haml, can be used. Tom Wardrop is named in the license as the copyright holder.
