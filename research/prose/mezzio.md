Mezzio is a PHP microframework built on PSR-15 middleware. The [docs](https://docs.mezzio.dev/mezzio/) say it "provides interfaces for routing and templating, letting you choose what to use". The docs name Plates, Twig and laminas-view as templating engines.

The [quick start](https://docs.mezzio.dev/mezzio/v3/getting-started/quick-start/) creates a project from a skeleton and starts the built-in web server for testing. The docs are hosted on the Laminas docs site.
