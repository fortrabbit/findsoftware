Axum is an HTTP routing and request-handling library for Rust, maintained by the axum Contributors. It is a thin layer on top of hyper, and the README's example is a Rust program that starts its own server and listens on a port.

## Worth knowing

The main branch of the repository is working toward the next release with breaking changes, and the README points to the 0.8.x branch for the version released to crates.io.
