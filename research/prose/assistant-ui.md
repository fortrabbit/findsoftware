assistant-ui is a TypeScript and React library for building AI chat interfaces. The [documentation](https://www.assistant-ui.com/docs) describes its components, runtimes and primitives for React, Vue, React Native and the terminal, and the README shows a new project started with a CLI or the packages installed from npm.

The README lists integrations for backends such as the Vercel AI SDK, LangGraph and LangChain.

## Worth knowing

Hosted persistence is a separate service. The [pricing page](https://www.assistant-ui.com/pricing) describes assistant-cloud as an optional backend for threads, history and auth.
