Lucid is the SQL library for AdonisJS. It combines a Knex-based query builder with class-based Active Record models, hand-written migrations, and schema classes that Lucid generates from the live database. Models extend the generated schema classes, so column types are not declared twice. The package is installed into an AdonisJS application from npm, and the [documentation](https://lucid.adonisjs.com/docs/introduction) covers the rest.
