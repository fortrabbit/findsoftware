Polyglot.js is an i18n helper for JavaScript that covers interpolation of values into translated phrases and pluralization. It runs both in the browser and in Node, and the [repository](https://github.com/airbnb/polyglot.js) holds its code and documentation.

## Worth knowing

Polyglot.js performs no translation itself and is agnostic to the translation backend: the application supplies the translated phrases for the current locale.
