Formik is an open source form library for React and React Native. It is described as a small group of React components and hooks for building forms. It is installed from npm, and the [overview](https://formik.org/docs/overview) also describes loading it in a page through a script tag from unpkg. The source is on GitHub under the jaredpalmer user, and the repository license names Formik, Inc. as the copyright holder. Questions go to GitHub Discussions, and the tutorial names a Formium community Discord server for help.

## Worth knowing

The repository holds more than one package, so its stars and contributor counts cover the whole monorepo.
