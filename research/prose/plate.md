Plate is a React framework for rich-text editors. Its core is a headless editor runtime with composable plugins, and the optional Plate UI components are added to a project with the shadcn CLI, which copies them into the project. The same core package runs in Node.js, where the project's Node guide covers reading, validating, transforming and serializing editor values outside the browser.

The docs include a [migration guide](https://platejs.org/docs/migration/slate-to-plate) for moving a Slate React editor to Plate.

## Worth knowing

The older package name `@udecode/plate` is deprecated on npm in favor of `platejs`.
