Boundless Commerce is a headless ecommerce platform with an admin panel and an API. Its open-source edition runs from Docker Compose, using Docker images from Docker Hub. The admin repository holds the installation steps, the API is written in PHP on the Yii2 framework, and one install can hold several shops that are switched between.

## Worth knowing

The company also offers the platform as a hosted service with a free trial. The admin repository's LICENSE file is MIT while its package.json says ISC, and the documentation site has no readable text, so the install steps come from the repositories and the open-source page.
