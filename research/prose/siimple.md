siimple is a themeable CSS toolkit, which its README calls a themeable and customizable CSS framework. Josemi Juanes writes and maintains it. The stylesheet is installed with npm or yarn, or linked from jsDelivr or unpkg. A command line tool compiles a customized stylesheet from a JavaScript configuration file, and the standalone package compiles that configuration in the browser.

## Worth knowing

The getting-started page says the command line tool needs Node.js 14 or higher, so that requirement applies to the build step rather than to the site that uses the stylesheet. The standalone package is marked experimental on the same page.
