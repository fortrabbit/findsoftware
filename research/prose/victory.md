Victory is an ecosystem of composable React components for building interactive charts and data visualizations. The umbrella package named victory is installed with npm, and the docs describe an ESM build that can be loaded from a CDN without a build step. The project is maintained by Nearform, and its README describes maintenance as active.

The repository is a monorepo of separately published victory packages. The legacy victory-native package is no longer developed there, and a separate project covers React Native.

## Worth knowing

Victory 38 requires React 18 or later. For React 16 or 17 the README names Victory 37.
