Sitecore Experience Platform is Sitecore's content management and digital experience platform for building and managing websites and applications. The [installation guide](https://doc.sitecore.com/xp/en/developers/105/guides/quick-installation-guide-for-a-developer-workstation/server-requirements.html) describes an on-premises install on Windows with IIS and SQL Server, and Sitecore also publishes a container deployment package. Sitecore Identity Server provides single sign-on for deployments.

## Worth knowing

The [server requirements](https://doc.sitecore.com/xp/en/developers/105/guides/quick-installation-guide-for-a-developer-workstation/server-requirements.html) call for Windows Server, IIS, the .NET Framework and Solr. The software is licensed commercially under Sitecore's subscription terms. Sitecore's developer portal now leads with SitecoreAI, a separate cloud product that this record does not describe.
