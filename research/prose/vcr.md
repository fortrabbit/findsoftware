VCR records the HTTP interactions of a Ruby test suite to cassette files and replays them in later test runs. The [usage docs](https://benoittgt.github.io/vcr) contain example-based documentation.

## Worth knowing

The gem carries two licenses. The Hippocratic License 2.1 grants its permission only where that is consistent with human rights laws and principles, and an MIT notice covers some portions of the code. The README also names a Python port of the same library, VCR.py.
