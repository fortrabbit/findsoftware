HttpClient is a PHP component of Symfony for sending HTTP requests from PHP code, such as calls to an API. It sends them through PHP stream wrappers or through cURL, synchronously or asynchronously. In the Symfony framework the client is available as the http_client service, which is autowired when a class type-hints the client interface. The docs have sections on interoperability with PSR-18 and PSR-17, HTTPlug and Guzzle.
