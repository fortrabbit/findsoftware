DotVVM is an open-source MVVM framework for ASP.NET. Pages are written in DotHTML markup with DotVVM controls, and the framework renders them on the server or as a single-page application.

The framework supports ASP.NET Core 8 and later, and the documentation names .NET Framework 4.7.2 as supported too. Paid add-on component packs and a paid support tier are sold alongside the Apache 2.0 framework.
