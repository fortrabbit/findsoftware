react-jsonschema-form is a React component that builds an HTML form out of a JSON schema. The schema describes the fields, and the component renders them as the form.

The repository is a monorepo. Next to the core package it holds theme packages for UI kits such as Material UI, Mantine and Chakra UI, and validator packages, and the README lists them as sibling packages.

## Worth knowing

The docs say the project began as a Mozilla Services project. The legacy unscoped npm package of the same name is marked as moved to the current core package, and the Bootstrap 3 theme is marked deprecated.
