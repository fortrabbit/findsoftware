almond.css is a class-less stylesheet: pages use plain HTML5 semantic tags with no classes or IDs, and the stylesheet normalizes browser defaults and adds its own styles. The README says no JavaScript is needed. Theming is by CSS variables with HSL colors. It installs from npm or loads from a CDN with a link tag. Alvaro Montoro, an individual, maintains the project.

## Worth knowing

The license is stated two ways. The repository's LICENSE file is MIT, while the npm package's latest version says GPL-3.0-or-later. The record keeps both statements.
