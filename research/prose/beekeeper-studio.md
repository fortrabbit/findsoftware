Beekeeper Studio is a desktop SQL client for MySQL, PostgreSQL, SQLite, SQL Server and other databases, published by Beekeeper Studio, Inc. It installs from a single download on the developer's machine, and premium features are added through in-app upgrades. The source is in the GitHub repository, and the user guides are on docs.beekeeperstudio.io.

## Worth knowing

The code in the repository is licensed under GPLv3, and the paid features are in the same repository under a commercial source-available license. The Ultimate Edition is licensed under a commercial end user agreement. The pricing page describes the Community Edition as more limited than the paid licenses. Cloud Workspaces is a separate hosted service that syncs and shares connections and queries with a team.
