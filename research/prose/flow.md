Flow is a PHP web application framework focused on Domain-Driven Design and clean code. A project is created with Composer from the Flow base distribution, as the [installation guide](https://flowframework.readthedocs.io/en/stable/TheDefinitiveGuide/PartII/Installation.html) describes. Templates are written in Fluid.

Flow is created by the Neos project and presents itself as a member of the Neos family. The community runs on discuss.neos.io and Slack.
