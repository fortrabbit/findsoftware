GoJS is a JavaScript and TypeScript library for creating and manipulating interactive diagrams, charts and graphs. It renders to an HTML canvas element, with export to SVG or image formats, or directly as SVG DOM, and it can run in a web browser or server side in Node. The npm package holds only the library. The samples and documentation are in the [GitHub repository](https://github.com/NorthwoodsSoftware/GoJS) and on the [project website](https://gojs.net/latest/learn), and the extensions are published as a separate package.

## Worth knowing

GoJS is commercial software. The README says use by or on behalf of an organization is commercial use and needs a purchased license, and that individuals may use it free of charge for non-commercial purposes under a separate agreement. The [pricing page](https://gojs.net/latest/pricing) covers the purchase.
