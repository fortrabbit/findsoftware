hybrids is a JavaScript framework for building web components, component libraries and client-side web applications. It describes components as plain objects and pure functions, and its README lists a global store, an app-like router, a layout engine and localization among its parts. Templates are written with tagged template literals.

The library is installed with npm, or loaded as an ES module from a CDN, and the docs say it runs in modern browsers without transpilation or bundling.
