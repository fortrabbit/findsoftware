CodeIgniter 3 is the 3.x line of the CodeIgniter PHP framework, documented in the [CodeIgniter 3 user guide](https://codeigniter.com/userguide3/). It is installed by downloading the package and uploading its folders to a server, with the `index.php` file at the web root, so PHP handles each request on the server.

The requirements page lists the supported databases, among them MySQL, PostgreSQL, SQLite, Oracle and Microsoft SQL Server.

## Worth knowing

The [download page](https://codeigniter.com/download) calls CodeIgniter 3 the legacy version. It is in maintenance and receives mostly security updates, and CodeIgniter 4 is the current version of the framework.
