Platformatic's application server, Watt, runs Node.js applications as worker threads under a single process. Applications written with a Node.js framework or with plain Node.js are added to a Watt project and started together, and the [quick start](https://docs.platformatic.dev/docs/getting-started/quick-start) creates a project with npx and starts it with npm. Its Database Service, Platformatic DB, generates REST and GraphQL endpoints from a PostgreSQL, MySQL, MariaDB or SQLite database.

## Worth knowing

The homepage also offers ICC, a control plane for Watt instances, through a sales contact.
