Unovis is a data visualization framework with charts, maps and network graphs. Its core package is TypeScript and works without a UI framework. Component packages for React, Angular, Svelte, Vue and Solid sit beside it, and a separate package renders charts to SVG or PNG in Node.

The project's own [comparison page](https://unovis.dev/why-unovis/) renders one dataset with Unovis and with Recharts, Chart.js, ECharts, Nivo and Observable Plot, among others.
