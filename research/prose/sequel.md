Sequel is a SQL database toolkit for Ruby. Queries and table schemas are written in a Ruby DSL, and an ORM layer maps records to Ruby objects and handles associated records. Connection pooling and thread safety are part of the core.

Sequel reaches each database through an adapter, and its README also lists support for prepared statements, savepoints, two-phase commit, primary/replica configurations and database sharding. The bin/sequel console opens an interactive session on a database and can also run migrations, dump schema migrations and copy databases.
