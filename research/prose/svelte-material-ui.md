Svelte Material UI is a set of Svelte components that implement Material Design. The components are published as separate `@smui/*` packages, and the project also publishes a package named svelte-material-ui, which holds the default stylesheet. Components are imported from their individual packages. The [installation guide](https://github.com/hperrin/svelte-material-ui/blob/master/INSTALL.md) lists the packages to install.

## Worth knowing

The README says the current release requires Svelte's current major version and points projects on the older Svelte to the previous release line. Some files are taken from Google's Material Components project and stay under its MIT license; the rest of the code is under the Apache license.
