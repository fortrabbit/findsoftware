Entu SSG is a static site generator that builds HTML files from Pug templates or Markdown. Pages take YAML data files, and styles are written in Stylus. Locale-specific content is selected by filename. The project is installed with npm, and the output is static files that the README says can be hosted on a server, on Netlify or on S3. Argo Roots is named as the copyright holder of the MIT-licensed code.

## Worth knowing

The README marks the assets and server.assets configuration options as deprecated since v5.6.
