Shopify is a hosted commerce platform for online stores, offered by Shopify Inc. The [developer documentation](https://shopify.dev/docs) describes a GraphQL Admin API for products, customers, orders and inventory, and the storefront docs describe headless storefronts with a team's own frontend on Shopify's APIs. The pricing page lists translation of the storefront and localized selling through Shopify Markets.

## Worth knowing

The platform is a hosted service under Shopify's terms of service, and the merchant does not install it. The storefront docs also name Hydrogen, a headless toolkit, and Oxygen, hosting for storefronts built with it; this record does not cover them separately.
