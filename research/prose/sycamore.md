Sycamore is a Rust library for building reactive web apps through WebAssembly. The homepage describes it as a web UI library powered by fine-grained reactivity. The book's first app adds the crate with `cargo add sycamore` and uses Trunk as the recommended build tool.

## Worth knowing

The deployment page of the book is a stub in the docs source and names no hosting target, so the book gives no deployment guidance for Sycamore apps. The homepage describes server-side rendering as supported.
