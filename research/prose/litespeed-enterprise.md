LiteSpeed Web Server is a web server from LiteSpeed Technologies, Inc. Its product page describes it as an Apache alternative that reads Apache configuration files directly and includes a WebAdmin console. It installs on a server with a script that asks for a serial number, or from a tarball unpacked and installed by hand. cPanel, Plesk and DirectAdmin users have pre-configured install options, and the release log describes its restart behavior under a systemd service.

## Worth knowing

The choosing-a-license page calls LiteSpeed Enterprise (LSWS) a paid product and names OpenLiteSpeed as its free, open source counterpart. A free Starter license limits the number of domains, workers and memory, and the paid plans raise those limits and add listener binding and anti-DDoS protection at the higher tiers. The install needs a serial number or trial key, and the server must reach the license server. The install page lists enterprise builds for Linux and FreeBSD.
