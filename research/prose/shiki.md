Shiki colors code using TextMate grammars and runs on JavaScript runtimes including browsers, Node.js and Cloudflare Workers. The homepage describes running it ahead of time, so the published page ships no JavaScript for highlighting; the [install guide](https://shiki.style/guide/install) also shows loading it in the browser from a CDN. The docs list integrations for Nuxt, Astro, VitePress, Next, markdown-it and Rehype.

## Worth knowing

The npm package is published as ESM only.
