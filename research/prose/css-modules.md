CSS Modules is a file convention: a CSS file in which all class names and animation names are scoped locally by default. The files compile to an interchange format called ICSS, and importing one from a JavaScript module gives an object that maps the local names to global ones. The repository holds documentation for the convention, with a [setup page](https://github.com/css-modules/css-modules/blob/master/docs/get-started.md) on bundlers and frameworks that support it.

## Worth knowing

The repository has no installable package of its own. Support comes from the tools that implement the convention.
