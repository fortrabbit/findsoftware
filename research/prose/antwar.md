Antwar is a static site generator built with React and webpack, with blog support. It is installed as the npm package antwar, and its build writes the finished site to a build folder. The project's FAQ describes publishing that folder with gh-pages, and previewing it through a static server, so the output is plain files.

## Worth knowing

The README says Antwar has been superseded by Gustwind, and the repository is archived on GitHub. The documentation on antwar.js.org still describes the software.
