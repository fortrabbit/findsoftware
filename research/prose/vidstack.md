Vidstack Player is a set of UI components and hooks for building video and audio players on the web, and the README calls it the successor to Plyr and Vime. It installs from npm with a JavaScript route and framework routes for React, Vue, Svelte, Angular and Solid, and a CDN route is available through jsDelivr.

The maintainers now describe the project as deprecated and in security-only maintenance. The README names Video.js 10 as the focus of the teams behind Vidstack, Plyr, Media Chrome and Video.js, and the project's homepage points visitors to it.

## Worth knowing

The npm deprecation message asks users to move to Video.js, and the Video.js docs include a migration guide from this player. Security patches are promised only until January 2028.
