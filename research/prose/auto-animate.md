AutoAnimate is an animation utility that adds transitions to a web app when an element is added, removed or moved. It takes a parent element and animates that element's immediate children, so existing markup can be used as it is. It is installed with npm, Yarn or pnpm and works with plain JavaScript as well as with the React, Vue, Preact, Solid, Svelte, Angular and Marko bindings, each on its own import path. FormKit, Inc. publishes it.
