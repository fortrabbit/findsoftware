CoreUI is an open source UI components library created as an extension to Bootstrap. It can be used as a standalone library or as a replacement for Bootstrap in an existing project, and it is installed from npm or loaded from a CDN. The React, Vue and Angular packages are separate packages from the same project.

## Worth knowing

A paid PRO edition is sold alongside the open source code and requires a commercial license, as the [introduction page](https://coreui.io/bootstrap/docs/getting-started/introduction/) states; the [pricing page](https://coreui.io/pricing/) lists it.
