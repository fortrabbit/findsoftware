Untitled UI React is a collection of React components styled with Tailwind CSS and built with React Aria. A project gets them in one of two ways: the `untitledui` command-line tool adds named components to an existing project, or a component is copied from its documentation page into the project by hand.

The components use CSS logical properties, so layouts mirror for right-to-left languages such as Arabic, Hebrew and Persian. The open-source components are MIT-licensed. The publisher, Sisyphus Ventures Pty Ltd, also sells a paid edition, Untitled UI React PRO, under a separate license agreement.

## Worth knowing

The components are copied into the project as source code. The single-user PRO license may not be shared, transferred or reassigned.
