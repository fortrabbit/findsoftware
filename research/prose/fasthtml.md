FastHTML is a Python web framework for building web applications. The [README](https://github.com/AnswerDotAI/fasthtml/blob/main/README.md) says FastHTML apps are just Python code, and the framework uses HTMX for interactivity. It is built on top of Starlette.

The [About page](https://fastht.ml/about/) says FastHTML can be deployed to any Python server or VPS, and that it was started at Answer.AI by Jeremy Howard. SQLite support is provided out of the box.
