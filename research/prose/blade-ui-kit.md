Blade UI Kit is a set of renderless components for Laravel Blade views, made for Blade, Laravel's templating engine. The documentation says the components ship without styling, and that a component needing a third-party library can load it from a CDN through two Blade directives. It is installed with Composer, and its documentation lives in a separate repository linked from the [README](https://github.com/blade-ui-kit/blade-ui-kit/blob/main/README.md).

## Worth knowing

The maintainer's README message says the project will come to an end: the maintainer will not continue it or look for a new maintainer, and invites forks. The Packagist entry for the latest version is marked abandoned. The installation page names PHP 8.0 and Laravel 9.0 as minimums, while the latest package requires PHP 8.1 and Laravel 10 to 12.
