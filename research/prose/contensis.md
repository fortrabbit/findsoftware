Contensis is a hosted digital experience platform from Zengenti Limited. Editors work in a dashboard, and content types can be enabled for several languages on projects that hold a multilingual license key. Content is delivered through a RESTful Delivery API.

Access is set by roles with permissions for each project, and users can sign in through single sign-on. Developers can also push code to the platform as Blocks, packages built as Docker images that Contensis takes for release.

## Worth knowing

The pages read describe the platform as hosted and name no self-hosting option. Blocks are a release route on Contensis, not a way to run the CMS elsewhere.
