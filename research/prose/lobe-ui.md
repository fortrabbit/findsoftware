Lobe UI is a React component library, published as @lobehub/ui, for building AI chat interfaces and web apps that show generated content. It is installed with pnpm, and React plus a few other packages are installed beside it as peer dependencies. The package is ESM only. LobeHub publishes it.

On GitHub, the releases page stops at the previous major line, while the current line is published to npm and exists as git tags without release pages of their own.

## Worth knowing

The current major drops Ant Design. Upgrading from the previous major is covered by a migration guide that the README links.
