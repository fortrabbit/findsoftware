Artgen is a low-code headless CMS. It runs with `npx @artgenio/core` or a Docker image, and it lets its users model data in a visual data modeller and generate REST APIs from it. Its system data is kept in PostgreSQL or SQLite, and its dashboard is customizable. The README describes the project as being in its beta phase.

## Worth knowing

The site the README links, artgen.io, now lists the domain for sale and no longer shows the software.
