WordPress Studio is a desktop app for creating and managing WordPress sites on the developer's machine, and for building and testing plugins and themes there. It can import a WordPress site to work on locally, sync a site with WordPress.com or Pressable, and share cloud-hosted preview links. The Studio CLI exposes some of its features outside the app. The app is installed from a download for macOS, Windows or Linux, and Automattic Inc. maintains it.

## Worth knowing

Sync and preview depend on WordPress.com: Preview Sites are hosted in the cloud and expire after seven days without updates. The README calls the app free and open source, and the repository is GPL licensed.
