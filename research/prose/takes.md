Takes is a Java web framework built from immutable, object-oriented components. It starts its own HTTP server from a Java `main` method, so the application runs as a long-lived process rather than as files that a web space serves. Pages can be rendered as XML transformed with XSLT, which the [README](https://github.com/yegor256/takes/blob/master/README.md) recommends for HTML, or with Apache Velocity templates.

## Worth knowing

The README lists WebSockets as not, and never to be, supported.
