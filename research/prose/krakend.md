KrakenD is an API gateway written in Go that routes and aggregates requests to backend services. The install guide describes it as a single binary that needs no external libraries, and names a Docker image, Homebrew, yum, dnf and apt packages, a tar.gz download and a build from source as ways to get it. Once started, the gateway runs as a service on the host it is installed on.

## Worth knowing

The repository holds the Community Edition, which is Apache-2.0 licensed. A commercial Enterprise Edition is offered beside it, and the project's open-source page lists audit logging, SSO/SAML, security fixes and a support SLA as its additions.
