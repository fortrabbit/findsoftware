Transloco is an internationalization library for Angular applications. It defines translations for several languages and switches between them at runtime. The [installation page](https://jsverse.gitbook.io/transloco/getting-started/installation) recommends adding it with the Angular schematics, and the source is on [GitHub](https://github.com/jsverse/transloco).

## Worth knowing

The next major version is in alpha and is published under a next tag on npm, while the stable release is the one the registry lists as latest.
