Keycloak is an identity and access management server written in Java that supports OpenID Connect, OAuth 2.0 and SAML 2.0. It runs from a container image or from a zip download on OpenJDK, as the [getting-started guide](https://www.keycloak.org/getting-started/getting-started-zip) describes. The homepage describes Keycloak as a Cloud Native Computing Foundation incubation project.
