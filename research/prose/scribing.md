Scribing turns Markdown posts and pages into a static blog. It builds a file for each post and each page, plus an archive page that lists posts by year, using Plates templates. A separate subcommand writes an Atom feed from the posts. The README describes hosting the generated files on GitHub Pages from a separate repository, and the tool is installed with Composer.

## Worth knowing

The repository is archived and read only. The Packagist record flags the package as abandoned, with no replacement named.
