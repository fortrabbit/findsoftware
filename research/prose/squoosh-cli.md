Squoosh CLI is a command-line tool that runs the image codecs of the Squoosh web app over many image files at once, using WebAssembly. It is installed from npm, either run with npx or installed globally, and it runs on the developer's machine. The package's README says it is no longer actively maintained, and the repository has removed the CLI source.

## Worth knowing

The Squoosh web app at squoosh.app is a separate product from the same project. The status of this package does not describe it.
