Ant Design Blazor is a component library for Blazor based on the Ant Design design system. It is published on NuGet as AntDesign and added to a project with dotnet add package. The README says it supports WebAssembly-based client-side and SignalR-based server-side UI event interaction, and WebAssembly static file deployment. The [getting-started guide](https://antblazor.com/en-US/docs/getting-started/) registers the library's services in the application and loads its styles and scripts automatically, with attributes that place or disable that import.

## Worth knowing

The guide says a good knowledge of Blazor and .NET Core is needed before using the library, and that the automatic import of styles and scripts is not supported in the static and Auto render modes, where they are imported manually. The docs site also links a preview of a new major version.
