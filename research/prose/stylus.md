Stylus is a CSS preprocessor language that a developer compiles to CSS with the `stylus` executable, which the npm package installs globally, or with its JavaScript API. It runs on Node.js, and the project's site offers its documentation in English and Chinese.

## Worth knowing

The executable and the JavaScript API run on the developer's machine or in a build step. The project's site also hosts an online playground that runs in the visitor's browser.
