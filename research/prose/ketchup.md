Ketchup is a developer-first CMS written in Go and distributed as one binary. Content is kept in an embedded BoltDB store, so no separate database server is needed. The admin interface is a React application that the binary serves, and the README describes a JSON API for fetching content from static sites or single-page apps.

Templates are developed in version-controlled theme repositories outside Ketchup and pulled in with git, and editors work with content fields that the templates declare. Pages can be previewed while they are edited.
