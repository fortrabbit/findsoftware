ServerPilot is a hosted service that manages servers the user rents from a cloud provider. The [connect guide](https://serverpilot.io/docs/get-started/connect-server/) describes running the ServerPilot installer on such a server, which installs and configures what the server needs for hosting. Apps are then created in the ServerPilot dashboard, and the [docs](https://serverpilot.io/docs/) describe apps that host any type of website, from dynamic web applications to static sites. The [what-is page](https://serverpilot.io/docs/what-is-serverpilot/) says the installer sets up Nginx, Apache, MySQL and several PHP versions.

The service is run by Less Bits, Inc.

## Worth knowing

The servers stay in the user's account at their cloud provider, and the provider's own features, such as its backups, remain available. The service is paid by the server and by the app, billed hourly on its hosted plans.
