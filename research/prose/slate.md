Slate was an API documentation generator created by @lord in 2013, written in Ruby. Documentation is written in Markdown and built into static files. The README speaks of it in the past tense and says its creator took it off GitHub; the repository now holds only that notice on the migration-notice branch, and the repository is archived.

## Worth knowing

The README says the creator keeps a read-only archive of the code on a personal site. The GitHub wiki, which holds the install and usage pages, stays readable.
