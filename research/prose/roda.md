Roda is a Ruby web toolkit built around a routing tree, as its [README](https://github.com/jeremyevans/roda/blob/master/README.rdoc) describes. It is installed as a gem and runs on any web server that handles config.ru files, such as Puma or Passenger. Templates use ERB, with output escaping through Erubi.

The project began as a fork of Cuba, and its README names Sinatra as the other inspiration.
