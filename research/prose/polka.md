Polka is an HTTP server framework for Node.js. It is a native HTTP server with routing, middleware and sub-applications added. Its README presents it as an Express.js alternative, and it extends Trouter, the routing library, to inherit that library's API.

Calling listen boots the underlying HTTP server. The package is installed with npm.

## Worth knowing

The highest stable release is in the 0.x line. The newest pre-release is a build of version 1.0.0.
