aichteeteapee is a Go library for building HTTP servers. Its README describes a server package built on net/http with grouped routes and middleware, WebSocket hubs, file uploads, static file serving and request proxying with caching.

## Worth knowing

The README shows no install command, so how a project adds the library is not stated on the pages read, and the record is a stub until it is. The project has no site of its own; a blog post by the author describes it.
