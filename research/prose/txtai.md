txtai is an AI framework for semantic search, LLM orchestration and language model workflows, written in Python. It can run as a web API backed by FastAPI. Content storage can use SQLite or DuckDB, and the embeddings can be stored in Postgres through the pgvector backend. txtai is installed with pip, run from Docker images on Docker Hub, or installed directly from its GitHub source. NeuML LLC maintains it.

## Worth knowing

A hosted txtai.cloud is planned: the cloud documentation lists it as planned for the future, while the homepage and the company site describe it as being built or in preview.
