Valine is a JavaScript comment system for static blogs and documentation sites. It has no server-side implementation of its own, and the comments are stored by LeanCloud, so a site needs a LeanCloud application to use it. It is installed from npm or loaded from the unpkg CDN. The English docs list Hexo, Jekyll, Hugo, VuePress and Gatsby among the site generators that embed it, and the interface text comes in several languages.

## Worth knowing

The comments live on LeanCloud, a third-party service the site depends on.

The README says updates to the src directory are suspended, while the repository continues to publish releases.
