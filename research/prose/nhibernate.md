NHibernate maps classes to database tables and runs queries against them. The [reference documentation](https://nhibernate.info/doc/nh/en/index.html) is the project's manual, and the user forum is a Google Group.

## Worth knowing

The package targets both .NET Framework and newer .NET runtimes, so the runtime an application needs depends on which target it builds against. The reference's dialect table also names DB2, Firebird, Informix, Ingres and Sybase. The documentation carries its own license, the GNU Free Documentation License, separate from the software's license.
