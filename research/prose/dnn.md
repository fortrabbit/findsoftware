DNN Platform is an open-source content management system for the Microsoft .NET stack. The history page says the project traces back to IBuySpy Workshop, which eventually became DNN, and dates the DotNetNuke release to 2003. Editors manage pages from a persona bar. The platform also covers roles and permissions, multilingual content and multiple sites.

The platform stores its content in a single Microsoft SQL Server database, which the requirements page names as mandatory. Third-party extensions are listed on the community site, separate from the platform.
