Spline Runtime is the JavaScript package that plays scenes made in the Spline editor. The editor is a hosted design tool, and the runtime renders an exported scene on a canvas.

## Worth knowing

The package has no public source repository, and neither its metadata nor its README names a license. The Spline terms page calls the software used with the service proprietary, so the terms for the runtime come from that page rather than from a license file. Scenes are designed in the hosted editor, and the pricing page ties code export to paid plans.
