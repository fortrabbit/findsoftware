Cloudscape is an open source design system from Amazon Web Services, built for and used by AWS products. It combines guidelines and design resources with React components, which the homepage describes as tested, accessible and responsive. The components are imported one at a time from the package, and the global styles package is installed alongside them to apply the system's base styles. The source is published on GitHub under the Apache 2.0 License.

## Worth knowing

The [install guide](https://cloudscape.design/get-started/for-developers/using-cloudscape-components/) states that Cloudscape only supports React.
