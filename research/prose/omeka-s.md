Omeka S is a web publishing platform for institutions, built to create and manage many sites from one installation. Content is managed in an administrative dashboard, and a REST API is documented in the developer documentation. The [user manual](https://omeka.org/s/docs/user-manual/) covers installation from a download, from GitHub or with a one-click installer. The Omeka Classic Importer module brings content from Omeka Classic into Omeka S.
