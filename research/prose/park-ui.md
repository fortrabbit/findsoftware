Park UI is a collection of accessible UI components built on Ark UI and styled with Panda CSS. A project does not import the components from a package: the Park UI CLI copies each component's source into the project, including its recipe, so the code can be read and changed there. The docs present the components for React and Solid, with quickstarts for Next.js and Solid Start. The repository now sits in the Chakra UI organization on GitHub.

## Worth knowing

The changelog says the @park-ui/panda-preset package was retired and that each component's recipe now arrives with the component code.
