WebsiteBaker is an open-source content management system that runs on PHP and MySQL or MariaDB, and it is maintained by WebsiteBaker Org e.V. The installation package is uploaded to a web space, and the installer then starts in a browser. Templates are built from PHP, XHTML and CSS files. The backend includes WYSIWYG editors, support for multiple languages and a group-based access privilege system, and add-ons are published in an official add-on repository.

## Worth knowing

The project's pages give two different PHP minimums, PHP 8.2 on the features page and PHP 8.1 in the installation guide. The installation guide lists Linux as the operating system and Apache as the web server. No page read shows a stable release date, so this record is a stub.
