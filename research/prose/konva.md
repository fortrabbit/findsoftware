Konva is a JavaScript library for drawing and handling interactive 2D shapes on an HTML canvas. It keeps shapes in a scene graph, so each shape has its own events, drag behavior, transforms, animation and export, and the library runs in the browser. The repository began as a GitHub fork of KineticJS.

Bindings for React, Vue, Svelte and Angular are separate packages that the README lists.

## Worth knowing

Running Konva in Node.js needs a canvas backend, either the canvas or the skia-canvas package, installed separately. DOM events require a browser. The README says the maintainers' team also builds Polotno, a commercial design editor SDK built on Konva, and that Polotno sponsors ongoing development.
