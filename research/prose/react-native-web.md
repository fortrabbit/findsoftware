React Native for Web is a compatibility layer between React DOM and React Native. It renders React Native components and APIs in a web browser, and the project says it works in web-only apps, multi-platform apps and existing React DOM apps alike. It is installed with npm, and its docs describe it as built on React DOM, which lets a React DOM app adopt its components one at a time.

Styles are written in JavaScript and converted to CSS by the library, as the docs describe.
