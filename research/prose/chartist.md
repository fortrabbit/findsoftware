Chartist is a JavaScript library that draws responsive charts as SVG and styles them with CSS. It installs from npm for use with a bundler, or loads as a native ES module from a CDN with no build step. The docs also describe server rendering: a chart can be rendered to an SVG string in Node.js, or rendered on the server and then taken over in the browser. The source is a monorepo that holds the library, the docs site and the examples.

## Worth knowing

The server rendering API is marked experimental in the docs and may still change.
