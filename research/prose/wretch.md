Wretch is a wrapper around the fetch API, written in TypeScript. It adds a chainable syntax for building a request, handling error responses and parsing the response body. The [API reference](https://elbywan.github.io/wretch/api/) is generated and hosted on a separate site.

## Worth knowing

The current major line targets modern browsers and recent Node.js releases. The README points users of older Node.js versions and older browsers to earlier major lines.
