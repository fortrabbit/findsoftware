PetaPoco is a micro-ORM for .NET that maps database rows to POCO objects and runs plain SQL queries. Its add-ons for SQL building and POCO generation ship as separate packages. The [wiki](https://github.com/CollaboratingPlatypus/PetaPoco/wiki) holds the documentation.
