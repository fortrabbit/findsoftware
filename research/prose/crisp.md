Crisp is a hosted customer support platform that a site reaches through a chat widget: the Web Chat SDK adds the widget to a website and sets its language from code. Agents answer from a shared inbox that collects conversations from all channels. Crisp IM SAS, based in Nantes, France, operates the service, and its security page says messaging servers are hosted in the Netherlands and plugin servers in Germany. The developer docs describe a REST API.

## Worth knowing

The homepage leads with a customer support platform with a shared inbox, which makes Crisp a helpdesk first and a site embed second. The record is a stub until a reviewer decides whether the chat widget alone meets the inclusion criterion for software added to a site.
