Broccoli Taco is a command-line tool for building static sites powered by Broccoli. It is installed globally with npm. The README describes `broccoli-taco new <folder>` for a new site, `broccoli-taco serve` for a development server, and `broccoli-taco build dist` for a build, with `BROCCOLI_TACO_ENV=production` set before the build to compress assets. Pages, assets and data are added to the new site folder.

## Worth knowing

The README points to broccoli-taco.com for full documentation, and that domain now shows an unrelated page, so the README in the repository is the documentation that remains.
