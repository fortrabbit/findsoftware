Rackla is an open source framework for building API gateways in Elixir. It builds on Plug, and its endpoints are written as Elixir pipelines. The library is added to a Mix project as a dependency from Hex, or a gateway can start from the project's skeleton repository, which the README says can be deployed to a cloud service such as Heroku or built into a Docker image. Anton Fagerberg is named as the maintainer in the license and the Hex package metadata.

## Worth knowing

The Hex package and the repository both stop at the same release, and the project's own homepage no longer resolves.
