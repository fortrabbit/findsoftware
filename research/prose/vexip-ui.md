Vexip UI is a Vue component library written in TypeScript, and its guide says the library is built on Vue 3.0 with the composition API. It installs into an existing project with `pnpm add vexip-ui` or `yarn add vexip-ui`. The [getting-started guide](https://github.com/vexip-ui/vexip-ui/blob/main/docs/en-US/guide/getting-started.md) also describes a `create-vexip` template, which starts a project with the relevant plugins already configured.

The project provides language packages for its built-in text, and the Chinese Simplified language is the default. Under server-side rendering the guide says no extra steps are needed. A first-party Nuxt module adds automatic import for Nuxt projects.
