Apache Pekko HTTP is the HTTP module of Apache Pekko, implementing a full server- and client-side HTTP stack on top of pekko-actor and pekko-stream. It is a fork of Akka HTTP 10.2.x, and the README describes it as a general toolkit for providing and consuming HTTP-based services rather than a web framework.

A project adds it as an sbt, Maven or Gradle dependency from the org.apache.pekko group, for Scala or Java on the Java Virtual Machine. The Apache Software Foundation publishes the documentation on the Apache Pekko site.
