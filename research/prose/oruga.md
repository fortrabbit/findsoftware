Oruga is a UI component library for Vue.js. Its components ship without CSS, so a project styles them through a class mapping that can be set globally or per instance, or through one of the ready-made themes for Bootstrap, Bulma, Tailwind or Oruga's own styles. The components are installed from npm, and the Vue app registers them as a plugin. Each component can be imported on its own.

## Worth knowing

The docs deprecate the Vue 2 package @oruga-ui/oruga and direct further work to @oruga-ui/oruga-next, the package this record covers.
