Spring Security is a Java framework for authentication and access control in Spring-based applications. Its reference documentation says that it provides authentication, authorization and protection against common attacks. The servlet documentation covers SAML 2, OAuth 2.0 with OpenID Connect, and LDAP as ways to authenticate users. Features such as LDAP and OAuth 2 come as separate modules that a project includes next to Spring Security.

## Worth knowing

The reference documentation states a minimum Java runtime for Spring Security.
