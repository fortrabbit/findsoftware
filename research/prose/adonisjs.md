AdonisJS is a Node.js framework in TypeScript for web apps and API servers, with an ORM, validation, mail and queues in the core distribution. The default ORM is Lucid, with SQLite as the default database. The official starter kits cover a hypermedia setup with Edge templates, React or Vue front ends through Inertia.js, and API servers.

## Worth knowing

The build writes a folder that runs as a long-running server, started with node bin/server.js, rather than static files. The project site also lists two paid offerings: AdonisJS Plus, with starter kits and components, and Adocasts, with video courses.
