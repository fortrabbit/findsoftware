nimib is a library for the Nim language that converts Nim source files and their outputs into HTML documents, in the style of notebooks. The library is installed with nimble, and the HTML is rendered from mustache templates. The project publishes its documentation and examples on GitHub Pages from the same repository.

## Worth knowing

Compiling and running a Nim file that uses nimib writes the HTML file next to the Nim source file. The project's ecosystem is being moved to the NimibLand organization on GitHub, while the repository named as the source is still under the pietroppeter account.
