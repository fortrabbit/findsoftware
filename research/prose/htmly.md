HTMLy is a blogging platform and flat-file CMS written in PHP. It keeps posts and pages in files, so no database is needed, and it has an admin panel for writing and editing content. Themes are PHP files that mix HTML tags with PHP code. The [README](https://github.com/danpros/htmly) describes installation as uploading and extracting the zip file on a web server.
