Iris is a web framework for Go. A project adds it with `go get` and writes its routes and handlers in Go code. Views can be rendered with the HTML, Django or Pug template engines, which are registered on the application.

An Iris app runs as a Go program that listens on a port, so a deployed app is a long-running process rather than a set of static files. The [documentation](https://www.iris-go.com/docs/) covers the getting-started steps and the view engines. The maintainer is Gerasimos (Makis) Maropoulos, and the company Hellenic Development created and maintains the framework.
