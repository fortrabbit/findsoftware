Rouge is a pure Ruby syntax highlighter that renders code as HTML or as terminal output. Its gemspec describes it as based on Pygments, and the README says its HTML output is compatible with stylesheets designed for Pygments.

The README names Jekyll's default highlighter as one of its uses, and it lists Middleman, RDoc and Rails integrations that are third-party or downstream.

## Worth knowing

The project site named in the gem metadata returned errors when it was checked, so the record has no homepage.
