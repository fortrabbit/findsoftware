Carbon Charts is a chart component library for vanilla JavaScript, with bindings for Svelte, React, Vue.js and Angular kept in the same repository. The core package is installed from npm, and the documentation site has a StackBlitz example for each chart type in each supported framework. The project is owned by IBM.

## Worth knowing

The core package uses IBM Telemetry, which collects anonymized usage data when the package is installed as a dependency. The README links the opt-out.
