Markdown All in One is an extension for Visual Studio Code that adds Markdown editing to the editor. Its commands cover keyboard shortcuts, a table of contents that can be inserted and kept up to date, table formatting, math and front matter. Math is rendered with KaTeX.

The extension runs inside the editor on the author's own machine. It edits Markdown files and builds no site itself.

## Worth knowing

Its releases are published on the Visual Studio Marketplace rather than as GitHub releases.
