React Bits is a library of animated React components and backgrounds. The project's introduction calls it a free, open source library that users copy into their project and change. Components are added with the shadcn CLI from the project's own registry under the @react-bits namespace, or the files are copied by hand. The install guide does not use npm for the components.

## Worth knowing

The license is MIT with the Commons Clause, which bars selling, sublicensing or redistributing the components. Exported code and images may be used in products and websites, including paid ones. A paid tier, Pro, sells one-time licenses for more components, blocks, templates and an agent kit. The repository has no releases or tags, so its activity is shown by the date of its last commit.
