tape is a test harness for Node.js and browsers that writes its results as TAP, the Test Anything Protocol. Test files load the package, make assertions, and run with node or with the tape command. The project has no website of its own; its [README](https://github.com/tape-testing/tape) is the documentation.

## Worth knowing

The README says the core is minimal and extra features come from other modules used alongside tape. The default output is TAP, which the README calls good for machines, and the README lists reporter packages that turn it into readable reports. Those packages are not part of tape.
