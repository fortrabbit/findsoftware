Tribute is a JavaScript @mention engine that attaches a suggestion menu to inputs, textareas and contenteditable elements. The README says it is written in ES6 with no dependencies. The README calls it a cross-browser engine, and a page attaches it to an element once it is initialized.

The README's framework section lists AngularJS, Angular, Ember, Vue and Rails bindings. They are separate projects, not parts of Tribute, and the README names Froala as a WYSIWYG editor with Tribute support.

## Worth knowing

The RubyGems gem named tribute is a separate package with its own version history, and its download count is the total since it was first published.
