BCMS is a headless CMS offered as the hosted BCMS Cloud, run by Becomes tech, LLC. Users edit content in the browser under per-user permissions, and a project serves content in several languages.

## Worth knowing

The open-source repository is public and free to use, fork and build on, but the project's README says it is no longer maintained. Core development moved to a private codebase in October 2024, and the README says BCMS Cloud went closed-source. The current product is the hosted service, so the record is a hosted service rather than installable software.
