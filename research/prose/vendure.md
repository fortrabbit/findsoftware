Vendure is a headless commerce framework that runs on Node.js and is written in TypeScript. It serves a GraphQL API. Vendure can be self-hosted, and the pricing page says self-hosting runs the same application as Vendure Cloud. The [installation guide](https://docs.vendure.io/current/core/getting-started/installation) covers setting up a project.

## Worth knowing

The repository's license file offers two licenses: GPLv3 for the Community Edition, and the Vendure Commercial License for commercial distributions.
