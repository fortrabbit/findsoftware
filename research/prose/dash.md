Dash is a Python framework for building data web apps and dashboards, built on Flask, React and Plotly.js. Plotly Cloud is a hosted service run by Plotly for publishing Dash apps, and Dash Enterprise is the paid edition of the product, which adds features the open-source package does not include.

## Worth knowing

Single sign-on and LDAP are documented for Dash Enterprise, not for the open-source package.
