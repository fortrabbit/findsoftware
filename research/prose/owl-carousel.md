Owl Carousel 2 is a touch-enabled jQuery plugin for carousel sliders. A page loads its stylesheet and script, with the script placed right after jQuery, and calls the plugin on a container element. The [documentation](https://owlcarousel2.github.io/OwlCarousel2/) is the project's own site.

## Worth knowing

The README opens by calling the project dead and names tiny-slider as the one to switch to.
