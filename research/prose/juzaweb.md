Juzaweb CMS is a content management system built on Laravel, installed with Composer as the [installation guide](https://github.com/digbly/cms/blob/master/docs/getting-started/installation.md) describes. It has an admin panel, keeps its data in MySQL or MariaDB, and offers static and database translation. The Juzaweb Team develops it, and the package is published on Packagist as `juzaweb/cms`.

## Worth knowing

The project has no reachable website: juzaweb.com did not resolve when checked, so the repository holds the documentation.

The repository detects GPL-2.0 while composer.json states MIT, and the project does not explain the difference.
