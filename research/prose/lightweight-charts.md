Lightweight Charts is a JavaScript library that draws interactive financial charts on an HTML5 canvas inside a web page. Plugins extend it, and a [plugin catalog](https://tradingview.github.io/lightweight-charts/plugins) lists ready-made ones.

TradingView maintains the library in a repository that also holds plugin examples and tooling. Plugin packages and a plugin wizard are released from the same repository, separate from the library's own releases.

## Worth knowing

The [documentation](https://tradingview.github.io/lightweight-charts/docs) says the library is a client-side library that is not designed to work on the server side, for example with Node.js.

The Apache-2.0 license comes with an attribution condition: the README says to add TradingView's attribution notice and a link to tradingview.com to a page of the website or mobile application that is available to users.
