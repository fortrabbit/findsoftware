Madoko is a Markdown processor for scholarly and technical documents, written in Koka. It runs locally as a command-line program on Node.js, installed with npm, and produces HTML and PDF output.

The license file names Microsoft Corporation as copyright holder.

## Worth knowing

The project's homepage could not be reached when this record was checked, so no homepage is listed. The readme also names an online service at Madoko.net with storage through Dropbox or GitHub; this record does not describe that service.
