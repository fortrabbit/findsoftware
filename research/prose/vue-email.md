Vue Email provides Vue components and render utilities for building email templates. Templates are written as Vue components, and the render utility turns a component into an HTML string or plain text. The homepage describes the rendering as happening directly from your server.

The project publishes two npm packages, one for the components and one for rendering.

## Worth knowing

The README calls the project experimental and says its APIs are subject to change. The current major release is a rewrite, and the older npm package named vue-email is not the one the install guide names.
