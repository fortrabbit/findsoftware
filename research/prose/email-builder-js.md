EmailBuilder.js is an email template builder with a no-code editor. The editor produces a JSON document that describes the email, and the `@usewaypoint/email-builder` npm package renders that document to HTML, either as a string or through a React component. The README shows the HTML passed to Nodemailer and to an email API.

The repository also contains the builder itself. The README says teams can fork it and self-host the editor from one of its examples.

## Worth knowing

The README points teams that want a better collaboration experience to Waypoint, the company that maintains the project. Waypoint's email API includes a hosted template builder with variables and reusable layouts.
