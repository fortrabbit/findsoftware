Agent Search is a Google Cloud service for building search engines over websites, structured data and unstructured data, and for grounding generative AI apps in that data. It was previously named Vertex AI Search. A search app is set up in the Google Cloud console, where a site URL is added as a data source, and results are served through the [API](https://docs.cloud.google.com/generative-ai-app-builder/docs/migrate-from-cse) or through a search widget added to a web page as an HTML component.

Access is controlled with predefined Google Cloud IAM roles, and the data can be confined to the US or EU multi-region. The [migration guide](https://docs.cloud.google.com/generative-ai-app-builder/docs/migrate-from-cse) describes moving from the Custom Search Site Restricted JSON API of Programmable Search Engine.

## Worth knowing

No self-hosted option is recorded for it. Prices are on the [pricing page](https://cloud.google.com/generative-ai-app-builder/pricing) and are not recorded here.
