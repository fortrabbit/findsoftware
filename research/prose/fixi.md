fixi.js is a small JavaScript library for hypermedia controls. HTML attributes on an element name the URL to request, the HTTP method, the element to update and how to swap the response in. The Big Sky Software organization on GitHub publishes it as a single standalone script that can be copied into a project, loaded from a CDN, or installed from npm under the fixi-js name.

The fixi project site lists fixi.js beside four companion libraries. This record covers fixi.js alone.

## Worth knowing

The repository ships no license file, so the license is taken from the README and from the project site. Both name a zero-clause BSD license.
