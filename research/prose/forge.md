Tyler Forge is a design system and a set of UI components built as Web Components, so the same elements can be used with any modern web framework or none. A page registers the components in the browser by importing them, and the package ships them as ES modules, plain CSS stylesheets and Sass sources. Adapters for Angular and React wrap the elements for those frameworks, and the install docs also link setup guides for Vue, Svelte and Blazor.

## Worth knowing

The repository is a monorepo: the install docs name the core package, while the framework adapters, a rich text editor and an MCP server are separate packages with their own releases.
