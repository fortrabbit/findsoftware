go-i18n is a Go package and a command for translating Go programs into several languages. Its messages use text/template placeholders, can carry plural forms based on CLDR plural rules, and are kept in message files in formats such as JSON, TOML or YAML. Nick Snyder holds the copyright, and the repository sits under his GitHub user account.

The project has no website of its own. Its documentation is the package page on pkg.go.dev.
