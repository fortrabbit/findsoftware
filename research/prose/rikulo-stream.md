Stream is a web server for Dart that handles request routing, filters, WebSocket connections, an MVC design pattern and file-based static resources. Dynamic pages are written as RSP files, Rikulo Stream Pages, which the `rspc` tool compiles into Dart files. The package is added to a project's `pubspec.yaml`, and its API reference is published on pub.dev.

## Worth knowing

The project's own website no longer shows the project, so the README in the repository and the package page on pub.dev are the sources that remain.
