Awesomplete is an autocomplete widget for input fields, with no dependencies. It is attached to an input either by a class name or with a few lines of JavaScript, and it can be loaded from a CDN or installed with npm or Yarn. The widget is added to a page by including its CSS and JavaScript files, and its project site is published under the nudeui name.

## Worth knowing

The GitHub releases page stops at a 2019 release. Later versions are published to npm and as git tags without a release page.
