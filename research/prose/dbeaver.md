DBeaver is a desktop database management tool and SQL client that connects to MySQL, MariaDB, PostgreSQL, SQLite and other databases. The [project homepage](https://dbeaver.io/) describes its Community edition as a free, open-source tool, and the [download page](https://dbeaver.io/download/) calls DBeaver a desktop application, installed on Windows, macOS and Linux from installers, packages or an archive. The [docs](https://dbeaver.io/docs/) also name an Eclipse plugin install route.

## Worth knowing

A paid edition, DBeaver PRO, runs under the DBeaver EULA, a commercial license, so the Apache-2.0 license applies to the Community code only. The software runs on the user's own computer and manages databases from there; the vendor's web-based option is a separate product, CloudBeaver. Every distribution bundles the Java runtime it needs, according to the download page.
