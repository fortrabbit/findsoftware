Protractor is an end-to-end test framework for Angular and AngularJS applications. It is a Node.js program built on top of WebDriverJS, a Selenium component, and is installed with npm.

The project has reached end of life. Its [homepage](https://www.protractortest.org/) advises new users not to adopt it and asks existing users to migrate to other end-to-end testing solutions, without naming one. The repository is archived, and the npm package carries a deprecation message.
