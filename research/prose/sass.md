Dart Sass is the primary implementation of Sass, the CSS extension language, and it compiles .scss and .sass stylesheets to CSS. The project is written in Dart and comes in several forms: a standalone archive that contains the Dart VM, the sass package on npm, and a Dart library installed with pub. Homebrew and Chocolatey packages are also named on the project's install pages.

The npm package runs on Node.js. The standalone archive needs no other software.
