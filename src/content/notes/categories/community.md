lead: Discussion, on your own server.
---

Community software lets visitors talk to each other and to the site. Comment systems add a discussion thread under each page through an embedded script, which gives comments to sites built with a [static site generator](/categories/ssg/), and some content management systems ship member profiles and discussion of their own. Each stores posts on its own server with moderation and sign-in options. A record carries this category when discussion is a main job. Forum software and social networks are finished applications rather than software to build a site with, so the register leaves them out. Remark42 is an example.
