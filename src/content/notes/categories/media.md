---
description: Software that processes images, video and documents for the web, such as resizing, conversion and PDF generation.
lead: Images, media and documents.
---

Media software handles files on their way to a page: resizing and cropping images, converting formats, compressing them, serving variants on request, playing video, or producing and reading documents such as PDFs. Some run as a separate server that transforms a file based on its URL, others are libraries called from application code. A record carries this category when processing media or documents is its main job, not when a CMS includes an image editor. imgproxy and Intervention Image are examples.
