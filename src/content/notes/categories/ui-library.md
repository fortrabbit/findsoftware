---
description: Ready-made interface components for the front end of a site or app, including rich text and code editors.
lead: Components to build interfaces from.
---

A UI library provides components such as buttons, form fields, dialogs and menus, either as components for a JavaScript framework or as classes on top of a CSS framework. Some come unstyled and handle behavior and accessibility only. Editors that embed in a page, for rich text, Markdown or code, count as components here. A record carries this category when its main output is reusable interface components. A library built on a [CSS framework](/categories/css-framework/) names it under "Built on". shadcn/ui and Headless UI are examples.
