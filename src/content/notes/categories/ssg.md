---
description: A tool that turns content files and templates into finished HTML at build time, including documentation site generators.
lead: Pages built once, served as files.
---

A static site generator reads content, usually Markdown, together with templates, and writes a folder of HTML, CSS and JavaScript ahead of time. Nothing runs on the server when a visitor requests a page, so the output can go on any host that serves [static files](/runs-as/static/). Documentation generators belong here too: they add a sidebar, page navigation and often search or versioned docs, and some build API reference pages from source code comments. A record carries this category when producing that folder is a documented way to use it. Frameworks that can also render pages on request carry [web framework](/categories/framework/) too. Hugo, Eleventy and MkDocs are examples.
