---
description: "Software that indexes a site's content and answers search queries."
lead: Search for a site or app.
---

Site search software builds an index from content and returns results for queries, usually with typo tolerance, filters and relevance settings. Some run as a server the application queries over HTTP. Others build an index at build time and search in the browser, which works on a host that serves only [static files](/hosting/static/). A plugin that connects a CMS to a search engine gets its own record. A record carries this category when search is its main job. Meilisearch and Pagefind are examples.
