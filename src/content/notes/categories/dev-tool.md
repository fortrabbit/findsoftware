---
description: A tool used while developing a site, such as a linter, a formatter or a local helper, that does not ship with it.
lead: Used while building, left out of production.
---

This category covers tools that help while code is written: linters that flag problems, formatters that rewrite code to a consistent style, and local helpers such as a mail catcher or a workbench for UI components. None of them is part of the deployed site. A record carries it when the software's place is the developer machine or CI. Tools that run automated tests have their own category, [testing](/categories/testing/). Prettier and Mailpit are examples.
