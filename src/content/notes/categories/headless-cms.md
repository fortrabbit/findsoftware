description: A content backend that delivers content over an API and leaves the front end to other software.
lead: Content over an API, the front end elsewhere.
---

A headless CMS manages content in an admin interface and hands it to other software over a REST or GraphQL API, without rendering public pages itself. The front end is built separately, often with a [web framework](/categories/framework/) or a [static site generator](/categories/ssg/). A record carries this category when its documentation names API delivery as the main way content leaves the system. Some also render pages and carry [CMS](/categories/cms/) too. Products offered only as SaaS sit beside the register as hosted services. Directus and Payload are examples.
