---
description: Software that bundles, compiles and optimizes front-end code for the browser.
lead: Source in, browser-ready files out.
---

A build tool takes source files such as JavaScript, TypeScript and CSS, resolves their imports, bundles and minifies them, and writes files a browser can load. Most add a development server that reloads on change, and many frameworks and site generators use one underneath. A record carries this category when building assets is the software's own purpose rather than a side feature. Build tools run on a developer machine or in CI and add nothing to what the live server needs. Vite and esbuild are examples.
