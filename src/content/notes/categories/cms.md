---
description: "Software that manages a site's content behind an admin interface and renders the public pages itself."
lead: Content, admin and templates in one install.
---

A content management system stores pages, posts and media, gives editors an admin interface to change them, and renders the public site from templates. A record carries this category when its documentation describes it as a CMS and it ships both the editing side and the delivery side. Many also expose an API, and the ones built mainly for API delivery carry [headless CMS](/categories/headless-cms/) as well. Where the content lives, in a database or in flat files, is a separate filter. WordPress and Kirby are examples.
