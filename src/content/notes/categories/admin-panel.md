---
description: "Software that generates an admin interface for managing an application's data."
lead: "A back office for an app's data."
---

An admin panel gives an application a back office: lists, forms and filters over its data, with users and permissions, without building each screen by hand. Some are packages for one framework and name it under "Built on", others sit on top of any database. A record carries this category when producing that admin interface is a main purpose. A [headless CMS](/categories/headless-cms/) often carries it as well. Filament and Directus are examples.
