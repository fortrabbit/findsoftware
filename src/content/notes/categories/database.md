---
description: "Software that stores an application's data, from relational databases to in-memory caches."
lead: Where an application keeps its data.
---

This category covers the data stores a web application runs against: relational and document databases, key-value stores, and in-memory caches that hold sessions or computed results. Backend platforms that bundle their own database carry it too. A record carries this category when storing data is a main function, not when the software only connects to a database. Which databases a CMS or framework supports is a separate filter. Redis and PocketBase are examples.
