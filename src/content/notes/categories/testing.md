---
description: Software for writing and running automated tests, of code or of a site in a browser.
lead: Automated tests, from unit to browser.
---

Testing tools run code that checks other code, from unit tests of single functions to end-to-end tests that drive a real browser through a site. They run on a developer machine or in CI, and nothing of them reaches the live server. A record carries this category when running tests is its purpose. Linters and formatters sit under [dev tools](/categories/dev-tool/) instead. Pest and Playwright are examples.
