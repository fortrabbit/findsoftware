This category covers software that gives an application its server side without writing it from scratch. Backend platforms bundle a database, user [authentication](/categories/auth/), file storage and an API generated from the data model. API and GraphQL servers, API gateways and realtime services handle one part of that: exposing data, routing and securing calls, or pushing updates to connected clients. A record carries it when serving as an application's back end or API layer is the stated purpose. Frameworks for writing a back end by hand are [web frameworks](/categories/framework/). Supabase and PocketBase are examples.
