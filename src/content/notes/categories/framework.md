---
description: A code foundation a developer builds a web application on, with routing and request handling provided.
lead: What an application is written on top of.
---

A web framework supplies the parts most applications repeat: routing URLs to code, handling requests and responses, templates or components, and often database access. The developer writes the application on top. A record carries this category when the software is meant to be built on rather than configured, whether it runs on the server or in the browser. Frameworks that can also export finished pages carry [static site generator](/categories/ssg/) as well. Laravel and Django are examples.
