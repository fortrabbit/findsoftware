---

A CSS framework supplies a starting point for styling: layout helpers, utility classes, prebuilt component styles or design tokens as custom properties. Some need a build step that scans templates for the classes in use, others are a stylesheet linked from the page. A record carries this category when it ships CSS meant to be used across a whole site. Component sets built on top get their own record under [UI libraries](/categories/ui-library/). Tailwind CSS and Bulma are examples.
