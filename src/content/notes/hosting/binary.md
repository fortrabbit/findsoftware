A single binary is a compiled program that runs on the server by itself: download it, start it, and it serves. No language runtime or package manager is needed on the host, only a machine where the executable can run as a process, which rules out hosting that accepts only PHP or only files. A record carries this value when its documentation offers a standalone executable for production. Most software here is written in Go or Rust. Caddy and PocketBase are examples.
