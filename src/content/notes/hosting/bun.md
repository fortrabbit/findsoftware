Bun is a JavaScript runtime with its own package manager and bundler, and it runs much of the code written for Node.js. A record carries this value when its documentation names Bun as a supported way to run the deployed site, not when Bun is only used to install packages. Software that runs on Bun usually documents other options too, often [Node.js](/hosting/node/), so the record shows whether a host without Bun can still run it. Hono and SvelteKit are examples.
