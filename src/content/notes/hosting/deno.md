Deno is a JavaScript and TypeScript runtime that runs TypeScript without a separate compile step and restricts file and network access unless permissions are granted. A record carries this value when its documentation names Deno as a supported way to run the deployed site. Software in this group usually documents other options as well, often [Node.js](/hosting/node/), so the record shows whether a host without Deno can still run it. Hono and Nuxt are examples.
