lead: Needs a server that runs PHP.
---

PHP here means the server that answers visitors executes PHP code on each request, usually through PHP-FPM behind a web server such as Apache or nginx. Most software in this group also needs a database and some PHP extensions, which a record notes under its server needs where the documentation names them. A record carries this value when its install documentation requires PHP on the production server. Software written in PHP that only builds files carries [static files](/hosting/static/) instead. Craft CMS and Drupal are examples.
