description: The deployed software runs on the .NET runtime on the server.
lead: Needs a server that runs .NET.
---

.NET here means the production server runs the application on the .NET runtime, on Linux or Windows, usually through its built-in web server behind a reverse proxy or under IIS. The host has to provide the .NET runtime, or the application is published self-contained with the runtime included. A record carries this value when its documentation requires .NET on the production server. ASP.NET Core and Umbraco are examples.
