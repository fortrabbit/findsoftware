A REST API exposes content as resources at fixed URLs, read and written with standard HTTP methods and usually returned as JSON. Any language with an HTTP client can use it, responses cache well at the HTTP layer, and fetching related content often takes several requests or query parameters. Some tools generate the REST endpoints from the content model. A record holds this value when its documentation describes a REST or JSON API for content, built in or as an official module. Many also offer [GraphQL](/api/graphql/).
