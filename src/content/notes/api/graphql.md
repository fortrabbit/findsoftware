description: Software that delivers content over GraphQL, where the client sends a query naming the fields it wants.
lead: One endpoint, queries that name their fields.
---

GraphQL serves content through a single endpoint. The client sends a query that names the types and fields it needs, related content included, and receives exactly that shape back. A typed schema describes what can be queried, which frontend tooling can read to generate types. Caching works differently from [REST](/api/rest/), since every request goes to the same URL. A record holds this value when its documentation describes a GraphQL API for content, built in or as an official module.
