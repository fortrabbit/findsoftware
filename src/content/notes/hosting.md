---
title: Hosting needs
description: What the live server has to run for the software to serve a site.
lead: What the server needs once the site is live.
---

Hosting needs describe production, the server that answers visitors. A record carries every option its documentation names for running the deployed site, so a framework that runs on Node.js and on Bun carries both. Software used only at build time, such as a static site generator, needs [static files](/hosting/static/) here even when it runs on Node.js on the developer machine; that requirement shows under [runtime](/runtimes/) instead. The values follow the runtimes hosting providers list, so each one matches what a host offers.
