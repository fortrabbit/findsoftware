---
title: Content API
description: The API types a software uses to deliver its content to a frontend, an app or another service.
lead: How content leaves the system.
---

A content API lets a separate frontend, a mobile app or another service read content over HTTP, which is what makes a CMS usable headless. The API type decides how a frontend asks for data and which client libraries fit. A record carries every API type its documentation describes as built in or provided by an official first-party module. Software with no content of its own, or with an API only through third-party plugins, carries no value here.
