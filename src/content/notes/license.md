---
title: License model
description: Under which terms a software can be used, changed and redistributed, from open source to commercial.
lead: What the license lets you do with the code.
---

The license model sums up the terms a software is offered under: whether the source is public, whether it may be used and changed freely, and whether some features or uses require payment. Each record carries one model, decided from the license file in the repository and the project's pricing or licensing page, and the exact license name sits in the record's License row. A paid edition or a hosted offer from the same vendor does not change the model of the code itself.
