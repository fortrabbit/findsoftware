description: "The software runs in the visitor's browser, so the server only delivers its files."
lead: Runs on the visitor's device.
---

In the visitor's browser means the software is JavaScript that runs on the visitor's device. The server delivers it as files, together with the rest of the site, and plays no further part. A search index that loads in the browser or a component library compiled into the page are examples. A record holds this value when its documentation describes it running client-side. MiniSearch is an example.
