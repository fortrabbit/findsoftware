---
description: Software that serves data over an API and renders no pages for visitors.
lead: Data out, pages made elsewhere.
---

API-only software stores and serves content or commerce data and leaves every visitor-facing page to a separate frontend. It typically ships an admin interface for editors, but the public site is built with another tool that reads the [content API](/api/). Choosing one means choosing and hosting a frontend as well. A record holds this value when its documentation describes the software as headless, with no built-in page rendering for the public site.
