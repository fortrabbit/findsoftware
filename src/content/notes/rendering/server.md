description: Software that renders each page on a server when it is requested.
lead: HTML made per request by a running process.
---

Server rendering means a process on the host builds each page when a visitor requests it, usually reading from a database or another source at that moment. Content changes show up at once, and pages can differ per user. The host has to run the software's runtime, and often a database, around the clock. A record holds this value when its documentation describes serving pages rendered on request. Traditional CMSs and web frameworks are the usual holders.
