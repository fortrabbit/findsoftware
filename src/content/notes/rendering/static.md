description: Software that renders pages to HTML files at build time, ready to serve from any static file host.
lead: HTML built ahead of time, served as files.
---

Static output means the software runs once at build time and writes finished HTML, CSS and JavaScript files. Those files can be served from any web server or CDN, with no runtime or database on the host. Content changes need a new build and deploy, and anything personal or interactive runs in the browser or calls a separate service. A record holds this value when its documentation describes generating a complete static site as a supported output.
