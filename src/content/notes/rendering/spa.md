---
description: Software that renders pages in the visitor's browser with JavaScript, as a single-page application.
lead: The browser builds the page from JavaScript.
---

Browser rendering sends a small HTML shell plus JavaScript, and the page is built on the visitor's device, fetching data from an API as needed. Navigation happens without full page loads. The files can be served from static hosting, with the data coming from a separate backend. First load waits on the JavaScript, and search engines and link previews see less unless a server pre-renders the page. A record holds this value when its documentation describes a client-side or single-page application mode.
