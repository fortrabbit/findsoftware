SQL Server is Microsoft's relational database, common in organizations that run Windows servers, .NET applications or Azure. Supporting it lets a tool sit beside existing systems in such an environment. It is rarely offered on general web hosting, and its editions carry their own license terms. A record holds this value when its documentation lists SQL Server, or Azure SQL, as a supported database.
