lead: The MySQL fork, often the default on Linux hosts.
---

MariaDB began as a fork of [MySQL](/databases/mysql/) and keeps a compatible protocol and SQL dialect, so many applications run on either. Several Linux distributions and hosts ship MariaDB where MySQL is requested. Compatibility has narrowed over time in areas such as JSON handling and replication, so a project that names MariaDB explicitly has tested against it. A record holds this value when its documentation lists MariaDB as supported, and does not infer it from MySQL support.
