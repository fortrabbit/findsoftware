---
description: Software that supports MongoDB, a document database that stores JSON-like records instead of tables.
lead: A document database without fixed tables.
---

MongoDB stores data as documents with flexible fields rather than rows in tables with a fixed schema. It is available as a self-hosted server and as a managed service, and it is not part of typical web hosting. Software built for relational databases often reaches MongoDB only through an adapter, so feature coverage can differ from the relational engines. A record holds this value when its documentation lists MongoDB as a supported database.
