MySQL is a relational database server and one of the engines most commonly provided by web hosts, from shared hosting to managed database services. Supporting it means a tool can run on a host that offers MySQL with no extra service. Many projects that support MySQL also support [MariaDB](/databases/mariadb/), its fork, though some features differ between the two. A record holds this value when its documentation lists MySQL as a supported database.
