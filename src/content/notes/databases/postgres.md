PostgreSQL is an open-source relational database server with strict standards compliance and extensions such as full-text search, JSON columns and geospatial types. Managed PostgreSQL is offered by most cloud providers and many platforms, though less often on classic shared hosting. Software that uses PostgreSQL-specific features may run only on it. A record holds this value when its documentation lists PostgreSQL as a supported database.
