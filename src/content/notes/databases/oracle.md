Oracle Database is a commercial relational database used mostly in large organizations and enterprise systems. Support for it matters when a web application has to read from or write to an existing Oracle installation. It is not offered on general web hosting, and running it involves Oracle's licensing. A record holds this value when its documentation lists Oracle as a supported database, typically through the framework's database layer, as with [Django](/django/).
