PHP here means the PHP interpreter has to be on the machine, usually with Composer to install dependencies. For most software in this group that machine is also the production server, so the record carries [PHP](/hosting/php/) under hosting needs too. PHP tools that only generate files need PHP on the machine that builds and nothing on the host. A record carries this value when its documentation requires PHP to install or run it. Laravel and HydePHP are examples.
