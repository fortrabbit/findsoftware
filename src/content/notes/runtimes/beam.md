lead: Needs the Erlang VM.
---

The Erlang VM, also called BEAM, is the runtime that Erlang and Elixir code compiles to. It runs many lightweight processes at once and is built for long-running, fault-tolerant services. For development, Erlang and Elixir have to be installed on the machine; production releases can bundle the VM with the application. A record carries this value when its documentation requires the Erlang VM. Phoenix is an example.
