description: The software needs Node.js installed to run or to build.
lead: Needs Node.js installed.
---

Node.js here means the Node.js runtime has to be on the machine, with npm or another package manager to install dependencies. That covers server software as well as front-end tooling that runs only during development and the build. A record carries this value when its documentation requires Node.js. Whether the live server needs Node.js too is a separate question, answered under [hosting needs](/hosting/node/): a static site generator needs it here and not there. Astro and Vite are examples.
