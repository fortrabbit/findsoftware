Ruby here means a Ruby interpreter has to be on the machine, with gems installed through Bundler. Ruby web applications need it on the production server too and carry [Ruby](/hosting/ruby/) under hosting needs, while Ruby site generators need it only where the site is built. A record carries this value when its documentation requires Ruby to install or run the software. Ruby on Rails and Jekyll are examples.
