A single binary is a compiled program that runs by itself: download the file for the operating system and start it. No interpreter or package manager is needed, which keeps the setup on a developer machine or a server short. A record carries this value when its documentation offers a standalone executable as a way to install it, even if a package manager is offered as well. Whether the result runs on the server or only produces files shows under [hosting needs](/hosting/). Hugo and Caddy are examples.
