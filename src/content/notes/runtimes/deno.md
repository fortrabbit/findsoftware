Deno here means the software documents Deno as a supported runtime. Deno runs TypeScript without a separate compile step and asks for file and network permissions unless they are granted up front. Software in this group usually supports [Node.js](/runtimes/node/) as well, so a machine with either can run it. A record carries this value when the documentation names Deno for running the software itself. Hono and Nuxt are examples.
