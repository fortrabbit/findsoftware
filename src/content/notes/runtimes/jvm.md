The Java VM runs compiled Java code and code from other JVM languages. Software in this group needs a Java runtime on the machine, from one of several distributions of OpenJDK, and a matching one on the production server, so it carries [Java](/hosting/java/) under hosting needs as well. A record carries this value when its documentation requires a Java runtime to run the software. Keycloak and Spring Boot are examples.
