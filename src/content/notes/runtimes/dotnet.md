.NET here means the .NET SDK has to be on the machine to build the software and the .NET runtime to run it, on Windows, Linux or macOS. Applications can also be published self-contained, with the runtime included in the output. A record carries this value when its documentation requires .NET, and the production side shows as [.NET](/hosting/dotnet/) under hosting needs. ASP.NET Core and Umbraco are examples.
