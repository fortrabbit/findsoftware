description: The software needs Python installed to run or to build.
lead: Needs Python installed.
---

Python here means a Python interpreter has to be on the machine, with dependencies installed from PyPI, usually into a virtual environment. Python web applications need it on the production server as well and carry [Python](/hosting/python/) under hosting needs. Python tools that only build a site need it on the machine that builds. A record carries this value when its documentation requires Python. Django and MkDocs are examples.
