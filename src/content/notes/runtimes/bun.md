Bun here means the software documents Bun as a supported runtime, not only as a faster way to install packages. Bun runs much code written for Node.js, and software in this group usually supports [Node.js](/runtimes/node/) as well, so a machine with either can run it. A record carries this value when the documentation names Bun for running the software itself. Hono and SvelteKit are examples.
