---
title: Rendering
description: Where and when a software turns content into HTML, at build time, on a server, in the browser, or not at all.
lead: Where the HTML is made decides what the host must run.
---

Rendering records where a page's HTML is produced. Pages built ahead of time need only file hosting, pages rendered on request need a running server, and pages assembled in the browser shift work to the visitor's device. A record carries every mode its documentation describes as supported, so a framework that can build static pages and also serve dynamic routes holds several. Libraries and tools that produce no pages carry no value here.
