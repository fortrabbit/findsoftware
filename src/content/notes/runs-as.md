---
title: Runs as
description: How the software runs once a site is live, which decides what the host has to provide.
lead: What the host keeps running, if anything.
---

Runs as records how the software behaves on the live site. Static files need only a web server or a CDN. A script per request needs a server that starts it on each visit, which is how most PHP hosting works. An always-on process needs a host that keeps a program running and restarts it when it stops. Software that runs in the visitor's browser or only during development puts no load on the server at all. A record carries every value its documentation describes, so a framework that can export static files and also run a server holds both. Which language the host must offer shows under [hosting needs](/hosting/).
