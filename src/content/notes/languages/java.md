Java here is the main language of the repository. Java compiles to bytecode for the [Java VM](/runtimes/jvm/), so running the software needs a Java runtime, and extensions or plugins for it are usually written in Java and packaged as JAR files. A record carries this value when Java makes up most of the codebase, as stated by the project or shown by its repository. Keycloak and Spring Boot are examples.
