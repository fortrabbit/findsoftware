JavaScript or TypeScript is the main language of the repository. The two count as one here: TypeScript adds static types to JavaScript and compiles to it, both install from the same package registries, and users can work with a TypeScript project from plain JavaScript, with types available in the editor. Plugins and configuration are usually written in either. Running the software usually needs [Node.js](/runtimes/node/), Deno or Bun. Eleventy, Ghost, Astro and NestJS are examples.
