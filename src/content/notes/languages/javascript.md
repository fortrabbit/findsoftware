JavaScript here is the main language of the repository, without TypeScript as the primary source. Many projects in this group still publish type definitions, so editors can offer types to users. Plugins and configuration are usually JavaScript too. A record carries this value when JavaScript makes up most of the codebase; a project that moved its source to TypeScript carries [TypeScript](/languages/typescript/) instead. Running it usually needs [Node.js](/runtimes/node/). Eleventy and Ghost are examples.
