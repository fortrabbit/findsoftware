Rust here is the main language of the repository. Rust compiles to native code, so software in this group usually ships as a [single binary](/runtimes/binary/) or as a native package installed through npm, and users never touch Rust. Several web build and lint tools are written in Rust and configured from JavaScript. A record carries this value when Rust makes up most of the codebase. Meilisearch and Biome are examples.
