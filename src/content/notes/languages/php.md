PHP here is the main language of the repository. Plugins, themes and custom code for this software are usually written in PHP as well, and dependencies come from Composer and Packagist. A record carries this value when PHP makes up most of the codebase, as stated by the project or shown by its repository. Front-end assets in JavaScript do not change that. Running the software needs [PHP](/runtimes/php/) installed. Craft CMS and Laravel are examples.
