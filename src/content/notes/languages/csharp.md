C# here is the main language of the repository. C# compiles for the [.NET](/runtimes/dotnet/) runtime, and packages for it come from NuGet. Extending software in this group, for example with custom modules or plugins, means writing C#, usually with Razor templates for the HTML side. A record carries this value when C# makes up most of the codebase, as stated by the project or shown by its repository. ASP.NET Core and Umbraco are examples.
