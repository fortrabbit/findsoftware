Go here is the main language of the repository. Go compiles to a standalone executable, so software in this group often ships as a [single binary](/runtimes/binary/) and needs no Go installation to run. Extending it usually means writing Go and compiling a custom build, though some projects offer templates, configuration files or JavaScript hooks instead. A record carries this value when Go makes up most of the codebase. Hugo and Caddy are examples.
