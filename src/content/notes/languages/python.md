Python here is the main language of the repository. Extensions, plugins and configuration for this software are usually written in Python too, with dependencies from PyPI. A record carries this value when Python makes up most of the codebase, as stated by the project or shown by its repository. Running it needs [Python](/runtimes/python/) installed, on the server for web applications and on the build machine for site generators. Django and Wagtail are examples.
