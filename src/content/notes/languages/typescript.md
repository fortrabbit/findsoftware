TypeScript here is the main language of the repository. TypeScript adds static types to JavaScript and compiles to it, so users can work with the software from plain JavaScript as well, with types available in the editor. A record carries this value when TypeScript makes up most of the codebase, as shown by the repository. A project written in plain JavaScript that ships type definitions carries [JavaScript](/languages/javascript/) instead. Astro and NestJS are examples.
