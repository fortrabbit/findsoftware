---
title: Written in
description: "The programming language the software's own source code is written in."
lead: The language of the source code.
---

The language is what the software itself is written in, read from its repository. It matters for reading the source, writing extensions and contributing fixes, and it is not always the language a user writes: a build tool written in Rust is configured in JavaScript, and an app server written in Go can run PHP applications. What a machine has to install shows under [runtime](/runtimes/). A record carries one language, the main one of its codebase.
