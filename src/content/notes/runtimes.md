---
title: Runtime
description: What has to be installed to run or build the software, on a developer machine or on a server.
lead: What a machine needs before the software starts.
---

The runtime is what a machine needs before the software runs at all. It covers local development and the build as well as the server, which is where it differs from [hosting needs](/hosting/): a static site generator written for Node.js needs Node.js here and only [static files](/hosting/static/) there. A record carries every runtime its documentation names as supported. The lowest supported version, where the documentation states one, is a separate field on the record.
