---
title: Databases
description: Which database engines a software supports for storing its data, as named in its own documentation.
lead: The engine the server has to run.
---

Databases lists the engines a software can store its data in. For anyone choosing, it answers whether a tool fits an existing database, or which engine a new host has to provide. A record carries every engine the project's documentation lists as supported, whether directly or through its bundled database layer. Engines reached only through a third-party plugin stay out. Software that keeps content in [flat files](/storage/flat-file/) often carries no value here.
