---
title: Content storage
description: Where software keeps the content it publishes, in a database or in flat files on disk.
lead: Where the content lives decides much of the hosting.
---

Content storage records where the pages, entries and settings a site publishes are kept. It shapes what a server must provide, how content moves between a laptop and production, and how backups work. A record carries every storage model its documentation describes as built in, so a tool that reads Markdown files and can also query a database holds both [flat files](/storage/flat-file/) and [database](/storage/database/). Libraries and tools that hold no content of their own carry no value here, and neither does software that only reads content from another service.
