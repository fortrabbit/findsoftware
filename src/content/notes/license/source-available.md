---
description: Software whose source code is public but under a license that restricts some uses, so it does not count as open source.
lead: The code is public, the license sets limits.
---

Source available means anyone can read the code, and often run and modify it, but the license adds conditions that open-source licenses do not, such as a fee for commercial or production use, a revenue threshold, or a ban on offering it as a competing hosted service. Some such licenses convert to open source after a set period. A record holds this value when the published source carries a license of this kind, such as the Business Source License, the Elastic License or a vendor's own terms. [Craft CMS](/craft-cms/) and [Kirby](/kirby/) are examples.
