---
description: Software whose core is open source, with some features or editions under a paid or proprietary license.
lead: An open-source core, paid features on top.
---

Open core means the main software is published under an open-source license and can be used without payment, while the vendor keeps some features, often enterprise or team functions, in a separate edition under proprietary terms. The open part is complete enough to run, and the boundary between free and paid is set by the vendor. A record holds this value when the repository or licensing page names both an open-source license and a commercial or enterprise license for parts of the code. Compare [open source](/license/open-source/).
