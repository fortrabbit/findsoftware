---
description: Software that keeps its content in a database server or a database file.
lead: Content in tables, edited through an admin or an API.
---

A database-backed tool stores entries, users and settings in a database and reads them on every request or build. Hosting then needs a database the software supports, listed on each record under [databases](/databases/), and moving content between environments means exporting and importing data rather than copying files. Editors usually work in an admin interface. A record holds this value when its documentation names a database as the place content is stored, including an embedded file database such as [SQLite](/databases/sqlite/).
