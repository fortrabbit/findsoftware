---
description: Software that keeps its content as files on disk, such as Markdown, YAML or JSON, with no database server.
lead: Content as files, versioned with the code.
---

Flat-file software reads content from files in the project, often Markdown with frontmatter, and turns them into pages at build time or on request. Content can live in the same Git repository as the code, so changes are reviewed, versioned and deployed together, and hosting needs no database. Concurrent editing by many people and large volumes of structured data are where teams often add a database. A record holds this value when its documentation describes files on disk as a content source.
