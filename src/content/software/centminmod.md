Centmin Mod is a shell menu based installer for an Nginx LEMP stack. It was created and is developed by George Liu. It is installed with an unattended command line installer on AlmaLinux and Rocky Linux servers.

The project names its releases as git branches, a stable branch and beta branches, not as tagged versions.

## Worth knowing

The git-clone install route is marked deprecated in the README. CentOS 7 is supported only on the stable branch, and the project lists CentOS 7 as end of life.
