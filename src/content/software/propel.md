Propel is an object-relational mapping library for PHP. A project describes its tables as an XML schema, or exports the schema from an existing database with a reverse-engineering command, and Propel generates model classes from it. Beside the ORM it provides a query builder and schema migration.

## Worth knowing

The installation page on the documentation site describes an older PHP minimum and an older Composer constraint than the current package manifest.
