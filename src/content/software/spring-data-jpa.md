Spring Data JPA is a Java library, part of the Spring Data family, that provides repository support for the Jakarta Persistence API to Spring applications. The [reference documentation](https://docs.spring.io/spring-data/jpa/reference/) describes it as repository support for JPA data sources, and the README says that Spring Data builds on Spring Framework. An application adds the library as a Maven dependency and declares repository interfaces, and the library provides their implementations.
