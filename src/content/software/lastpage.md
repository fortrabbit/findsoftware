lastpage is a static website generator written in C# for .NET. A site is made of a skeleton file, partials and pages, which are stored as files with the custom extensions .lps, .lpl and .lpe and templated with Mustachio, a library based on Mustache. The tool is installed as a .NET global tool with `dotnet tool install`.

## Worth knowing

The repository is archived, and the README says the project is no longer maintained and its NuGet package is deprecated.
