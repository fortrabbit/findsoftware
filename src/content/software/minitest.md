Minitest is a testing framework for Ruby with unit tests, specs and benchmarks, distributed as a gem. A unit test is a method whose name begins with test_, and a spec wraps its expectations in a value call inside describe and it blocks. Requiring minitest/autorun runs the suite, a rake task can run it from a Rakefile, and plugins can add command line options and reporters. The project is maintained by Ryan Davis, and its [documentation](https://minite.st/docs/) is published on minite.st.
