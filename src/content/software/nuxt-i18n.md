Nuxt I18n adds internationalization to a Nuxt project. It is registered in the Nuxt configuration and set up under an i18n key, and it is built on Vue I18n, which the module configures for the project. The module localizes routes, loads the messages of each language only when they are needed, and provides composables for SEO tags and redirects by locale.

## Worth knowing

The docs describe an edge channel that installs builds from the repository's main branch, for users who want a change before a release. The documentation list in the README also keeps the docs of earlier majors, and marks the oldest as the line for Nuxt 2, which has reached end of life.
