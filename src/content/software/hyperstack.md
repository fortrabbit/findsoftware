Hyperstack is a Ruby DSL and web toolkit for building interactive web applications. The documentation describes integrating it with a Rails application by adding the rails-hyperstack gem and running the installer. Ruby code is compiled by Opal into JavaScript, and the DSL wraps React and ReactRouter.

## Worth knowing

The README's development status table is dated April 2021 and describes the 1.0 release candidates as weekly. The newest tag and the newest RubyGems upload are from that period. The website named in the README does not resolve, so the documentation site is the one this record links.
