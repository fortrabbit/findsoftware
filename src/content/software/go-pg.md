go-pg is a PostgreSQL client and ORM for Go. It is the older project: its documentation points to Bun, and the README names Bun as the place where new development happens. The maintainer is listed as the "github.com/go-pg/pg Authors".

## Worth knowing

The project is in maintenance mode. The README says only critical issues are addressed, and the documentation says it will not receive new features and asks readers to use Bun instead.
