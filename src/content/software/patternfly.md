PatternFly is an open source design system. Its HTML and CSS library delivers layouts, components and utilities as Sass and CSS files, which a project installs from npm. The design system is sponsored and maintained by Red Hat.

## Worth knowing

The develop page says Font Awesome is included by default as part of the PatternFly CSS file. It labels this legacy and recommends Red Hat icons instead.
