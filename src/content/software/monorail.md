MonoRail is a model-view-controller web framework for .NET from the Castle Project, which its documentation describes as inspired by ActionPack. The MR2 documentation covers running it under IIS, where a handler mapped to a URL extension in web.config routes requests to MonoRail, and its views use the NVelocity template engine.

## Worth knowing

The Castle Project's organization describes these repositories as archived and generally unsupported, and the repository description calls MonoRail 3 a prototype. The Castle Project's own site links the MR2 documentation as the reference for MonoRail 2.
