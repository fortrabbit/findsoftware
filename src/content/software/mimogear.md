Mimogear is a static site generator and web development boilerplate built on Gulp, Sass and Pug. It is set up by cloning the repository and running npm install, after which gulp starts the build. Templates are written in Pug, and the project builds static sites.

## Worth knowing

The project has no GitHub releases and no npm package, so it is installed from the repository itself.
