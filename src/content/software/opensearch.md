OpenSearch is a search and analytics engine written in Java. It exposes a REST API and runs as a server process. The OpenSearch Software Foundation maintains it as a project of the Linux Foundation. The [downloads page](https://opensearch.org/downloads/) lists container images and Linux packages, and the [getting-started guide](https://docs.opensearch.org/latest/getting-started/) names OpenSearch Dashboards as the web interface.
