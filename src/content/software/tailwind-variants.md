Tailwind Variants is a variant API for Tailwind CSS. A component's base styles, variants, defaults and compound rules are declared once as a recipe, and the recipe returns class strings for each combination of typed props. Recipes can style several parts of a component through slots. The library is written in TypeScript, is installed from npm, and is maintained by NextUI Inc. It adds Stitches-style variants on top of Tailwind CSS, and its comparison page names Class Variance Authority and Windstitch as alternatives.

## Worth knowing

The default build resolves conflicting Tailwind classes. A lite build, imported from a separate path, skips conflict resolution.
