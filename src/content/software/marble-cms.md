Marble is a headless CMS for blogs, changelogs and articles. Writers manage posts in a web dashboard, and a REST API returns the content to a site or app. Workspaces hold the posts, media and team members of one site, with Owner, Admin and Member roles.

## Worth knowing

Marble is offered as a hosted service at marblecms.com. Its source is public, but the docs give no guide for running it on your own server. Webhooks, an MCP server and media hosting come with the hosted workspace.
