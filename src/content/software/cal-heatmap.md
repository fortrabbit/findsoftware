Cal-Heatmap is a JavaScript library that draws time-series calendar heatmaps. Its README lists animated date navigation, time interval customization, locale and timezone support, a plugin system and right-to-left support.

The documentation source sits on the gh-pages branch of the repository and describes installing the library from a CDN script or from npm.
