Reach UI is a set of accessible React components, written in TypeScript and published as separate @reach packages. The docs example installs `@reach/dialog` with npm or Yarn. The copyright line names React Training LLC as the maintainer. The docs site is published at reach.tech, and the project's homepage at reacttraining.com points there.

## Worth knowing

The project is no longer maintained. Its default branch opens its README with a notice that Reach UI is currently not maintained, and an issue from the maintainer states the same and suggests switching to another library.
