Grunt is a JavaScript task runner. A Gruntfile configures the tasks, and each task runs a plugin installed from npm, such as minification, compilation, unit testing or linting. Grunt and its plugins are listed as development dependencies of the project, and the Grunt command line interface runs the version of Grunt installed next to the Gruntfile. The [getting-started guide](https://gruntjs.com/getting-started) describes the setup.

## Worth knowing

The README marks older minor versions as unsupported and names a commercial support provider for them, which is a third-party service rather than an edition of the project.
