React Email Editor is a React component that embeds Unlayer's drag-and-drop email editor in an application, installed from npm. The component is client-only: the editor renders into the DOM.

## Worth knowing

At runtime the component loads Unlayer's embed script, and Unlayer's docs say that script loads everything needed to run the builder. Whether the editor can run without that hosted script is not established.
