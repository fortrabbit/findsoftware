Waku is a React framework for marketing sites, headless commerce and full-stack web apps, built around React Server Components. Layouts and pages can each be prerendered statically or rendered on the server, and the homepage describes server-side rendering as a separate concept from React Server Components.

The build output can be copied to any hosting service as the dist/public folder, or the production server can be started with the waku start command.
