BootstrapVue is a component library that implements Bootstrap's components and grid system as Vue components, with automated ARIA markup. The [getting-started page](https://bootstrap-vue.org/docs/) installs it from npm alongside Vue and Bootstrap, or loads it in the browser from CDN links when no module bundler is used. A Nuxt module is included in the package.

## Worth knowing

The README on the repository's default branch reads "MOVED to" BootstrapVueNext, and the documentation site recommends migrating to it, calling it a complete rewrite. BootstrapVue itself targets an earlier generation of Vue and Bootstrap, and the docs describe a compatibility path for running it under the migration build of the newer Vue generation.
