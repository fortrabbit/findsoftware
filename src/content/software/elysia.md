Elysia is a TypeScript web framework for building backend servers, and its project pages describe it as optimized for Bun. A Node.js adapter, published as the separate package @elysia/node, runs the same server on Node.js. A new project starts with the bun create elysia command.

The deployment guide shows how to compile the server into a single binary or bundle it into one JavaScript file, and the server is run to start listening. The Vercel integration page describes deployment there as a Vercel Function.

## Worth knowing

The deployment guide says Bun requires a machine with AVX2 hardware support.
