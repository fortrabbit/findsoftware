bashblog-ng is a Bash script that creates a blog of static HTML pages in a public web folder. It is a fork of bashblog, and the README calls it the next generation version of that project. The README describes the installation as downloading `bb.sh`, copying it into a public folder and running it from a shell on the server. It says all content is static, so the published blog is files that any web space serves. David Satime Wallin is named as the author in the script's header comment.
