Redis Cloud is the fully managed hosted service of Redis Ltd, which the project describes as the fully-managed version of Redis. It runs Redis databases on public clouds, and the service is managed through the Redis Cloud console.

The [supported regions page](https://redis.io/docs/latest/operate/rc/supported-regions/) lists the AWS, Google Cloud and Azure regions the service runs in, with a number of European locations. The self-managed counterpart is Redis Software, which the Redis Cloud pages say is for on-premise environments.

## Worth knowing

The contracting Redis entity depends on where the customer is domiciled: Redis Inc. in San Francisco for the Americas and Asia Pacific, Redis Ltd for Israel, and Redis EMEA Ltd in London for Europe, the United Kingdom, the Middle East and Africa. The [Cloud terms](https://redis.io/legal/cloud-tos/) names each entity.
