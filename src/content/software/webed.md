WebEd is a content management system based on Laravel, with an administration dashboard and access control lists. It is installed with Composer, either as a new project through the create-project command or into an existing project by requiring the sgsoft-studio/base package.

## Worth knowing

The README states that WebEd has been discontinued because the author cannot continue developing it, and the Packagist package is flagged abandoned. The homepage and the documentation site do not resolve, so the README and its installation steps are the only documentation read for this record.
