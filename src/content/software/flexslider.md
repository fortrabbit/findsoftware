FlexSlider is a slider plugin that turns a list of slides into a slider or, when an item width is set, a carousel. The README documents its options itself and states that the plugin requires jQuery. Official builds are listed on the releases page of the GitHub repository.

## Worth knowing

The README says the repository is no longer actively developed and that the latest version is incubated inside the WooCommerce repository. The GitHub repository is archived, and the project's own website redirects to a company page that no longer mentions FlexSlider.
