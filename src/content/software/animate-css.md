Animate.css is a CSS library of ready-to-use, cross-browser animations for web projects. A project installs it with npm or yarn, or adds it to a page through a CDN. The README names Daniel Eden as creator and maintainer.

## Worth knowing

The main branch of the repository carries the Hippocratic License 2.1, a custom license, while the latest release carries the MIT license.
