MongoEngine is an Object-Document Mapper for Python. Applications define documents as Python classes with typed fields, connect to a MongoDB database, and then save, query and count the documents through those classes. The README describes it as an ORM-like layer on top of PyMongo, the MongoDB driver it requires. The documentation on Read the Docs holds a tutorial, a user guide and an API reference.

## Worth knowing

The README warns that mongoengine.org is no longer controlled by the project and appears to be an expired domain takeover. The README on the default branch states a newer minimum Python version than the metadata of the latest release does.
