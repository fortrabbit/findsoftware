Odometer is a JavaScript and CSS library for smoothly transitioning numbers on a web page. The [project site](https://github.hubspot.com/odometer/) shows it as a script and a theme stylesheet that a page adds, and the library was made at HubSpot.

## Worth knowing

The GitHub repository is archived, so the library receives no further changes there.
