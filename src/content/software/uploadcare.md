Uploadcare is a hosted platform for file uploads, processing and delivery. Its homepage names a file uploader, an image CDN and a video CDN, and the [documentation](https://uploadcare.com/docs/) describes how an application connects to them.

## Worth knowing

No self-hosted version is documented on the pages read, so files and transformations run on the vendor's service. The free plan has a monthly operations limit. Single sign-on through Okta is listed for the Enterprise plan.
