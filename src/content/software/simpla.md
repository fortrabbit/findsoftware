Simpla is a modular content system for frontend developers, built on Web Components. Content is edited inline on the page, and sign-in goes through an OAuth adapter. The content is kept in a GitHub repository, and the page data is pushed as JSON to a static CDN. The library is installed with npm or loaded from unpkg, and the components are added with Bower. The copyright line in its license names Sean King and Bede Overend.

## Worth knowing

The homepage and the docs domain both answer with a parked page that says the domain may be for sale, so the project's own site no longer shows the software. The README and the npm package still describe and publish it.
