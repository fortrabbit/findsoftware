Statamic SSG is a package for Statamic that generates a Statamic site into static HTML files. The [README](https://github.com/statamic/ssg/blob/4.x/README.md) installs it with `php please install:ssg` and runs the generator with `php please ssg:generate`. The generated site is a directory that can be deployed however you like.

## Worth knowing

According to its composer file, the package requires the Statamic CMS. The repository states no license: it has no license file, and its composer file and Packagist entry name none.
