react-vis is a set of React components for data visualization charts, including line, area and bar charts, heat maps, sunbursts and tree maps. The application composes a chart from separate components, such as the XY plot, axes and series. A CDN bundle is also published, which exposes a global reactVis object.

## Worth knowing

The project's own deprecation notice says the library has no active maintainers and will receive no patches or new features. The [README](https://github.com/uber/react-vis/blob/master/README.md) links that notice from its badge.
