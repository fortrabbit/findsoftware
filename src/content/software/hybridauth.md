Hybridauth is a PHP library for social sign-in. It gives an application one interface to the social networks and identity providers it supports, such as Facebook, Twitter and Google. The application sets a callback URL and the provider keys, starts the authentication, and then reads the access token and the user's profile. The same provider object makes API requests to that provider.

## Worth knowing

The Apple provider needs two further packages that the Composer manifest lists as suggestions.
