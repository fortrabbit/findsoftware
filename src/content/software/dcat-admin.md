Dcat Admin is a toolkit for building administration interfaces on top of Laravel. It adds data grids, forms, detail pages and a code generator to a Laravel application, and describes itself as a secondary development of laravel-admin. It is added to an existing Laravel project with Composer and a publish and install step, and a [Chinese-language guide](https://learnku.com/docs/dcat-admin) covers its use.

The README lists role-based permission management with unlimited-level permission nodes and the interface is served by the same PHP application as the rest of the Laravel project, behind a web server pointed at its public directory.

## Worth knowing

The project has no working website: the address its repository names now serves an unrelated company, so the repository and the Chinese-language documentation are the only sources. The README and documentation are in Chinese.
