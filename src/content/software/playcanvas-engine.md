PlayCanvas Engine is an open-source engine for 2D and 3D graphics on the web, with its graphics running on WebGPU and WebGL2. It is added to a project from npm, and the project also offers a CDN-hosted build that the browser can load. Engine apps run in the browser, and the package also runs in Node.js, which the project's [Node guide](https://developer.playcanvas.com/user-manual/engine/running-in-node/) documents.

## Worth knowing

The PlayCanvas Editor, a browser-based visual editor, and SuperSplat are separate products and are not covered by this record. The Editor is also offered as a hosted service at playcanvas.com.
