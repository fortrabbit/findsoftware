Flamingo is a web framework based on Go for building modular, pluggable web applications. A project is a Go module that imports the framework and starts with the serve command, which listens on port 3322 by default.

The framework includes localization support and renders templates with Go templates or pug. Its documentation is at docs.flamingo.me.
