Vanilo is an e-commerce framework for Laravel. It is a Composer package added to a Laravel application, and it stores its data in that application's database. Vanilo UG, named in the homepage copyright notice, maintains it. The [documentation](https://vanilo.io/docs/) holds the installation and usage guides.

## Worth knowing

Vanilo is a package, not a standalone shop, so it needs a Laravel application to run in.
