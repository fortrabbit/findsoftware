validate.js is a JavaScript library that validates objects against declarative constraints. The homepage says the constraints can be declared in JSON and shared between clients and the server. The [documentation](https://validatejs.org) is on the project's own site.

The repository is archived. Its README says the maintainer no longer has the time to maintain the project, that no new features will be added and that no bugs will be fixed.
