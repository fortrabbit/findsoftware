Backbone.js gives JavaScript web applications models, collections, views and events, and connects them to an existing API over a RESTful JSON interface. The [homepage](https://backbonejs.org/) presents it for rich client-side applications and says it is an open-source component of DocumentCloud. It is distributed as a script file to download.

## Worth knowing

Backbone depends on Underscore.js, and the homepage says jQuery is needed only for RESTful persistence and for DOM manipulation with views.
