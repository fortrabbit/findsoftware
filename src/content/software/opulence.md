Opulence is a PHP web application framework with a router, middleware, an ORM and a console component. Views are rendered with its own template system, Fortune. A project starts with `composer create-project opulence/project`, and the [installation docs](https://www.opulencephp.com/docs) ask for the tmp directory to be writable from PHP.

David Young wrote Opulence and holds the registered trademark on its name.
