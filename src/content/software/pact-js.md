Pact JS is the JavaScript and TypeScript library of Pact, a contract testing framework for HTTP APIs and asynchronous messaging systems. The README names HTTP/REST and event-driven systems as the systems it supports, and lists a configurable mock server among its features. It is installed from npm as a development dependency and runs on Node.js.

## Worth knowing

PactFlow, described on the Pact homepage as a premium, fully hosted Pact Broker, is a separate product. The README says Pact JS integrates with the Pact Broker and PactFlow.
