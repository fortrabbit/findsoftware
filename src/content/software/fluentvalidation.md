FluentValidation is a .NET library for building strongly typed validation rules in C#. The FluentValidation NuGet package is added to a project with the NuGet package manager or the dotnet CLI, and the rules run inside the .NET application that references it. The library ships translations of its default validation messages in several languages. The source is on GitHub under the FluentValidation organization, and Jeremy Skinner maintains the project. The [documentation](https://docs.fluentvalidation.net/en/latest/) is a Sphinx site.

## Worth knowing

The current major line supports .NET 8 and newer. The docs name an earlier major line for older runtimes. Blazor integration comes from third-party packages, which the Blazor page lists.
