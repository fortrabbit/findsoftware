Behat is a behavior-driven development framework for PHP that tests business expectations. It is added to a project as a development dependency with Composer or downloaded as a PHAR archive, and it is run from the command line. Its documentation is hosted at docs.behat.org, and behat.org forwards visitors there.

## Worth knowing

The quick-start guide still names an older PHP minimum than the one the current release declares.
