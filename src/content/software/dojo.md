Dojo is a framework for web applications written in TypeScript, with widgets, routing, state management and internationalization tools. Applications are created and built with the Dojo CLI, which is installed from npm. The [overview](https://dojo.io/learn/overview/introduction) describes the framework as aimed at single-page applications, and the [building guide](https://dojo.io/learn/building/introduction) describes rendering routes at build time to produce initial HTML and CSS.

## Worth knowing

The documentation site's version menu names an older version as the latest than the newest release in the repository. The npm package named "dojo" is the Dojo Toolkit, a separate project.
