Pigeon Maps is a React library for interactive tile maps, with markers and overlays, and it describes itself as ReactJS maps without external dependencies. Its introduction contrasts its size with Google Maps JavaScript and Leaflet.

## Worth knowing

Map tiles are not part of the library. It loads them from OpenStreetMap by default, and a function that returns a tile URL points it at another provider.
