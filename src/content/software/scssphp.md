scssphp is a compiler for Sass written in PHP. It is installed with Composer under the package name scssphp/scssphp and runs inside PHP code. Its homepage gives the Composer command as the officially supported way to install it.

## Worth knowing

The homepage says that scssphp does not support Sass modules yet, and that requests for new Sass language features are rejected and must go to the upstream Sass project. The maintenance notes describe the project as not an official implementation of Sass.
