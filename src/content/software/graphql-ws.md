graphql-ws is a JavaScript library that implements the GraphQL over WebSocket protocol for both a server and a client. The [get-started guide](https://the-guild.dev/graphql/ws/guides) shows servers built on ws, uWebSockets.js, Fastify, Bun, Deno and crossws. The homepage describes the library as zero-dependency.

## Worth knowing

The README says the library and the protocol are not cross-compatible with subscriptions-transport-ws, a deprecated package.
