React Slick is a carousel component for React, a React port of the slick carousel. Bug reports and help requests are taken in a Discord channel.

## Worth knowing

The CSS and font come from the separate slick-carousel package. The [install guide](https://react-slick.neostack.com/docs/get-started) lists it as its own install, imported from npm or linked from a CDN.
