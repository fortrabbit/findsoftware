BentoPDF is an online PDF toolkit. The [documentation](https://www.bentopdf.com/docs) states that all processing happens locally in the browser using WebAssembly, so its tools run on the visitor's device. The [self-hosting guide](https://www.bentopdf.com/docs/self-hosting/docker/) calls Docker the easiest way to self-host it in production. The [about page](https://www.bentopdf.com/about/) names Alam as the person who builds it.

## Worth knowing

The project's pages describe the tools and the self-hosted build, but none documents an API, SDK, webhook or embed that a website calls. The [licensing page](https://www.bentopdf.com/licensing) also offers a commercial license for using the software in a closed-source or proprietary application.
