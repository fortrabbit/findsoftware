AgnosticUI is a component library whose source a CLI copies into the project instead of installing it as a dependency. The homepage says the library lives in the project for React, Vue, Lit, Svelte, Solid and more. Its components are authored as Lit Web Components.

## Worth knowing

The installation page is headed "Experimental Alpha" and says the library is "not ready for production". No stable release exists on GitHub or npm yet.
