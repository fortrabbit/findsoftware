Dialoguewise is a hosted headless CMS for content that reaches several platforms. Editors work in a web portal, and content is delivered to platforms through an API. The docs list SDKs for Angular, .NET, NativeScript and Flutter, plus integration guides for Gatsby, Next.js, React and Vue.

The portal can deploy content in a Pilot mode for testing and a Publish mode for live delivery. The documentation is at [docs.dialoguewise.com](https://docs.dialoguewise.com/getting-started/).
