Siemens iX is an open-source design system of web components for interfaces of industrial software. Siemens Aktiengesellschaft publishes it. The core package `@siemens/ix` is installed with `@siemens/ix-icons` through npm, and the install guides add one framework package next to the core for React, Vue or Angular. The project's README describes the components as built on native Web Components.

## Worth knowing

The Blazor package, `SiemensIXBlazor`, is installed from NuGet for C# applications, and its install page marks it experimental. The project's Figma library is held in a Siemens AG account for Siemens employees, and a classic open-source version is available on request.
