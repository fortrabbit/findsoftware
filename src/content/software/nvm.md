nvm is a version manager for Node.js. It is designed to be installed per user and invoked per shell, and the README describes an install script and a git install. The README is the project's documentation.

## Worth knowing

nvm runs in the user's own shell and is not a server process. The README says it works on POSIX-compliant shells on unix, macOS and Windows WSL, and that Homebrew installation and the Fish shell are not supported.
