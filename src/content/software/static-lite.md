Static Lite is a configuration for generating a static website with npm scripts. Its HTML templates are written in Pug. `npm run compile` builds the static files, and `npm run watch` starts a local server that rebuilds when files change.

The project is installed by cloning its repository and running `npm install`. The README links a Netlify deploy button that creates a hosted copy of the repository on Netlify.

## Worth knowing

The repository has no releases.
