Lightning CSS is a CSS parser, transformer, bundler and minifier written in Rust. It is used from JavaScript through an npm package, from Rust as a library, or through a standalone command-line tool that compiles, minifies and bundles CSS files. Parcel includes it as its default CSS transformer. The project is maintained by Devon Govett and Parcel Contributors.

## Worth knowing

The command-line tool is a separate npm package from the JavaScript library.
