css.gg is an icon library, described in its README as featuring vanilla CSS, SVG and Figma UI icons. The README published with the last GitHub release shows two ways to use it: install the css.gg package from npm or yarn, or link its stylesheet from a CDN. Astrit, the original author named in the license file, maintains it.
