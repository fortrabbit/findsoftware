React95 is a React component library inspired by the Windows 95 user interface design. The `@react95/core` package is installed with npm, yarn or pnpm, and its README recommends importing one of the theme stylesheets in the package, with an optional global stylesheet for fonts, scrollbars and links. Components are then imported by name and used like any other React component.

## Worth knowing

The MIT license covers the code. The license file states that Windows and the images associated with it belong to Microsoft Corp. and are not covered by the license, so a project that reuses those images needs its own rights to them.
