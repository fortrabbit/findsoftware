w2ui is a JavaScript UI library of widgets, loaded either as ES6 modules or as a download that a page includes through script tags for w2ui.js and w2ui.css. The [get-started page](https://w2ui.com/web/get-started) recommends the ES6 module route and links a starter repository, and the [documentation](https://w2ui.com/web/docs) covers the widgets. The repository keeps its translations in a locale folder.

## Worth knowing

The README calls an older release branch the stable line and describes the master branch as the next version in progress, while the homepage presents the newer line as current. Since the newer line, the library has no dependencies, and the homepage says its widgets can also be used as jQuery plugins for backward compatibility.
