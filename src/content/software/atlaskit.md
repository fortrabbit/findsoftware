The Atlassian Design System is the design system Atlassian describes as a central resource for all of its design decisions. The code ships as Atlaskit React components on npm under the @atlaskit scope, and @atlaskit/button is one of those packages. The package repository field points to a Bitbucket mirror rather than GitHub.

## Worth knowing

The design system carries its own [license agreement](https://atlassian.design/license) alongside the Apache-2.0 license the npm package reports, and the two read differently. The agreement grants a limited license to use the design system for add-ons and integrations that interoperate with Atlassian products, and it forbids modifying, redistributing or reverse engineering the design system. Atlassian may end the agreement if it stops offering the design system.
