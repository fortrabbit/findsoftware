Clarity Angular is the Angular component library of the Clarity design system. Its styles come from the separate @clr/ui package, which the install instructions add next to it, so an Angular project installs both with npm. The [Angular documentation](https://angular.clarity.design) describes the components and how to use them.

The code is developed in the vmware-clarity organization on GitHub, and the project's copyright notice names Broadcom Inc.

## Worth knowing

The project's code is MIT-licensed, while its fonts are licensed under the SIL Open Font License.
