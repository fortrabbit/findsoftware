Nexus is a library for building GraphQL schemas in TypeScript and JavaScript, where the schema types are declared in code. The [docs](https://nexusjs.org/docs/) say Nexus builds upon the primitives of graphql-js, and the README names graphql as a peer dependency that the installation needs alongside it.

## Worth knowing

The npm name nexus carries older 0.x versions published by another project, and those versions are marked deprecated with a notice that development has ended. The notice does not apply to the 1.x line this page describes.
