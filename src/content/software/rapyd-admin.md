Rapyd Admin is a Composer package that adds an admin panel to a Laravel application. The panel is built from Livewire components and Blade views that live in the application's own code, and it includes users, companies, roles and permissions, and logs. A single command generates CRUD modules.

## Worth knowing

The README says premium modules and themes will be distributed to subscribers through a private Composer repository.
