Beanie is an asynchronous object-document mapper (ODM) for MongoDB, written in Python. Its data models are based on Pydantic, which the README and the homepage both name. The documentation site at beanie-odm.dev holds the tutorial, the API documentation and the development guidelines, and the project runs a Discord server for questions and discussion. The README names Bunnet as a synchronous version of the ODM, which is a separate project.

## Worth knowing

The README says a major release, Beanie v3, is in progress and has most of the maintainers' attention, so responses to pull requests and issues may be slower than usual.
