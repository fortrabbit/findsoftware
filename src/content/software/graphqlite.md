GraphQLite is a PHP library for writing a GraphQL API as controllers and classes annotated with PHP attributes. The docs say the library is framework agnostic and describe separate integrations for Symfony and Laravel, each in its own repository.

The docs state that GraphQLite relies on the webonyx/graphql-php library internally. The docs also say it needs a PSR-11 compatible container and a PSR-16 cache.
