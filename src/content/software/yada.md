yada is a web library for Clojure, built around an interceptor chain on manifold. It is added as a dependency in `project.clj` or `build.boot` and runs on the JVM. The [install guide](https://github.com/juxt/yada/blob/master/doc/install.adoc) has the application choose a port and start the built-in web server, Aleph, so a process stays running to serve requests.

The user manual is in the repository's `doc` folder. The juxt.pro address the README gives for it now redirects to the GitHub repository.

## Worth knowing

The newest release in the Clojars registry is older than a 1.2.16 tag in the GitHub repository, which has no matching Clojars release. No end of the project is stated on its pages.
