Basecoat is a component library of HTML, CSS and JavaScript built with Tailwind CSS. The README describes it as an implementation of the shadcn/ui design system for any web stack, without React, Radix or framework runtime dependencies. It is loaded from a CDN or installed from npm as the package `basecoat-css`, as the [installation page](https://basecoatui.com/installation) explains, and the README also lists Nunjucks and Jinja templates among its templates.
