Skeleton is a responsive CSS boilerplate that styles raw HTML elements and provides a responsive grid. It is downloaded as a zip file from the GitHub releases or cloned from the repository. Dave Gamache is named as the author in the license, which is MIT.

## Worth knowing

The project describes itself as a starting point rather than a UI framework. No GitHub release has followed the newest one. The project site is served over plain http only, so it is not linked here.
