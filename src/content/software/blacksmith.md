Blacksmith is a Node.js static site generator that renders Markdown content into HTML pages. All rendered HTML is written to a public folder. Partials are rendered with Plates, and content is read from Markdown files with Marked.

It is installed with npm.

## Worth knowing

The README marks the layout JSON properties as not yet supported, and its roadmap lists an RSS feed and nested partials as open items.
