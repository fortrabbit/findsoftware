Moleculer is a microservices framework for Node.js and TypeScript that puts service discovery, load balancing and an event bus inside the framework itself. It is installed from npm as the `moleculer` package.

The [documentation](https://moleculer.services/docs/0.15/) lists an API gateway among its modules and says Moleculer also works as a regular web framework, with the moleculer-web module as the HTTP layer.

## Worth knowing

The project is on major version 0, and its documentation says that breaking changes are released with a new minor version. The license copyright line names Icebob, while the documentation footer names MoleculerJS.
