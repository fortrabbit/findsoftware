Nhost is an open-source backend platform. It combines a PostgreSQL database, a GraphQL API built with Hasura, authentication and file storage, with a dashboard for managing an app. It is offered as a cloud service and as a self-hosted stack, and the [documentation](https://docs.nhost.io) covers both.

## Worth knowing

The self-hosting path is the Docker Compose reference implementation of the community edition. Paid support agreements and a dedicated cluster are offered beside it.
