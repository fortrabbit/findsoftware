Wisp is a hosted headless CMS for blogs on Next.js and React. Authors publish posts in a hosted publishing interface, and a site reads them through a REST API or the JavaScript client, which installs with npm. One account can hold several blogs, each its own instance.

Synscribe is the parent company.

## Worth knowing

The REST API is limited to 100 requests per minute and is available on paid plans only. The free plan adds an attribution line to every post.
