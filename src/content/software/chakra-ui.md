Chakra UI is a React component system, installed from npm and used through a provider component generated at the root of the app. Its command-line tool adds prebuilt snippets to a project, and a LocaleProvider component sets the locale for the app.

## Worth knowing

Premium blocks are sold as Chakra UI Pro under its own [license agreement](https://pro.chakra-ui.com/legal/license), and the [pricing page](https://pro.chakra-ui.com/pricing) lists the paid plans.
