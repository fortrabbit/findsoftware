swagger-jsdoc is a Node.js library that reads JSDoc-annotated JavaScript source code and generates an OpenAPI specification from it. A command line interface wraps the library and is available under the package name when installed globally.

The README lists OpenAPI, Swagger 2 and AsyncAPI as supported specifications. The [6.x documentation](https://github.com/Surnet/swagger-jsdoc/tree/v6/docs) gives the details for that line.
