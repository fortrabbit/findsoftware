Grommet is a React-based component library and framework. It is installed with npm or yarn together with styled-components, and its components provide theming, responsive layouts, and accessibility support, as the [homepage](https://grommet.io) describes.

## Worth knowing

The install command adds styled-components beside Grommet, so a project that uses Grommet depends on both.
