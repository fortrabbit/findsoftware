wangEditor is an open-source web rich text editor for pages that take formatted text input. It does not depend on a third-party framework and can be used with jQuery, Vue or React. The project publishes optional official Vue and React components that wrap the editor, and a [plugins page](https://www.wangeditor.com/en/v5/plugins.html) lists extensions.

The interface ships in Chinese and English, Chinese being the default, and other languages can be added. The editor core installs from npm, and the repository holds several packages in one monorepo.

## Worth knowing

The compatibility section names most PC browsers, says mobile editing is not supported, and says Internet Explorer is no longer supported.
