styled-components is a styling library for React. It lets a component's styles be written as CSS in tagged template literals, and the styles are scoped to that component. The package is installed with npm, pnpm or yarn, and the [documentation](https://styled-components.com/docs) covers the API.

## Worth knowing

The README says the project is largely maintained by one person and asks for funding through Open Collective. Prerelease builds of a next major version are published on GitHub.
