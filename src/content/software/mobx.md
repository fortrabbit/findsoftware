MobX is a JavaScript library for state management. A field is updated with a normal JavaScript assignment, and the functions and components that read a value are tracked, so only those that depend on a changed value run again. The project describes MobX as unopinionated and able to manage state outside of any UI framework. It can be loaded from npm or from a CDN script. The React bindings are separate packages in the same repository.

## Worth knowing

MobX runs in browsers and in Node.js environments that provide native Proxy support, and the installation page states that requirement without a version.
