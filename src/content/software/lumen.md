Lumen is a PHP micro-framework from Laravel for building web applications. The [installation page](https://lumen.laravel.com/docs/11.x/installation) calls it "a totally separate framework from Laravel".

## Worth knowing

The installation page says new projects are no longer supported with Lumen and recommends beginning them with Laravel. That is a support statement; no page read says Lumen has ended.
