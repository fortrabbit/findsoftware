TestCafe is a Node.js framework for writing and running end-to-end tests of web pages in browsers. It is a command-line application that runs test scripts, and Developer Express Inc. maintains it. The [documentation](https://testcafe.io/documentation/402635/getting-started) is linked from its README.

The README says TestCafe runs on Windows, macOS and Linux, drives desktop, mobile, remote and cloud browsers, and does not need WebDriver. The FAQ describes a hybrid automation engine in which a proxy injects client-side automation scripts into web pages.

## Worth knowing

The installation section of the README and the npm package name different minimum Node.js releases.

TestCafe Studio is a separate paid IDE built on the open-source framework, and the README describes it as a different product.
