Spring Framework is a Java framework that provides a programming and configuration model for enterprise applications. It is published as separate artifacts on Maven Central, so an application adds only the modules it uses to a Maven or Gradle build, such as `spring-context`. The [reference documentation](https://docs.spring.io/spring-framework/reference/) covers the modules, and the project's wiki gives the JDK versions each release line supports.
