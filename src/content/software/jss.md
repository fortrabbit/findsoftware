JSS is an authoring tool for CSS: styles are described in JavaScript and compiled into style sheets in the browser, on the server or at build time in Node. It is installed with yarn or loaded from the unpkg CDN, and its [documentation](https://cssinjs.org) is on the project's own site. The source is in the cssinjs organization on GitHub, and Oleg Isonen is named in the copyright line of the license.

## Worth knowing

The README states that the project is no longer maintained. Its maintainer says they are working on a new tool, Webstudio, which the README links.
