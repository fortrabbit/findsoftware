swift-doc generates documentation for Swift projects. Given a directory of Swift files, its generate subcommand writes documentation for each class, structure, enumeration and protocol, as HTML or as CommonMark formatted for a GitHub Wiki. The coverage subcommand generates documentation coverage statistics, and the diagram subcommand writes a graph of symbol relationships in DOT format. The repository also hosts a GitHub Action that runs the generator.

## Worth knowing

The repository is archived on GitHub, and the homepage named in the candidate list now redirects to an unrelated site.
