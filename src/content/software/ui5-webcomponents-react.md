The package lets React applications use the UI5 Web Components as native React components. Its docs describe it as a Fiori compliant React library built on top of the UI5 Web Components. The recommended install adds @ui5/webcomponents and @ui5/webcomponents-fiori next to the React package. SAP SE maintains it.

## Worth knowing

Support for the 1.x line has ended, and new releases come from the 2.x line. The charts package in the same repository is deprecated.
