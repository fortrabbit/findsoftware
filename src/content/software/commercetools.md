commercetools is a hosted headless commerce platform, presented on its pages as Sphere, and it is run by commercetools GmbH in Munich. It exposes commerce data through an HTTP API and a GraphQL API, and changes to resources can be made through the Merchant Center, a web interface on the platform. Projects are located in a region (North America, Europe or Australia). The docs also list SDKs, managed MCP servers and a Frontend Studio.

## Worth knowing

commercetools is a hosted service, and no installable part is named. The homepage offers a free trial rather than a free plan.
