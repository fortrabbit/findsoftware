bashblog is a blog generator delivered as a single Bash script, written by Carlos Fenollosa. Installing it means copying `bb.sh` into a public web folder and running it there, and running `./bb.sh post` starts a post. The README says all content is static, so the web server only has to serve files, and it describes running the script locally as well.

## Worth knowing

The README states support for GNU/Linux, OSX and BSD. The repository has no tagged release and no license file, so the license comes from the README's License section.
