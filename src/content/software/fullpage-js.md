fullPage.js is a JavaScript library that builds fullscreen scrolling websites, with sections and horizontal slides inside them. The project is a project by Alvaro Trigo. Official wrappers for Vue, React and Angular are separate packages, and the library can also be used as a jQuery plugin.

## Worth knowing

A website or application that is not open source and not compatible with GPLv3 needs the commercial license, which the project sells in several plans on its pricing page. The extensions are paid add-ons, and each needs its own activation key and license key.
