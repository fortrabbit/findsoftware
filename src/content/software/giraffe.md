Giraffe is an F# web framework for ASP.NET Core, and it is built on top of ASP.NET Core. Views can be written with the Giraffe View Engine, which is functional F# code, and Razor and DotLiquid views are supported through add-on packages. A project adds the Giraffe NuGet package with dotnet add package Giraffe. The source is published under the giraffe-fsharp organization on GitHub.
