Fluent.js is a JavaScript implementation of Project Fluent, a localization framework for translations with plurals, genders and grammatical cases. The [API reference](https://projectfluent.org/fluent.js/modules/_fluent_bundle.html) documents the core package, @fluent/bundle, which the README lists first. The repository is a monorepo that also holds packages for the DOM, React, locale negotiation and syntax, and the project's own site describes Fluent as a localization system with implementations in JavaScript, Python and Rust.

## Worth knowing

The project site calls Fluent a research project by Mozilla, and the copyright notice names the Mozilla Foundation and others, so the code is maintained by Mozilla together with contributors.
