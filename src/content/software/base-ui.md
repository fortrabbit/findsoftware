Base UI is a React library of unstyled UI components, which means it supplies the behavior and accessibility of interface parts without a visual design of its own. The homepage says the library was built by the creators of Radix, Floating UI and Material UI.

It is published as the npm package `@base-ui/react`, and the [quick-start page](https://base-ui.com/react/overview/quick-start) installs it with pnpm, npm, yarn or bun. The package was renamed from `@base-ui-components/react`, and the older name is deprecated on npm.

## Worth knowing

The homepage FAQ says Base UI has no enterprise SLA, and that dedicated support goes to some design partners.
