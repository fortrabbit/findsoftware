WPWMM4 is a static web page generator that runs on make and m4. A Makefile builds HTML pages from m4 source files, and the m4 macro processor supplies the templating, so the output is plain files that any web space can serve. It is run with the make command.

## Worth knowing

The README requires BSD make (the bmake package on Linux) and m4, and gives no install steps. The project's own homepage refuses connections, so the record rests on the GitHub repository and its README.
