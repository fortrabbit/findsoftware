MariaDB Server is a relational database server with an SQL interface, written in C++ and shipped as compiled binaries. Its GitHub description calls it a community developed fork of MySQL server. The community source code is maintained by the MariaDB Foundation, while the company MariaDB plc sells the commercial products built around it.

Installs come from Linux package managers, a Windows installer, a binary tarball, or the official image on Docker Hub. After installation the server starts as a service.

## Worth knowing

Subscriptions with additional enterprise features and a managed cloud service come from the company, not from the Foundation. Community releases follow a rolling line and an LTS line, so the newest release and an LTS release can differ.
