Gloria is a static website generator for Node.js. The [install guide](https://gloria.js.org/documentation/install/) adds the gloriajs npm package to a project and runs the build from package.json scripts, and the [deployment guide](https://gloria.js.org/documentation/deploy/) builds the site and copies its files to any static host, with GitHub Pages as the worked example. The README describes the project as a substitute for Jekyll.

## Worth knowing

The LICENSE file is not an SPDX license. It grants use "with specific restrictions FOR the purposes of satire, evil, or advancing evil", and GitHub does not identify a license for the repository. The README calls the project a satire of other projects.
