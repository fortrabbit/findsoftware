Craftable is a Laravel-based toolkit with a CRUD generator. Its admin UI is built on Bootstrap 4 and CoreUI. It includes permissions and roles for users and a translation system for Eloquent models. It is installed with a Composer global installer.

## Worth knowing

The [homepage](https://getcraftable.com) announces the end of support for Craftable by the end of 2024 and recommends moving to Craftable PRO, which the README calls the premium version of the project.
