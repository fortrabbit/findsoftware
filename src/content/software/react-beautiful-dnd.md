react-beautiful-dnd is a drag and drop library for lists in React, installed from npm and also usable in a browser through a UMD bundle and a script tag.

The repository is archived and the npm package's latest version is marked deprecated. The README points to Pragmatic drag and drop, a separate project, for Atlassian's ongoing work on drag and drop.
