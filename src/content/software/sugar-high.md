Sugar High is a JavaScript library that highlights source code and returns the result as HTML. Its README says it runs in browsers and JavaScript runtimes without requiring a DOM. The [API reference](https://github.com/huozhi/sugar-high/blob/main/docs/API.md) lists the package exports, the language mapping and the highlighting options.

The repository is a monorepo. Besides the core package, it holds the React package @sugar-high/react and the Remark package @sugar-high/remark.
