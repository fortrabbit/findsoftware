VanJS is a reactive UI framework that builds DOM trees from plain JavaScript functions, without JSX. A project loads VanJS from a CDN script tag, installs the `vanjs-core` npm package, or downloads the files and serves them itself. It runs in the browser, and code written with it can be run from the browser's developer console.

## Worth knowing

The [about page](https://vanjs.org/about) says the creator built VanJS in personal time while employed at Google, and that Google waived its copyright claims on the work, so the copyright belongs to the creator. The project's discussions are on [GitHub](https://github.com/vanjs-org/van/discussions).
