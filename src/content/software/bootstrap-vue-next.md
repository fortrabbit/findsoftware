BootstrapVueNext is a component library for Vue that provides Bootstrap components as Vue components, written in TypeScript. The homepage describes it as a way to build ARIA accessible projects on the web with Vue.js and Bootstrap, and the install docs add it with npm.

The [getting-started page](https://bootstrap-vue-next.github.io/bootstrap-vue-next/docs) calls the project an attempt to have the BootstrapVue components in Vue 3, Bootstrap 5 and TypeScript, and links a migration guide for BootstrapVue users.

The Nuxt integration is a separate package, @bootstrap-vue-next/nuxt, installed as its own step on the Nuxt page.
