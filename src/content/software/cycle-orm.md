Cycle ORM is a PHP package whose README states that it is designed to work in classic and daemonized PHP applications. Projects install it with Composer, as the [installation guide](https://cycle-orm.dev/docs/intro-install/current/en) describes. The [integrations page](https://cycle-orm.dev/docs/intro-integrations/current/en) lists packages that connect it to the Spiral and Yii frameworks and to Laravel.

## Worth knowing

The installation guide lists the PHP PDO extension and the PDO drivers for the chosen databases as requirements.
