ROM is a Ruby toolkit for data mapping and persistence. It keeps database access separate from application logic, and its adapters (rom-sql, rom-mongo, rom-http and others) ship as separate gems. The SQL adapter covers PostgreSQL, MySQL and SQLite, and the homepage says ROM also works with document databases, search engines, HTTP APIs and local data files. The project's docs include a guide that compares ROM with ActiveRecord.

## Worth knowing

The project's page is hosted by Hanakai, and the repository moved from the rom-rb organization to hanakai-rb. The copyright line in the license still names the rom-rb team.
