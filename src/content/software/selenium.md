Selenium is an umbrella project of tools and libraries for automating web browsers, built on the W3C WebDriver standard. A script uses the library for its language to open a browser, load pages and interact with them. Each language binding is installed from its own package manager, and Selenium Manager finds the driver that matches the installed browser and downloads the browser itself when none is installed.

The project is a member of the Software Freedom Conservancy, a non-profit.

## Worth knowing

Selenium Grid, which runs test cases on different machines across platforms, is documented as a separate component. The project's bindings are client libraries and no single runtime applies to all of them.
