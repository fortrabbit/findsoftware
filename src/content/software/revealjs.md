reveal.js is an HTML presentation framework: a deck is a web page that runs in a browser. The basic setup needs only a browser and an index.html file opened directly. The full setup uses Node.js and a local development server, which the installation guide says external Markdown files require. The framework can also be installed from npm as a dependency of another project. Hakim El Hattab started the project and maintains it.

## Worth knowing

Slides.com, a graphical editor for reveal.js presentations, is made by the same people but is a separate product. The video course the project links to is marked as paid and is not part of the software.
