Taiga UI is an Angular UI kit made of base libraries and add-ons. A project installs it with npm or with the ng add command, and the [getting-started guide](https://taiga-ui.dev/getting-started/) describes both routes. The kit ships its components as tree-shakable entry points, so a bundle carries only the parts it imports. Pineopticone, a company, maintains it and publishes it from the taiga-family organization on GitHub.

## Worth knowing

The code is under the Apache 2.0 license and the licensing page states it is free for commercial use. The maintainer also sells Taiga Premium, which covers design-kit licenses and support, and enterprise support. These paid services sit outside the open source code.
