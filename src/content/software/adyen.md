Adyen is a hosted payment platform: merchants and platforms connect to it through its API. The platform takes online and in-person payments and sends payouts, and the company describes it as one platform for payments, data and financial products. Client code for the API is published as server-side libraries for several package systems, including npm, Maven and Composer, and the Customer Area, where account users work, supports single sign-on over SAML 2.0 and user roles that set what each user may do. Adyen N.V. is registered in Amsterdam, where the company was founded in 2006.

## Worth knowing

Fees are charged per transaction: a fixed processing fee plus a fee set by the payment method.
