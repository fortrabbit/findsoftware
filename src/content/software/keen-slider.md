Keen-Slider builds sliders and carousels. Its core is framework-agnostic, and the documentation covers a React hook and a Vue 3 composable shipped with the same library. The library also comes as a UMD bundle for loading directly in HTML.

## Worth knowing

The docs warn that the browser's render performance can slow down when slides carry complex markup and CSS.
