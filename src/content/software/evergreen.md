Evergreen is a React component library and design system from Segment. Its components are built on a React UI primitive, and the site documents them under foundations, components and patterns sections. The README says it bundles its own CSS-in-JS solution from ui-box and exposes an extractStyles() function for server-side rendering.

## Worth knowing

The install page asks for React and React DOM alongside the package.
