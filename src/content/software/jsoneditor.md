JSON Editor is a JavaScript component that puts an editor for viewing, editing, formatting and validating JSON into a web page. The README presents it as a component for a web application, and its features include JSON schema validation through ajv, JMESPath queries and an Ace-based code mode. The interface has built-in translations, and further languages can be supplied through an option.

## Worth knowing

The README names svelte-jsoneditor as its successor while still describing this library as usable. The README also expects commercial users to help fund its maintenance, in its words a social but not a legal expectation.
