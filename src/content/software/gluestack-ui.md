gluestack-ui is a library of copy-pasteable components and patterns for React Native and Expo, styled with Tailwind CSS through NativeWind. The [installation guide](https://gluestack.io/ui/docs/home/getting-started/installation) sets it up with a CLI in an existing Expo or React Native project, and components are then added to the project with the same CLI or copied from the documentation.

GeekyAnts publishes the library. A separate Pro edition offers premium React Native templates and UI components.

## Worth knowing

The CLI that sets up and adds components needs Node.js on the developer's machine.
