Tabulator is a JavaScript library that builds interactive tables and data grids from HTML tables, arrays or JSON data. It runs in the visitor's browser. The core has no dependencies, and it works with React, Vue and Angular as well as with no framework.

## Worth knowing

Some features need an extra library that the project's [dependencies page](https://www.tabulator.info/docs/6.x/dependencies) names: SheetJS for importing and exporting Excel spreadsheets, jsPDF for PDF export, and Luxon for date and time handling in several formatters, sorters and editors.

The maintainers also sell annual support plans for organizations, and they say the MIT license is not changing.
