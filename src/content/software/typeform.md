Typeform is a hosted form, survey and quiz builder. A finished form can be embedded in a website or web app with the Embed SDK. The developers' documentation lists APIs to create forms, read responses as JSON and receive webhooks.

Forms can be translated so that respondents answer in their own language, and roles and permissions can be assigned to users of an organization and its workspaces.

## Worth knowing

Single sign-on, two-factor authentication, HIPAA compliance, the choice of a US or EU data center, and custom domains are marked Enterprise only on the pricing page. The software is a hosted service, and the record holds no self-hosted option.
