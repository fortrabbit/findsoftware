Lume is a static site generator for Deno. The homepage lists Markdown, Vento, Nunjucks, Liquid, JSX, Pug and Eta among the template formats it accepts.

## Worth knowing

The main branch README describes Lume as a static site generator for Node and says previous versions were available for Deno. The npm package carries a beta of that line as its latest tag, so the Node line is a pre-release, while this record covers the stable Deno line.
