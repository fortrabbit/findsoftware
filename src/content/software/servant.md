Servant is a set of Haskell libraries for writing type-safe web applications. The core package is named servant, and the servant-server package is the one that runs webservers implementing an API type. The tutorial's install page builds its project with cabal or stack.

The [documentation](https://docs.servant.dev/en/latest/) includes a tutorial, and the project's landing page at [servant.dev](https://www.servant.dev/) describes servant as packages for declaring web APIs at the type-level.
