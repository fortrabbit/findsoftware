OpenLayers puts an interactive map into a web page and can display map tiles, vector data and markers from any source. It is written in JavaScript and runs in the visitor's browser, so the live site needs nothing from the host beyond serving the files. The project also publishes a full distribution as a download from its release page. The [documentation](https://openlayers.org/doc/) covers the quick start, the FAQ and the tutorials, and the [third-party page](https://openlayers.org/3rd-party/) lists libraries that extend it.

## Worth knowing

The code and the documentation carry different licenses: the code is under the 2-Clause BSD License, and the documentation is under CC BY 3.0.
