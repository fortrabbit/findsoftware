django-components is a UI framework for Django that builds reusable template components. The README says it combines Django's templating system with the modularity of frontend frameworks, and it builds on Django rather than replacing it. It is installed with pip under the name django_components, and the installation page adds it to a Django project's settings. Emil Stenström, named in the license file, is the maintainer, and the project is developed on GitHub with other contributors.
