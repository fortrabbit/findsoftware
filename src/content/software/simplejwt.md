Simple JWT adds JSON Web Token authentication to an API built with Django REST Framework; the project calls itself an authentication plugin for it. It includes an optional token blacklist app and a stateless authentication backend that does not look up the user in the database. Its strings can be translated.

The project says it borrows code from Django REST Framework and concepts from django-rest-framework-jwt.
