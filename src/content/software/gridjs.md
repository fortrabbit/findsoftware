Grid.js is a table plugin for JavaScript that works with most frameworks, including React, Angular, Vue and plain JavaScript. A table takes a list of column names and rows of data, and a render call attaches it to an element on the page. The [install page](https://gridjs.io/docs/install) gives two routes: the npm package, and a CDN that serves the JavaScript and CSS files.

A React integration is a separate wrapper, and it needs Grid.js installed as a peer dependency.
