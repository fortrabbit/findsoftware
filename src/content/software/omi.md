Omi is a framework for building Web Components. Components are written in JSX, with reactive state provided by signals, and the README lists a router, a Suspense component for asynchronous dependencies and directives among what is included. Projects install it with npm, and a separate command-line tool, omi-cli, creates a starter project.

The repository is maintained by THL A29 Limited, a Tencent company. Some third-party components bundled with the source keep their own license terms, as the LICENSE file lists them.
