Easystatic is a static site generator written for Node.js. Pages are Markdown files, and the site layout comes from an EJS template and Postcss. It is installed globally with npm. The README credits the copyright to the Easystatic contributors.

## Worth knowing

The project's domain is now for sale and shows a domain broker's page, so the README and the docs folder in the repository are the documentation that remains.
