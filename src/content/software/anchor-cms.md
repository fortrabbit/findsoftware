Anchor CMS is a blog system written in PHP that runs on MySQL or SQLite, with an administration interface. It can be installed with `composer create-project anchorcms/anchor-cms anchor`, or uploaded by FTP or SFTP. The code is published on GitHub under the GNU General Public License version 3.

## Worth knowing

The maintainers archived the project, and the README heading reads "No Longer Maintained". The documentation page says the project "is no longer in active development", and the README advises against treating it as production ready. The GitHub repository is archived, the Packagist package is marked abandoned, and the newest GitHub release dates from 2018.
