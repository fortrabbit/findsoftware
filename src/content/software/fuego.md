Fuego is a Go framework for building APIs and web applications. It generates OpenAPI documentation from handler code and is built on net/http. Its feature set includes serialization, validation and centralized error handling, and it renders HTML with html/template, templ or gomponents. Projects install it with the Go toolchain, and the resulting Go program starts a server that listens for incoming requests.
