PJ Blog is a blog application built with Laravel and Vue.js. Its administration dashboard is made from Vue components, and it offers multi-language switching and roles and permissions. The project installs from a git clone or with Composer, and the [repository's readme](https://github.com/jcc/blog/blob/master/readme.md) lists the steps.

## Worth knowing

The default branch and the newest release name different Laravel requirements.
