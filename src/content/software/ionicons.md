Ionicons is an icon set published by Drifty Co., which trades as Ionic and is part of OutSystems. Its [readme](https://github.com/ionic-team/ionicons/blob/main/readme.md) describes a Web Component that loads one SVG per icon and only for icons that are visible. Ionic Framework packages it by default, and pages without Ionic Framework load it with a script tag. Each icon comes in filled, outline and sharp variants.
