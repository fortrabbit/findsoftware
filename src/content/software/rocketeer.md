Rocketeer is a PHP task runner and deployment package for remote servers. The README lists commands to deploy a project, roll back to an earlier release, clean up old releases and check or set up the server.

The README's install section gives a binary download.

## Worth knowing

The repository is archived and the README says the project is no longer maintained. The README recommends Deployer and CD pipelines to users who want to move on. The project's homepage does not resolve, so the download and documentation links in the README are not reachable.
