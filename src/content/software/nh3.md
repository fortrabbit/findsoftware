nh3 lets Python code clean HTML fragments by calling ammonia, an HTML sanitization library written in Rust. The [documentation](https://nh3.readthedocs.io/en/latest/) is hosted on Read the Docs.

## Worth knowing

The package is a wrapper, so the sanitizing itself happens in the Rust library underneath.
