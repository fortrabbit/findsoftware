Tremor is a set of React components for building charts and dashboards with Tailwind CSS. A project copies the components into its own code and then keeps and edits them. The components are built with React and Tailwind CSS, and Tremor Labs, Inc. publishes them.

## Worth knowing

The site carries a banner stating that Tremor is joining Vercel. The pages read for this record do not say what that means for ownership or maintenance.
