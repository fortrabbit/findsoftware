jOOQ is a Java library that models SQL as a type-safe Java API, so queries are written in Java code and checked against the database schema the project's code generator reads. It is added to a project as a Maven dependency or downloaded, and it works with several relational databases.

## Worth knowing

Commercial licenses replace the open-source license for users who want limited warranties, support, maintenance and commercial database integrations.
