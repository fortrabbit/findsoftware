Blitz is a fullstack toolkit for Next.js that adds libraries and conventions on top of it. The homepage says it picks up where Next.js leaves off. Blitz RPC lets client code read and write server data with full type safety, without handling HTTP or serialization by hand, and Blitz ships authentication libraries that include social third-party logins. Prisma is the default database client, and a new app starts with a local SQLite database; the [database overview](https://blitzjs.com/docs/database-overview) describes switching to PostgreSQL. A project is created with `blitz new`, and the libraries can also be added to an existing Next.js project through the `@blitzjs/next` package.
