reactstrap is a set of stateless React components for Bootstrap 5, the CSS framework. The README describes React Bootstrap components that favor composition and control and do not depend on jQuery or Bootstrap's JavaScript. It is installed from npm alongside React and Bootstrap, and it declares React and React DOM as peer dependencies.

## Worth knowing

The README says reactstrap does not include the Bootstrap CSS, so a project installs Bootstrap and imports its stylesheet separately. Projects on Bootstrap 4 are pointed to an earlier reactstrap line.
