ImpressPages is a PHP framework that comes with a content editor. Site owners edit pages in place, with inline editing and drag-and-drop. The package installs through Composer, and the [repository's readme](https://github.com/impresspages/ImpressPages/blob/master/readme.md) describes the steps: a composer.json that requires the package, a `composer install` run, and a web server pointed at the `public` directory.

## Worth knowing

The project's own site and docs describe an older line than the newest package on Packagist, and the repository has no GitHub releases. No page declares the project ended or unmaintained.
