Kotti is a Python web application framework built on Pyramid and SQLAlchemy. It includes the Kotti CMS, a content management system whose editors change content where it appears on the page. The CMS has a user and permission management system and a fully translatable interface.

The installation guide starts a site with the pserve command, which runs the Waitress WSGI server by default. Kotti includes support for PostgreSQL, MySQL and SQLite. The documentation is hosted on Read the Docs, and the copyright belongs to the Kotti developers under the Repoze Public License, a BSD-derived license.
