AbanteCart is an open-source ecommerce platform for running an online store, maintained by the AbanteCart community. The admin interface is part of the application, which keeps its data in MySQL or MariaDB and runs behind Apache or Nginx with URL rewriting enabled.

## Worth knowing

The core software is free to use. The homepage also names AbanteCart Charged, a paid distributed edition for custom solutions, and offers hosting through partners and a managed service.
