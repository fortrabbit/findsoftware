Goshtoso is a Go component library for server-rendered web applications, installed as a Go module with `go get`. Its components are pre-generated [templ](https://templ.guide/) components. The library renders on the server by default, and its homepage describes rendering complete pages at build time for any static host.

The project began as a hard fork of PenguinUI. Arai Hû, which the homepage calls the organization behind Goshtoso, maintains it under the MIT license.

## Worth knowing

The README says the components are usable but the API surface is still being refined toward a stable public release. The documentation site is a separate module in the repository and is not part of the library itself.
