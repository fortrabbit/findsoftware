Vue-Multiselect is a select, multiselect and tagging component for Vue.js. The [README](https://github.com/shentao/vue-multiselect/blob/master/README.md) lists single and multiple select, tagging, filtering, search with suggestions, async options and v-model support among its features, and says the component has no dependencies.

## Worth knowing

The README says the component requires Vue's Options API to function properly, and warns that some versions of the Vite Vue plugin can disable it. A newer major version is published as a prerelease.
