Salesman is a headless e-commerce framework for Django and Wagtail. It is installed with pip and added to a Django project's INSTALLED_APPS, with its API URLs included in the project's urls.py. The framework provides endpoints for the basket, the checkout and the orders through a RESTful API, and a pluggable modifier system for basket processing. The docs name django-shop, django-oscar, django-cart and longclaw as alternative e-commerce options.

The admin is either Wagtail or the Django admin.

## Worth knowing

The package metadata limits Django to versions from 5.0 up to, but not including, 6.0.
