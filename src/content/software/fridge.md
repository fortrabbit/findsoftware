Fridge is a hosted content platform for any kind of content, not only websites. Content types are defined first, content is then entered and managed in Fridge's content application, and apps pull it through a RESTful API. The homepage describes custom permission sets and a customizable dashboard.

The documentation covers content types, API libraries, integrations, webhooks and static sites, and the GitHub organization fridge-cms publishes client libraries and a Jekyll helper.

## Worth knowing

Fridge is a hosted service with a 30-day trial and paid plans.
