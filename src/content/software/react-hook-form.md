React Hook Form is a React library for form state management and validation, installed from npm. It works with standard React inputs, and its get-started guide also covers React Native.

The FAQ compares it with Formik and Redux Form. It describes its own state model as uncontrolled by default, with controlled inputs also supported, while Formik and Redux Form use controlled state.
