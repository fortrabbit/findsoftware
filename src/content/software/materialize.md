Materialize is a front-end library of CSS styles and JavaScript components that follows the Material Design language. It is a fork: the project's about page says a community forked MaterializeCSS into MaterializeWeb because the original developers were inactive, and this repository is that fork. It installs from npm, loads from jsDelivr, or comes as a file download from the project's downloads. The codebase is written in TypeScript, and the [getting started guide](https://materializeweb.com/getting-started.html) covers the setup.
