Caisy is a hosted headless content management system with a GraphQL API. Its features page describes TypeScript-focused SDKs, a web editor with Live Preview, and content in several locales. The company is cyclus.digital GmbH in Stuttgart, Germany, and caisy is a brand of that company. The [developer documentation](https://caisy.io/developer/docs) is on the same site.

The GitHub organization caisy-io publishes many repositories, among them a CLI for importing and exporting content and example and starter projects for several frontend frameworks. None of them is recorded as the product's repository.

## Worth knowing

The pricing page lists custom SSO, custom user roles and on-premise hosting for the Enterprise plan. A free plan is listed as well. No page documents installing it, so it is treated as a hosted service.
