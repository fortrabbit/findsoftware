Fern turns an API definition into SDKs, API reference documentation and command-line tools. The open source part is the `fern-api` command-line tool, installed with npm, which needs Node.js 18 or later. Documentation sites are written as Markdown kept in Git and are hosted by Fern by default. A [Docker container](https://buildwithfern.com/learn/docs/self-hosted/overview) for self-hosting the docs is offered on the Enterprise plan. Birch Solutions, Inc., a Postman company, maintains it.

## Worth knowing

The README of the open source repository says the project is no longer maintained and points to the hosted product, which the company still publishes.
