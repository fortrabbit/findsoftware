osCommerce is a shopping cart and e-commerce platform published as osCommerce 4 in a [GitHub repository](https://github.com/osCommerce/osCommerce-V4), built on the Yii 2 framework. The README lists multiple front ends, themes, a visual theme designer and site content managed through a CMS. It is installed by cloning the repository, or by extracting an archive, into the web root, and the README says the database has to be created by hand before the installation runs. The homepage names an app store alongside it, and one backend can run several websites.

## Worth knowing

The repository's LICENSE.TXT opens with osCommerce v4 programme terms that limit use to testing purposes, at the user's own risk, and the GPL version 2 text follows them.
