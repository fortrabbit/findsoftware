Metro is the JavaScript bundler for React Native projects. It bundles the app's JavaScript modules and serves them from a development server, and its build API returns the bundle for use in a build step.

It is added to an existing project from npm, with the packages metro and metro-core, and it runs on the developer's machine.

## Worth knowing

Metro is included with React Native, and its README points new projects to the React Native documentation. Its output is a JavaScript bundle for React Native apps.
