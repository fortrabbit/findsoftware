Bootswatch is a set of free themes for Bootstrap, each one a replacement CSS file with SCSS variables for customization. A project downloads a theme file, uses it in place of Bootstrap's default stylesheet and adjusts the variables to change it. The community maintains the project on GitHub, in a repository owned by Thomas Park.

## Worth knowing

The themes are built for the latest version of Bootstrap.
