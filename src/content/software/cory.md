Cory is a static site generator for Node.js. It combines Handlebars templates with Markdown files and runs from the command line after a global npm install. Settings such as the port, the output directory and the default layout go in a `config.json` file in the project.

## Worth knowing

The repository is archived, and the README declares the project deprecated and points to Next.js.
