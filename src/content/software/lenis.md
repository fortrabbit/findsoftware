Lenis is a JavaScript library that smooths scrolling on web pages. It wraps the browser's native scroll, so position sticky, anchor links and accessibility keep working. One loop can drive WebGL scroll scenes, GSAP ScrollTrigger and parallax effects. It can be started with a line of code from a package manager, or from a script tag with no build step.

Framework packages exist for React, Vue and Framer, and a snap package aligns sections. The maintainer, darkroom.engineering, describes the library as free and open source and accepts sponsorship.

## Worth knowing

The README lists its limits: no CSS scroll-snap without the snap package, frame rate caps on some Safari builds and in low power mode, and no smooth scrolling over iframes.
