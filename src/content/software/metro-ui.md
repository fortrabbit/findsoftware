Metro UI brings CSS styles, JavaScript modules and more than 150 web components to responsive web apps, with a built-in module for translating an app into other languages. The quick-start page opens the page in a browser, so the library runs in the visitor's browser. The project is MIT-licensed and maintained by Serhii Pimenov, who also sells paid support for it.

## Worth knowing

The README says long-term support for older versions does not currently exist, and that a project needs to upgrade to receive new features. Earlier lines of the framework live in separate repositories named in the README, and they are not part of this record.
