Patron is a Go framework for creating microservices. The repository is a fork of mantzas/patron, which the README says was originally created by Sotiris Mantzaris, and the fork is maintained by Beat Engineering.

The docs name a Go module path for each package, such as the HTTP component, and show how to import it. The docs also describe a client package for MongoDB.
