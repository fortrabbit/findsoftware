Modulo is a framework for creating HTML web components: reusable snippets of HTML, CSS and JavaScript that become new HTML-like tags. It runs entirely in the browser, so a single script file loaded from a CDN adds it to an HTML page and no terminal use is needed. The [README](https://github.com/modulojs/modulo) also describes starting a project from the terminal with `npm init modulo`.

## Worth knowing

The README gives the project status as alpha and describes it as still a work in progress. The README, the LICENSE file and the npm package name different LGPL versions.
