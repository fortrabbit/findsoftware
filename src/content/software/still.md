still is an Elixir static site generator installed as a Hex package and started with mix. A new site is created with the still_new archive, and an existing Mix project adds the still dependency and sets its input and output folders in the config. The first page is an index.slime file in the input folder.

## Worth knowing

The repository is archived on GitHub. The project's own site still links to it as its source.
