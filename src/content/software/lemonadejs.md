LemonadeJS is a reactive JavaScript library for building components with a React-like API. Its getting-started guide loads it from a script tag or installs it from npm, and its example runs when the page is opened in a browser. The footer of the website names Jspreadsheet Team as the copyright holder.

## Worth knowing

The guide documents the next major line, which npm publishes only as a beta. The stable line is one major earlier.
