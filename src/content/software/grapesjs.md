GrapesJS is a web builder framework that adds a visual editor for HTML templates to an application. Its README says it was designed to be used inside a CMS, where the template structure is edited visually. The editor interface is English by default, with other languages imported separately. The package is installed with npm, and its plugins are listed in the GitHub topic for GrapesJS plugins. The LICENSE names Artur Arseniev, and the repository holds more than one package.

## Worth knowing

The project's pages also present Grapes Studio, a hosted editor, and the Studio SDK, an embeddable visual builder. They are products separate from the open source library, which is the record here.
