Fae is a CMS engine for Ruby on Rails that generates models, controllers and views into the host Rails application. The [documentation](https://www.faecms.com/documentation) installs it by adding the fae-rails gem to the Gemfile and running a Rails generator.

Visiting /admin sets up the first super admin account, and the quickstart adds the scaffolded objects to the application's database. The [homepage](https://www.faecms.com) lists content in several languages and three built-in user levels. It says the Devise gem handles authentication.
