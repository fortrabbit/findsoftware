Concise CSS is a CSS framework written in Sass and processed with PostCSS. It is installed from the npm package or loaded from a CDN, and its repository holds a command-line compiler that turns the Sass source into a style sheet. The core covers native HTML elements, with a UI kit and utility classes offered as add-ons. The documentation presents it as an alternative to Bootstrap and Foundation.

## Worth knowing

The project is discontinued: the [repository README](https://github.com/ConciseCSS/concise.css/blob/dev/README.md) carries a notice that it is not actively maintained.
