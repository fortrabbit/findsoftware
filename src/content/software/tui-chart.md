TOAST UI Chart is a JavaScript library that draws statistical charts, including bar, line, pie and heatmap charts, in a web page. The getting-started guide offers npm, a CDN and a source download, and the README lists plain JavaScript, React and Vue packages. The maintainers have deprecated it: the [repository](https://github.com/nhn/tui.chart) notice says it is no longer maintained, and the npm package carries a deprecation notice too.

## Worth knowing

The README states that no new features or bug fixes will be released.
