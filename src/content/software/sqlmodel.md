SQLModel is a Python library for interacting with SQL databases from Python code, using Python objects. It is based on Python type annotations and builds on Pydantic and SQLAlchemy. The README says it is designed to be compatible with FastAPI and was created by the same author as FastAPI.

The [install guide](https://sqlmodel.tiangolo.com/install/) covers adding it to a project.
