Baker is a static website generator for C# and .NET projects. It builds a site from Markdown content and Razor views, and the `Baker.exe --bake` command builds a project folder into static files. The README describes a built-in web server for testing the output, which runs on the developer's machine.

## Worth knowing

The website the README names did not resolve when checked, so no homepage is linked here. The newest commit on the default branch is dated 2015, and the repository has no release or tag. The README's download link for the binary archive answered with an access error on the same day.
