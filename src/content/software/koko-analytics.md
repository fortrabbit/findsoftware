Koko Analytics is a WordPress plugin that adds website statistics to a WordPress site. It is installed from the WordPress plugin directory and activated like any other plugin, and the plugin outputs its tracking script into the site. The company behind it, ibericode BV, is based in Nijmegen in the Netherlands.

Cookies are optional. The plugin can run without them, and the project documents a cookieless tracking method next to the cookie method. It has built-in importers for Jetpack Stats, Plausible Analytics and five WordPress statistics plugins, and the documentation describes an integration with the Complianz consent plugin. Statistics appear on a dashboard inside WordPress admin.

## Worth knowing

Koko Analytics Pro is a separate paid add-on for the free plugin, not part of it. Its listed features are email reports, geolocation, device and event tracking, and UTM tracking.
