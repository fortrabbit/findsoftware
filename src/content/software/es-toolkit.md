es-toolkit is a JavaScript utility library, installed from npm for Node.js and Bun, through JSR for Deno, or by importing it from a CDN in the browser. Its functions cover arrays, objects, promises and type guards. Viva Republica, Inc. maintains it.

The package includes a compatibility layer at `es-toolkit/compat` that the project describes as a replacement for Lodash.
