Trieve is an open-source API platform written in Rust that combines search, recommendations and retrieval-augmented generation over chunks of uploaded content. Its README names self-hosting guides for AWS, GCP, Kubernetes and docker compose. The README's Local Development section sets up its services with cargo, yarn and docker compose, and it links a hosted sign-up that includes a free allowance of chunks.
