Subrion is a content management system written in PHP, with MySQL as its database. Its homepage describes it as a CMS and framework, and it includes an admin dashboard and multilingual content support.

It is installed by uploading the files to a server and running the setup in a browser, or through the Softaculous or Installatron auto-installers. The [download page](https://subrion.org/download/) lists the server requirements.
