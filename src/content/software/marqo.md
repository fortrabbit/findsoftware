Marqo was an open-source ecommerce search engine written in Python, kept in the marqo-ai GitHub organization. Its README says the open-source project is deprecated and no longer receives updates. The company, S2Search Australia Pty Ltd according to its privacy policy, offers a hosted product search and discovery platform at [marqo.ai](https://www.marqo.ai).

## Worth knowing

The repository is still public, and the record lists it as discontinued for that reason. The README names no self-hosted install route, and the [documentation](https://docs.marqo.ai) describes the hosted platform.
