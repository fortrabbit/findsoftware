Karate is a test automation framework that covers API tests, mocks, performance tests and UI automation in one tool. Its tests run through JUnit, the Karate command-line tool or a CI/CD pipeline. The command-line tool brings its own Java runtime, so a machine without Java can run tests.

## Worth knowing

Karate Enterprise is a commercial edition of the framework, under a commercial license. It adds an async protocol pack, Enterprise IDE licenses and Karate Agent.
