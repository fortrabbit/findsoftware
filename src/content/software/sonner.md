Sonner is a React component that shows toast notifications. A Toaster element is rendered once in the app, and toast() calls from anywhere in the app display their messages in it. The getting-started page says Toaster can be placed anywhere, even in server components such as layout.tsx. The full API reference is in the [documentation](https://sonner.emilkowal.ski/getting-started).
