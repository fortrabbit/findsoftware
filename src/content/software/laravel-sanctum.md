Laravel Sanctum authenticates single page applications, mobile applications and token-based APIs. According to the [Laravel documentation](https://laravel.com/framework/docs/sanctum) it issues API tokens without the complication of OAuth, stores them in a single database table, and can attach abilities to each token. For single page applications it issues no tokens and uses Laravel's built-in cookie-based session authentication services instead.
