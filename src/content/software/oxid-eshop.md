OXID eShop Community Edition is the source code of the OXID eShop shop system, a PHP e-commerce platform from OXID eSales AG in Freiburg. The [developer documentation](https://docs.oxid-esales.com/developer/en/latest/getting_started/installation/eshop_installation.html) describes Composer downloading the source files of the chosen edition, after which the shop is set up in a browser wizard or with a command-line tool. The vendor describes the framework as built on Symfony components.

The shop runs as PHP on an Apache web server and keeps its data in MySQL or MariaDB, as the [system requirements](https://docs.oxid-esales.com/eshop/en/7.5/installation/new-installation/server-and-system-requirements.html) list.

## Worth knowing

The Community Edition license is proprietary. It limits use to non-commercial purposes and one tenant, and the period of use is six months from the first download unless extended. The [pricing page](https://www.oxid-esales.com/en/pricing) also lists paid Professional and Enterprise editions.
