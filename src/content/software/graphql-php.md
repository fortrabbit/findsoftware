graphql-php is a PHP implementation of the GraphQL specification. It is a library, not an application: a PHP project installs it with Composer and uses it to define types and to validate and execute GraphQL queries against its own data layer. The README says it follows the JavaScript reference implementation, and the documentation lists integrations with several PHP frameworks as separate packages.

The package is published on Packagist as webonyx/graphql-php, and its repository is in the webonyx organization on GitHub.
