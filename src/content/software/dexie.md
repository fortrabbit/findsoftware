Dexie.js is a wrapper library for IndexedDB, the standard database in the browser. It is written in TypeScript and can be loaded from unpkg as a download, as its [README](https://github.com/dexie/Dexie.js/blob/master/README.md) describes. David Fahlander created it, and Awarica AB manages it.

## Worth knowing

Dexie Cloud is a separate hosted service that adds sync, authentication and real-time collaboration to Dexie.js. Its [pricing page](https://dexie.org/pricing) lists the hosted plans.
