CyberPanel is a web hosting control panel for a Linux server. Its web interface covers websites, email, DNS, FTP and databases, and the README names OpenLiteSpeed as the web server it is powered by. The installer is a shell script that sets the panel up on a Linux server, and the codebase is Python on Django. CyberPersons LLC publishes it, and the source is on GitHub.

## Worth knowing

The open-source edition runs OpenLiteSpeed. A paid CyberPanel Enterprise edition runs LiteSpeed Enterprise under a license, and the company also sells a cloud server with the panel preinstalled.
