shadcn/ui is a set of React components that a CLI copies into a project's source tree, where the project holds the code and can change it. The project is maintained by an individual who publishes as shadcn.

## Worth knowing

The components carry no version of their own: only the CLI is versioned, and a project's copy of a component is the code it holds.
