GlowCookies is a JavaScript cookie consent banner for a website. The site adds a script tag that loads the banner from jsDelivr and starts it with a call that sets the language, the banner style and the tracking codes for Google Analytics, Facebook Pixel and Hotjar. According to the README, each tracking code starts only when the visitor accepts cookies.

The project's source is on GitHub, and the README examples load the script from jsDelivr.
