Waterline is a storage and retrieval layer for Node.js code. Code reads and writes data through one query API, and adapters translate those calls into queries for each store. The README names MySQL, MongoDB and Postgres among the stores it reaches, and says adapters exist for both core and community-maintained stores.

Waterline is the default ORM of the Sails framework, and the README also points to documentation for using it standalone. Its documentation is kept on the [Sails website](https://sailsjs.com/documentation/reference/waterline-orm).
