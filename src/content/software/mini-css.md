mini.css is a CSS framework written in Sass, with most of its components built on Flexbox. Its look comes from flavors, which the project distributes as prebuilt and custom style stylesheets. The package can be installed from npm or loaded from a CDN.

## Worth knowing

The GitHub repository is archived, and the record is listed as discontinued for that reason.
