Don is a Go API framework that parses request data from paths, queries, headers and bodies and renders responses in the format the client asks for through the Content-Type and Accept headers. JSON, XML, YAML, form and text encodings are each enabled by importing a package. The README credits fasthttp and a custom version of httprouter for its performance.

## Worth knowing

While the project is on major version 0, its README treats minor version updates as breaking changes.
