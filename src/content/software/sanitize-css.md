sanitize.css is a CSS library that restyles HTML elements with consistent defaults across browsers. Its main stylesheet is linked or installed with npm, and the README describes separate stylesheets for forms, assets, typography, reduced motion, system-ui and ui-monospace support, each used on its own or alongside the main file. It wraps its styles in zero-specificity `:where()` selectors and documents each rule as either a normalization or an opinion. The library is built upon normalize.css, and the README says the two are maintained in sync.
