Lightbox3 is a JavaScript library that overlays images on the current page as a lightbox, with galleries, captions and touch gestures. It has zero dependencies.

## Worth knowing

Lightbox3 is the next version of Lightbox2, which is in maintenance mode and required jQuery. The Lightbox3 page has an upgrade section for Lightbox2 markup.
