Spikard is a codegen-first polyglot web toolkit with a Rust core and language bindings generated from it. The core is a crate, and the other bindings and a command-line tool each ship through their own package manager. Its crate description on crates.io says it is built on Axum and Tower-HTTP. The [runtime documentation](https://spikard.dev/concepts/runtime/) says the runtime binds to a socket and serves requests.

## Worth knowing

The project describes itself as experimental and pre-1.0.
