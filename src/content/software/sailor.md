Sailor is a Lua web framework with an MVC structure, installed with LuaRocks and run by a Lua-capable web server such as Apache with mod_lua or Nginx. Its views are Lua Pages, files with the `.lp` extension, and it works with MySQL, PostgreSQL and SQLite through the luasql library. The copyright line in its license file names Etiene Dalcol.

## Worth knowing

The project's own website no longer serves Sailor: the address now shows an unrelated site, so the documentation is only the `docs` folder in the repository. The repository's only tagged releases are prereleases from 2014 and 2015, and the README asks for new maintainers.
