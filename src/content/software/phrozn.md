Phrozn is a static site generator written in PHP. The README's installation steps are to clone the repository and install its dependencies with Composer.

## Worth knowing

The repository is archived on GitHub and the Packagist package is marked abandoned. The project's own domain, phrozn.info, shows unrelated content, so the record has no homepage.
