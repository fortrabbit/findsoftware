Ant Design Vue is a component library for Vue, based on Ant Design and Vue, which its own pages describe as an enterprise-class set of UI components. The package is installed from npm as ant-design-vue, and the source is hosted in the vueComponent organization on GitHub. The docs source describes a ConfigProvider component that takes a locale package setting.

## Worth knowing

The README says the library supports Vue 2 and Vue 3, but the current npm release declares a peer dependency on Vue 3 or later, so the two statements do not agree.
