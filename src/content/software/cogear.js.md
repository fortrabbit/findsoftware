Cogear.JS is a static site generator built with Node.js and based on webpack. It is installed as the global cogear command from the npm package of the same name. The project says its output is static HTML and assets, so any host that serves files can serve a Cogear.JS site.

## Worth knowing

The README opens with the project's own deprecation notice, and the repository is archived on GitHub.
