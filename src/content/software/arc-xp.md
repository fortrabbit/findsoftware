Arc XP is a hosted content platform for publishers and broadcasters. Its Composer editor combines text, video, audio, images, embeds and structured metadata in one integrated editor, and the platform supports headless delivery through REST APIs. The front end is built with PageBuilder Engine, which translates content from intl.json files.

Sites can be managed centrally across several sites, brands and regions with shared content and governance controls.

## Worth knowing

Arc XP is a hosted platform with no installable server part documented. The FAQ describes pricing as modular and based on usage, scale and selected capabilities.
