Playwright drives the Chromium, Firefox and WebKit browser engines through one API from scripts, and ships a test runner for end-to-end tests of web applications. Besides TypeScript and JavaScript, the homepage lists Python, .NET and Java as supported languages. Microsoft maintains the project, and the [introduction](https://playwright.dev/docs/intro) is the starting point in the documentation.
