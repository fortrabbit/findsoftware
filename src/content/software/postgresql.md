PostgreSQL is an object-relational database system that uses and extends the SQL language. Its origins go back to the POSTGRES research project at the University of California at Berkeley, which began in 1986, and it is developed by The PostgreSQL Global Development Group. The server is written in C and should be started as a background process, perhaps at boot time. Packages and installers are available for several platforms, and a source code archive can be built by hand.

## Worth knowing

The database is released under the PostgreSQL License, an open source license similar to the BSD and MIT licenses. The GitHub repository is a mirror of the project's own Git repository, and contributions are not taken through GitHub. The project's mailing lists are its community channel.
