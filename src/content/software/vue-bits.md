Vue Bits is a collection of animated, interactive Vue components that its maintainer describes as an open-source collection of expressive UI components. Each component is a single `.vue` file written in TypeScript and styled with Tailwind. A component is installed either by copying its source into the project or by pulling it in with a CLI: the shadcn and jsrepo CLIs both fetch the same source from the project's own registry. The README calls it the official Vue port of React Bits.

## Worth knowing

The license is MIT with the Commons Clause. Components may be used in an application, website or product, including for commercial purposes, but not sold, sublicensed or redistributed as components. The repository has no tagged release, so its newest commit date stands in for its currency.
