Tagify is a JavaScript component that turns an input field or a textarea into a tags input, with optional suggestions and validation. The README has React and Vue wrapper sections, and the component also works in plain JavaScript. The jQuery wrapper is marked deprecated.

## Worth knowing

The README supports modern evergreen browsers only and says Internet Explorer is not supported. The React wrapper is raw ES module source, and the README says Tagify is not a controlled component.
