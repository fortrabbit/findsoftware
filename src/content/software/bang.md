Bang is a text processor and static website generator. It fills keyword placeholders in text files with values from a Bang markup file, and it writes the processed files out as static HTML pages. The README says it comprises a minimal markup language and a short Python script, and it requires Python 3 and bash. The `run.sh` script processes the example files and opens them in a web browser, which is the first run the README documents.

The repository was published earlier under the squdle name and now redirects to its current owner. Its versions are marked by tags, not GitHub releases.

## Worth knowing

The README's preview link leads to a generated sample page, not a project website, so no homepage is linked here.
