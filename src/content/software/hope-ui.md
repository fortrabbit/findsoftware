Hope UI is a component library for SolidJS, published on npm as @hope-ui/solid and developed in a GitHub repository under the hope-ui organization. Its README says the library was inspired by Chakra UI and Mantine.

## Worth knowing

The project is no longer maintained. Its README says so and names a new project in the same organization as its replacement, which this record does not describe. The repository is archived, and the npm package carries a notice that it is no longer supported.
