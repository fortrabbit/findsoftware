Material Components for the web is a library that a core team at Google built to help developers apply Material Design in web projects. Its components are published on npm as Sass and JavaScript packages. The install guide names an all-in-one npm package and offers a CDN route that loads precompiled CSS and JavaScript bundles from unpkg. The guide says the precompiled JavaScript is consumable directly by browsers.

The README calls the project the successor to Material Design Lite.

## Worth knowing

The README says the project is no longer actively maintained, and the GitHub repository is archived. The README names no replacement.
