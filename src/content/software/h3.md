h3 is an HTTP server framework for JavaScript runtimes, written in TypeScript and built on the Request, Response, URL and Headers primitives of the web platform. An application is an H3 instance with routes, and the serve function starts a server listener, while the app's fetch method lets the same application run in any web-compatible runtime. It runs on Node.js, Deno, Bun and Cloudflare Workers, and the [guide](https://h3.dev/guide) shows the setup.
