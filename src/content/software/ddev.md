DDEV is a command-line tool that sets up Docker-based environments for developing PHP and Node.js projects on a developer's machine.

## Worth knowing

DDEV needs a Docker provider on the machine before DDEV itself is installed, as the [installation guide](https://docs.ddev.com/en/stable/users/install/ddev-installation/) states.
