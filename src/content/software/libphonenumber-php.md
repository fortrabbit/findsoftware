libphonenumber for PHP parses, formats, stores and validates international phone numbers. It is a PHP port of Google's libphonenumber and uses phone number metadata from Google's project.

## Worth knowing

The library tries to follow Google's version numbers rather than semantic versioning, so a jump in the major number may carry no backward-incompatible change. It requires the PECL mbstring extension.
