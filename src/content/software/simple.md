Simple turns posts written in a browser editor into static pages in a GitHub Pages repository. The README describes the flow: the user signs in with a GitHub account, sets up a repository named username.github.io, and writes posts that the save step turns into static pages.

The templates sit in the project's template folder. A user who wants a custom theme clones the project, edits the templates and pushes the src folder to a gh-pages branch.
