Simple Icons is an icon set of SVG logos for popular brands, published as an npm package and a Composer package. The icons can be installed from npm or Composer, or downloaded as SVG files. Simple Icons Collaborators maintain the set.

## Worth knowing

The README asks users to read a legal disclaimer before using the icons, and the disclaimer covers the brand trademarks.
