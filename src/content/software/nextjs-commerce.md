Next.js Commerce is a server-rendered storefront template built with the Next.js App Router and React Server Components. The repository ships a Shopify provider, and the README says other providers can fork it and replace the lib/shopify module. The README lists forks for other commerce backends, which are separate repositories. Locally, the template runs with pnpm install and pnpm dev, using the variables from .env.example.

## Worth knowing

The repository is archived, and its README says the template is deprecated and that development has moved to vercel/shop, a Shopify storefront built with Next.js. The homepage listed for the template now describes that other project, so no homepage is recorded.
