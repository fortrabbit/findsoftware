ProComponents is a React library of page-level components built on Ant Design, for the tables, forms, layouts and cards of admin-style applications. Its [components overview](https://pro-components.antdigital.dev/en-US/components) says it was developed to reduce the cost of building CRUD screens in the middle and back end, and the homepage describes the set as built on top of Ant Design with extra encapsulations for better usability.

The package is installed from npm as @ant-design/pro-components. The homepage also states full i18n support integrated with Ant Design.

## Worth knowing

The homepage says version 3 is released and links a migration guide, but the npm latest tag and the stable GitHub releases are on the 2.x line. Version 3 appears on npm only under the beta tag, with no stable release on GitHub.
