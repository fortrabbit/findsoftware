PaperCSS is a CSS framework that styles plain HTML elements, so a page needs few added classes: the project's stated goal is that a button looks like a paper button without a paper-button class. The stylesheet is installed with npm or yarn, downloaded, or linked from unpkg's CDN. Its documentation site is built with Hugo, and the about page says the original creator and two other maintainers keep the project.

## Worth knowing

The newest release is older than the most recent commit on the default branch, so a reader who needs changes made after the last release should look at the repository's history.
