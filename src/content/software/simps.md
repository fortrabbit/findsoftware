Simps is a PHP framework built on coroutines and the Swoole extension. Its README lists HTTP, WebSocket, TCP, UDP and MQTT servers among its supported features.

## Worth knowing

Simps needs the Swoole PHP extension, which the [install guide](https://github.com/simple-swoole/docs/blob/master/docs/en/install.md) lists among its requirements.
