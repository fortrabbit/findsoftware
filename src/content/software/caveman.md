Caveman2 is a web application framework for Common Lisp, built on ningle and Clack. Djula is its default templating engine, and because it is based on Clack the same application can run on several web servers without code changes. Its source is public on GitHub.

## Worth knowing

The license is LLGPL, stated in the system definition file because the repository has no LICENSE file. The repository's only tags belong to an earlier line of the project, so the record is held as a stub until a Caveman2 release or a statement from the project settles its listing.
