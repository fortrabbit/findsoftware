ServBay is a desktop application for macOS and Windows that sets up local web development services on the developer's own machine. Its install includes language runtimes and databases such as MySQL, MariaDB and PostgreSQL, and its homepage describes an MCP server for AI agents. The source code is not published: the GitHub repository holds the README, translated READMEs and images. The README describes installation as running the downloaded installer.

## Worth knowing

The terms of service grant a limited license to use the services for personal and non-commercial purposes. The free edition is offered next to paid Pro and Team plans, and the homepage says the paid plans add team-scale features.
