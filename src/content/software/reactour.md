Reactour highlights parts of a React application with a mask and a popover, and walks a visitor through them from an array of steps. Its documentation says the project began in 2017 as an attempt to simplify the logic of intro.js with React components. The main package, @reactour/tour, brings the mask and popover together. A TourProvider at the application root holds the steps, and a hook controls when the tour opens. The [documentation](https://docs.reactour.dev) describes each package.

## Worth knowing

The npm package named reactour is the earlier line, which the documentation says is now on a v1 branch. The current package is @reactour/tour.
