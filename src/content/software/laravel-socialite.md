Laravel Socialite is a Laravel wrapper around OAuth 1 and OAuth 2 libraries that signs users in through OAuth 1.0 and OAuth 2.0 providers. It is a client of those providers and not an SSO server. The docs list the providers it currently supports as Facebook, X, LinkedIn, Google, GitHub, GitLab, Bitbucket and Slack.

## Worth knowing

The README says the project is not accepting new adapters. Adapters for other platforms are listed on the [Socialite Providers](https://socialiteproviders.com/) site, which the community runs.
