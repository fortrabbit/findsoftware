Web Awesome is a library of framework-agnostic web components, built with Lit and installed through a CDN script or the @awesome.me/webawesome npm package, which can also be downloaded and self-hosted. The [installation guide](https://webawesome.com/docs/) describes these routes.

Web Awesome is the successor of Shoelace, and its [migration guide](https://webawesome.com/docs/resources/migrating-from-shoelace) covers the move from Shoelace.

## Worth knowing

The core library is MIT licensed. Web Awesome Pro is a paid edition that adds premium components and themes, among other features, under its own license; plans and prices are on the [purchase page](https://webawesome.com/purchase).
