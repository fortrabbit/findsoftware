AG Grid is a JavaScript data grid library for displaying and editing tabular data. It comes in two packages: ag-grid-community, which is MIT licensed, and ag-grid-enterprise, which is available under a commercial license and comes with advanced features. Both are installed from npm or loaded from a CDN. The repository also holds the binding packages for React, Angular and Vue, and AG Grid Ltd publishes the project.

## Worth knowing

The project's homepage says an AG Grid licence is required to use AG Grid Enterprise in production. The [pricing page](https://www.ag-grid.com/license-pricing/) lists the licence options.
