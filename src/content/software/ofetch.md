ofetch is a JavaScript library that the README describes as a better fetch API. It is written in TypeScript and installed with npm, and the README says it works on Node.js, in browsers and in workers.

## Worth knowing

The README's documentation describes an alpha development line on the default branch, and it links the stable line's own branch for the stable documentation.
