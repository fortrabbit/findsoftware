Apache APISIX is an API gateway that the Apache Software Foundation publishes as a top-level project. Its architecture page says it is built on NGINX and ngx_lua, with LuaJIT for request-time logic, and etcd is the configuration store in the modes that use one. The installation guide covers Docker Compose, a Helm chart, RPM and DEB packages, and source builds. The official Docker image is apache/apisix, and the project lists more than 100 open-source plugins.
