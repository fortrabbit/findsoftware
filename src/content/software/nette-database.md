Nette Database is a database layer for PHP that wraps PDO. Its SQL way keeps full control over the queries an application writes, and its Explorer layer fetches table rows and their relations. The package is one of the standalone components of the Nette family, and the [documentation](https://doc.nette.org/en/database) describes both layers.

## Worth knowing

The Explorer layer does not cover every server the core layer supports, according to the core documentation. The license text calls "Nette Framework" a protected trademark and asks users not to put "Nette" in a project name or top-level domain.
