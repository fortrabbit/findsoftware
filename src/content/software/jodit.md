Jodit is a TypeScript WYSIWYG editor that turns a textarea into a rich-text field. A page calls `Jodit.make` with a selector, and the editor's content is then read and set through the `value` property. The project includes a built-in file browser and image editor, and it ships through npm, GitHub releases and a zip archive from the Jodit Builder service.

## Worth knowing

A separate commercial PRO version adds premium plugins that the open-source package does not include. The README says testing the file browser and uploader needs a separate PHP connector.
