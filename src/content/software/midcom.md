MidCOM is a component framework and content management system for PHP. It runs on top of the Midgard framework.

The repository that publishes the `openpsa/midcom` package also holds OpenPSA, which the [OpenPSA site](http://openpsa2.org/) describes as an open source web application for web agencies and consultants.

## Worth knowing

The [MidCOM page](http://midgard-project.org/midcom/) describes installation with PEAR packages, while the repository README describes Composer.
