Tailgrids is a React component library built with Tailwind CSS. Its CLI copies the components into a React project, so they become files the project owns and can change. The project also publishes an icon set. Tailgrids UI, an organization, maintains it.

## Worth knowing

The free edition is MIT licensed. Pro blocks, templates and a Figma kit are sold as paid tiers on the [pricing page](https://tailgrids.com/pricing), beside the free edition. The npm package named tailgrids is deprecated in favor of @tailgrids/cli.
