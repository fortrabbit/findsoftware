WebSharper is a web programming platform that compiles F# and C# code to JavaScript, so the server and the browser parts of an application can both be written in .NET languages. Its client-server template includes both server-side and client-side code, and its ASP.NET Core integration adds WebSharper's middleware to the application pipeline. A separate template generates static HTML sites. IntelliFactory develops it, and the project is released under the Apache 2.0 license.
