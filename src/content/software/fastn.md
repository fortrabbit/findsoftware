fastn is a programming language and a web framework for building user interfaces and content-centric websites. A fastn site can be compiled into static HTML, CSS and JavaScript, or served with `fastn serve`, where processors execute on the server side. The `fastn build` command writes the compiled output to a `.build` folder.

FifthTry, the company named in the README and in the license header, also offers its own hosting for static and dynamic fastn sites.

## Worth knowing

The repository description calls fastn alpha stage software.
