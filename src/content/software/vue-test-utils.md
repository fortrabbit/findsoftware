Vue Test Utils is the testing utility library for Vue.js components. It provides methods that mount a component on its own and interact with it from a test, and it works with any test runner. The [guide](https://test-utils.vuejs.org/guide/) names Vitest as the recommended runner, shows Jest as an option through vue-jest, and lists Cypress, Playwright and WebdriverIO as browser-based runners. Cypress Component Testing and Testing Library both use Vue Test Utils under the hood and expose the same API.

## Worth knowing

The library's current line targets Vue 3. The first line targets Vue 2, and the migration guide covers the change between them.
