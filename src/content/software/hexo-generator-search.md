hexo-generator-search is a plugin for Hexo that writes a search index file during the Hexo build. The index is written into the generated output as XML or JSON, and a search script on the page reads it in the visitor's browser. The [README](https://github.com/wzpan/hexo-generator-search/blob/master/README.md) is the project's documentation.

The plugin is installed with npm.

## Worth knowing

The README names Hexo 3.x and 4.x as the supported versions. The repository has no GitHub releases or tags, and the npm package is the release record used here.
