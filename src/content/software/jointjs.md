JointJS is a JavaScript and TypeScript library for building diagramming applications from SVG elements and links. It is framework-agnostic and has a React binding beside the core library, and it can be installed from a package manager or loaded from a script tag without a build step. The code lives in a monorepo maintained by client IO s.r.o., a Prague company that is part of client.IO.

## Worth knowing

The open-source library covers core diagramming. A commercial extension, JointJS+, adds plugins on top of it.
