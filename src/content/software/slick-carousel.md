Slick is a carousel that runs as a jQuery plugin. The README lists its settings in a table and documents breakpoint-based responsive settings, with a right-to-left option among them. The [repository](https://github.com/kenwheeler/slick) holds the README.

## Worth knowing

Slick needs jQuery on the page. The README names jQuery as its dependency, and the npm package declares it as a peer dependency.
