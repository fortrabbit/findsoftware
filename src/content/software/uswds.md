U.S. Web Design System is a library of user interface components, a CSS stylesheet and JavaScript, built from Sass source, for U.S. federal government websites. A project installs the `@uswds/uswds` npm package or downloads the release archive, then either links the precompiled files or compiles its own stylesheet from the Sass source. The component templates in the source are written in Twig.

## Worth knowing

The project is in the public domain, but some icons, fonts and normalize files in it keep their own open source licenses, which travel with copies of those parts. Customizing the JavaScript needs Node.js and a module bundler.
