HUGE is a PHP skeleton that combines a user login, registration and account system with a small MVC structure. It is installed by cloning the repository to a server and running Composer, with the web server routing all requests to the project's public folder and MySQL as the database.

## Worth knowing

The README states that HUGE has reached "soft End Of Life": it gets no new features, and bugfixes continue.
