Effector is a state manager for JavaScript and TypeScript apps, developed in a monorepo under the effector organization on GitHub. The core package is framework agnostic: the project publishes separate packages that bind it to React, Vue and Solid, and a package for Next.js. Node.js and Deno are both named among the environments it runs in. Apps install the core with npm, and the project also documents importing its build from a CDN. A migration guide covers moving from Redux.
