ViewComponent is a Ruby framework for building reusable, encapsulated view components in Ruby on Rails. A component is a Ruby class that wraps a template, and the [getting-started guide](https://github.com/ViewComponent/view_component/blob/main/docs/guide/getting-started.md) installs the gem with a `Gemfile` entry. The project tests it against ERB, Haml and Slim templates, and translations use a sidecar YAML file.

The ViewComponent Team maintains the gem, and the repository belongs to the ViewComponent organization on GitHub.

## Worth knowing

The homepage says version 4 is in Long-Term Support and considered feature-complete.
