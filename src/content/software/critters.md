Critters is an npm package that inlines an app's critical CSS and lazy-loads the rest of its stylesheets. It is installed as a development dependency. It does not render pages in a headless browser, and the repository also holds a webpack plugin, critters-webpack-plugin, as a separate package.

## Worth knowing

The project has ended. The repository is archived, the README says it "won't receive any future updates", and npm marks the latest version as deprecated. The README points anyone who wants to keep using Critters to the [Beasties fork](https://github.com/danielroe/beasties).
