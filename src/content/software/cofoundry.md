Cofoundry is an open source content management system and application framework for ASP.NET Core, built code first. Page templates are ASP.NET Razor views, and content is stored in a SQL Server database.

It is added to an ASP.NET Core project as the Cofoundry.Web.Admin NuGet package, or created from a dotnet new template. Plugins install from NuGet and add features such as image resizing, background tasks and mail.

## Worth knowing

The README describes the 0.x releases as early development in which breaking changes can happen at any point.
