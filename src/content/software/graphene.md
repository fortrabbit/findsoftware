Graphene is a Python library for building GraphQL APIs. Its homepage describes it as a library for building GraphQL APIs in Python, and its docs quickstart takes a code-first approach: the schema is written as Python code instead of GraphQL schema language. A project installs it with pip.

Syrus Akbary maintains Graphene under the MIT license. Its integrations with Django, SQLAlchemy and Google App Engine are separate projects.
