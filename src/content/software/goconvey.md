GoConvey is a testing tool for Go that works with go test. Its homepage describes writing behavioral tests in the editor, and the tool can be used in the terminal or in a browser view of the results.

## Worth knowing

The README says the maintainers may consider enhancement requests and may or may not act on them. The license file says optional and subordinate components carry their own licenses, and the README names none of them.
