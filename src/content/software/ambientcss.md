AmbientCSS is a pure CSS lighting framework. The [README](https://github.com/kikkupico/ambientcss/blob/master/README.md) describes defining a light source on a parent element, after which shadows, highlights and surface gradients follow from it. It is set up with light-direction classes and CSS custom properties, and the package has zero dependencies. The documentation calls it a small design system in two packages: @ambientcss/css, with the lighting primitives and utility classes, and @ambientcss/components, a set of React controls built on them. This record is the CSS package.

## Worth knowing

The project has no GitHub release or tag, and its versions are published to npm only.
