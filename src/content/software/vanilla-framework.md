Vanilla Framework is an extensible CSS framework written in Sass by the Canonical Web Team. A project can link the compiled stylesheet from a CDN, download the latest release from GitHub, or install the package with npm or yarn and compile its own stylesheet from the Sass source. The source can be imported whole or in parts, and its settings can be overridden before the compile. The framework is designed to be used directly or through themes that extend or supplement its patterns.
