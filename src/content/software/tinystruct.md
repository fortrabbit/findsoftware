tinystruct is a Java framework for web and command-line applications, built from one codebase. Its methods are routed by annotation, so the same method can run from the command line through `bin/dispatcher` or answer an HTTP request. The [homepage](https://tinystruct.org/) calls `HttpServer` the built-in default server and names Tomcat, Netty and Undertow as supported alternatives.

## Worth knowing

The getting-started page lists a JDK and Maven as prerequisites, and the one-command installer needs Git for Windows or WSL on Windows.
