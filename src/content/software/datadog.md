Datadog is a hosted monitoring and security platform: hosts, containers and applications send their metrics, events, traces, logs and errors to the Datadog service, and the data is read in the browser. Hosts report through the Datadog Agent, which the agent docs describe as software that runs on hosts and sends events and metrics to Datadog, and applications report through SDKs such as the browser Real User Monitoring SDK. The company behind it is Datadog, Inc.

## Worth knowing

The Datadog Agent is open source, but it sends its data to the hosted service, and the service itself has no self-hosted option. Datadog runs separate sites in several regions. Each site is independent, and data cannot be shared across sites.
