Omeka Classic is a web publishing platform for sharing digital collections and creating media-rich online exhibits. Content is managed in an admin dashboard. The [installation instructions](https://omeka.org/classic/docs/Installation/Installing/) describe uploading the extracted zip to the server and finishing setup in a web installer. The Omeka team documents the plugins it supports, and community plugins are listed in a plugin directory without that documentation.

## Worth knowing

The same project runs Omeka.net, a hosted service. This record covers the self-hosted software only.
