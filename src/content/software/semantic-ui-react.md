Semantic UI React is a set of React components that render Semantic UI markup without bundling its CSS. The [usage guide](https://react.semantic-ui.com/usage/) installs the components with yarn or npm, or loads them from a CDN, and says the themes come from Semantic UI as CSS stylesheets. The guide asks the project to set up React first, following React's own guide.

## Worth knowing

The documentation site shows a beta version as its current release, while the fields record the latest stable release. The README says any Semantic UI CSS theme can be loaded on top of the React components.
