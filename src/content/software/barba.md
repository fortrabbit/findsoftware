Barba.js is a JavaScript library that adds transitions between the pages of a website. Its [user guide](https://barba.js.org/docs/getstarted/intro/) says it makes the site run like a single-page application. The core package, @barba/core, is installed with npm or Yarn and imported into the build, or loaded from a CDN. The repository is a monorepo that also holds the router, prefetch and CSS plugins.

## Worth knowing

The install page says a CDN script with no version named targets the latest release, and it advises bundling a specific tagged version.
