Contao is a content management system built on the Symfony framework. One installation can run several websites, each in several languages, and editors share the administration area under detailed user permissions. The [install guide](https://docs.contao.org/manual/en/installation/install-contao/) sets it up through the Contao Manager's graphical interface or with Composer on the command line, and the [download page](https://contao.org/en/download) also offers it as a bundle for an existing Symfony application.
