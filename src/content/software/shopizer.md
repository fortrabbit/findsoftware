Shopizer is open source e-commerce software written in Java, offered as a headless backend with a REST API. The README lists catalog, shopping cart, checkout, merchant, order, customer and user among its components, and gives a Swagger UI address on the running backend. The backend is built with the Maven wrapper or started from the `shopizerecomm/shopizer` Docker image. The administration tool runs from its own Docker image and needs the backend running.

## Worth knowing

The homepage now describes a separate Shopizer microservices product and calls this repository's headless version a legacy one that is still available for download. This record covers the repository only.
