spatie/image-optimizer is a PHP library that optimizes image files by running them through external optimizer binaries, which are installed separately. The package uses whichever of them are present on the system. It is installed with Composer, and Spatie bvba, a company in Antwerp, Belgium, publishes it.

## Worth knowing

The README warns that SVGO can break an SVG file.
