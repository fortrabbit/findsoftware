SeaQuery is a query builder for Rust that helps construct dynamic SQL queries. It renders them for MySQL, Postgres and SQLite through one API, and the [API documentation](https://docs.rs/sea-query/latest/sea_query/) is published on docs.rs. The README calls SeaQuery the foundation of SeaORM, the ORM from the same organization.

## Worth knowing

The README names MS SQL Server support as available under SeaORM X, a separate closed-beta product.
