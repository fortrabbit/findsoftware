Voluptuous is a Python data validation library, primarily intended for validating data coming into Python as JSON, YAML and similar formats. Its validation messages go through gettext hooks, and it ships no translation catalogs.

## Worth knowing

The README opens with a "CONTRIBUTIONS ONLY" notice: the maintainer no longer uses the library, fixes and new features come only from pull requests, and the library is largely feature stable.
