Marx is a classless CSS framework that styles plain semantic HTML: a page adds one stylesheet and the page styles itself. The stylesheet comes from the npm package marx-css or from a CDN link, and Matthew Blode maintains the project on GitHub.

## Worth knowing

The npm name marx belongs to a different package by another author, so the install command names marx-css.
