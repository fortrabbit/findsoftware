VueUse is a collection of utility functions for Vue, based on the Composition API, published as the @vueuse/core package. The functions are written in TypeScript, and the [guide](https://vueuse.org/guide/) documents them. Add-ons in the same repository extend the collection to Electron, Firebase, Head, Integrations, RxJS and Router. The homepage says the functions work with server-side rendering and generation, and a CDN build runs without a bundler.

## Worth knowing

The README says VueUse no longer supports Vue 2 and points Vue 2 projects to an older release line.
