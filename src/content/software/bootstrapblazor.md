BootstrapBlazor provides Blazor components styled with Bootstrap. The code is written in C#, and the README's install route is the NuGet package, added with dotnet add package.

The README names both WebAssembly and server applications as targets, and says the stylesheet location depends on which one the application runs. The project states that it is part of the .NET Foundation.
