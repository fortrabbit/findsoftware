Marten is a web framework for Crystal. Handlers process web requests and return responses, and templates define the HTML they render. The framework ships with translations and localized content, and it supports MariaDB, MySQL, PostgreSQL and SQLite3 as databases.

A project is installed with Homebrew, the AUR or from the sources, which provides the `marten` CLI. A deployed project is a compiled server binary that runs as a SystemD service.
