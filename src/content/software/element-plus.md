Element Plus is a UI component library for Vue 3, written in TypeScript. It is installed from npm, yarn or pnpm, or loaded from a CDN, and its README names it as the upgrade path from Element UI.

## Worth knowing

Element Plus does not support Internet Explorer. Its install guide says Vue 3 no longer supports IE11, so the library does not support it either.
