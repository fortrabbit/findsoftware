ElasticSuite is a Magento 2 module that adds a merchandising and search engine built on Elasticsearch to a Magento store. It is installed with Composer and needs an Elasticsearch or OpenSearch server alongside Magento. SMILE, a French company, develops it.

## Worth knowing

The project has a premium version. The README marks the recommendations engine as premium, and the documentation marks further features as premium too.

SMILE also licenses its standard software, including ElasticSuite, under a commercial subscription for on-site use. The company's pricing page says its paid tiers support hybrid hosting, and the Enterprise plan names a Private Cloud option.
