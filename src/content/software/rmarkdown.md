R Markdown is an R package that renders documents combining code, its output and prose. The package's homepage lists HTML, PDF, Word, slides, dashboards and websites among its output formats.

## Worth knowing

The README requires Pandoc outside RStudio, and RStudio includes it. The README describes the documents as analysis documents. A Shiny document needs a running Shiny server to be served, which the run function starts.
