go-api-boot is a Go framework for building gRPC and HTTP API services. A bootstrap command, installed with go install, scaffolds a new service, and the service is built into a binary and started as a long-running server. Its data layer is a generic object model for MongoDB. The README also lists Temporal workers, Azure and GCP helpers, zero-configuration HTTPS and MCP tools among the features.
