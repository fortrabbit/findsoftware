ConvertX is a self-hosted file converter with a browser interface. People sign in to an instance, upload files and convert them to other formats, using converter tools that the README lists, among them Inkscape, LibreOffice, Pandoc, ImageMagick and FFmpeg.

The software is written in TypeScript on Bun. The README's install route is a Docker image, started with a compose file or a single docker run command, and the compose example mounts a data folder into the container.
