Magic UI is a collection of animated React components and effects, built with TypeScript, Tailwind CSS and Motion. A project copies components into its own code with the shadcn CLI instead of installing a package. The docs set it up the way shadcn/ui is set up, and a project adds a component by name, such as the globe component.

## Worth knowing

The repository has no release or tag, so the record carries no version. A paid Pro edition sits beside the free components and adds blocks and templates.
