Consent Banner JS is a zero-dependency JavaScript cookie banner for any website. It is consent platform agnostic: its [project page](https://tagconcierge.github.io/consent-banner-js/) describes a banner configured with a JSON object that fires a callback when the visitor interacts with it and provides a consent state object. A site includes a stylesheet and the script from a CDN, or uses the Google Tag Manager template, a WordPress plugin or a PrestaShop plugin that the page lists as integrations. The library is compatible with Google Consent Mode.

Tag Concierge sp. z o.o., a company with an address in Kraków, Poland, maintains it.

## Worth knowing

The package has no npm release under this name. The script is served from the vendor's own host, public-assets.tagconcierge.com, which the project page names.
