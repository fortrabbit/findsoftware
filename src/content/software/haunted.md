Haunted brings React's Hooks API to web components. A component is a function that uses hooks such as state and effects, and the library turns it into a standard custom element. Templates are written for lit-html or hyperHTML. The package installs with npm, and the [getting-started guide](https://hauntedhooks.netlify.app/docs/guides/getting-started/) also shows importing it from a CDN into a page without build tools.
