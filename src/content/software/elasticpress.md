ElasticPress is a WordPress plugin that connects a site to an Elasticsearch server and uses that server to answer the site's search. The plugin is developed by 10up, a company. ElasticPress.io is a hosted option named on the [project site](https://www.elasticpress.io/).

## Worth knowing

The Elasticsearch server is a separate product that the plugin needs and does not include.
