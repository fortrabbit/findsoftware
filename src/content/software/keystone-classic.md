KeystoneJS Classic is the version 4 line of Keystone, a Node.js content management system and web app framework built on Express and Mongoose. Developers define data models in code, and the framework generates an admin interface from them, so editors can manage records in the browser. Content is stored in MongoDB.

The setup guide's launch file starts the application server, so a Keystone site runs as a long-lived Node.js process rather than as static files.

## Worth knowing

The repository is archived. Its README says the project is "not receiving any new updates" and names Keystone 6 as the choice for new projects.
