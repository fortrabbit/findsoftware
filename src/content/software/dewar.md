Dewar is a static site generator for Python, inspired by Flask. A site is a Python program that registers pages and renders them to static files in a `dist` folder when run, so no server needs to be running to view the result. It is installed with pip. The setup script names tfpk as the author.

## Worth knowing

The site named in the repository's CNAME file does not resolve, so the repository is the only source left for the project. Its GitHub releases are all marked as prereleases, and the stable versions are published on PyPI.
