Elix is a community-driven collection of web components for common user interface patterns such as lists, menus, dialogs and carousels. It is installed from npm. Its README says the source is plain JavaScript that loads directly in the browser, that no shared runtime is needed to use the components, and that the project itself requires no build step. Component Kitchen leads the project and offers professional support for it.
