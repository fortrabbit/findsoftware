Editor.md is an embeddable Markdown editor component for web pages, built on CodeMirror, jQuery and Marked. The project calls itself an open source online Markdown editor, and its [documentation](https://pandao.github.io/editor.md/en.html) is a README and examples site on GitHub Pages. The component ships with multi-language support and can be added to a page from the npm package `editor.md`, with Bower, or from a zip download of the repository.
