InfyOm Laravel Generator is a Laravel package that generates CRUD code, APIs and admin panel views for a model. The model can come from the command line, a file or database tables. Generation runs through Artisan commands, and the package is added to a Laravel project's composer.json and installed with a Composer update, as the [installation guide](https://www.infyom.com/open-source/laravelgenerator/docs/10.0/installation.html) describes.
