SSOReady is open-source tooling that adds SAML and SCIM support to an application. A product redirects users to their identity provider and redeems the returned access code through an HTTP API, or lists SCIM users the same way, with SDKs in several languages wrapping those endpoints.

## Worth knowing

The project site and docs no longer resolve, and the repository holds no self-hosting guide, so the installation route is unclear.
