Perfect is a server-side Swift toolkit and web framework from PerfectlySoft, divided into several repositories. The README lists an HTTP server that Perfect can run as a standalone process, Mustache template support, and separate connectors for Redis, SQLite, PostgreSQL, MySQL and MongoDB. Projects are built with the Swift Package Manager and can be deployed to any Swift-compatible Linux server.

The code is under the Apache License 2.0, and PerfectlySoft also offers a [commercial license](https://perfect.org/licensing.html) for modified source that is kept confidential or for products sold commercially.

## Worth knowing

The repository description on GitHub reads "Legacy Perfect", and the same organization publishes Swift 6 versions of several packages under other names.
