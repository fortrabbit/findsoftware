Carbon Components Svelte is the Svelte implementation of the Carbon Design System, an open source design system by IBM. It installs from npm, and the Carbon styles are imported from the package once, at the top-level entry point of the app.

## Worth knowing

The README says the package uses IBM Telemetry to collect de-identified and anonymized metrics data in CI environments, and that installing the package is agreement to that collection. It points to the IBM Telemetry project for how to opt out.
