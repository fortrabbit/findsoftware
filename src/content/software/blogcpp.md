blogcpp is a static blog generator that converts Markdown articles and pages into static HTML. A site is laid out as a templates folder, a folder of posts, a folder of pages and an output folder, and the blogcpp binary sits in the site root and writes the output. The [README](https://code.rosaelefanten.org/blogcpp/doc/trunk/README.md) in its Fossil repository gives the build with CMake and Conan, and the source lives in that repository.

## Worth knowing

The project is discontinued: its README says the author will not continue it and asks anyone interested to get in touch, and no successor is named. The README also says the software needs a C++17 compiler and Conan to build.
