S-Cart is online store software built on Laravel and the GP247 ecosystem. The overview page lists products, cart, orders, customers and news content, managed through an admin panel with role-based permissions, and it extends through plugins and templates. It is installed with Composer's create-project command, from a git clone or with Docker, and it stores its data in MySQL or MariaDB. GP247 maintains it and publishes the code on GitHub. The project is the GP247 core, front and shop packages together, and the core package is shared with GP247 CMS.

## Worth knowing

Some extensions are sold as one-time Pro plugin purchases, with no subscription needed to run S-Cart: multi-vendor marketplaces, multiple stores, and purchases, returns and cash flow.

The package moved on Packagist. The older s-cart/s-cart package is marked abandoned and names gp247/s-cart as its replacement, so the registry figures in this record come from gp247/s-cart.
