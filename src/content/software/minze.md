Minze is a JavaScript framework for building native web components on the Web Components API. It gives those components a typed JavaScript interface with reactivity, lifecycle hooks and scoped styles. A component can be added with a CDN link, installed from npm, or started with a scaffolding command that sets up a project.

The repository holds the framework next to its scaffolder, a VS Code extension and a Vite plugin, each published as its own package.

## Worth knowing

The project's introduction says Minze is not a framework for complex user interfaces or single-page apps, and it names React, Vue and Angular for those. The installation page lists Node.js 16 or above as a requirement for the command-line install.
