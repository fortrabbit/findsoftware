DuckDB is an analytical SQL database that runs in the same process as the application that uses it. Its [Python client](https://duckdb.org/docs/2.0/clients/python/overview.html) is installed with pip. Its Node.js client is installed with npm. The [install page](https://duckdb.org/install/) also lists a command line build, installed with a script or run from a Docker image.

DuckDB-Wasm compiles the engine to WebAssembly, so a full DuckDB engine can run inside a visitor's browser, on any device, as the [wasm overview](https://duckdb.org/docs/2.0/clients/wasm/overview.html) describes.
