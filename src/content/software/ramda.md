Ramda is a functional utility library for JavaScript. Its README says it emphasizes a purer functional style, with immutability and side-effect free functions, that its functions are automatically curried, and that the data to operate on is generally supplied last. Loaded by script tag, it adds the variable R to the browser's global scope. The [API documentation](https://ramdajs.com/docs/) is on the project's own site.
