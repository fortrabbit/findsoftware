Pattern Lab is a frontend workshop environment for building, viewing and showcasing a design system's UI components using atomic design. At its core it is a Node-based static site generator that stitches UI components together. A new project starts with npm create pattern-lab. The copyright line of its MIT-licensed code names Brian Muenzenmeyer and Brad Frost.

## Worth knowing

The project is archived. Its homepage says so, and its README says it is no longer actively maintained and that no new releases or security patches will be made. The code and its history remain under the MIT License, and forks can continue independently.
