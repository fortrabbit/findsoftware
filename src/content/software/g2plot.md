G2Plot is a JavaScript charting library that draws interactive and responsive charts in the browser. The README describes it as a secondary encapsulation based on the G2 library. A page installs it from npm for use with a bundler, or loads a built file from a CDN with a script tag. The license copyright line names the AntV team as the maintainer.

## Worth knowing

The README says no newer G2Plot line built on the newer G2 release is planned, and it suggests Ant Design Charts instead.
