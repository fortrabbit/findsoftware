Meraki UI ships Tailwind CSS components as HTML that a project copies into its own code instead of installing a package. Each component page shows the code with a copy button, and the repository holds the component HTML under its components folder. Khatab Wedaa maintains it, and the code is MIT-licensed.

## Worth knowing

The repository has no tagged release, so its status rests on the date of its last commit. The site also offers page templates with prices shown on the homepage, sold beside the components.
