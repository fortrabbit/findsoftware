Tufte CSS is a stylesheet that styles web articles after the ideas in Edward Tufte's books and handouts. The homepage describes its features as extensive use of sidenotes, tight integration of graphics with text, and carefully chosen typography. A project uses it by copying `tufte.css` and the `et-book` directory of font files into its own files and linking the stylesheet from the document head.

## Worth knowing

The project is CSS only. Its README rules out JavaScript solutions and integration with static site generators.

The README says the project is maintained but not under active development, and considers it essentially feature-complete. Refactoring and new functionality are a very low priority; contributions that fix bugs or add functionality are still welcome.
