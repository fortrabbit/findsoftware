Constructor is a hosted product search and discovery service for ecommerce websites. Catalog changes can be sent to it through a full REST API, and its dashboard offers reports, controls and experiments.

Constructor.io Corporation maintains the service. The company also publishes client libraries and UI libraries for it as open source, which are separate packages from the hosted service.
