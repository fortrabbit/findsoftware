TanStack Query keeps server data in a cache inside a web application, and updates and synchronizes that cache as the data changes. The React adapter is its own npm package, and the [React installation guide](https://tanstack.com/query/latest/docs/framework/react/installation) covers its setup.

## Worth knowing

The version and download figures on this page belong to the React adapter, with the framework-neutral core published as a separate package. The docs state that older browsers need a transpiled copy of the library.
