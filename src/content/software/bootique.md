Bootique is a Java platform for building runnable applications that do not need a web container. Each app is made of modules that interact through dependency injection, and the modules are added to a Maven project through a bill of materials. The [getting-started guide](https://bootique.io/docs/3.x/getting-started/) builds a REST endpoint, runs it from an IDE, and packages it as a runnable jar that starts an embedded Jetty server with a command-line option. ObjectStyle LLC maintains the project under the Apache License 2.0.
