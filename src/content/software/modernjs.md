Modern.js is a progressive web framework based on React. Applications default to client-side rendering, and the introduction says server-side rendering can be enabled when needed. The [static site generation page](https://modernjs.dev/guides/basic-features/render/ssg) describes pages generated at build time. A project is created with `npx @modern-js/create@latest`.

The core package, @modern-js/app-tools, provides the CLI commands and integrates the Modern.js Server for development and production.

## Worth knowing

The docs site labels itself "Modern.js 2.x Docs" while the current major on npm is 3.
