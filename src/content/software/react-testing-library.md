React Testing Library provides utilities for testing React components through the DOM, building on top of DOM Testing Library. It is installed as a development dependency and runs under Node.

## Worth knowing

Current releases need DOM Testing Library installed beside it, because it is a peer dependency. The docs include a [guide for developers moving from Enzyme](https://testing-library.com/docs/react-testing-library/migrate-from-enzyme).
