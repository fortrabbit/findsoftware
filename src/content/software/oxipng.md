Oxipng compresses PNG and APNG files without loss. It is a multithreaded optimizer written in Rust, and it runs as a command-line tool. Rust projects can also use it as a library, documented on docs.rs. It is installed with cargo install oxipng, from a Docker image, or from the Windows download on the GitHub releases page. Joshua Holmer holds the copyright on the MIT-licensed code.
