Cusdis is a comment widget that websites embed to show and collect comments. It is open source under the GPL.

The project has ended. Its README says Cusdis is deprecated and asks users who want their data to email for an export. The GitHub repository is archived and names no successor, so the record is discontinued.

## Worth knowing

The project's own homepage and documentation site did not answer when this record was checked, so no homepage is linked.
