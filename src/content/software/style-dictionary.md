Style Dictionary is a build system that takes design tokens defined once in JSON or JavaScript files and exports them to platform formats such as CSS, iOS, Android and JavaScript. It runs on Node.js and, according to its installation page, in browsers as well. A project installs it as a dev dependency with npm or Yarn and runs it as a build step. The homepage says it is forward-compatible with the Design Tokens Community Group specification.
