Ilch is a content management system written in PHP for clan and community websites, with modules and designs that can be installed on it. It stores its data in MySQL or MariaDB, and it is installed by placing the files in a web directory and following the steps the [README](https://github.com/IlchCMS/Ilch-2.0) gives. Ilch 2 is the direct successor to Ilch 1.1, as the same README states.

## Worth knowing

The project's site is in German. Its documentation pages under the Dokumentation menu cover Ilch 1.1, so the steps for version 2 are in the README and the [wiki](https://github.com/IlchCMS/Ilch-2.0/wiki).
