HiQ is a CSS framework that sets responsive typography and input styling on top of custom properties, so a project can build its own styles on it. The source version is processed with PostCSS and gives access to utility mixins. The compiled stylesheet can be installed from npm or loaded from a CDN. The [documentation](https://jonathanharrell.github.io/hiq/) includes a reference for the custom properties.

## Worth knowing

The README says taking full advantage of the source version's PostCSS features means configuring PostCSS with three plugins it names. Importing the compiled stylesheet is the README's basic usage.
