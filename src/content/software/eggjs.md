Egg.js is a Node.js framework for enterprise web applications and APIs, built around Koa. A project is created with `npm init egg --type=simple`. Production deployment starts the application with egg-scripts, which creates a master process through egg-cluster, as the [deployment guide](https://eggjs.org/core/deployment) describes.

The project is maintained by Alibaba Group Holding Limited and published under the MIT license.
