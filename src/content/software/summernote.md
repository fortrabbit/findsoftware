Summernote is a WYSIWYG editor that a page loads as a JavaScript library. It turns a div element in the page into an editing field. The homepage says it is based on Bootstrap and jQuery, and the README says it is built on jQuery.

The [getting-started guide](https://summernote.org/getting-started/) shows how to load the library's CSS and JavaScript into an HTML page, with jQuery and Bootstrap included beside it, or to download the compiled files. Interface languages come from separate language files that the page includes.

## Worth knowing

The README warns that the code view accepts script content and recommends filtering or sanitizing the HTML on the server before it is shown to other users.
