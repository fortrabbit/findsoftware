Vanta.js inserts an animated effect as a background into any HTML element, which can keep other children as foreground content. Each effect is drawn with three.js (using WebGL) or p5.js.

## Worth knowing

The project's own demo site, linked from the [README](https://github.com/tengbao/vanta/blob/master/README.md), could not be read because its TLS certificate has expired, so the software could not be checked there.
