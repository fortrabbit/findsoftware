OpenLiteSpeed is an open source HTTP web server from LiteSpeed Technologies. It is event-driven and compatible with Apache rewrite rules and ModSecurity rules. It includes a built-in WebAdmin interface for managing the server.

The server can be installed from a LiteSpeed package repository, from a binary package, from source, from a Docker image or with a one-click script. After installation a command starts the web server, and it then keeps running as a server process.
