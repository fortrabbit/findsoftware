Stimulus is a JavaScript framework that connects controller objects to HTML through `data-controller` attributes. It watches the page for those attributes and creates a controller instance for each element that carries one. It is installed as an npm package added to a JavaScript bundle, or imported in a script tag.

Stimulus does not render HTML itself. The handbook describes it as designed to enhance static or server-rendered HTML.
