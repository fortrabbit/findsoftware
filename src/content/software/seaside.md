Seaside is a framework for developing web applications in Smalltalk. Its README says it is based on Smalltalk, which several vendors implement, and gives install steps for Pharo, GemStone, Squeak and VAST. In a Pharo image the install is a Metacello load, after which a default server adaptor starts on port 8080.

The [wiki](https://github.com/SeasideSt/Seaside/wiki) holds the documentation the README points to, and its add-on libraries are listed on a separate wiki page.

## Worth knowing

The README says Seaside for Squeak is unmaintained.
