markdown2 is a Python module that converts Markdown text to HTML. It is called from code through a function or a converter object, and the README also shows a command-line form that converts a file. Extras such as tables, footnotes, header IDs, a table of contents and syntax coloring of code blocks are switched on by name when converting. Syntax coloring needs Pygments, which the `all` extra of the install command brings in.

Trent Mick maintains the project in a personal repository. The README says everything needed to run it is in one file, which can be copied onto the Python path as a module or onto the executable path as a script.

## Worth knowing

Some files in the repository, used for testing and performance work, carry licenses other than MIT. The package the registry ships is under MIT.
