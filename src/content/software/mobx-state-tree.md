mobx-state-tree is a state container built on MobX. MobX supplies the observable state, and mobx-state-tree adds a structure on top: models declared with a types API, trees of model instances that can be read as snapshots, and changes made through actions. The README calls MobX the engine and mobx-state-tree the structure around it. The installation page lists browsers, Node and React Native among the environments it runs in, and a CDN build exposes the library as a global.
