onessg (One Static Site Generator) compiles HTML and Markdown files into HTML pages. Front matter in each source file is passed to the layouts, which are written in any template engine that has a jstransformer. It is installed with npm as a development dependency and run through an npm script. The [tutorial](https://github.com/RyanZim/onessg/blob/master/docs/tutorial.md) covers the file layout.
