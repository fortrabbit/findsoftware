behave is a behavior-driven development framework for Python, documented on Read the Docs. Feature files are written in a natural-language style called Gherkin, backed by Python code, and languages other than English are available for them. It is installed with pip, from a source distribution or from the GitHub repository. The project keeps its source on GitHub, and its ecosystem page lists other software that enhances it.
