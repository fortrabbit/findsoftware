SearchWP is a search plugin for WordPress that builds a configurable search index over posts, custom fields and other site content. It is distributed from the SearchWP website rather than the WordPress plugin directory, and it is operated by SearchWP, LLC.

## Worth knowing

The plugin is licensed under the GPL. Updates and support run for one year after purchase and then need a renewal.
