Groonga is an open-source full-text search engine and column store. Applications can link its C library directly, or run its built-in server command, which supports HTTP. Groonga also works as a column-oriented database management system, and it keeps its data in its own database files.

Packages are available through apt, Homebrew and MacPorts, and a Docker image is distributed on Docker Hub. The [CMake build guide](https://groonga.org/docs/install/cmake.html) covers building from source. The repository describes Groonga as the successor project to Senna.

## Worth knowing

The project's own pages name Mroonga, PGroonga and a Ruby binding as related projects. Each is separate software and none is recorded as built on Groonga here.
