Robot Framework is an automation framework for acceptance testing and robotic process automation. Tests are run from the command line with the `robot` command. Libraries written in Python, Java and other languages extend it, and the project describes an ecosystem of separately developed libraries and tools around it.

Development is sponsored by the non-profit Robot Framework Foundation.
