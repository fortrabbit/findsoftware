Objection.js is an ORM for Node.js that is built on knex, the SQL query builder, so the databases knex supports can be used through it. The project calls it a relational query builder. Its README lists declarative models with relationships between them, eager loading and transactions among its features, and it ships TypeScript typings, optional JSON schema validation, and a way to store complex documents as single rows.

## Worth knowing

The original repository, Vincit/objection.js, still exists under the same project name. The project says development continues at ditojs/objection, the repository this record names.

Objection is an ES module. CommonJS code can still load it with require.
