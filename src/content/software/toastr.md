toastr is a JavaScript library that shows non-blocking notifications on a web page. It is installed through npm, NuGet, Bower or a script tag served from cdnjs and jsDelivr. The source is on [GitHub](https://github.com/CodeSeven/toastr).

## Worth knowing

The library needs jQuery on the page, because its README states that jQuery is required.
