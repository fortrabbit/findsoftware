Shopware 5 is open-source e-commerce software from shopware AG with an event-driven plugin system and a backend at /backend. Its README names Symfony, Doctrine and Zend Framework as technologies it is based on. It runs on PHP with a MySQL database, and its README describes installation by cloning the repository from Git.

## Worth knowing

The repository carries a notice that it is no longer actively monitored or maintained, and every 5.x release line is past its end of life on endoflife.date. The Shopware developer portal states that the official Shopware 5 documentation is now continued by SafeFive. The license statements in the repository disagree: the README header gives GPL v3, the license section gives AGPL v3, and license.txt gives GNU General Public License 3.
