WireUI is a library of Blade components for Laravel and Livewire applications, which the [README](https://github.com/wireui/wireui/blob/main/readme.md) calls a library of components and resources. Projects add it with Composer, following the [getting-started guide](https://wireui.dev/getting-started), and its components cover forms, dialogs, notifications and icons. The homepage presents the Blade components as made for Alpine.js, Tailwind, Livewire and the Tall Stack.

## Worth knowing

Laravel is a Composer dependency, so the components are added to an existing Laravel application and do not run on their own.
