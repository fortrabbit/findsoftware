Raytha is a content management system built with .NET. Its admin is a React single-page app served at /raytha, and templates are Liquid, edited in the browser. Content is kept in one PostgreSQL database and is available through a REST API. The platform includes role-based access control and single sign-on with SAML and JWT. It runs from a Docker image, from a Docker Compose file in its repository, or from a one-click deploy on Railway.

## Worth knowing

The project's terms say raytha.com no longer offers a hosted Raytha service, so a site runs on infrastructure its operator provides. The company behind the software is Raytha, Inc.
