Fluent UI System Icons is an icon set from Microsoft, offered in regular, filled and color styles at several sizes. The icons are kept as SVG assets with metadata in the repository. The plain SVG icons are installed from npm, and Android, iOS and Flutter projects take the same icons through their own package managers.

The SVG package README structures each icon name as the name, size and style joined by underscores. The repository's README describes a metadata check that keeps the size and style lists in step with the SVG files.

## Worth knowing

The SVG package README says some icons do not yet have every size, so a size that exists for one icon may be missing for another. The same README marks the color style as deprecated and says it may be removed in a future release.
