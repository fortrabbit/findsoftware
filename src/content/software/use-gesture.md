use-gesture binds drag, pinch, move, hover, scroll and wheel events to a component. The React package and the vanilla JavaScript package are separate npm packages in one repository, and the docs say the library was originally built for React and is now platform agnostic.

## Worth knowing

The README suggests pairing the library with an animation library such as react-spring.
