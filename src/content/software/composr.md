Composr CMS is a PHP content management system with social features such as forums, member blogs and a wiki. The GitHub repository is the development repository; its description says it is not intended for end users, and installation packages come from the project's website. The [installation guide](https://github.com/composr-ecosystem/composr/blob/v11/docs/INSTALL.md) describes uploading the contents to a server and running the installer in a browser. A Git clone is meant for developers, not for release websites.
