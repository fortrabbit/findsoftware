Poltergeist is a static site generator built on Gulp. It is set up by cloning its template repository.

Pages are written as Nunjucks templates, Markdown, or both, and each post is a folder. The README describes deployment to an Amazon S3 bucket, with CloudFront cache invalidation when a distribution is configured.

## Worth knowing

The repository has no license file and no releases.
