jQuery is a JavaScript library for working with HTML documents. It covers document traversal and manipulation, event handling, animation and Ajax, and it runs in the browser. The library is installed with npm or yarn, or loaded from the project's CDN, and the [API documentation](https://api.jquery.com) lists its methods.

The OpenJS Foundation maintains jQuery, and the source is in the jquery organization on GitHub.
