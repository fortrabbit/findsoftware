Metalsmith is a static-site generator for Node.js. It reads the files in a source directory, passes them through a chain of plugins and writes the result to a destination directory. The [getting-started guide](https://metalsmith.io/docs/getting-started) describes its output as static files that can be deployed to a web server. Plugins extend the core, and the [plugin directory](https://metalsmith.io/plugins) lists them.

## Worth knowing

The [about page](https://metalsmith.io/about) says the copyright of the software and its official plugins has been held by Kevin Van Lierde DBA webketje since September 2021.
