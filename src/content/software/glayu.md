Glayu is a static site generator for mid-sized sites, written in Elixir. Each article is a Markdown file placed inside a subfolder of the `source` directory, and the [README](https://github.com/pablomartinezalvarez/glayu/blob/master/README.md) gives the install and build commands for a site. The software runs on Erlang and is installed as a binary that the README links from the repository.

The author is Pablo Martínez, who released it under the MIT license.

## Worth knowing

The project's website no longer shows the software: its address redirects to a domain parking page, and the documentation link in the README points to the same address. The repository has no release, so the binary linked from the repository is the only install route the project itself names.
