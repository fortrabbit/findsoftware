Intlayer is a TypeScript i18n library that keeps the translation dictionaries of each component next to the component. The project also offers a visual editor and a content management system, which sit beside the library.

The visual editor is part of the open source project, and its documentation says it runs on the creator's own infrastructure. The [CMS concept page](https://intlayer.org/doc/concept/cms) describes the CMS at app.intlayer.org as a hosted, optional paid service that can also be self hosted, with a Docker Compose stack.

Intlayer can be set up as a wrapper around i18next, next-intl and similar libraries, and the documentation has migration guides for several of them.

## Worth knowing

The hosted CMS is a paid service. The terms of service add that reusing the code to create direct competitor tools without significant transformation or substantial value addition is prohibited.
