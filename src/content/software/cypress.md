Cypress runs tests in a real browser, and the Cypress App is where tests are written and run. The App runs locally and in CI, and the package installs from npm. The project also publishes Docker images that include the required dependencies.

## Worth knowing

Cypress Cloud, a paid service for recording tests, is sold beside the Cypress App. The docs say the bundled Electron browser is deprecated as a test browser and will be removed in a future version.
