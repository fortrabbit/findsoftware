Scale is the digital design system for Telekom products and experiences, built as Stencil components written in TypeScript. The components install from npm under the next tag, and the README says Angular and Vue support Web Components directly. The project ships two versions of the same components: the Telekom version, whose brand and design assets the README says are not available for free use, and an open source version with a neutral theme that the README says is covered by the MPL 2.0 license. A Sketch library for designers is documented alongside the code.

## Worth knowing

The project describes itself as an open beta, and no stable release exists yet. The README says customization for anything other than the Telekom needs the Deutsche Telekom default theme replaced.
