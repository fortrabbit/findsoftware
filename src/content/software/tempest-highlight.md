tempest/highlight is a PHP package that highlights source code on the server, for web pages and for the terminal. It is installed with Composer, and the Tempest project publishes it on its [package page](https://tempestphp.com/3.x/packages/highlight).

The docs describe CSS themes, an inline-style theme and a terminal theme. The supported languages are listed in the GitHub repository.
