Netlify Visual Editor is an environment for content editors to work with structured content in a visual way, with a live preview of the site. The editor runs as part of the Netlify platform and stores content back to the source it reads from, such as Contentful, Sanity or Git.

Developers install the Visual Editor CLI with npm and can run a local setup from a template site.

## Worth knowing

Visual editing is only available to teams that already have it enabled through Netlify Support, and a new project or team cannot enable it. The record stays a stub until Netlify states that the product is still offered or retired.
