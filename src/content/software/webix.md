Webix is a JavaScript UI library for building data-heavy web applications, and its widgets run in the browser on desktop and mobile. The library is included from its CDN or installed from npm. It supports single-page application architecture and adjusts the labels, date and number formats of its components to a language and culture. [The documentation](https://docs.webix.com/) describes the components and the getting-started steps.

The copyright in the repository belongs to XB Software Ltd, which also publishes the documentation. The source is on [GitHub](https://github.com/webix-hub/webix).

## Worth knowing

The library is offered under two licenses. The free version is under GPLv3, and the PRO packs add the enterprise widgets under a paid commercial license.
