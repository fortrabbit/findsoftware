marshmallow is a Python library for converting complex objects to and from native Python types. A schema declares the fields of a structure: dumping turns an object into primitive values that can be rendered as JSON for an HTTP API, and loading validates incoming data against the same schema.

The library makes no assumption about web frameworks or database layers, so it works with any ORM or with none. Steven Loria maintains it, with contributors, under the marshmallow-code organization on GitHub.
