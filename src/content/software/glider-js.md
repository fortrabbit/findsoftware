Glider.js is a dependency-free scrollable list with customizable paging controls. The project calls it a carousel alternative, and its [documentation](https://nickpiscitelli.github.io/Glider.js/) says it is not truly a carousel.

## Worth knowing

The docs say Glider.js is not a drop-in replacement for carousels.
