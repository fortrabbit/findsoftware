WordPress VIP is a managed hosting platform for WordPress sites and Node.js applications, built on open-source WordPress and operated by WPVIP Inc., which Automattic owns. Each WordPress environment has its own MySQL database, and an environment can be a single site or a WordPress multisite network. The VIP Dashboard manages applications, environments and network sites, while each site's content and users are handled in the WordPress admin dashboard. The vendor's site says developers can build on REST and GraphQL APIs.

The vendor says it handles migrations from Sitecore, Drupal and Adobe Experience Manager as a service. Its comparison hub points readers to competitor comparison pages, and one of them covers Sitecore.

## Worth knowing

Hosting is sold in three plans, each marked as priced on request. The VIP Local Development Environment runs the platform's web stack on a developer's machine, and it is a developer tool for the hosted platform.
