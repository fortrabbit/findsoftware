SimpleCov measures how much of a Ruby codebase its tests execute. It gathers the data with Ruby's built-in Coverage library, then filters, groups and merges the results across test suites and writes them as an HTML report and a JSON file. A bundled command-line tool opens and inspects the report.

The README also describes measuring which lines a live process runs in production, to find code that neither tests nor traffic touch.
