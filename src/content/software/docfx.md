DocFX builds documentation websites from markdown pages, .NET API reference and REST API reference files. A project is created and built with the docfx command, and the build can start a local preview server. The output is static HTML files that can be published to any static site hosting server, and the [quick start](https://dotnet.github.io/docfx/) shows publishing to GitHub Pages.

The project moved to the .NET Foundation after Microsoft Learn stopped using it. It runs on the .NET SDK and is installed as a global .NET tool.

## Worth knowing

The README says the project is not released on a regular cadence and is planned to continue as a community-driven project.
