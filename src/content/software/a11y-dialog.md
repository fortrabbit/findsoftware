a11y-dialog is a script that turns markup in a web page into accessible modal dialog windows. It follows the Dialog (Modal) pattern from the ARIA Authoring Practices Guide and supports alert dialogs. A dialog is declared with data attributes in the markup, and the bundle instantiates each marked element when the page is ready; a JavaScript API handles dialogs that are created in code. The [installation guide](https://a11y-dialog.netlify.app/installation) covers a bundler and a script tag loaded from a CDN.
