doctree is a Go program that indexes library source code and serves the documentation over HTTP. It is a single binary that the README says is designed to run on a local machine and can be self-hosted, and it is also available as a Docker image. Its README lists support for Go, Python and Zig source code and for Markdown files.

## Worth knowing

The GitHub repository is archived. The README describes the project as experimental and not yet ready for production use.
