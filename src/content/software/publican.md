Publican is a static site generator that runs on Node.js and is installed with npm. Content is written in Markdown, and templates are written with JavaScript template literals. By default every page is rendered to a directory containing an index.html file.

The build step needs Node.js on the machine that produces the files. The [documentation](https://publican.dev/docs/) covers the quick start, templates and configuration.
