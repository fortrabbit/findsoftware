mo.js is a JavaScript library for motion graphics. It animates HTML elements and shapes on a page through a declarative API, and the README says it ships built-in components such as html, shape, swirl, burst and stagger. It is installed from npm or loaded with a script tag from a CDN.

## Worth knowing

The getting-started page calls mo.js a client-side library that is not meant to run on a server. For sites that render pages on a server, its server-side rendering section says to run the mo.js code only on the client side.
