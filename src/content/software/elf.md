Elf is a reactive state management library built on RxJS. The store is updated with pure functions and read with RxJS operators, and the package README lists separate packages for entities, requests, pagination, persisted state, state history and devtools. The package declares RxJS as a peer dependency. The source repository and the documentation site that the package names do not load, so the project's current status cannot be checked from them.
