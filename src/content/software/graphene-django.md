Graphene-Django is a Python library that integrates Graphene with Django, so a Django project can serve a GraphQL API. The project's docs say that Graphene-Django is built on top of Graphene and that it adds GraphQL functionality to a Django project. It is installed with pip.

Syrus Akbary maintains it under the MIT license. The view can serve GraphiQL, a browser-based query tool, when that option is turned on.
