SKF is a plugin-based static website generator written as a bash script, inspired by the Suckless Web Framework. It is installed from the source tree with make, or from an Arch Linux package.

## Worth knowing

The README sends readers to the project's own site for usage instructions, and that address no longer resolves. The record is a stub without a homepage until a working site is found. The repository has no release or tag.
