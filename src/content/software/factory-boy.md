factory_boy is a Python library for building test objects from declarative factory classes, a replacement for static test fixtures. Its [documentation](https://factoryboy.readthedocs.io/en/stable/) describes factories for Django, Mogo, MongoEngine and SQLAlchemy models, and its random values come from Faker through `factory.Faker`.

The project describes itself as based on thoughtbot's factory_bot, the Ruby library. The Credits page names Jeff Widman and Raphaël Barrois as the people who operate and maintain the project, and the LICENSE file names The FactoryBoy project as copyright holder.
