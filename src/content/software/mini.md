MINI is a skeleton PHP application that uses only native PHP code, PDO for database requests and clean URLs, so that people do not have to learn a framework. It is the successor of php-mvc.

## Worth knowing

The README lists [MINI3](https://github.com/panique/mini3) among the forks of MINI and calls it the successor of MINI. The repository has no tagged release.
