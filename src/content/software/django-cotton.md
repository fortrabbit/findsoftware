Django Cotton is a UI component framework for Django that builds reusable components from single template files. The project describes itself as enhancing Django templates without replacing them, and it installs as a Python package with pip. Will Abbott, an individual, maintains it.

## Worth knowing

The project's ecosystem page lists third-party projects built on Cotton and says most of them are independently maintained.
