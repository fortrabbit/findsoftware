Sigma.js is a JavaScript library that draws large graphs in the browser with WebGL, for interactive graph visualization. It uses graphology as its graph data structure, and the README describes the library as built on top of it. The repository is a monorepo that also holds companion packages such as @sigma/layer-webgl.

## Worth knowing

graphology is a required install next to sigma.
