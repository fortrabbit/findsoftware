Searchanise is a hosted site search and product filter service for online stores. Bolide Network LLC operates it from San Diego, California, as the terms of service and privacy policy state. A store adds the service through apps for the platforms it lists, and the API documentation covers a store on a platform the app does not support: the store signs up for an API key pair, imports its catalog through the update endpoint and then gets results from the search endpoint.

The API documentation sets a limit of 200,000 products.

## Worth knowing

The service is paid: the pricing page lists plans by name and offers a 14-day trial.
