factory_bot is a Ruby library for defining factories, which build test objects from one definition with several build strategies: saved, unsaved, attribute hashes and stubs. It is installed as a gem, and its reference is a book published on GitHub Pages. Rails and RSpec are supported through separate integrations that the README points to.

## Worth knowing

The getting-started guide in the repository is marked deprecated.
