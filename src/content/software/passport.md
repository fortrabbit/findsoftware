Passport is authentication middleware for Node.js that authenticates each request through plugins called strategies. It does not mount routes or assume any particular database schema. The README describes it as Express-compatible, and the [documentation](https://www.passportjs.org/docs/) explains three concepts: middleware, strategies and sessions. Strategies range from username and password checks to OAuth and OpenID delegation, and the README links strategies such as passport-local as separate repositories.
