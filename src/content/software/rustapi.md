RustAPI is a Rust web framework for HTTP APIs, built on hyper and tokio. An application starts its own server with a call to run on a listening address, and the crate is added to a Cargo project with cargo add. The framework's own command-line tool is installed with cargo install.

The project also offers RustAPI Cloud, managed hosting that applications deploy to from the command line, as the [README](https://github.com/Tuntii/RustAPI/blob/main/README.md) describes.
