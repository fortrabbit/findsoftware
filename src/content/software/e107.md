e107 is a content management system written in PHP, with MySQL or MariaDB as its database. A site is installed by extracting the release archive into the web root and running install.php in a browser. The admin panel manages content, users and groups, and languages, and plugins and themes add features and designs. The project has been open source since 2002, e107 Inc. is the name its site uses for the releasing organization, and its source is on GitHub.
