Auro is the open-source design system of Alaska Airlines, and its components are framework-agnostic custom elements. The button's package, @aurodesignsystem/auro-button, is installed with npm or loaded from a CDN.

## Worth knowing

The design system is a set of separate repositories, one per component, so the repository recorded here covers the button alone.
