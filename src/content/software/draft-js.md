Draft.js is a rich text editor framework for React. Applications render its editor component, and its editor state is built on an immutable model. It depends on React and React DOM, which the application installs alongside it, and it is distributed through npm.

## Worth knowing

The project is archived and receives no feature updates. The README places it in maintenance mode, limited to critical security patches, and names Lexical as the framework Meta has been migrating to.
