SqlSugar is a C# ORM framework for .NET, published as open source on GitHub. A project adds the SqlSugarCore package from NuGet, the package the install guide names, and maps classes to tables in one of several supported databases. The [documentation](https://www.donet5.com/Home/Doc) is written in Chinese.

The README credits the Fructose Big Data Technology team with maintaining the project.

## Worth knowing

The repository's LICENSE file names the MIT license, while the documentation's footer names the Apache License 2.0.
