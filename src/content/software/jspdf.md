jsPDF is a JavaScript library that generates PDF documents, in the browser or in Node.js. The package ships separate builds for module loaders and for Node. The README describes the features merged from the yWorks fork as an advanced API mode, next to a default mode that keeps the original API.

## Worth knowing

The 14 standard PDF fonts cover the ASCII range only. Text beyond it needs a TTF font added to the document.
