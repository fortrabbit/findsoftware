Vuetify is a UI component framework for Vue, distributed as the vuetify npm package. A new project starts from the create-vuetify scaffolding tool, and an existing Vite or Nuxt project adds the vuetify and vite-plugin-vuetify packages, as the [installation guide](https://vuetifyjs.com/getting-started/installation/) describes.

The locale service supports a list of languages, and a locale in a right-to-left language also changes the direction of the components. Questions go to the project's Discord community.
