Vant is a set of Vue components for mobile web apps, written in TypeScript and installed from npm as `vant`. The [quickstart](https://github.com/youzan/vant/blob/main/packages/vant/docs/markdown/quickstart.en-US.md) describes importing single components and their stylesheet into a Vue project, or loading all components from a CDN on a plain HTML page, where they are reachable through one global variable named `vant`.

The components ship with built-in translations. The README links GitHub discussions.

The maintainer is 杭州起码科技有限公司, the company behind Youzan.com. The source is hosted on GitHub under the youzan organization.
