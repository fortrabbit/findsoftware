Acquia Drupal Starter Kit, formerly Acquia CMS, is a set of Drupal modules and configuration for building low-code websites on the Acquia platform. This repository holds the Drupal module. A new site starts from a separate Composer template that the [README](https://github.com/acquia/acquia_cms/blob/develop/README.md) links.

## Worth knowing

The GPL is stated two ways: the repository and the README name version 2, while the Packagist package states version 2 or later.
