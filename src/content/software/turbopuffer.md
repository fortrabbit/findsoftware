turbopuffer is a hosted database for vector and full-text search, operated by turbopuffer Inc. Its data is kept in object storage, and there is no server for a customer to install. Public clusters run in AWS, GCP and Azure regions. Single-tenant clusters and bring-your-own-cloud clusters are also offered, the latter inside a customer's VPC.

## Worth knowing

The permissions guide states that turbopuffer has no built-in row or document-level RBAC.
