Dokka is an API documentation engine for Kotlin. It reads Kotlin's KDoc comments and Java's Javadoc comments, so mixed-language projects can be documented in one build. It writes its own HTML format, Javadoc HTML and several flavors of Markdown.

It runs as a Gradle plugin, a Maven plugin or a command line runner, and the [documentation on kotlinlang.org](https://kotlinlang.org/docs/dokka-introduction.html) covers all three. With Gradle, a task writes the generated documentation into a build directory.

JetBrains maintains Dokka under the Apache License 2.0.

## Worth knowing

The README badges Dokka as Kotlin Beta.
