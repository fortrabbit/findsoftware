styled-jsx is a CSS processor for JSX. CSS written in a `<style jsx>` tag inside a component is transpiled by a Babel plugin into class names unique to that component, so its rules reach the elements the component renders and no others. The project is installed from npm and maintained by Vercel Inc. Next.js configures the plugin itself, so a Next.js project needs no separate Babel setup for it.
