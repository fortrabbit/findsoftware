FUEL CMS is a content management system built on the CodeIgniter PHP framework, as its [homepage](https://www.getfuelcms.com) states. It is installed by copying its files to a web-accessible folder. Its admin stores content in a MySQL database.

## Worth knowing

The README states that the project is no longer in active development and is not recommended for production websites.
