CanCanCan is an authorization library for Ruby and Ruby on Rails. It is installed by adding the gem to a Gemfile, and it is published on RubyGems under the name cancancan. The [developer guide](https://github.com/coorasse/cancancan/blob/main/docs/README.md) in the repository documents its use in detail.

The gem's README describes two parts: the authorization library itself and helpers for Rails controllers.
