Aplus Framework is a full-stack PHP framework made of independent libraries. A project is created with `composer create-project aplus/app`, an application skeleton that requires the framework package. The [User Guide](https://docs.aplus-framework.com/guides/projects/app/index.html) describes the skeleton's structure, configuration and bootstrap, says the application is designed for HTTP and the command line, and covers deployment to shared hosting and to a private server.
