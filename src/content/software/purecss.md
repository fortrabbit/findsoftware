Pure is a set of small, responsive CSS modules that a web project loads as plain stylesheets. The modules cover a base built on Normalize.css, grids, forms, buttons, tables and menus, and the [Get Started page](https://purecss.io/start/) gives the stylesheet link.

## Worth knowing

Pure has minimal styles and, by the project's own description, encourages applications to write their styles on top of it and makes it easy to override them.
