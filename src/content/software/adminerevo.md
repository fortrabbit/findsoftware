AdminerEvo is a fork of Adminer, a database management tool distributed as a single PHP file. Its README says the fork was started under a new name to carry on the original project. The repository is archived. The README states that the maintainer is closing the repository and names pematon/adminer as the option to follow.

## Worth knowing

The project has no ongoing development in its own repository, so it is listed as discontinued. Its README gives the supported databases as MySQL, MariaDB, PostgreSQL, SQLite, MS SQL, Oracle, Elasticsearch and MongoDB, under a heading that credits the original developer.
