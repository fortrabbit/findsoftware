Konsta UI is a set of mobile UI components built with Tailwind CSS, with iOS and Material Design looks. The components are available for React, Vue and Svelte, and each framework has its own documentation section. A project installs the package from npm.

The homepage describes Ionic and Framework7 as parent frameworks that can supply the app shell, with Konsta UI components used for the inner pages. Vladimir Kharlampidi is named as the copyright holder in the license file.
