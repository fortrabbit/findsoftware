Codedoc is a command-line tool that builds a documentation website from a project's Markdown files, which it transforms into HTML files. The CLI is installed from npm and needs Node.js, and a development server on the local machine rebuilds the docs as the files change. The project's site says the output can be deployed to services such as GitHub Pages. Its rendering and components are built on CONNECTIVE SDH.
