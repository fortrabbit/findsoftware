Laravel Data is a PHP package for Laravel that describes data once, as a PHP class that extends the package's Data class. From that class the package creates data objects from request data and validates them, transforms them into resources like Laravel's API resources, and generates TypeScript definitions for a frontend. The [documentation](https://spatie.be/docs/laravel-data/v4/introduction) describes how to define and use the classes.
