React is a JavaScript library for building user interfaces from components. The react-dom/server APIs render components to HTML on the server, and the reference says a framework may call them. The [installation page](https://react.dev/learn/installation) describes starting a new app with a recommended framework or adding React to an existing project.

## Worth knowing

The homepage describes the library as used for web and native interfaces, and native rendering is provided by React Native, a separate project. The installation page says Create React App has been deprecated, which concerns that tool and not the React library.
