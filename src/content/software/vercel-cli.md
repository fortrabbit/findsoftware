Vercel CLI is the command-line interface of the Vercel hosting platform. It lets a developer interact with the platform from a terminal, and its `vercel dev` command replicates the Vercel deployment environment locally. It is installed globally with npm, pnpm, yarn or bun, and the package still needs Node.js to run its launcher. Vercel Inc. publishes the CLI from the [vercel repository](https://github.com/vercel/vercel), where the package sits in a monorepo.
