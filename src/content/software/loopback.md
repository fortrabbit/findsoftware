LoopBack 4 is a Node.js and TypeScript framework for building APIs and microservices, based on Express. A project is generated with `npm create loopback`. The copyright line names IBM Corp. and LoopBack contributors.

## Worth knowing

LoopBack 3 reached end of life at the end of 2020; this record covers LoopBack 4, which the homepage lists as active. The README states that no long-term support version exists yet for LoopBack 4.
