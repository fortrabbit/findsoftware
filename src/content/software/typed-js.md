Typed.js types strings into a page element at a set speed, backspaces what it typed and begins the next string. The homepage demos show looping, a fade-out option, controls to start, stop, reset and destroy the animation, and strings that contain HTML tags.

The strings can also be read from HTML already on the page, so search engines and visitors without JavaScript see the text. The README shows a React component that creates the instance in an effect and destroys it on cleanup.

## Worth knowing

Personal and open source projects use the library under the GPL-3.0. A commercial project needs one of two paid licenses, one for a single project and one for unlimited projects.
