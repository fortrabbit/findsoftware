dry-validation is a data validation library for Ruby that defines schemas and validation rules through contract objects. Its schemas are powered by dry-schema, a separate gem. The Hanakai team maintains it, and its documentation sits in the Hanakai guides for the dry family of gems.

## Worth knowing

The README and the documentation give no install command.
