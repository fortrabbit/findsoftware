Conductor is an open source workflow engine written in Java. It runs as a server with a built-in web UI and exposes REST and gRPC endpoints for workflow and task operations. The project's configurations pair a database such as Redis, Postgres or MySQL with Elasticsearch as the search index. Workers can be written in Java, Python, Go, JavaScript, C#, Ruby or Rust.

## Worth knowing

The project was created at Netflix, and the original Netflix repository is archived. The current repository continues it and is maintained by Orkes Inc., which also offers a hosted version of Conductor.
