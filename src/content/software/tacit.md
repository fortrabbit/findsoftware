Tacit is a CSS framework that styles standard HTML5 elements without any CSS classes, so a page written in plain markup gets a default look. The framework is one stylesheet. A page loads it from the jsDelivr CDN or from a downloaded copy served with the site. The layout adapts to narrow screens only when the page also declares a viewport meta tag. Yegor Bugayenko, an individual, maintains the project, which is published on npm as tacit-css.

## Worth knowing

The [homepage](https://yegor256.github.io/tacit/) describes the framework as a work in progress. Themes that change its look are built on top of it by other projects, such as kacit.
