Stylelint checks stylesheets against a set of rules and reports errors and deviations from the configured conventions. Plugins and shareable configs extend the rules. It is set up with npm, and the npx command runs the locally installed package. It can also be used as a PostCSS plugin.

## Worth knowing

The README describes the project as maintained by volunteers.
