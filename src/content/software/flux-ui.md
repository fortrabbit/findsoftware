Flux is a UI component library for Livewire applications, installed with Composer into a Laravel project and styled with Tailwind CSS. The free package holds a core set of components, including buttons, dropdowns, icons, separators and tooltips. The remaining components belong to a paid Pro tier, which a project activates with an artisan command after purchase.

The setup adds two Blade directives to the layout, then imports the Flux stylesheet into the Tailwind CSS file. A project that needs to change a component publishes its Blade file with an artisan command.

## Worth knowing

The core package's manifest names a proprietary license, and the Flux Terms of Service and License Agreement governs use of the components. Those terms bar using Flux in open source projects and redistributing its components apart from an end product. The README lists Laravel, Livewire and Tailwind CSS as prerequisites to install first.
