ContentTools is a JavaScript library for building WYSIWYG editors for HTML content. The build files are downloaded from the project or loaded from the jsDelivr CDN, and the npm package carries the same name. The [API reference](https://getcontenttools.com/api/content-tools) covers the library's classes for building an editor.
