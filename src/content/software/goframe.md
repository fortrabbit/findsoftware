GoFrame is a Go framework for web services, components and full application projects. Its README says a project can use it as a complete application framework or take individual components from it. The module is added with `go get`, and the `gf` command-line tool, installed with `go install`, scaffolds a project with `gf init`.

Database drivers ship as separate packages in the repository, and the framework includes a template engine and internationalization support. The standalone deployment guide runs a built application as a background daemon process.

## Worth knowing

The address goframe.org serves a Chinese-language site; the English site is at goframe.org/en, and many documentation pages under it are still Chinese.
