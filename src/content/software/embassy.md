Embassy is an HTTP server library written in Swift for iOS, macOS and Linux. It is added to a Swift project through CocoaPods, Carthage or the Swift Package Manager, and its source is under the MIT license.

The project's README links an article titled "Embedded web server for iOS UI testing" and names Ambassador, a web framework built on Embassy, as a related project.
