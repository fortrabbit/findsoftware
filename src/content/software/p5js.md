p5.js is a free and open-source JavaScript library for creative coding on the web. The README says it treats a web page as the sketch and supports audio-visual, interactive, experimental and generative works. The [reference](https://p5js.org/reference/) has documentation with visual examples, and community-created libraries extend it through the project's [libraries page](https://p5js.org/libraries/).

## Worth knowing

The copyright page puts the reference and example pages under CC BY-NC-SA 4.0, which it says allows reuse for non-commercial purposes with credit.
