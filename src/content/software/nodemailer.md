Nodemailer sends email from Node.js. The project's site describes SMTP, Sendmail, Amazon SES and stream transports, and a plugin API for adding logic to a message before it is sent.

## Worth knowing

The team behind Nodemailer also sells EmailEngine, a self-hosted email API. The site says Nodemailer's development is sustained by EmailEngine licenses; EmailEngine is a separate product and is not part of this package.
