CMSimple_XH keeps pages and settings as files on the server and needs no database, so installing it means copying its files to a PHP web server over FTP. Editors change the site in the browser in admin mode, and plugins from the project's plugin repository add features. A team of several members maintains it. The project's [history page](https://www.cmsimple-xh.org/?The-XH-Story) describes the classic CMSimple by Peter Harteg and says a group of CMSimple enthusiasts began CMSimple_XH in 2009.

## Worth knowing

The project's [site](https://www.cmsimple-xh.org/) states the license as GPL3, and GitHub reports none for the repository.
