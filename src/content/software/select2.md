Select2 is a jQuery plugin that replaces an HTML select box with a searchable, customizable control. It is built on jQuery, ships message translations in many languages and supports right-to-left pages. Support questions go to the project's [forum](https://forums.select2.org), and the [installation guide](https://select2.org/getting-started/installation/) describes how to include it in a page.
