Material Web is a library of web components that uses the Material 3 design system. A site installs the components from the @material/web npm package or loads them from a CDN. The docs name Lit, React, Vue and Svelte among the frameworks the components work with.

The support page says the project aims to support the latest two major versions of browsers at each release.

## Worth knowing

The project's homepage says it is in maintenance mode pending new maintainers. The roadmap plans no new components or features and accepts bug fixes on a case-by-case basis.
