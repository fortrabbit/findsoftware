Urubu is a Python tool that builds a static website from Markdown files and Jinja2 layouts. Its pages describe it as a tool for sites that are a set of logically related content rather than a blog, with a navbar, a table of contents sidebar, breadcrumbs and pagers set up from the folder tree. `urubu build` writes the site into a `_build` directory, and `urubu serve` starts a local server on port 8000. The homepage also describes Python hooks that assist in templating, and deployment by pushing to a git repository.

## Worth knowing

The homepage calls Urubu a micro CMS, while the start page describes it as a tool to build static websites. The software is under the GNU Affero General Public License, and the documentation content is under CC-BY-SA.
