ngx-translate adds translations to Angular applications. Its homepage presents it as an alternative for cases where Angular's built-in i18n system does not fit. The [concepts page](https://ngx-translate.org/reference/concepts/) describes it as fully standalone and built on Angular Signals. The optional http-loader package loads translation files from a server, and the [plugins page](https://ngx-translate.org/resources/plugins/) lists further plugins that add functionality.

## Worth knowing

Only the current major version receives updates, and the project calls older versions end-of-life. A third-party company offers commercial support for end-of-life versions. The company behind the library also sells BabelEdit, a translation editor for ngx-translate files; it is a separate product, and the [FAQ](https://ngx-translate.org/resources/faq/) says the library itself is free, including for commercial use.
