ConfigCat is a hosted service for feature flags and configuration. Teams change flag values in its dashboard, including after the code is deployed, and applications read the values through ConfigCat's SDKs.

For use inside the user's own infrastructure, ConfigCat names the ConfigCat Proxy, a Docker image or standalone executable that caches the config JSON. An on-premise plan of the service is deployed with Docker.

## Worth knowing

ConfigCat's own page says the full service is not open source, and the on-premise plan is arranged through a sales contact.

The EU-only option comes with every plan, and Dedicated plans can choose the US, Canada, UK or Australia.
