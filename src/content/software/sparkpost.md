SparkPost is a hosted email sending service that applications call through an HTTP API to send transactional email. The [developer site](https://developers.sparkpost.com) documents a send call and offers client libraries for several languages. Bird runs the service, and www.sparkpost.com redirects to a Bird product page, while the developer site and sign-up stay under the SparkPost name.

## Worth knowing

The SparkPost security page on bird.com is marked as an inactive archive, so its statements may not describe the current service. The open-source client library is a separate package from the service.
