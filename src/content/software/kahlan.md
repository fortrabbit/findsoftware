Kahlan is a test framework for PHP with a describe-it syntax in the style of RSpec and JSpec. It stubs and monkey patches code directly, and the project says this works without any required PECL extensions.

## Worth knowing

Code coverage analysis needs phpdbg or Xdebug. The documentation site is older than the current release and still gives an earlier PHP requirement, so the requirement that applies comes from the package manifest of the latest release.
