HashBrown is a headless content management system built with Node.js and MongoDB. Multiple projects and environments are part of its structure, so one installation can hold the content for several websites, and locales are set per project. The README describes installing it from the repository with git and npm, or from the published Docker images, and the server runs as a long-running process. The README lists Node.js, MongoDB and ImageMagick as dependencies.

The project is published under the MIT license, and its LICENSE file names Jeppe Zapp as the copyright holder.

## Worth knowing

The homepage the repository names no longer shows the software, so the repository, its README and its wiki are the remaining sources for the project.
