PayPal's developer platform, documented at developer.paypal.com, provides REST APIs, a JavaScript SDK, a React SDK and server SDKs that let a website or app accept PayPal payments. The REST APIs authenticate with OAuth 2.0 access tokens, and the [sandbox guide](https://developer.paypal.com/tools/sandbox/) describes a testing environment with the same API feature set as the live service.

The platform is run by PayPal, Inc., a Delaware corporation in the United States, which names PayPal Holdings, Inc. as its parent.

## Worth knowing

The user agreement on paypal.com applies to U.S. PayPal accounts only. The Developer Agreement names PayPal, Inc. as the contracting entity for the United States.
