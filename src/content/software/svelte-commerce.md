Svelte Commerce is a storefront built with SvelteKit and TypeScript that connects to commerce backends through APIs. Each backend is reached through a connector package under the @misiki scope, covering platforms such as Shopify, WooCommerce, Vendure, Saleor and Medusa, and the default configuration points at a public Litekart demo API.

The built app runs on a Node server, and the README also gives a Docker image and one-click deploy buttons for Netlify, Vercel and ZopDay.

## Worth knowing

The README says none of the connectors has yet been run against a live production instance.
