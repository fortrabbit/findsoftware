Vanilla Calendar Pro is a JavaScript date and time picker written in TypeScript. It can select one date, several dates or a continuous range, show one month, several months side by side or a compact week, and add a 12- or 24-hour time picker. It can also open from an input field, and its labels can be localized.

The homepage says it works with any JavaScript framework or library without extra dependencies, and it lists ready components for Angular, React, Vue and Web Components.
