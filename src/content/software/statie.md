Statie is a static site generator written in PHP. It takes HTML, Markdown and Twig files and generates static HTML pages, and it is installed with Composer. The README links migration guides from Jekyll and from Sculpin.

## Worth knowing

The README states that Statie is deprecated and tells users to use Symfony Static Dumper instead. The repository is archived, and the Packagist record names symplify/symfony-static-dumper as the replacement.
