Bazar adds e-commerce to a Laravel application. It is built on Laravel and on Root, an admin package from the same vendor, and is added with Composer to run as a package inside the application rather than as an application of its own. The [documentation](https://root.conedevelopment.com/docs/extensions/bazar/) sits on the Root site.

## Worth knowing

Bazar provides no REST API and no ready-to-use web shop, so the application builds its own storefront.
