TNTSearch is a full-text search engine written in PHP and installed with Composer. It stores its index in SQLite by default, or in MySQL or Redis, and the README says a search returns document ids that the caller uses to load the records. TNT Studio, based in Zagreb, Croatia, publishes it.

## Worth knowing

The package is a PHP library with no separate search server. The README also describes a Laravel Scout driver as a separate package, which is not part of this record.
