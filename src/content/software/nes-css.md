NES.css is a CSS framework that gives HTML components an NES-style, 8-bit-like look. The stylesheet installs from npm and loads from a CDN, and the project states that it needs no JavaScript. It provides components only, and the page layout is left to the project. B.C.Rikko maintains the project.

## Worth knowing

The README says the code is under the MIT License and the documentation is released under Creative Commons, with no version named. The Creative Commons line covers the documentation only.
