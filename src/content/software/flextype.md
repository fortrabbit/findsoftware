Flextype is a content management system that keeps its content in flat files instead of a relational database. The [what-is page](https://awilum.github.io/flextype/documentation/getting-started/what-is-flextype/) describes it as a hybrid CMS with a REST API for headless use. It is written in PHP and builds on the Slim framework.

Installation is a download of the release, unzipped and uploaded to a web host, as the [installation page](https://awilum.github.io/flextype/documentation/getting-started/installation/) describes. It runs on a web server through PHP, not as a long-running process.

## Worth knowing

The latest release on the repository is labeled alpha.
