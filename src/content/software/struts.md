Apache Struts is a Model-View-Controller framework for Java web applications. A project starts with Maven and optional archetypes, which the [download page](https://struts.apache.org/download.cgi) describes as giving easier dependency management and version upgrade. Views are written in JSP, Velocity or FreeMarker, and the [primer](https://struts.apache.org/primer.html) describes the servlet container that hosts a web application.

## Worth knowing

Some Struts versions are no longer supported, and the project's homepage recommends moving to the latest release. The supported versions and their end-of-life dates are held on endoflife.date, which the record cites.
