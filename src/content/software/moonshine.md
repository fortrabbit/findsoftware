MoonShine is an admin panel for Laravel projects, added to a Laravel application with Composer. Its interface is built with Blade, Alpine.js and Tailwind CSS.

The panel has built-in capabilities for managing users and roles. The [installation guide](https://getmoonshine.app/en/docs/4.x/installation) lists migrations as a setup step that these capabilities need.
