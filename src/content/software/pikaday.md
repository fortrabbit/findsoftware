Pikaday is a JavaScript date picker that attaches a calendar to an input field. Dates are formatted with the JavaScript Date object, or with Moment.js when it is loaded, and the repository includes an optional jQuery plugin.

## Worth knowing

The maintainers archived the GitHub repository and the README says the project has not been actively maintained for years. Pikaday picks a date only, with no time of day.
