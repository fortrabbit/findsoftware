dhtmlxGantt is a JavaScript Gantt chart component for project scheduling, timelines and task dependencies. It supports drag-and-drop editing. The [Community Edition](https://github.com/DHTMLX/gantt/blob/master/README.md) is the MIT-licensed package DHTMLX publishes on npm, and it ships its TypeScript and JavaScript sources, so the library can be built from source. XB Software publishes it.

## Worth knowing

The PRO edition is a commercial product that adds auto-scheduling and critical path to the Community Edition. Its prices are on the [licensing page](https://dhtmlx.com/docs/products/licenses.shtml). PDF, PNG, Excel, iCal and MS Project export run through the DHTMLX online export service.
