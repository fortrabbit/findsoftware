Flasgger is a Flask extension that extracts OpenAPI specifications from the Flask views of an API and serves Swagger UI for them. The Swagger UI is embedded in the extension.

## Worth knowing

The demo site named in the repository answers with a placeholder page, so the repository is the only working source for examples. The README says support for Python 2 ends with an earlier release line.
