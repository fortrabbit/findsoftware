Tiny Slider is a JavaScript library that turns a set of HTML elements into a slider, with carousel and gallery modes, and it can respond to breakpoints, lazy-load images and nest one slider inside another. It works on markup that is already in the page: the page calls its function once the content is there, and calls it again when content is loaded later. A project installs it from npm or bower, and the library's options and methods are documented in the README.

## Worth knowing

The README says the library works in the browser only.
