Makdoc, published as gulp-makdoc, is a task library that builds documents into a static site. It is run with the gulp command and turns Markdown and Handlebars documents into HTML, and Handlebars templates into files such as `index.html` and `sitemap.xml`, decorated with layouts and partials. Document metadata comes from a `model.json` file beside each document, not from YAML front matter. The README shows deploying the built output to GitHub Pages.

## Worth knowing

The repository is archived.
