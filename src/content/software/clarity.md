Clarity is an open source design system that combines UX guidelines, design resources and web components. The core package holds the web components, which the install docs import one at a time into a JavaScript or TypeScript project and then use inside Angular, Vue or other templates. The same repository also held shims for Angular and React, and an open source sans-serif typeface.

## Worth knowing

This record covers the Clarity Core repository, which is archived. Its README says Clarity Core is no longer supported and recommends the project's updated tools and resources, without naming them. The Angular edition of the design system is published from a separate repository that is not archived.
