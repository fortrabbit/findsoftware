maptalks.js is a JavaScript library for integrated 2D and 3D maps. It pitches and rotates 2D maps to add a third dimension, and it is extended through plugins; the [plugin list](https://maptalks.org/plugins.html) names the extensions the project links to. The library runs in browsers, and Node.js can render maps on the server. The [getting-started page](https://maptalks.org/getting-started.html) covers the standalone download and the CDN route.

## Worth knowing

The root README of the repository is a notice that maptalks is moving to maptalks-gl, a separate WebGL and WebGPU map engine still in development. The library itself lives in a package inside the same repository, and that package is the one the homepage documents.
