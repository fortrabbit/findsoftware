tawk.to is a hosted live chat widget that a website embeds with one JavaScript snippet. The vendor's platform places a shared inbox, contact records, a pipeline, tickets, a knowledge base, feedback boards and AI answers around the widget. tawk.to inc. operates the service and says all processing takes place in the United States. A JavaScript API and webhooks are documented for the service.

## Worth knowing

The service is hosted only, with no self-hosted option. The homepage leads with a customer experience suite as well as live chat, so it is unclear whether the widget alone is what this record covers.
