@hello-pangea/dnd is a drag and drop library for lists in React. It is installed from npm, and the project also publishes a UMD bundle that runs directly in the browser. React and React DOM are peer dependencies, so the application that uses the package supplies them.

The README describes react-beautiful-dnd as the original project. Atlassian contributed to it and is no longer involved with this package, and the maintainers listed in the README maintain it.

## Worth knowing

The project's own community page says that the community repositories listed there are built on react-beautiful-dnd and might not work with future versions of this package.
