Bogus is a fake data generator for the .NET languages C#, F# and VB.NET. It is a C# port of faker.js, and its locale data is re-bundled from faker.js. The library is installed from NuGet and runs inside .NET code, where it fills objects with generated values for tests and for seeding databases.

## Worth knowing

Bogus Premium is a paid license for separate add-on packages with extra data sets. The add-ons are not part of the open-source library.
