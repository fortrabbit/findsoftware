Sakura is a classless CSS stylesheet, distributed as sakura.css, that styles plain HTML elements directly, so a page takes its look without class names. A page gets it by linking the stylesheet from a CDN, a downloaded copy or an npm install, and the README describes using normalize.css before sakura as an optional reset. Theming works through variables for a duotone color scheme in the project's SCSS source, and the repository ships several ready-made themes as CSS files in its css folder. A darker theme file can be selected for the dark color scheme with a media attribute on the stylesheet link.
