Contentlayer is a content SDK that validates content files and turns them into type-safe JSON data an application can import. It reads local Markdown, MDX, JSON and YAML files, and runs as part of the Next.js dev server or through its CLI. It is installed with npm and set up in a Next.js project with the next-contentlayer plugin. Its LICENSE names Stackbit Inc. and Johannes Schickling as copyright holders.

## Worth knowing

The README says Contentlayer is no longer maintained because of lack of funding, and it links a fork. The repository is not archived, so the discontinued status rests on that statement alone.
