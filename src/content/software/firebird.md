Firebird is a relational database server with ANSI SQL features, stored procedures and triggers, developed by the Firebird Project as a community project from the InterBase source code. It can run as a service or as an application, and an embedded version is available as a DLL. Windows installers and zip kits, RPM and tar.gz packages for Linux, distribution repositories, a Docker image and build instructions for compiling from source are all published. Users and roles are managed with GRANT and REVOKE, and free support runs through mailing lists.

## Worth knowing

The project states that Firebird is free for commercial and educational use with no license fees. The source is released under the Initial Developer's Public License and the InterBase Public License, both variants of the Mozilla Public License 1.1, and GitHub shows no single license for the repository.
