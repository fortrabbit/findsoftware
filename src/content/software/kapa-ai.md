kapa.ai is a hosted platform that indexes a company's knowledge sources and answers questions over them with AI retrieval. It assembles one knowledge base from the connected sources and keeps it up to date as the content changes. It is deployed as a website widget, Slack and Discord bots, a support form deflector, a Zendesk agent, an API or a hosted MCP server.

## Worth knowing

The service is hosted, and it names US and EU hosting regions. Single sign-on and role-based access sit in the Enterprise plan, which the pricing page describes as the one for governed, global deployments.
