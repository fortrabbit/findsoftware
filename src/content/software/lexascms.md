LexasCMS is a hosted headless content management system for e-commerce sites. Editors work in a web interface to plan and schedule content changes, preview content that has not been published, and personalize what each audience sees. Developers read content through a Content Delivery API that offers both [GraphQL and REST](https://www.lexascms.com/), and the homepage says delivery runs from a global network of edge regions.

The platform connects to WooCommerce, Magento 2 and commercetools, so products and categories from a store can be embedded in CMS content.

## Worth knowing

No installable version of LexasCMS appears on the pages read, so the record has no install method or self-host option. Subscriptions are priced by the users, spaces and roles bought, and the [pricing page](https://www.lexascms.com/pricing/) lists the plans.
