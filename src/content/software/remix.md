Remix 3 is a full-stack web framework made of single-purpose packages built on Web APIs, distributed together as one `remix` package. Its server side routes standard Requests and returns standard Responses for HTML, JSON, redirects, files and streams. The packages run across Node.js, Bun, Deno and Cloudflare Workers, and a new app starts with `npx remix new`.

Remix 3 has its own component runtime and data packages for MySQL, PostgreSQL and SQLite.

## Worth knowing

The README describes Remix 3 as under active development, and the production chapter of the [guide](https://guides.remix.run/production/) is marked unfinished. The project's blog says Remix v1 and v2 were merged into React Router v7; this record covers Remix 3 only.
