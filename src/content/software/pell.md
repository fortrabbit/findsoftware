pell is a WYSIWYG text editor for the web, written in JavaScript with no dependencies. The README includes examples for React and Vue, and its comparison table sets pell against other editors, among them medium-editor, CKEditor, Draft and Froala.

## Worth knowing

The README points to a v2 branch and project board, which are work in progress and not a release.
