Svelte Bits is a collection of animated Svelte components for text, backgrounds and UI. Components are added to a project as source files, either copied by hand or installed with the shadcn CLI or jsrepo from the project's own registry at sveltebits.xyz. The project calls itself an official Svelte port inspired by React Bits, and David Haz maintains it.

## Worth knowing

The license allows use in applications and websites, but the components may not be sold, sublicensed or redistributed. The repository has no versioned releases, so a project's copy of a component is the code it holds.
