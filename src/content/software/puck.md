Puck is a React component that gives an application a drag-and-drop visual editor over the components the app defines. It is an editor library rather than a CMS: Puck does not save anything itself, so the app takes the page data and stores it in its own database.

The editor is installed into an existing React app from npm, and a generator, create-puck-app, creates a starter application.

## Worth knowing

The maintainer, Puck Technologies, Inc., also runs Puck Cloud, a hosted service with its own terms that runs the Puck AI features. It is separate from the MIT-licensed open-source package.
