Odyssey is a connection pooler and request router for PostgreSQL. It sits between applications and a PostgreSQL server. The [quick start](https://pg-odyssey.tech/quick-start.html) installs it from the PGDG Debian and Ubuntu packages, from a Docker image on ghcr.io, from a local Docker image build or from a local build, and the packaged version runs as a systemd service. Odyssey can check pool users with PAM or LDAP.
