MJML is a markup language and an engine that compiles MJML markup into responsive HTML email. Authors write components such as sections, columns and text, and the engine outputs HTML. The engine is installed from npm and runs in Node.js, and a separate browser build runs it in the browser. A command line tool compiles a file to HTML. Mailjet SAS develops it, and the [documentation](https://documentation.mjml.io/) is the project's own.

## Worth knowing

The project also offers a hosted MJML REST API beside the engine, and an online editor at mjml.io for trying MJML without installing anything.
