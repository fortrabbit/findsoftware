Reshaped is a React component library with a matching Figma library, written in TypeScript and installed with npm. Its React package sits in a monorepo, where other packages share the same repository.

## Worth knowing

The reshaped package declares React 18 or 19 and postcss 8 as peer dependencies, so the application has to provide a matching React version.
