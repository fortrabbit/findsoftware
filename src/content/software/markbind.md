MarkBind generates static websites from Markdown text. It installs globally from npm as markbind-cli, and per the [deployment guide](https://markbind.org/userGuide/deployingTheSite.html) a generated site can be deployed by uploading its files to any web server.

## Worth knowing

The [about page](https://markbind.org/about.html) says the project is based at the National University of Singapore, School of Computing.
