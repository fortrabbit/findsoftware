staticjinja is a Python library for building static sites with the Jinja2 template engine. Installing it from PyPI provides two things: a command line interface for basic needs, and a Python library for custom build scripts.

The command line renders the templates in a templates folder into an output folder, and a watch command recompiles them when they change. Both folders can be set with options.
