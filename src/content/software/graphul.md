Graphul is a web framework written in Rust. The README describes it as an Express inspired framework, a model it follows rather than a parent project. An application starts its own server with `app.run`, so it runs as a long-lived process. It is added to a Cargo project with `cargo add graphul`, and the README shows templates written with Askama.

Community chat is on a [Discord server](https://discord.gg/3WCMgT3KCS) that the README links. The documentation is on the [project site](https://graphul-rs.github.io/).
