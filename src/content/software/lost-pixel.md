Lost Pixel is an open-source visual regression testing tool for Storybook, Ladle and Histoire stories and for application pages. The lost-pixel npm package runs the tests, and the README sets it up with a project config file and a GitHub Action that runs on every push. A managed version, Lost Pixel Platform, is offered alongside the open-source package.

## Worth knowing

The README opens with a notice that the team is joining Figma and that the product is being sunset. The GitHub repository is archived.
