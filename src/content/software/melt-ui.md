Melt UI supplies builders, functions that return a collection of properties for the project's code to assign to any element or component. The README describes it as a base for the project's own styles and components. It is installed with npm as @melt-ui/svelte, and a CLI is offered to help start a project. The MIT-licensed code is maintained by Thomas G. Lopes.

## Worth knowing

The introduction page says Melt UI is in its early stages and that minor releases may contain breaking changes until the first stable major release is ready. The homepage links to a newer line that calls itself the next generation of Melt UI and is built for a later Svelte release, and no release of that line is listed here.
