APIrocket is a hosted service from E-xisto Diseño Web S.L. that builds a GraphQL API for a project from a data model defined without code. Each project gets its own API key and one GraphQL endpoint shared by all projects, and the [API documentation](https://docs.apirocket.io/api/) describes sending queries with a bearer token from curl, JavaScript and Node.js.

Content is edited online in the service's headless CMS, which supports content in several languages. An API Explorer opens from the project view to run queries and generate mutations against the data model.

## Worth knowing

The service is marked as beta on its homepage. Its plans set limits per project, per user, per locale and per document, and the API enforces a rate limit.
