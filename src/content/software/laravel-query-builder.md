Laravel Query Builder builds Eloquent queries from the filter, sort, include and field parameters of an API request. Its query builder extends Laravel's default Eloquent builder, so the methods and macros of that builder stay available, and the parameter names follow the JSON API specification as closely as possible. The [documentation](https://spatie.be/docs/laravel-query-builder/v7/introduction) shows it working together with existing queries.
