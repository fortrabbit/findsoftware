Rickshaw is a JavaScript toolkit for creating interactive time-series graphs. It is built on d3, so graphs are drawn as SVG and styled with CSS. The toolkit supplies the pieces a graph is put together from: renderers, legends, hovers and range selectors.

## Worth knowing

d3 has to be loaded alongside the library, and a few extensions also need jQuery and jQuery UI.
