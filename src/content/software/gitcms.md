GitCMS is a hosted content management service for websites whose content lives in a Git repository. It connects to the repository through a GitHub App, reads and writes the repository directly, and gives team members, clients and AI agents a visual editor and roles such as editor, reviewer and viewer. The product's homepage lists Astro, Next.js, TanStack Start, Hugo and Jekyll among the static site frameworks it works with, and the documentation says a repository can hold several sites.

## Worth knowing

Use requires a license per site, bought once and not expiring. The pricing page says "Today: pay once. Soon: monthly.", so the billing model is expected to change.
