Tinkerer is a Python blogging engine built on Sphinx. Posts and pages are reStructuredText files in a blog directory. The tool builds them into a static website, as the [deployment page](https://vladris.com/tinkerer/doc/deploying.html) states. It is installed with `pip install tinkerer`.

## Worth knowing

The README says Tinkerer is retired in favor of Baku, which it names as its replacement, and the repository is archived on GitHub. The record is marked discontinued.
