React Router is a router for React that, in its framework mode, adds server rendering, static pre-rendering and data loading for full-stack web apps. The framework mode runs on Vite, and a project starts from the create-react-router template. The output can be a client-only single-page app, routes rendered by a Node process, or routes pre-rendered to static HTML files. Server rendering runs through the `react-router-serve` command, which keeps a Node process running, so such routes cannot go on static hosting; client-only and pre-rendered output need no server. The Remix team maintains the project under a steering committee, and the Remix team joined Shopify in 2022. What was planned as the next major version of Remix was released as React Router instead.
