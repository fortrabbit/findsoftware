Matter.js is a 2D rigid body physics engine that runs in the browser or on Node.js. It covers compound bodies, collisions, friction, restitution, constraints and gravity, and a canvas renderer draws the bodies. The wiki shows how to use an app's own game and rendering loops with the engine.

Liam Brummitt maintains it with contributors, and plugins can extend the engine.
