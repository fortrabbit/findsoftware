SkyDocs is a documentation builder written in Java. It turns Markdown files kept in a project's content folder into a complete website, rendered with the jtwig template engine, and it can generate a multi-language documentation. The output is static files, and the README says the site can be hosted anywhere. The builder is run on a developer's machine, with a command to serve the site locally.

## Worth knowing

The GitHub repository is archived. The project's site still answers and serves the documentation.
