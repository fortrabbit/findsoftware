Keep is an open-source AIOps platform for alert management. Monitoring tools such as Grafana and Datadog send alerts to Keep through webhooks, and the [Docker deployment guide](https://docs.keephq.dev/deployment/docker) describes starting it with Docker Compose.

## Worth knowing

Code under the ee/ directory is licensed under the Keep Enterprise Edition license, and the rest of the repository is MIT. The [pricing page](https://www.keephq.dev/pricing) offers Keep Cloud as a managed option beside self-hosting.
