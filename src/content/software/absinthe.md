Absinthe is a GraphQL toolkit for Elixir that covers the GraphQL Working Draft specification. Schemas are written with macros that check their structure at compile time, and the query processing pipeline can be configured. Plug and Phoenix integrations serve the API, and the GraphiQL tool can run from the application itself. The package is installed from Hex by adding it to a project's mix.exs file, and the source is on GitHub.
