CKEditor 5 is a rich-text editor framework for JavaScript, written in TypeScript and built from packages that each add a feature. It uses an MVC architecture and a custom data model. The README describes editors ranging from document editors similar to Google Docs to chat-style inputs, and it names collaboration support among its features.

An editor is installed from npm, loaded from a CDN, or copied into a project as a ZIP file. The [getting started guide](https://ckeditor.com/docs/ckeditor5/latest/getting-started/index.html) also covers integrations with Angular, React and Vue.

## Worth knowing

The framework is offered under the GPL or under a commercial license from CKSource. The [licensing page](https://ckeditor.com/legal/ckeditor-licensing-options/) names paid Premium features under the commercial license, and the documentation marks many features as premium.
