React Bootstrap provides Bootstrap components as React components. Each component is built as a React component and relies on the Bootstrap stylesheet, so Bootstrap themes apply to it. The project installs from npm next to the bootstrap package. The package is written in TypeScript.

## Worth knowing

A new major line is in beta on npm, and the docs site labels that beta as the current version; the stable release is the one this record tracks.
