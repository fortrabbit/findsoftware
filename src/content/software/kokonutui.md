Kokonut UI is a collection of React components built with Tailwind CSS, Motion and shadcn/ui. The project describes itself as a shadcn/ui registry, so a project adds components with the shadcn CLI, and each component lands in the project as source code the project owns. The homepage says it is built by Dorian Baffier, and the repository belongs to the kokonut-labs organization.

The project publishes no release tags and no npm package; its install path is its own shadcn registry. A paid Pro tier adds components beyond the free collection.
