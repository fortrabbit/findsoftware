vfsStream is a stream wrapper for a virtual file system, used in PHP unit tests to mock the real file system. It can be used with any unit test framework, such as PHPUnit or SimpleTest, and is added to a project as a Composer dependency.

## Worth knowing

The homepage named in the package metadata no longer resolves, so this record is a stub until the project's own site or a named successor can be read. The documentation is the project's GitHub wiki. On Linux based systems the PHP Posix extension is required, and some distributions disable it by default.
