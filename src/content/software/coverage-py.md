Coverage.py measures code coverage for Python programs, typically during test execution. It is installed with pip. The project is maintained by Ned Batchelder with contributors, and it is open source under the Apache 2.0 license.

## Worth knowing

Tidelift sells an enterprise subscription that covers Coverage.py along with many other packages. The project's own sources describe no separate edition.
