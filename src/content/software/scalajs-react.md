scalajs-react is a Scala.js library that lifts React into Scala, written to be as type-safe and Scala-friendly as possible. The [usage guide](https://github.com/japgolly/scalajs-react/blob/main/doc/USAGE.md) says components come with a method for rendering them into the DOM, so the library runs in the browser.

It is added to an sbt build as Maven artifacts, with a core module and further modules listed on the modules page. The maintainer named in the project's POM is David Barri.

## Worth knowing

The README lists minimum requirements for React, Scala and Scala.js, and the usage guide points to a separate prototype repository for setting up React itself.
