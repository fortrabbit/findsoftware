Mockall is a mock object library for Rust. It generates test doubles for traits and structs, so a unit test can set what a dependency returns in place of the real object. The README says the crate is typically used only by unit tests and shows it added as a development dependency. It is written in stable Rust, and the README says the minimum supported Rust version changes only together with a major or minor version bump.
