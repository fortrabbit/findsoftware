Builder.io is a hosted platform for visual editing and headless content, published by Builder.io, Inc. Its headless CMS is delivered through REST and GraphQL APIs, with a drag-and-drop visual editor in the hosted interface. The [developer docs](https://www.builder.io/c/docs/intro) cover the SDKs that render that content in front-end code.

## Worth knowing

The GitHub repository holds the SDKs, examples, starters and plugins rather than the platform, and its MIT license covers that code only. The sources name no self-hosted build of the platform. The homepage presents the company as an AI agent platform, and the CMS features described here are the ones its headless CMS page lists.
