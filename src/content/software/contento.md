Contento is a hosted headless CMS for marketing websites. Content is edited in a hosted admin panel, and it is read through a REST Content API. The JavaScript client for that API is published as @gocontento/client, and the Next.js toolkit provides the visual preview.

The visual preview uses Next.js draft mode to show edits made in the Contento editor before they are published. Content can be held in several locales, with URI-based routing or a language key for domains, and some plans allow more than one site. Sign-in with Google and GitHub accounts is available on all plans.

## Worth knowing

The Community plan is stated as free forever. Auto translation is listed on the pricing page as a beta add-on, and the visual preview is part of the Next.js toolkit.
