dc.js is a charting library for JavaScript that works natively with crossfilter and renders its charts with d3.js. The project describes it as a library for data visualization and analysis in the browser. Installation is through npm or a CDN copy, and the project's GitHub Pages site holds the examples and the API reference.

## Worth knowing

The README says the project is seeking new maintainers. The current line does not support Internet Explorer.
