ArkType is a TypeScript validation library that defines validators with TypeScript-like string and object syntax and checks data against them at runtime. The package is published from a monorepo, and its docs describe conversion to and from JSON Schema, support for Standard Schema validators, and integrations with tRPC and Drizzle.

The repository also holds the packages for the schema, utilities, regular expressions and attestation tooling.

## Worth knowing

The setup page requires TypeScript 5.1 or higher and an ES module setup, with strict null checks in the TypeScript configuration.
