Chyrp Lite is a blogging engine for running a blog on one's own web server. It stores posts in a database. The release archive is uploaded to the web server and set up with the installer, or the project runs with Docker Compose. Themes use the Twig template engine, posts can be plain text, Markdown or raw markup, and the administration console manages users and visitors through a rights model. The [wiki](https://chyrplite.net/wiki/) holds the documentation.
