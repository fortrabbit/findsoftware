Hastie is a static site generator written in Python. It takes a folder of Markdown files, applies Jinja templates and writes an HTML site to an `output` folder, which can be published anywhere. It is installed with pip from its GitHub repository, not from PyPI. It began as a Go project, and the Python version is a rewrite. Marcus Kazmierczak holds the copyright under the MIT license.
