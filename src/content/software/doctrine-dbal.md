Doctrine DBAL is a database abstraction layer for PHP that gives code one object-oriented API for database access, with schema introspection and management on top. The [introduction](https://www.doctrine-project.org/projects/doctrine-dbal/en/4.5/reference/introduction.html) lists Db2, MariaDB, MySQL, Oracle, PostgreSQL, SQL Server and SQLite as supported vendors, and it says that Composer provides the class loader the library needs.

The DBAL can be used without the Doctrine ORM, as the same introduction states. The Doctrine Project maintains it.
