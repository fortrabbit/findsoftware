deco is a git-based visual CMS for TypeScript sites. The repository holds a Deno framework that renders pages with server-side JSX templates, and the content is kept in git alongside the code. Roles and permissions limit what content editors can change. The README describes deployment to any Deno-compatible host and a hosted visual editor.

The [developer docs](https://docs.decocms.com/) now describe a different framework, Blocks 7.x, as the released default and call the Fresh runtime and the former admin retired. They link other repositories for it, so which repository holds the current deco CMS is in doubt and the record stays a stub.

## Worth knowing

The README says the editor is hosted, and that self-hosting it was planned for early 2025. A managed hosting tier is also described.
