Umami is a web and product analytics platform built in TypeScript on Node.js, with its data in PostgreSQL. The database connection string is the only environment variable the [configuration docs](https://umami.is/docs/environment-variables) require. The [install guide](https://umami.is/docs/install) covers a source install, Docker Compose, a Docker image and a Kubernetes Helm chart. Umami Software, Inc. develops the platform and also runs Umami Cloud, a hosted version of it.
