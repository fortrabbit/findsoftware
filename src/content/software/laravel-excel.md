Laravel Excel is a PHP package for Laravel that exports collections, queries and views to Excel or CSV files and imports workbooks into Eloquent models. It wraps PhpSpreadsheet, which reads and writes the files, and it is installed with Composer. The [documentation](https://docs.laravel-excel.com/4.x/getting-started/) covers exports and imports.

## Worth knowing

Besides the MIT license, the project says the package is "licensed as Postcardware": it asks for a postcard from your hometown once the package reaches production.
