Carbon is a PHP library that extends the built-in DateTime class with an API for creating, changing and comparing dates and for formatting them. Dates are immutable: each operation returns a new instance. The library covers time zone conversion, human-readable differences such as "2 days ago", and output in more than 200 languages. It is installed with Composer, or by extracting the release archive into a project and requiring its autoload file.

## Worth knowing

The repository is moving from briannesbitt/Carbon to CarbonPHP/carbon. The README says code on both is kept up to date and asks people to search issues and pull requests in both.
