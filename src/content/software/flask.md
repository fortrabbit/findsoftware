Flask is a WSGI web application framework for Python, and its pages are rendered with Jinja templates. The [deployment guide](https://flask.palletsprojects.com/en/stable/deploying/) says a WSGI server runs the application, so a deployed Flask app is a long-running process rather than a set of static files. Pallets, an open-source community organization, develops and supports the framework.
