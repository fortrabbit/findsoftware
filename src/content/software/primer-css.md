Primer CSS is the CSS implementation of GitHub's Primer design system. It is published as the npm package `@primer/css`, written in Sass using SCSS syntax, and installed with npm.

## Worth knowing

The repository's README says the project is in KTLO (keep the lights on) mode. It asks users to use the existing utility classes where needed and points to [Primer React](https://github.com/primer/react) or, if necessary, Primer ViewComponents for more complete patterns that include styling and markup.
