Rough Notation is a JavaScript library that creates and animates hand-drawn annotations on a web page. The README says it uses RoughJS for the hand-drawn look. Third-party wrappers for React, Svelte, Vue, Web Components and Angular exist, and the README lists them.

## Worth knowing

The README says annotating an element adds an SVG element as a sibling, which can cause trouble in places such as a table.
