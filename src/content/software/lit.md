Lit is a JavaScript library for building web components, and its homepage states that every Lit component is a native web component. The library is installed from npm as the `lit` package, and it adds reactive properties and declarative HTML templates to the component model.

Lit SSR renders Lit components and templates to static HTML markup in non-browser JavaScript environments such as Node. The [SSR documentation](https://lit.dev/docs/ssr/overview/) describes the package as part of the Lit Labs family of experimental packages.
