FOSElasticaBundle is a Symfony bundle that connects a Symfony application to Elasticsearch through the Elastica client library. It is installed with Composer. It requires a recent Symfony release. Its persistence drivers are named for Doctrine ORM, MongoDB and PHPCR. The [documentation](https://github.com/FriendsOfSymfony/FOSElasticaBundle/blob/v7.2.0/doc/index.md) describes setup and usage.

## Worth knowing

The README states that earlier versions of the bundle are not maintained anymore.
