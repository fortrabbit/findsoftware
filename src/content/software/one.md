One is a PHP framework that runs under php-fpm or in Swoole. Under Swoole it is a resident process, which the README starts in daemon mode with a script in the project. Sessions can be used over HTTP, WebSocket, TCP, UDP and the command line. Projects are created with Composer from the one-app skeleton, as the [README](https://github.com/lizhichao/one/blob/master/README.md) shows.
