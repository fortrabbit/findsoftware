JTL-Shop is online shop software from JTL-Software-GmbH, written in PHP. The installation package is uploaded to the web space by FTP, and the installer then sets up the shop on a MySQL or MariaDB database. The admin back end is where layout, templates, plugins and central shop settings are managed, and an extension store offers plugins and templates. Orders from the shop are transferred to JTL-Wawi, the maintainer's ERP software. The maintainer also offers hosting for the software.

The software is sold in editions: the Community Free Edition leaves hosting to the operator, while the purchased editions differ in the number of shops and modules they include.

## Worth knowing

JTL-Shop 5 ships with unencoded source code and runs without an IonCube loader; that describes the code's encoding, not its license. The public GitLab project carries two statements: LICENSE.md says "Released under MIT License" and includes/composer.json says "proprietary". No page read settles which terms apply to the whole package.
