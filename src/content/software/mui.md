Material UI is a React library of components that follows Google's Material Design. A project installs the @mui/material package from npm with its Emotion styling packages and imports the components into its React code. A theme setting switches the component text to another locale. The npm package comes from the mui/material-ui repository, which also holds Joy UI.

## Worth knowing

MUI X is a separate product with paid plans listed on the pricing page, beside a Community plan that includes Material UI.
