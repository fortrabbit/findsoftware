EasyDeployBundle is a Symfony bundle that a developer installs with Composer into a Symfony application. It deploys that application over SSH from the developer's machine to one or more servers. The [installation guide](https://github.com/EasyCorp/easy-deploy-bundle/blob/master/doc/installation.md) describes adding it to a Symfony project as a development dependency, and the repository's README lists what the local machine and the remote servers need.

## Worth knowing

The vendor's website no longer shows the bundle, so this record is kept as a stub, hidden from the default view, until the project is checked again.
