Tabler is a dashboard UI kit built on Bootstrap 5, with layouts, demo pages and components for admin panels, dashboards and web apps. Every component has a dark color scheme, every stylesheet ships in an RTL version, and the kit can be customized with Sass or CSS custom properties. The package bundles third-party plugins for charts, date pickers, selects and editors in its dist/libs folder.

## Worth knowing

The homepage sells a premium HTML admin template and a paid package under a personal and commercial license. The bundled ApexCharts plugin has its own terms: organizations under a revenue limit use it for free under a Community license, and larger organizations pay. Redistributing it needs a separate OEM license.
