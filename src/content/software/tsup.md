tsup is a TypeScript library bundler that needs no configuration, powered by esbuild. It is installed locally in a project with npm, yarn or pnpm.

## Worth knowing

The README states that the project is not actively maintained anymore and suggests tsdown instead. Releases have continued after that notice.
