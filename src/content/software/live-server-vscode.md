Live Server is a Visual Studio Code extension that launches a local development server with a live reload feature for static and dynamic pages. It is installed from the VS Code Marketplace and is maintained by Ritwick Dey.

## Worth knowing

The server runs on the developer's computer. The README points to a separate extension for server-side pages such as PHP.
