Canvas Editor is a rich text editor that draws its document on an HTML canvas, with an SVG backend available through an editor option. The scoped npm package is imported into a page, and the editor is created on a container element with an options object that holds the document's content. The README and the documentation describe pagination with headers, footers and page numbers, tables, images, form controls, a table of contents and print output built from the canvas rendering.

The editor is a browser library, and its documentation is published in English and Chinese.
