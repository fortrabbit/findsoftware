Strawberry is a GraphQL library for Python. Its README describes it as based on dataclasses, and the docs say it is built on Python's dataclasses and type hints, so a GraphQL type is written as a type-annotated dataclass.

The [server guide](https://strawberry.rocks/docs/guides/server) describes a built-in development server for trying an API out, started with a command. The README also provides a Django view for adding a GraphQL endpoint to a Django application.
