ZIO HTTP is a Scala framework for building HTTP clients and servers, built on ZIO. The project's own site carries its documentation.

Projects depend on the zio-http artifact through sbt and need JDK 17 or higher. A server built with it binds to an address and port and keeps listening, by default on all addresses. The project is maintained by the ZIO Maintainers and licensed under Apache 2.0.
