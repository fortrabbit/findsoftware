Yamada UI is a React component library that its homepage describes as a design system with components and advanced styling. Its repository describes it as built with React and Emotion. The [get-started guide](https://yamada-ui.com/docs/get-started) covers installing the npm package and a CLI setup, and the same guide has separate steps for Next.js, Vite, React Router, TanStack Start and TanStack Router.

## Worth knowing

The package declares React 19 as a peer dependency, and the guide says React 18 or earlier must be upgraded first. The repository holds several packages, so the registry figures on this page are for the React package alone.
