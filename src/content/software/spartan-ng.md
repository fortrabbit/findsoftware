Spartan is a set of accessible UI primitives and styled components for Angular. The install model has two parts: the behavior comes from an npm package, and the styled layer is copied into the project's code by a CLI added as a dev dependency. The [installation guide](https://spartan.ng/documentation/installation) describes both parts. The project's documentation says the components are SSR compatible and zoneless ready.

## Worth knowing

Spartan requires Tailwind CSS. The repository also holds spartan/stack, an optional full-stack set built on AnalogJs, which this record does not cover.
