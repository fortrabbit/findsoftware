validator is a Go package that checks struct and field values against rules written as struct tags, with customizable error messages that are aware of i18n. The README describes it as the default validator for the gin web framework. Dean Karn holds the copyright.

## Worth knowing

The README has a "A Call for Maintainers" section that asks for people to maintain the package. It does not declare the project ended.
