Redis Commander is a Node.js web application for viewing, editing and managing the data of Redis servers from a browser. Its project homepage names Joe Ferner as its maintainer.

It installs globally with npm and then runs as a web application. The README also describes a Docker image on the GitHub Container Registry and a Helm chart that is installed from a local checkout of the repository.

## Worth knowing

The npm package's latest version is behind the repository's newest tag, so an npm install can differ from the code in the repository. The README says new versions are not published to Docker Hub, so the container image comes from the GitHub Container Registry only.
