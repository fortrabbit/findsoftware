BagelDB is a hosted content platform from Bagel Studio that the docs describe as a database that feels like a headless CMS. Collections are managed in the BagelDB admin and read through a Content REST API, and user groups hold rules per collection.

The only repository under the project's GitHub organization holds MIT-licensed client libraries, including a Nuxt.js client, not the platform itself.

## Worth knowing

The service is hosted and has a free plan, described alongside paid plans on the [pricing page](https://bageldb.com/pricing). The homepage also lists webhooks and realtime data, which the record does not otherwise describe.
