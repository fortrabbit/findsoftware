Oracle ADF is a Java EE application framework from Oracle for building enterprise web applications. It provides infrastructure services out of the box and a visual, declarative development experience, with Oracle JDeveloper as the development environment. An ADF application is deployed to an application server that has the ADF runtime installed. Oracle's documentation describes the current release as running on a newer platform than the previous one, with the same development features.

## Worth knowing

Applications run from JDeveloper in its Integrated WebLogic Server do not need the runtime installed separately. Deploying to a standalone server does, and the deployment guide describes that as a set of Oracle Fusion Middleware installers for WebLogic Server.
