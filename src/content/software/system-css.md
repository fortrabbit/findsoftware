system.css is a CSS library for building interfaces that resemble Apple's System OS, based on System 6. It uses no JavaScript and is meant to work with any front-end framework, and most of its styles can be overwritten for deeper customization. The README names 98.css as its inspiration.

## Worth knowing

The README calls the library still in beta and warns that some components may be missing.
