SurveyJS Form Library is a JavaScript library that renders forms and surveys from JSON definitions in the browser, for React, Angular, Vue and plain JavaScript applications. The application collects responses in the browser and sends them to whatever backend or database it uses; the library runs no backend of its own. It is published on npm as a set of packages: the framework-independent core holds the form model, and framework packages render it. The [documentation overview](https://surveyjs.io/form-library/documentation/overview) describes the rendering and data-flow model, and the [source repository](https://github.com/surveyjs/survey-library) holds the code.

## Worth knowing

The company that publishes the library also sells Survey Creator, PDF Generator and Dashboard. Those components are proprietary, outside the MIT license, and need a developer license under the company's end user license agreement.
