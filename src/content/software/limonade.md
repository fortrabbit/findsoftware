Limonade is a PHP micro framework for rapid web development and prototyping, copied into the application rather than installed through a package manager. The project site describes installation as downloading the latest stable version and copying the contents of its lib folder into the project. The [README](https://github.com/sofadesign/limonade/blob/master/README.mkd) is the main documentation. Routes combine an HTTP method, a URL pattern and a callback.
