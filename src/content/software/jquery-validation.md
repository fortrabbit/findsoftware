jQuery Validation Plugin adds client-side validation to HTML forms on pages that already use jQuery. It ships a set of validation methods and an API for writing custom ones, and its error messages come translated into other languages.

## Worth knowing

The project's reference says the plugin can never replace server-side validation. The site also says Markus Staab took over maintenance of the codebase from its original author, with Brahim Arkni assisting later.
