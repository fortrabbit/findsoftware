Forms.md is a JavaScript library for building multi-step forms and surveys inside a web page or web app, formerly called Blocks.md. A form is defined in code with a Composer class, or in a Markdown-like text syntax, and a Formsmd object renders it into a container element on the page. Each answer set is posted to an endpoint the developer names. The library runs in the visitor's browser, and the project's own pages say it stores nothing itself: the developer provides the endpoint and the storage for submissions.

## Worth knowing

The pricing page sells a Pro licence that removes the Forms.md branding from forms, so a form built without it shows that branding. The project also ships a WordPress plugin, which its own site presents as a separate product.
