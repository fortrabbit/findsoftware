Foundation for Emails is a framework for responsive HTML emails, formerly known as Ink. It supplies grid, component and typography styles that render in email clients, Outlook included. Emails can be written with the Inky templating language, which converts HTML tags into the table markup that email clients need, and the Foundation stack workflow also includes Handlebars. The [documentation](https://get.foundation/emails/docs/) describes a CSS version and a Sass version.

## Worth knowing

The README says the project will merge into Inky and that new feature development happens there, while this repository "will continue to receive maintenance updates". The Sass version requires Node.js for its build, and the output is HTML and CSS files.
