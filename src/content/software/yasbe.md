YASBE is a static blog generator written in Python. It renders a blog from Mako templates and writes the result to a `www` directory. A make target builds the blog and serves it on localhost for preview.

## Worth knowing

The README says the engine was made to be modified, with no themes or plugins shipped. The repository has no tagged release.
