UploadThing is a hosted file upload service for web applications. Authentication happens on the application's own server, and the upload itself goes to UploadThing's servers. The [documentation](https://docs.uploadthing.com/) covers the framework adapters and frontend libraries that connect an app to the service, and the service has a dashboard for managing and tracking uploaded files.

## Worth knowing

No self-hosting route was found in the documentation or the repository README, so the record treats UploadThing as a hosted service only.
