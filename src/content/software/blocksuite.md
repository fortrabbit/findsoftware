BlockSuite is a toolkit for building editors and collaborative applications. It has a headless framework and a set of prebuilt editor components built on it.

TOEVERYTHING PTE. LTD. maintains it under the Mozilla Public License 2.0. The [quick start](https://blocksuite.io/guide/quick-start.html) names the presets package from npm as the source of prebuilt editors.

## Worth knowing

BlockSuite originated from the AFFiNE knowledge base, which uses it.
