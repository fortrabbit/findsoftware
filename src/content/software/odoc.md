odoc is a documentation generator for OCaml. It reads the doc comments in OCaml source files and in .mld files and outputs HTML, LaTeX and man pages. The README gives opam as the way to install it and Dune as the way to generate a project's documentation. The [odoc documentation](https://ocaml.github.io/odoc/odoc/index.html) describes the markup syntax. The odoc distribution also contains sibling packages: Sherlodoc for search, odoc-driver, odoc-parser and odoc-md. The copyright holders are Thomas Refis, Leo White and David Sheets, and the README names Jane Street and Tarides as funders of the ongoing development.
