Shepherd is a JavaScript library that guides users through a web app with product tours and onboarding steps: dialogs attach to elements in the interface, highlight them with a modal overlay and walk users through what to do next. The library runs in the browser of the application that embeds it. Its core works without a framework, and the project lists wrappers for React, Angular, Vue and Ember.

A page can load Shepherd from npm or pull a release from the jsDelivr CDN, and each GitHub release carries the built files.

## Worth knowing

The library is dual-licensed. Open-source, personal and non-commercial use fall under AGPL-3.0, and commercial use needs a commercial license that the project sells on its pricing page.
