WebdriverIO is a test automation framework that runs on Node.js and drives web browsers, mobile apps and desktop apps. It supports end-to-end, unit and component tests, and runs them locally or on cloud services. The [getting started guide](https://webdriver.io/docs/gettingstarted) describes a configuration wizard that asks what to test, which framework and reporters to use, and installs the rest.

The project says it is run by its community under the OpenJS Foundation and has no paid tier.

## Worth knowing

Enterprise support is available through a Tidelift subscription, which the README names.
