zend-search-lucene is the Lucene search component of Zend Framework 1, published as its own Composer package for PHP. The README says the package is part of Zend Framework 1, and that it does not exist in Zend Framework 2, so users can keep using it without requiring the entire framework.

## Worth knowing

The release fields on this record show the newest version published. The Zend Framework site says the framework is now the Laminas Project.
