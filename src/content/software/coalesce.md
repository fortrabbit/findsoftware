Coalesce is a full-stack framework for ASP.NET Core and Vue, which its homepage calls a meta-framework for both. It generates API controllers, DTOs and TypeScript from Entity Framework Core models, and it generates admin pages for viewing and editing the data. A project is created with `dotnet new install IntelliTect.Coalesce.Vue.Template` and then generated with `dotnet coalesce`, and the front-end tooling needs Node.js and pnpm. IntelliTect is named in the license file and as the author of the NuGet package, and the source is published under the Apache License.
