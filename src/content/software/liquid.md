Liquid is a template engine written in Ruby for the Liquid template language, which Shopify created. The README says it was written to be non evaling and secure, so users can edit templates without their code running on the server, and to be stateless, with separate compile and render steps.

The repository belongs to Shopify's GitHub organization. The homepage names Shopify themes among its uses.
