visx is a collection of reusable low-level visualization components. It uses d3 for calculations and React for updating the DOM. The repository is a monorepo that holds every visx package, and the README says a project can pick the packages it needs.

## Worth knowing

The packages take React as a peer dependency, so the app that uses them must provide React.
