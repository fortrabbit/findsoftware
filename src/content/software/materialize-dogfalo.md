Materialize provides CSS styles and JavaScript behaviors for web pages and follows Google's Material Design language. This repository is the original project, under the Dogfalo GitHub account. The README lists npm, cdnjs, a release download and Meteor as install routes, and the [getting started guide](https://materializecss.com/getting-started.html) walks through the setup.

## Worth knowing

The project's own pages do not say it has ended. The fork MaterializeWeb says on its own about page that the original developers were inactive and that it continues the project under its own repository and name.
