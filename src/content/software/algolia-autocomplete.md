Autocomplete is an open-source JavaScript library from Algolia, Inc. for building autocomplete experiences, and it lives in a monorepo on GitHub. The README recommends the @algolia/autocomplete-js package over the core package, and the same repository publishes plugins for recent searches, query suggestions and Algolia Insights. The README says the library works with any Virtual DOM solution, including JavaScript, Preact, React and Vue, and the [documentation](https://www.algolia.com/doc/ui-libraries/autocomplete/introduction/what-is-autocomplete/) describes its sources and API.
