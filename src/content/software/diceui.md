Dice UI is a set of accessible React components that extend shadcn/ui, written by Sadman Sakib. Its components are installed the way shadcn/ui components are installed, so the code is copied into the user's project, where it can be changed. The repository is a monorepo of per-component packages, such as the combobox and the mention packages. The introduction credits Base UI as the default component primitives and Radix UI as the alternative.

## Worth knowing

Each component is installed on its own as a shadcn registry item, such as the action bar, rather than as one npm package, so a project adds the components it uses one at a time.
