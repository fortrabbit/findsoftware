pystatic is a static site generator that builds a blog from Markdown posts, one file per post, and from HTML and CSS templates. The build runs as a Python script started from the command line, and the complete website is written to a site folder. The project is installed by cloning its GitHub repository. The owner of the repository has archived it and states that they no longer maintain the tool.
