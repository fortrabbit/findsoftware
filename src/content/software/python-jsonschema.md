jsonschema is a Python implementation of the JSON Schema specification. A program gives it a schema and a document, and the library reports whether the document conforms. The [documentation](https://python-jsonschema.readthedocs.io/en/stable/) says validation errors can be queried programmatically, so code can see which properties or items failed.

The README lists support for Draft 3 through Draft 2020-12 and lazy validation that can report every error. A command-line tool, check-jsonschema, is a separate package.
