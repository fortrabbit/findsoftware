MudBlazor is a set of Material Design components for Blazor apps, written in C#. A project adds the NuGet package to a Blazor application, with the NuGet Package Manager or the dotnet CLI, or starts from the project's dotnet templates, and uses the components in Razor markup. The components can be translated through a localization service.

## Worth knowing

The project file names .NET 8 as its lowest target, so an application needs .NET 8 or later. The README says that static rendering is not supported.
