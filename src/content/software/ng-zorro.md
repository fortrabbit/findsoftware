NG-ZORRO is an Angular UI component library based on Ant Design, published on npm as ng-zorro-antd and developed in the NG-ZORRO organization on GitHub. The Angular CLI adds it to a project with `ng add ng-zorro-antd`, and npm installs it as well. The documentation lists Server-side Rendering and modern browsers as supported environments, and the library keeps the same major version as @angular/core.
