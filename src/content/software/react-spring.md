react-spring is a spring-physics animation library for React. The README says it supports `react-dom` and `react-three-fiber`, with a separate package for each target, and animations can be written declaratively or imperatively.

The source is a monorepo that holds several packages, and the install guide names the web package as the target for a React DOM app.

## Worth knowing

A newer major line is in prerelease on GitHub.
