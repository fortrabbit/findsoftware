Mavo is an HTML-based language for building small data-driven websites and web applications. A page is written in HTML and CSS with Mavo attributes, and Mavo extends the syntax to describe how data is stored and transformed. The author includes Mavo's CSS and JavaScript files in the page head, so the page needs no server backend of its own. Data can be edited in the page through an auto-generated interface, and for JavaScript developers Mavo can also serve as a declarative front-end framework. It is developed in the Haystack Group at MIT CSAIL and led by Lea Verou, and the plugins at plugins.mavo.io extend what it can do.

## Worth knowing

Where a Mavo page keeps its data depends on the backend the author picks, which can be the cloud, locally, or nowhere.
