Apache Lucene.NET is a C# port of the Lucene search library for applications that run on .NET. The [project homepage](https://lucenenet.apache.org/) describes it as a full-text search library for .NET, and the project's documentation describes it as a code library and API that an application calls to add search to its own code.

The homepage presents a beta line as the latest version, and its install command asks NuGet for a prerelease package. The Apache Software Foundation publishes the project.

## Worth knowing

The stable line on NuGet is older than the beta line, and the two support different .NET targets.
