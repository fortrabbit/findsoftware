Radix Primitives is a low-level UI component library of React components with no styles, for building design systems or web apps. The [introduction](https://radix-ui.com/primitives/docs/overview/introduction) says the components follow the WAI-ARIA design patterns where possible, and that the project handles ARIA attributes, focus management and keyboard navigation. Each component exposes its parts, so a site can wrap them, add its own event listeners and styles, or use them as the base layer of a design system.

The recommended install is the radix-ui package, from which the primitives are imported. Each primitive can also be installed as its own @radix-ui/react package. The source is in a GitHub repository.

## Worth knowing

When the individual packages are installed, the docs recommend updating all Radix packages together to prevent duplicated shared dependencies.
