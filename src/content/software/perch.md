Perch is a commercially licensed content management system from Perch Runway Limited, written in PHP and installed into an existing website. The perch folder goes into the root of the site and a setup form in the browser finishes the install, with MySQL or MariaDB as the database. Editors work in a control panel whose content forms come from templates the developer writes. The control panel supports roles with permissions and a localized interface, and add-ons extend it.

## Worth knowing

Perch is sold as a license for one website at a one-time fee. The news page lists no release after the 3.x line, which leaves open whether the project is still active, so this record is a stub.
