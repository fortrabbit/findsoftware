ProperDocs is a static site generator for project documentation. Pages are written in Markdown, and a single `properdocs.yml` file sets the documentation structure, the theme and the plugin settings. The `properdocs build` command writes static HTML to a site folder, and any host that serves static files can serve it.

ProperDocs is a fork of MkDocs. It installs with pip, and the ProperDocs Team maintains it. Plugins and themes are listed in a catalog on GitHub.

The [deployment guide](https://properdocs.org/user-guide/deploying-your-docs/) covers GitHub Pages, Read the Docs and other static hosts.
