FullCalendar is a JavaScript calendar that the project describes as a full-sized drag and drop calendar. Its vanilla JavaScript package needs the temporal-polyfill package as a peer dependency. Connectors for React, Angular, Vue, Preact, web components and Salesforce Lightning Web Components are separate packages in the same monorepo.

The Premium plugins add resource views, timelines and printer-friendly rendering, and they are licensed separately from the rest of the packages.

## Worth knowing

Premium use depends on who uses it. A for-profit company or an individual using Premium for commercial work needs a commercial license. A not-for-profit organization can use it under a free non-commercial license, but governments and universities are not covered by that license. Open-source projects can use Premium under AGPLv3.
