Snarkdown is a JavaScript function that takes a Markdown string and returns an HTML string. The README describes it as a parser for constrained use cases where a full Markdown parser would be inappropriate. It ships ES Modules, CommonJS and UMD builds through unpkg.

## Worth knowing

Tables are not supported, and the README says Snarkdown does not sanitize HTML, since its primary target usage does not require it.
