emlog is a blog and CMS written in PHP. It needs MySQL or MariaDB and is recommended on Linux with Nginx. Users install it by uploading the extracted files to the web root or by uploading the zip archive and unzipping it on the server. The [installation guide](https://emlog.dev/docs/en/install/) also describes a Docker deployment.

The project's site links an [app plaza](https://www.emlog.net/plaza) for extensions.

## Worth knowing

The repository is licensed under GPLv3. Releases are tagged `pro-` and the sites label the current version as Pro, and the pages read do not say how a Pro release relates to that license.
