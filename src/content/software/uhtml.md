uhtml renders HTML and SVG from template literals written in a JSX-inspired syntax, with React-like components and Preact-like signals. The README loads it as an ES module from a CDN. The repository is the project's only web presence, and Andrea Giammarchi is named as the author in the license copyright line.

## Worth knowing

The README says the 5.x line is a rewrite whose reactivity is not yet complete, and it asks users of the previous line to stay on it. Server rendering is described there as a work in progress.
