Inferno is a React-like JavaScript library for building user interfaces, with an API and component lifecycle modeled on React's. It renders in the browser and, through the separate inferno-server package, on the server. It is installed from npm as inferno, loaded from a CDN, or started with the Create Inferno App scaffolder.

## Worth knowing

The README says Inferno compiles JSX with its own plugins for Babel, SWC and TypeScript, that the plugin's major version matches Inferno's, and that JSX compiled by an older plugin version does not work with the current Inferno.
