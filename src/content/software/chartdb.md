ChartDB is a web-based editor that visualizes and designs database schemas as diagrams and exports DDL scripts. It supports MySQL, MariaDB, PostgreSQL, SQL Server and SQLite. It is written in TypeScript, licensed under AGPL-3.0 and maintained by ChartDB, Inc.

It runs on the developer's own machine. The README gives an npm route with a development server and a build, and a Docker image. A cloud version of the same app is offered next to the open source code.

## Worth knowing

The README describes the project as in public beta. The AI-assisted export calls OpenAI when an API key is set, and the app includes Fathom Analytics, which a build flag can turn off. ChartDB is a schema tool, not a site builder.
