MAMP is a local server environment for building and testing websites on the developer's own computer, with Apache or Nginx, PHP and MySQL. It runs on macOS and on Windows.

MAMP PRO is the commercial frontend to the same environment. It gives each project its own local host, can install WordPress, Joomla or Drupal with a few clicks, and keeps snapshots that hold a project's files together with its database. MAMP Cloud, sold separately, backs a project up to a cloud account or an own (S)FTP server.

## Worth knowing

MAMP PRO is designed exclusively for local development. The software is proprietary: the terms grant a limited licence to install and use it, and forbid copying except for backup, modification and resale.
