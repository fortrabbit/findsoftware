AVA is a test runner for Node.js with a concise API, detailed error output and concurrent test runs. It is installed as a development dependency with npm or Yarn. Its documentation sits in the docs folder of the repository. The project has no website of its own: its domain redirects to the GitHub repository.

## Worth knowing

AVA cannot be run globally, so each project installs its own copy. Support follows Node.js: the project supports the latest release of each Node.js major version that Node.js itself still supports.
