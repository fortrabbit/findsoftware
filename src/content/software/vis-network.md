vis-network is a TypeScript library that displays networks of nodes and edges as an interactive view in a web page. It supports custom shapes, styles, colors, sizes and images, and has clustering support for larger networks. The [documentation](https://visjs.github.io/vis-network/docs/network/) describes standalone, peer and legacy builds of the package, and the standalone build bundles its JavaScript dependencies and injects its CSS.
