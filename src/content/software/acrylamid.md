Acrylamid is a Python static blog generator. It compiles Markdown, reStructuredText and Textile articles into static HTML with incremental builds, using Jinja2 or Mako templates. The generated output is plain HTML that any host can serve.

## Worth knowing

The repository description marks the project as unmaintained, and its homepage no longer answers. The [README](https://github.com/posativ/acrylamid/blob/master/README.md) says the PyPI releases do not work with Python 3.3 and later.
