Koa is a middleware framework for Node.js that the project describes as expressive HTTP middleware for web applications and APIs. The framework ships without any bundled middleware, as its README states. It is installed with npm and needs Node.js 18 or higher, and the [documentation](https://koajs.com) says `app.listen()` creates an HTTP server.

The project's koa-vs-express page names Express and Connect as the frameworks to stay with for traditional Node.js-style coding.
