Moment.js is a JavaScript library for parsing, validating, manipulating and formatting dates and times. Its docs say it can be used in browsers and in Node.js, and that it supports internationalization.

## Worth knowing

The project calls itself a legacy project in maintenance mode that accepts no new features. Its 2026 status update says the maintainers are volunteers, expect further maintenance releases of the current line and have no schedule for a next major release. An earlier post on the same news page, since superseded, names Luxon and Day.js as alternatives. Moment Timezone is a separate project that the homepage lists beside it.
