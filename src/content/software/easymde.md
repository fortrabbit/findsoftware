EasyMDE is a Markdown editor that replaces a textarea on a page. It shows the Markdown syntax while the text is written, with a toolbar, a status bar, autosave and spell checking, and it renders previews with Marked using GitHub Flavored Markdown. The project bundles CodeMirror and depends on Font Awesome for its icons.

## Worth knowing

The README describes EasyMDE as a fork of SimpleMDE and as a continuation of that project. The LICENSE names two copyright holders, the SimpleMDE project's Sparksuite and this fork's maintainer. The image upload options hand files to an endpoint or a custom function, and the README asks the server to check file size and type because the browser check can be bypassed.
