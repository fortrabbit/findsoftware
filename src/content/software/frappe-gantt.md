Frappe Gantt is an open source JavaScript library for interactive Gantt charts, the bar charts that show a project's tasks, schedule and dependencies. It started as a component for ERPNext. Its [README](https://github.com/frappe/gantt/blob/master/README.md) lists the options that customize a chart, with their possible values and defaults, and the library can exclude weekends and holidays from task progress.
