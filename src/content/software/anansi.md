Anansi is a full-stack web framework for Rust, with database records, views, templates and WebAssembly components. The installation page installs the command-line tool, published as the crate ananc, with cargo. The project's tutorial covers a site with an admin interface, SQLite by default and PostgreSQL as a change in the project settings.

## Worth knowing

The newest published crate release and the last commit to the repository are both from 2023.
