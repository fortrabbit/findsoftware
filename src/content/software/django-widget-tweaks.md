django-widget-tweaks is a Python package that changes how form fields render in Django templates, without editing the form classes in Python. Its template tag and filters add, replace or remove HTML attributes and CSS classes on a field, so the markup can be adjusted in the template. The package moved from the jazzband organization to django-commons, and its repository now sits there.
