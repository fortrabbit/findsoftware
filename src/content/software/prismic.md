Prismic is a hosted headless CMS in which developers define reusable page sections, called slices, and editors assemble them into pages with a visual page builder. Content is served as JSON through a REST API, with a read-only GraphQL endpoint alongside it. The official client, @prismicio/client, is open source and reads from the Content API. The docs include integration guides for Next.js, Nuxt and SvelteKit.

## Worth knowing

The service has no self-hosted edition. The local tool Slice Machine is deprecated and archived, and new projects use the Type Builder and the Prismic CLI instead.
