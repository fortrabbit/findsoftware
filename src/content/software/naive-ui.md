Naive UI is a component library for Vue 3, written in TypeScript. It is installed from npm, and its components do not need a separate CSS import. A config provider component sets the global language for the components.

The theme is set through a theme overrides object in JavaScript. The README says no Less, Sass or CSS variable tooling and no webpack loader is required for it.

## Worth knowing

The README lists a separate fonts package to install and recommends the xicons icon library. The graphics of the result component carry their own CC-BY 4.0 license, as the README states.
