SimpleMDE is a JavaScript Markdown editor that replaces a textarea on a page, with a toolbar, optional autosave and a spell checker. It began as an improvement of lepture's Editor project. It is bundled with CodeMirror, which parses much of the Markdown as it is written, and previews are rendered by Marked using GFM.

## Worth knowing

SimpleMDE depends on Font Awesome for its icons. By default it checks whether the page already includes Font Awesome and downloads it accordingly.
