microCMS is a hosted headless CMS run by 株式会社microCMS. Editors enter and publish content in a browser admin panel, and a site reads it through a REST content API, so the front end is built separately from the content. The company's SDKs and tools are open source and sit in its GitHub organization, while the service itself runs only on its servers. The [documentation](https://document.microcms.io/) is in Japanese.

## Worth knowing

No installable part was found, so the content store and the admin panel run only as the hosted service. User roles need the Business or Enterprise plan, and SAML single sign-on needs the Enterprise plan.
