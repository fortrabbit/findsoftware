drf-yasg is a Python package that generates Swagger/OpenAPI 2.0 specifications from APIs built with Django REST framework, the framework it builds on. It is installed with pip.

## Worth knowing

The output is OpenAPI 2.0 only. The README names drf-spectacular, a separate project that works with OpenAPI 3.0 schemas, as the project that shares most of its goals.
