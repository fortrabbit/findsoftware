billboard.js is a chart library built on D3 that draws charts as SVG or on a canvas element from the same configuration. A project installs it from npm, loads it from a CDN, or downloads the dist files from the repository. A React component ships in the same package.

The [API documentation](https://naver.github.io/billboard.js/release/latest/doc/) describes the chart options. A wiki migration guide covers moving from C3.js, whose interface billboard.js keeps apart from the namespace and a few option names.
