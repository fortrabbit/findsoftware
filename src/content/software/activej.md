ActiveJ is a Java platform built from separate libraries that its pages describe as having no third-party dependencies. The libraries cover dependency injection, asynchronous I/O and an HTTP server, and the README says they can be used together or separately. A new web project is generated from the archetype-http Maven archetype, which produces a Java class that starts an HTTP server through a launcher. The homepage names Spring, Micronaut, Apache Spark and Quarkus as the solutions it is an alternative to.

## Worth knowing

The newest published versions are release candidates and betas, so check which line Maven Central marks as stable before depending on it. The GitHub repository has tags but no release objects.
