Doctor is a single-file documentation language. Its compiler, a Python script, runs in GitHub Actions and turns `.doctor` files in a docs folder into a GitHub Pages site. The README states that Doctor requires no installation, so nothing is set up on a developer's machine. The repository is owned by the DoctorrrrBuild organization on GitHub.

## Worth knowing

The README calls the project open source without naming a license, and the repository has no license file. The docs link on the project's landing page returns 404, so the README is the only documentation.
