Master CSS is a CSS language with its own class-name syntax: styles are written in the class attributes of the HTML, and the library generates the matching CSS. The getting-started guide describes npm and CDN setups, and the browser support section says the generated CSS is injected into the browser instantly.

## Worth knowing

The newest stable release on npm is older than the project's current release candidates, which are published on GitHub. The default branch of the repository is the release candidate branch.
