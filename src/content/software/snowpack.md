Snowpack is a frontend build tool that serves a project's JavaScript as unbundled ES modules during development and builds the project for production. It is installed from npm and runs on Node. The project's site keeps a plugin catalog.

The project's README and homepage state that Snowpack is no longer actively maintained and is not recommended for new projects. The README points to Vite as a well-maintained alternative.
