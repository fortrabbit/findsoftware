ROR Ecommerce is a Ruby on Rails application for running an online store. Its admin covers purchase orders, product creation, shipments, fulfillment and order creation, as its [README](https://github.com/drhenner/ror_ecommerce/blob/master/README.md) describes. It is installed with bundle install and stores data in SQLite or MySQL.

## Worth knowing

The homepage the project names, ror-e.com, does not serve the site, so the live project pages are the repository and its [documentation](https://drhenner.github.io/ror_ecommerce/). The documentation describes an older Rails than the README does.
