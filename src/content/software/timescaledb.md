TimescaleDB is an extension for PostgreSQL, aimed at real-time analytics on time-series and event data. It loads into a PostgreSQL server, so it uses that server's databases. The [install guide](https://docs.tigerdata.com/self-hosted/latest/install/) covers apt and yum packages, Homebrew, MacPorts, a Windows installer, a Docker image, Kubernetes and a build from source, plus community-built Arch packages. Timescale, Inc. maintains the project, which is also sold under the Tiger Data name.

## Worth knowing

The repository holds two editions. The Apache 2 Edition is under Apache-2.0. The Community Edition, which is the default, is under the Timescale License. That license does not allow offering it as a database-as-a-service. The hosted version of the Community Edition is Tiger Cloud, the company's own service.
