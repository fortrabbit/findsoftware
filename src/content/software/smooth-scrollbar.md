Smooth Scrollbar is a JavaScript plugin that replaces an element's native scrollbar with a customizable one that scrolls with momentum. It runs in the visitor's browser and is written in TypeScript. The repository's [docs folder](https://github.com/dolphin-wood/smooth-scrollbar/tree/develop/docs) holds the documentation, and the [homepage](https://dolphin-wood.github.io/smooth-scrollbar/) describes it.

## Worth knowing

The README warns against custom scrollbars unless the team knows what it is doing.
