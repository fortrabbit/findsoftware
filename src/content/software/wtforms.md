WTForms is a Python library for form validation and rendering. Its README says it works with whatever web framework and template engine a project uses, and that it supports data validation, CSRF protection and internationalization.

## Worth knowing

The README lists community libraries that integrate WTForms with frameworks and ORMs, among them Flask-WTF and Starlette-WTF. They are separate projects and are not part of this library.
