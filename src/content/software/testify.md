Testify is a set of Go packages for writing tests. It provides assertions, mock objects and test suites, and it installs with go get. The [API documentation](https://pkg.go.dev/github.com/stretchr/testify) lists every package and function.

## Worth knowing

The README says the repository is maintained at the first major version and accepts no breaking changes. It also says the suite package does not support parallel tests.
