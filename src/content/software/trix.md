Trix is a WYSIWYG rich text editor for web applications that outputs HTML. The README describes it as a way to compose formatted text in a web application. It can be loaded from an npm CDN, or installed from npm and imported into the application.

The README says Trix sanitizes its content with DOMPurify. It describes the project as open source from 37signals, the company that created Ruby on Rails, and names a source build for contributors that uses Yarn.

## Worth knowing

The Rails link is to the company that wrote Trix. The README names no framework that Trix is built on, so none is recorded.
