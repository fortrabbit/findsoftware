Karma is a JavaScript test runner that executes code in multiple real browsers. It launches an HTTP server and generates the test runner HTML file that loads the tests in each browser.

## Worth knowing

The project's README says Karma is deprecated and names Web Test Runner, jasmine-browser-runner, Jest and Vitest as alternatives. Critical security issues are still triaged and fixed until 12 months after Angular CLI's Web Test Runner support is marked stable.
