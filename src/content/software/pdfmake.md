pdfmake is a JavaScript library that generates PDF documents in Node.js and in browsers. It is based on PDFKit, which the README names as the library it builds on. A document is described by a document definition object passed to the library, and the README shows a Node.js script that writes a file and a browser page that offers a download. The [documentation](https://pdfmake.github.io/docs/) covers usage and the API.

## Worth knowing

The project's own homepage cannot be read, so the record is a stub; the repository and the documentation are its sources. The README's feature list includes tables, SVG, QR codes, page headers and footers, and PDF/A output.
