Poem is a web framework for Rust, published on crates.io as the poem crate. An application maps routes to handler functions and starts a server on a TCP listener, and the crate is installed with Cargo. The README states that the crate forbids unsafe code.

## Worth knowing

The main branch of the repository is preparing the next major release, which is not yet published. It needs a newer Rust compiler than the latest published release.
