GraphQL.js is the official JavaScript implementation of the GraphQL specification. It supplies the parser, validator, executor and type system that a Node.js application uses to build a GraphQL server, client or tool. The package installs from npm, and the [documentation](https://www.graphql-js.org/docs/) describes its use.

The repository belongs to the graphql organization on GitHub, and the GraphQL Contributors maintain the code under the MIT license.
