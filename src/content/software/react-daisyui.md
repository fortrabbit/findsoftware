react-daisyui provides daisyUI components as React components, written in TypeScript and installed from npm or Yarn. The package is a React layer over daisyUI, so a project installs daisyUI and Tailwind CSS alongside it. The components are documented in a Storybook that the README links.

## Worth knowing

The package depends on daisyUI and needs Tailwind CSS in the project, and the install section names both as requirements.
