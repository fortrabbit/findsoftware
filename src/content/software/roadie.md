Roadie is a Ruby gem for HTML emails. It inlines an email's stylesheets into the matching elements and rewrites relative URLs. Its README says it supports any type of HTML document, not only Rails mail.

## Worth knowing

The README says the gem is in passive maintenance mode. The Rails integration is a separate gem, roadie-rails, which the README names.
