li₃ is a PHP framework in which, per its README, every component of the stack is replaceable through a plugin architecture. The README also names MongoDB, CouchDB and Redis as storage technologies it integrates. Installation goes through the distribution unionofrad/framework, which contains the framework as the core package unionofrad/lithium, and `composer create-project` creates a new application from it.

## Worth knowing

The manual on [li3.me](http://li3.me/docs/book/manual/1.x/installation/requirements) covers the 1.x series.
