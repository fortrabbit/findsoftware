Schedule-X is a JavaScript event calendar component that shows month, week, day and agenda views on a web page. It is a framework-agnostic core with official components for React, Vue, Angular, Svelte and Preact, and it is also loadable from a CDN with a script tag. The docs list several supported languages, and plugins extend the core, among them a community plugin list.

## Worth knowing

A Premium edition adds resource views, event forms, drag-to-create, drawing and Gantt charts under a commercial license that requires one license per project. Schedule-X Cloud is a hosted backend that pairs with the Premium calendar and syncs with Google Calendar.
