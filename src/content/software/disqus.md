Disqus is a hosted comment system that websites add with a script snippet or a plugin. Disqus, Inc. runs it. Its help center describes a feature-rich comment system with advanced administration and moderation options, and it defines organization owners, organization admins and site moderators as roles.

Sites can import existing comments from WordPress. The service also has an API.

## Worth knowing

The Basic plan is free and shows ads, and the plans are tiered. Pricing sits on the [pricing article](https://help.disqus.com/en/articles/1717110-comments-pricing-and-plans). The API has a request limit per hour on the Basic plan.
