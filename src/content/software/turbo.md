Turbo is a JavaScript framework from Hotwire. The server delivers HTML, and Turbo applies it to the page: Turbo Drive handles links and form submissions, Turbo Frames update independent parts of a page, and Turbo Streams apply changes sent over WebSocket or SSE, or returned from a form submission.

A page loads Turbo from a jsDelivr script tag, from a download of the compiled packages from unpkg, or from npm as `@hotwired/turbo`. It can also be installed with yarn, and Rails applications get it through the `turbo-rails` gem.

## Worth knowing

For JavaScript that Turbo does not cover, the project names Stimulus, which has its own record.
