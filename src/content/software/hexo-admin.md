Hexo Admin is an admin interface for the Hexo blog engine, installed into a Hexo blog as an npm package. It was designed as a local editor: the blog runs on the author's machine, and the static files that Hexo generates are deployed to a static host. The [Readme](https://github.com/jaredly/hexo-admin/blob/master/Readme.md) also describes running it on a live blog, on a hosting service that keeps a process running, and recommends password protection in that case.

The project is published as an npm package under the ISC license, and its maintainer is Jared Forsyth.

## Worth knowing

The Readme opens with a request for a maintainer. The author says they have not used Hexo in several years and asks for volunteers to take the project over.
