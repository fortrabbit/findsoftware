MikroORM is a TypeScript ORM for Node.js. It is based on the Data Mapper, Unit of Work and Identity Map patterns, and its README describes the design as heavily inspired by Doctrine and Hibernate. The core package, @mikro-orm/core, is installed next to one driver package per database, such as @mikro-orm/postgresql or @mikro-orm/mysql, which the quick start installs.

## Worth knowing

The major line before the current one still gets releases alongside it.
