TypeIt animates typed text in a web page. It types one or more strings, deletes and replaces them, and can loop them. Strings can contain HTML, and chained commands control speed, pauses and line breaks. An effect can wait until its target element scrolls into view.

The repository holds two packages: the vanilla library and a React wrapper around it.

## Worth knowing

The library is GPL-3.0 for open source and personal projects. A commercial project needs a paid license.
