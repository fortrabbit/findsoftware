Ant Design is an enterprise-class UI design language, and antd is the React component library that implements it. The introduction says the library encapsulates a set of components that embody the design language, and welcomes community implementations of the design system in other front-end frameworks. antd installs from npm, yarn, pnpm or bun, and it ships its own TypeScript definitions.

## Worth knowing

The introduction says antd is intended to be used with a build tool and discourages loading its whole script files in a browser. Its environment table lists the supported browsers and server-side rendering, and records dropped support for older browsers and for older React versions in later major releases.
