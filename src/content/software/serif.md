Serif is a static site generator and blogging system that builds a site from Markdown files and Liquid templates. `serif generate` writes the finished site into a `_site` folder that a web server serves, and `serif dev` serves it locally for testing. The RubyGems package summary adds an optional admin interface. Serif is installed with RubyGems.

## Worth knowing

The GitHub repository is archived.
