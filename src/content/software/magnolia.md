Magnolia is a Java digital experience platform for managing and delivering web content, founded in Basel, Switzerland. The Community Edition is a zip download that contains an Apache Tomcat directory with the Magnolia webapps, so it runs as a Java web application on a Tomcat application server. Content lives in a Jackrabbit content repository that maps its hierarchical data onto a relational database. Editors work in the Shell, the web administration interface. Pages are rendered on the server from FreeMarker template scripts, and a REST delivery endpoint and a GraphQL module bundled with DX Core expose content for headless front ends. Magnolia also offers the platform as a managed service, DX Cloud.

Magnolia's core source is not in a public repository. The Magnolia organization on GitHub holds demos, tutorials and documentation sources, so the code is reached through the downloads and the [documentation](https://docs.magnolia-cms.com/product-docs/).

## Worth knowing

The Community Edition is free under the GPLv3 license, but it has fewer features than DX Core and is limited to one receiver and one site. DX Core requires a license to run.
