Mezzanine is a content management platform built on Django. It adds pages, a blog and an admin dashboard to a Django project. The package is installed from PyPI with `pip install mezzanine`, and the `mezzanine-project` command starts a new project.

Multi-tenancy works through a Site record for each tenant, so one running instance can serve several sites. Blog posts can be imported from WordPress, Blogger, Tumblr, Posterous, RSS and BlogML.
