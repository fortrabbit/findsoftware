Viewer.js is a JavaScript image viewer that shows images from a web page in a modal or inline mode. The README documents installing it with npm or loading it from the cdnjs CDN, and lists its options, methods and events. Chen Fengyuan holds the copyright.

## Worth knowing

The README lists support for the latest Chrome, Firefox, Safari, Opera and Edge, and for Internet Explorer 9 and later. A jQuery plugin wrapper exists as a separate project.
