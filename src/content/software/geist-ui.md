Geist UI is a React component library, described on its introduction page as a community project not associated with Vercel. It is installed from npm as the @geist-ui/core package.

## Worth knowing

The project's homepage and its README say it is archived, and the repository is archived on GitHub. No new releases, bug fixes or support are planned, and the homepage says the source and published packages stay available for reference.
