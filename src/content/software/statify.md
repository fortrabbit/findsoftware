Statify is a static site generator written in Python 3 that renders Markdown files with Jinja2 templates. Articles and pages are Markdown files in a contents folder, and an HTML comment at the top of each file sets its title, subtitle or author. Site settings such as the social links and blog information are kept in a config.json file, and the generator runs as the statify.py script.

## Worth knowing

The README lists an online editor, multiple themes and tags under ToDo.
