Tera is a template engine for Rust, added to a Rust project through Cargo. Its template syntax is inspired by Jinja2 and the Django template language, and the project says it intentionally deviates from both in many ways.

The project's [documentation site](https://keats.github.io/tera/) is the main documentation, and the API reference is published on docs.rs.

## Worth knowing

An optional companion crate, tera-contrib, holds filters, functions and tests that need third-party dependencies.
