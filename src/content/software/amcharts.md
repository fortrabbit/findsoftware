amCharts 5 is a JavaScript library for charts, maps and stock charts. The [getting-started guide](https://docs.amcharts.com/v5/getting-started/) describes three ways to add it to a page: the npm package, the vendor CDN, and a ZIP archive hosted on the site's own server. The library is written in TypeScript and comes with a set of locales.

The copyright line in the license names Antanas Marcelionis as the copyright holder. The company behind the library is based in Vilnius, Lithuania, according to its about page.

## Worth knowing

The free license covers any project, commercial ones included, as long as the branding link and logo attribution stay in place. Uses the free license does not cover need a commercial license from the vendor's online store.
