Radix Themes is an open-source component library from the Radix project whose components come pre-styled. The [getting started guide](https://radix-ui.com/themes/docs/overview/getting-started) installs the npm package, imports its stylesheet and wraps the application in a Theme component. Props on the Theme component set the look: an accent color, a gray color, a radius and a scaling value. A ThemePanel component can be added beside the app to preview theme changes in real time.

The docs describe the library as designed to work out of the box with minimal configuration. Layout primitives such as Flex and Grid, text and form components are documented as part of the same package.

## Worth knowing

For components without styles, the docs point to Radix Primitives, a separate library in the same project.
