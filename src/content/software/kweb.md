Kweb is a Kotlin web framework with a DSL for creating and changing a browser's DOM elements from the server. It is built on Ktor.

The README carries a project status notice dated June 2024. It says the author can no longer actively support Kweb, and it invites anyone interested to fork the repository. The repository is archived, and the homepage that the record would link no longer resolves.
