notie is a JavaScript library for notification alerts, confirmation dialogs, text input prompts and selection lists, written in ES6 with no dependencies. Its styling can be changed through a Sass file or by overriding the CSS.

## Worth knowing

The repository is archived and read-only on GitHub. The demo page the README links returns not found.
