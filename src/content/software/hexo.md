Hexo is a Node.js blog framework that generates a static website from Markdown posts and a theme. Source files live in a project folder, and generating the site writes HTML into a public folder, so the output needs only static file hosting. Themes use EJS, Pug or Nunjucks templates, and internationalization covers both themes and posts. A built-in deploy command publishes the generated files to targets such as a Git repository, Netlify or an SFTP server. The hexojs GitHub organization maintains Hexo as a community project.
