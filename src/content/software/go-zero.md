go-zero is a Go framework for web and RPC services. The repository also holds goctl, a command-line tool that generates code from API definitions for many languages. The framework requires Go 1.21 or later and is added to a project with go get, and its services compile to a single binary. The bare-metal guide runs a service as a long-running process under nohup, and the database guide covers MySQL, MongoDB and Redis. The project is maintained by Junfeng Wan.

## Worth knowing

The repository tags goctl releases next to the framework's own releases. The release fields on this record follow the framework's tags, not the goctl tags.
