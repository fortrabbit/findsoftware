GWT is a Java framework that compiles Java source code to JavaScript, so that browser applications are written in Java. The project's own pages describe it as a way to develop AJAX applications across all major browsers. GWT modules are stored on a web server as a set of JavaScript and related files, so the compiled application is served as static files. The SDK is downloaded from the [project site](https://www.gwtproject.org/), and the GWT Open Source Project is named as its maintainer.
