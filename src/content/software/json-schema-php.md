JSON Schema for PHP validates JSON data against a JSON Schema and reports the violations it finds. The README describes support for several drafts of the JSON Schema specification, and the docs say the library integrates into frameworks such as Laravel and Symfony.

## Worth knowing

The README notes that features of newer drafts might not be supported, and it points to a Bowtie compliance report for the current state of draft support.
