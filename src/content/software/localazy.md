Localazy is a hosted service for translating the text of software, mobile apps and websites. Developers connect a project through a command-line client or a REST API, and translators, reviewers and managers take part with roles assigned per project. The service also includes a language CDN.

## Worth knowing

Localazy is offered only as a hosted service, and no self-hosted option is recorded. Single sign-on uses SAML 2.0 and is documented as part of the Enterprise plan. Documented API limits differ by plan, with higher daily import and fetch limits on the higher plans.
