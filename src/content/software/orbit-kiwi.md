Orbit is the React component library of Kiwi.com's Orbit design system. It installs from npm, and the project's readme says the components are styled with Tailwind CSS, which the application must install itself for them to display correctly.

## Worth knowing

The homepage the readme names, orbit.kiwi, does not resolve, so the documentation it links is not reachable at that address. The Storybook at kiwicom.github.io/orbit is the live preview the readme also gives.
