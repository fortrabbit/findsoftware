Coil is an Elixir static content engine that builds a blog and pages from Markdown articles and EEx templates. It is installed by cloning the repository and fetching its dependencies with mix, and `mix coil` bootstraps a sample blog in a separate folder. The README lists the routes for the index, pages, articles, the RSS feed and the archives.

## Worth knowing

The README states its Elixir requirement as the latest stable version at the time it was written, and the GitHub repository has one release.
