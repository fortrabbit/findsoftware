TypeRocket is a WordPress framework with an MVC structure. It is installed either as a WordPress plugin or as a Composer project, and the [getting-started guide](https://typerocket.com/docs/v6/get-started/) recommends the basic plugin install. Robojuice, LLC develops it.

## Worth knowing

TypeRocket has a paid edition, TypeRocket Pro, which the terms page says offers additional features over the free version. The README states the license as GPL 3.0 and the terms page as GPL v3 or later.
