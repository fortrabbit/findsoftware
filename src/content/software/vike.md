Vike is a framework for web apps that works with any UI framework and supports server-side rendering, pre-rendering at build time and client-only pages. The [why page](https://vike.dev/why) describes it as a core with extensions, and the scaffolder offers apps with or without those extensions.

Pre-rendering removes the need for a production server, and the pre-rendered output can go to any static host. Without it, the app runs in a production server, as the [self-host guide](https://vike.dev/self-host) describes.

## Worth knowing

The [open source pricing page](https://vike.dev/pricing) describes a pricing model that is not implemented yet, and states that Vike stays MIT licensed.
