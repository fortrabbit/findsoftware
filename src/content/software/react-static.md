React Static is a static-site generator for React. It exports each route as an HTML file, and the exported page then loads a single-page React application, so later navigation runs in the browser. The CLI creates projects and bundles them for production. Exported files go to any static file server.

## Worth knowing

The README says the project is in maintenance-only mode with no new major versions, and the maintainer's discussion on the repository says the maintainer is letting go of the project. The README names Remix and NextJS as alternatives.
