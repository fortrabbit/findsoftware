Chosen is a jQuery plugin that makes long select boxes easier to use. A page that loads it needs jQuery alongside it. The project distributes its files through the GitHub releases page and through npm, Bower and Composer packages, whose package names differ.

## Worth knowing

The repository description and the README both call Chosen deprecated, and the README says this version is not under active development while the maintainers decide on its future direction.
