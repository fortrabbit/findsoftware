GraphQL Java is the Java implementation of the GraphQL specification, used to build GraphQL servers on the JVM. A project adds the library as a dependency from Maven Central through Gradle or Maven, as the [getting-started guide](https://www.graphql-java.com/documentation/getting-started/) describes. Andreas Marek and contributors maintain it, and the source lives in the graphql-java organization on GitHub.
