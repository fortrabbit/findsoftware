VeeValidate is a form library for Vue.js. It takes care of value tracking, validation, errors and submissions, and the [overview](https://vee-validate.logaretm.com/v4/guide/overview) describes two ways to add validation to forms: a composition API and declarative components. A companion package holds built-in validation rules, with locales for their messages.

## Worth knowing

The README links its main documentation to a newer line that is still in beta, while the homepage documents the earlier line.
