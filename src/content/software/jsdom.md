jsdom is a pure-JavaScript implementation of many DOM and HTML web standards for Node.js. The README gives its goal as emulating enough of a subset of a web browser to be useful for testing and scraping real-world web applications. Canvas and image support depend on the optional `@napi-rs/canvas` package, which the README says to install alongside jsdom.

## Worth knowing

The README is the main documentation, with a GitHub wiki beside it, and it names a mailing list and a Matrix room for questions. Parts of the package come with notices under other licenses, including the W3C Software and Document License for CSS color conversion code.
