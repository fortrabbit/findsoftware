JekyllPad is a browser-based visual editor for the content of static sites whose files are in a GitHub repository. Changes made in the editor save and commit directly to that repository. The editor combines WYSIWYG and Markdown editing and runs in the browser without a local install. The project is built by Arman and describes itself as independent of GitHub and of the static site generators it names.

## Worth knowing

No source code or self-hosted build was found, so the editor is available only as the hosted service at jekyllpad.com. The homepage lists GitHub Pages, Jekyll, Astro, Hugo, Eleventy and Gatsby as the sites it works with.
