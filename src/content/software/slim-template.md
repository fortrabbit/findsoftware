Slim is a template language and engine for Ruby. Its README describes the goal as reducing the view syntax to the essential parts, and it works with Rails, Sinatra and Tilt. A translator plugin provides I18n for templates. The README lists Haml and Pug among similar template languages and links a converter from Haml templates. The [repository](https://github.com/slim-template/slim) holds the gem's source and the plugin documentation.
