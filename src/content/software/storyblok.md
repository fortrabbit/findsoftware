Storyblok is a hosted headless CMS. Editors work in a browser-based visual editor, and sites read content through a Content Delivery API over REST, with GraphQL on its higher plans. Storyblok GmbH, based in Austria, runs the service, and the company was founded in 2017. The official client libraries for JavaScript frameworks, PHP and Swift and the storyblok CLI live in the open-source monoblok repository.

## Worth knowing

No server part can be installed. The content database and the editor run only as a service.
