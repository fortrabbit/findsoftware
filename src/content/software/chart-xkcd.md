chart.xkcd is a JavaScript chart library that draws sketchy, cartoony or hand-drawn styled charts. A page includes the script along with a single SVG node, and the chart renders into that node. The [documentation](https://timqian.com/chart.xkcd/) includes examples.

The library is installed from npm or loaded from a CDN with a script tag.
