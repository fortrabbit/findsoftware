PHP-Nuke is a news publishing and content management system written in PHP on MySQL. The source is on [GitHub](https://github.com/phpnuke/phpnuke), and the install.php file in it is a web installer. The software includes an admin area.

## Worth knowing

The project's site, phpnuke.ir, also sells hosting. The repository holds no installation guide, so the installer and the site's forum are the only setup references.
