Poi is a bundler built on webpack, made for developing and bundling web apps and npm libraries. Its README installs it as a development dependency with yarn and also describes a create-poi-app starter. For production, a build step creates a minified bundle.

The project is deprecated. Its README says so and asks users to migrate to Vite, and the GitHub repository is archived. The README credits EGOIST under the MIT License.
