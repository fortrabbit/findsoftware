Authlib is a Python library for OAuth and OpenID Connect. It builds OAuth clients that sign users in, authorization servers that issue tokens, and protected APIs that check access tokens. The homepage names Flask, Django, Starlette and FastAPI as the frameworks it connects to, and it is installed with pip.

The project is one of three packages the homepage lists as a family: joserfc for JOSE and JWT, and OTP Auth for one-time passwords, each published under its own name.

## Worth knowing

The authlib.jose module is deprecated in favor of joserfc. A commercial license is available from the project's pricing page for organizations that need one.
