Dropzone is a JavaScript library that turns an HTML element into a drop target for files. It shows file previews and upload progress, and it is installed through Composer or as a script tag loaded from unpkg. The source repository also holds the library's documentation and website, and support questions go to its GitHub Discussions.

## Worth knowing

The Composer package is published from a separate repository, enyo/dropzone-packagist, not from the main repository.
