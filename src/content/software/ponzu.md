Ponzu is an HTTP server framework and CMS written in Go. It has a JSON API and a generated admin dashboard, and its content is kept in an embedded BoltDB database. It is distributed as a single binary plus assets, or as a Docker image.

## Worth knowing

The README states that the project is abandoned and points to Caddy Server for an HTTP server with TLS. It also lists maintainers as wanted.
