Raygun is a hosted service for error tracking, real user monitoring and application performance monitoring of web and mobile apps. The [homepage](https://raygun.com/) lists crash reporting, real user monitoring and application performance monitoring as its products. Apps send their events to the service through Raygun SDKs, and the [documentation](https://raygun.com/docs) describes installation for many languages and frameworks. The service is operated by Raygun Limited, a New Zealand company.

The [pricing page](https://raygun.com/pricing) lists user roles and permissions, and it offers SAML 2 single sign-on. The security page states GDPR compliance.

## Worth knowing

Raygun is offered only as its own cloud service.
