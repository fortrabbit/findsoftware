pyenv is a version manager for Python, forked from rbenv and modified for Python. It lets a user switch between multiple installed versions of Python, and the global version it sets applies to that user's account. It is installed with an automatic installer, a git clone into the home directory or a Homebrew formula. The project has no homepage of its own, so its [README](https://github.com/pyenv/pyenv/blob/master/README.md) is the documentation.

## Worth knowing

The README says pyenv does not officially support Windows and does not work there outside the Windows Subsystem for Linux.
