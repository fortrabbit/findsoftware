phpenv is a command-line tool for installing several PHP versions on a developer's machine and switching between them. The [README](https://github.com/phpenv/phpenv/blob/main/README.md) says it was originally inspired by rbenv and ruby-build. At installation it injects itself into the PATH, and it can be installed with Homebrew, by a git checkout into a `.phpenv` folder, or with the phpenv-installer script.
