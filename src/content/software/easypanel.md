Easypanel is a self-hosted server management panel that runs on the user's own servers and deploys applications and services on them. The [docs](https://easypanel.io/docs) describe three ways to install it: an install script, a Docker image, and one-click images from several cloud providers. Once it starts, it runs as a long-lived service on the server. Postgres, MySQL, MongoDB and Redis are offered inside the panel as services.

## Worth knowing

The software is proprietary and its source code is not published. Paid plans are licensed per server, and the paid tiers add features such as unlimited projects and multiple users. The [pricing page](https://easypanel.io/pricing) lists the tiers.
