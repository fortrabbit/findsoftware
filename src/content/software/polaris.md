Polaris is the React implementation of Shopify's Polaris design system, a component library for interfaces that work with Shopify software. Its source sits in an archived repository that keeps the project's history.

## Worth knowing

Shopify deprecated the React library and no longer maintains it, and the repository will not receive updates. The README names Polaris Web Components as the replacement for new development. That is a separate product, so it is not part of this record. The source code license limits use to applications that integrate or interoperate with Shopify software or services, and icons and images carry their own license agreement.
