Alchemy CMS is an open source content management engine written for Ruby on Rails, so it runs inside a Rails application. A Rails application template installs it into a new project, or the gem is added to an existing Rails app. The README lists an admin interface with live preview, multiple languages and domains, and a RESTful API. The README says it can be hosted on any server that supports Ruby on Rails, a SQL database and ImageMagick.

Blish GmbH maintains it.

## Worth knowing

The homepage announces a Cloud hosting service as coming in 2026, with a waiting list. The open source engine is self-hosted and has the same licensing, code and features, according to the homepage.
