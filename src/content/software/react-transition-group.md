React Transition Group provides React components that manage a component's mounting, unmounting and transition stages over time. It does not animate styles by itself: it exposes the transition stages, manages classes and group elements, and manipulates the DOM, which makes the visual transitions easier to implement. The components are Transition, CSSTransition, SwitchTransition and TransitionGroup, described in the [main documentation](https://reactcommunity.org/react-transition-group/).

## Worth knowing

The README says the API from version 2 on is not backwards compatible with the original React addon, and that the v1 codebase is no longer updated.
