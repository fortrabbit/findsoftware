Lightning Web Components is a UI framework for building custom elements, the web components standard, with HTML and JavaScript. Salesforce maintains it. The framework's core package is lwc on npm, and the homepage says to create an app with the lwr tool, using npm init lwr.

The framework uses core Web Components standards and runs natively in browsers, so the components it produces are standard custom elements.
