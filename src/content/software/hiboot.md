hiboot is a web and CLI application framework written in Go, with dependency injection. The README says its features borrow from Spring, including dependency injection, aspect oriented programming and auto configuration. A project adds the Go module with `go get github.com/hidevopsio/hiboot`, and a web application starts its own HTTP server on a port, so it runs as a long-running process. The [getting started guide](https://hiboot.netlify.app/getting-started/) asks for Go 1.21 or later. The copyright line names John Deng as the author, and the source is held by the hidevopsio organization on GitHub.

## Worth knowing

The README and the Go quick start link to hiboot.hidevops.io, which does not resolve. The documentation is on the netlify site named above.
