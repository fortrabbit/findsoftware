Hiawatha is an open source web server for Unix-like systems, written in C, with a focus on security. The project offers a source tarball that is built with CMake, and packages for Debian and Ubuntu, FreeBSD, OpenBSD and macOS, plus a Windows package compiled with Cygwin. The server is a long-running process that stops by its process ID, as its starting and stopping HOWTO describes. The project's support page holds its HOWTO pages on installation and configuration. Hugo Leisink maintains it under the GPL version 2.

## Worth knowing

The Debian and Ubuntu packages come from a third-party packaging repository, not from the project itself.
