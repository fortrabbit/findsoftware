Static Site Exporter is a WordPress plugin that exports posts, pages and settings to Markdown and YAML for Jekyll, Hugo and other static site generators. The output is a zip archive of those files. The plugin is copied into the WordPress plugins folder and activated in the dashboard, which adds an export item to the Tools menu. The readme also documents a WP-CLI command for exporting selected categories or tags.
