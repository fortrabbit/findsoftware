Remark42 is a self-hosted commenting engine that embeds into blogs and articles. It is written in Go and stores comments either in BoltDB or through an RPC store, as the [configuration parameters](https://remark42.com/docs/configuration/parameters/) list. The [installation guide](https://remark42.com/docs/getting-started/installation/) offers Docker Compose, a binary archive, a systemd service and a source build, and names Docker as the recommended way to run it.
