Globalize is a JavaScript library for internationalization and localization that formats and parses numbers, dates, currency and messages and handles plurals, using Unicode CLDR JSON data. It embeds no locale data: developers load the CLDR JSON they want, so locale coverage is their choice. The library is split into modules (core, currency, date, message, number, plural, relative time and unit), and a site loads only the ones it uses. The README also names the Globalize Compiler, a separate command-line tool.
