Kumo is Cloudflare's component library for web applications: a set of accessible React components. The project says it is built on top of Base UI, a library of unstyled, accessible React components, and describes its components as design-system-compliant. Cloudflare, Inc. is named as the copyright holder in the license file.

Kumo installs from the @cloudflare/kumo npm package, which a project imports from. Blocks such as page headers are installed with the Kumo CLI, which copies their code into the project so the project can change it. The docs name React and react-dom as peer dependencies.
