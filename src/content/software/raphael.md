Raphaël is a JavaScript library for working with vector graphics on the web. Its homepage describes using it to build custom charts and image widgets.

The library runs in the browser: raphael.js is downloaded and included in an HTML page, or loaded with a script tag or AMD. The README lists eve as a dependency and includes it in the minified build.
