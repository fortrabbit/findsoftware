Univer is an Office SDK for building spreadsheet, document and other Office editing, calculation and file processing into an application. The SDK has three parts: a Web SDK, a Server SDK and an AI SDK. This repository holds the open-source Web SDK core and the Sheets and Docs editing capabilities, and its view layer is built on React.

The quick start builds a spreadsheet editor in a browser application with a bundler, and the README states that headless Univer also runs in Node.js.

## Worth knowing

Some modules are commercial. The Web SDK plugins, the Server SDK and the AI SDK extensions are licensed separately, and the freemium evaluation includes watermarks and feature limits.
