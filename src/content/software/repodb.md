RepoDB is a hybrid ORM for .NET whose fluent methods cover everyday CRUD, with raw SQL available beside them. It works through the IDbConnection interface. Each supported database has a provider package installed beside the core package, and bulk operations come as separate add-on packages for each provider. An opt-in telemetry package is also available.

## Worth knowing

The README's Enterprise Notice says the project is maintained by one individual. The Desktop Studio, which the README describes as still in development, is available on request.
