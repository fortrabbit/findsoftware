Selectize replaces a select box with a control that combines a text input and a dropdown, for selecting and tagging items. It is based on jQuery and supports right-to-left pages. The [getting started guide](https://selectize.dev/docs/intro) explains installation and use.

## Worth knowing

The GitHub repository is archived. The README asks for new members on the maintenance team.
