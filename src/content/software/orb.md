Orb is a hosted billing service for usage-based pricing. A product sends usage events to Orb's API, and Orb meters them, applies the customer's pricing plan and produces invoices. The docs describe a REST API and client libraries for Python, Node.js, Ruby and Go. Orb states that it runs on Amazon Web Services and holds a SOC 2 Type II report. Orb, Inc. operates the service, and its client code is published as separate packages under the orbcorp organization.
