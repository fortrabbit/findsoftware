AbeCMS is a Node.js CMS and static site generator. Developers mark up HTML templates with `abe` tags, and the system builds the editing back-office from those tags. Content is stored as JSON documents in a data folder, and published pages are written to a site folder as static files.

The README describes an API-first REST server that serves the documents as JSON, a validation and permissions workflow, and deployment to Surge, Amazon S3, GitHub Pages or an SFTP server.
