Graffle is a GraphQL client for JavaScript, written in TypeScript and installed from npm. The project was published before as graphql-request, and the older name continues on a branch of the same repository and as its own npm package.

The package is maintained by Jason Kuhrt and is distributed under the MIT license, from a repository in the graffle-js organization on GitHub.

## Worth knowing

The install guide says Graffle has no stable release yet and points to the npm next tag for the pre-release. The older graphql-request package still publishes its own stable line.
