PrimeReact is a React UI component library that PrimeTek publishes on npm. The [Styled guide](https://primereact.dev/docs/styled/guides/introduction) describes components that come pre-styled with a built-in design system, and the installation guide for the Vite setup adds the @primereact/ui package with a theme package and an icon package. PrimeTek Informatics Bilisim AS maintains it, from Ankara.

## Worth knowing

The current line is licensed under the PrimeUI License, which requires a license key. A free Community License covers eligible users, and a paid Commercial License is licensed per developer. The earlier line on GitHub remains under the MIT License, and the README of that repository says it no longer receives active development and points to PrimeUI.
