Laravel Vite Plugin configures Vite for a Laravel backend server. Laravel's official plugin and Blade directive load a Laravel application's JavaScript and CSS entry points, and the dev command runs the Vite development server while a developer works on the application. The plugin is installed through npm with the rest of a Laravel application's frontend dependencies.

## Worth knowing

The Laravel documentation gives an older Node.js minimum than the package's own manifest does. The record uses the manifest value.
