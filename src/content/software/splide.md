Splide is a slider and carousel library with no dependencies. The getting-started guide covers three ways to add its files to a site: an npm install, a downloaded build and a CDN.

Integration packages exist for React, Vue and Svelte. The Vue integration's latest version supports Vue 3 only. The texts used in the carousel can be translated.

## Worth knowing

Splide Premium is a separate, sponsor-only package that adds transition effects built with three.js to a carousel. The premium page says it may be used commercially only once the user becomes a sponsor.
