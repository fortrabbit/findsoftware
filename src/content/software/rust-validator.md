validator is a Rust crate that checks the fields of a struct against rules declared with a derive macro.

## Worth knowing

The repository is a Cargo workspace whose derive crate and test crates sit beside the main crate. The newest version on crates.io has no matching tag in the repository, so the registry is where the current release is found.
