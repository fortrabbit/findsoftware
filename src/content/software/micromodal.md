Micromodal is a JavaScript library for creating modal dialogs with no dependencies. The README lists what it manages: ARIA attributes toggled on open and close, closing on an overlay click or the Escape key, focus trapped within the open modal, and nested modals.

## Worth knowing

The README says the project is looking for more core maintainers.
