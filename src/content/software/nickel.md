Nickel is a web application framework written in Rust. Its README says the API is inspired by Express, the JavaScript framework. The project's homepage lists routing with parameters and wildcards, middleware including a static files handler, JSON body mapping onto structs, a custom error handler and mustache templates. An application adds nickel as a Cargo dependency, and the examples have the program listen on a local address.

## Worth knowing

The repository has tags but no GitHub releases. The README's development plan lists the synchronous line as bug fixes only and names the master branch as the asynchronous line.
