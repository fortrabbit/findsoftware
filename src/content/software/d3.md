D3 builds bespoke data visualizations in the visitor's browser. The [getting-started guide](https://d3js.org/getting-started) covers installing it from npm, loading it from a CDN in vanilla HTML, or downloading it. A static site can serve the library as a file, with no server-side process for the visualizations.
