Jasmine is a framework for testing JavaScript code that runs in browsers and in Node.js. The jasmine npm package is the Node.js command line tool that runs specs. The core library is published as jasmine-core and lives in the main repository, while the Node.js package has its own repository. Runs in a browser use the separate jasmine-browser-runner package.

## Worth knowing

The Node.js setup guide labels a global install of the jasmine package as not recommended.
