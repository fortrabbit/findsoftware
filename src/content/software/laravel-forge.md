Laravel Forge is a hosted service for managing servers and deploying applications to them. It provisions servers on a cloud provider or on Laravel VPS and installs a stack that includes Nginx, PHP and the MySQL, Postgres and Redis databases. Sites and servers are managed in a web dashboard, and teams can be given role-based access. Laravel Holdings Inc. operates the service, and a migration tool moves existing Envoyer sites onto Forge.

## Worth knowing

Forge runs as a service operated by Laravel Holdings Inc. rather than as software the user installs. The servers it manages sit on the user's chosen cloud provider or on Laravel VPS.
