Avo is an admin panel framework and content management system for Ruby on Rails, published by Dependev SRL. It is added to a Rails application as a gem, and the [installation guide](https://docs.avohq.io/4.0/installation.html) covers the steps. The install generator mounts the panel inside the host app under the /avo path. Ruby 3.2 or later is required.

## Worth knowing

The license has two parts. The open source code is licensed under the LGPLv3, while the [commercial license](https://github.com/avo-hq/avo/blob/main/COMM-License.md) covers the Pro, Advanced and Enterprise versions, which require a purchased license. The same commercial license lets anyone use the community version commercially for free, on the conditions it sets out.

The pricing page lists a REST API add-on, and single sign-on and role-based access control on the Enterprise plan.
