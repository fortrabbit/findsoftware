Fractal is a tool for building and documenting website component libraries and design systems. It runs as a Node project dependency installed with npm, and its web UI lets you browse the components in a local development server. The same UI can be exported as static HTML files. Templates are rendered with Handlebars by default, and other template engines load through adapters.

## Worth knowing

The GitHub repository is archived, so the project no longer receives changes there.
