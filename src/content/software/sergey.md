Sergey is a static site generator that combines HTML files with partials and named and default slots. Running the sergey command writes the built site to a public folder, which is the folder to upload to a web server. The project's own site calls it a tiny static site generator and says it is still in its infancy.

## Worth knowing

The repository is archived on GitHub.
