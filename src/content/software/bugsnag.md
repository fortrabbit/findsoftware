BugSnag is an error and performance monitoring service for mobile, web, desktop and server applications, run by SmartBear Software Inc. as a hosted platform. The [documentation](https://docs.bugsnag.com) also describes an on-premises installation on a Kubernetes cluster that uses Replicated KOTS. A first on-premises install starts with a contact to BugSnag for a license file and a guided installation.

## Worth knowing

The server code is not public. The docs call the legacy single-machine version deprecated and point to the high availability and single node cluster installs.
