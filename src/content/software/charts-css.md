Charts.css is a CSS framework for data visualization. Each chart is a standard HTML table: the figures sit in the markup as rows and cells, and CSS classes on the table draw them as a chart.

## Worth knowing

The introduction page says charts with special behaviors the framework does not cover call for a JavaScript charting library. The design principles page says the core project does not use JavaScript.
