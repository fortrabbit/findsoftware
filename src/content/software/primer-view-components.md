Primer ViewComponents is the Ruby on Rails implementation of the Primer Design System, built with the ViewComponent library. A Rails application adds it as a gem from its Gemfile, and the [Rails guide](https://primer.style/product/getting-started/rails/) also has the application load the matching @primer/view-components, @primer/css and @primer/primitives packages from npm for its stylesheets and JavaScript.

## Worth knowing

The README places the gem in maintenance mode. It takes no new features, components or significant enhancements; security updates, dependency bumps and critical bug fixes continue, and issues stay open without a guaranteed response. It encourages GitHub's internal consumers to migrate to Primer React, and tells non-GitHub consumers they should consider forking a copy of the repository.
