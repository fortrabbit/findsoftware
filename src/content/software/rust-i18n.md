Rust I18n is a Rust crate for loading localized text from YAML, JSON or TOML mapping files. The mappings are converted into data readable by Rust programs at compile time.

## Worth knowing

The cargo i18n command is an experimental extractor that the README installs from a separate crate, rust-i18n-cli, so it is not part of the library's own install route.
