Gettext is an Elixir implementation of the Gettext system, a standard for internationalization and localization. Source code calls `gettext` macros with the strings written in the source language, and translators supply the translations in Portable Object files, one per locale. Mix tasks extract the strings from the source into template files and merge them into each locale's file.

The library is added to a project as a Mix dependency. Its [documentation](https://gettext.hexdocs.pm/) is published on Hex.
