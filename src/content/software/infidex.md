Infidex is a search engine library for .NET. The application creates a search engine, indexes its documents, and runs fuzzy queries. Results come with ranking, filters and facets. The [README](https://github.com/lofcz/Infidex/blob/master/README.md) names NuGet as the install route.

The README describes saving the index to disk and loading it again.

## Worth knowing

Infidex is a .NET library installed from NuGet, not a hosted service.
