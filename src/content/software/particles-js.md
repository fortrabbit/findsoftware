particles.js draws animated particles inside an element of a web page. A page loads the script, places an element with an id, and calls `particlesJS.load` with that id and a JSON file that sets the number, color, shape, movement and interactivity of the particles. The [generator](https://vincentgarreau.com/particles.js/) on the project's site writes such a configuration, and the [README](https://github.com/VincentGarreau/particles.js/blob/master/README.md) lists the options.
