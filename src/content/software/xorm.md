XORM is a Go library for mapping structs to SQL database tables, with queries, transactions, caching and schema sync. The repository description names MySQL, PostgreSQL, SQLite, SQL Server and Oracle among the databases it supports, and the README adds MariaDB.

The repository moved from GitHub to Gitea. The GitHub copy is archived and names the Gitea repository as its new home, which holds the current code.
