SimplCommerce is an e-commerce system built on .NET Core, organized as self-contained modules inside one application. Its back-office sits at /Admin on the same application, and it keeps its data in a database.

The [README](https://github.com/simplcommerce/SimplCommerce/blob/master/README.md) gives build-from-source steps for Visual Studio with SQL Server and for Mac and Linux with PostgreSQL, and a Docker image marked for testing only. The source is Apache-2.0 licensed and maintained under the SimplCommerce name.

## Worth knowing

The repository has no stable release. Its newest tag is a 2018 release candidate, so the record shows no current version.
