Craft Commerce is an ecommerce platform that runs as a plugin inside [Craft CMS](https://craftcms.com). It is installed in a Craft project from the Plugin Store or with Composer, and it uses the PHP runtime and relational database that Craft needs. Pixel & Tonic, Inc. maintains the plugin.

## Worth knowing

Craft Commerce requires Craft Pro, and the Craft CMS license is separate from the plugin license. The plugin license allows each licensed copy to be installed in no more than one production environment at a time.
