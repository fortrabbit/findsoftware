Grok is a Python web framework based on the Zope Toolkit. The README points new users to the grokproject package on PyPI, which creates a project area and installs Grok into it. The core package is published on PyPI as grok, and the source is on [GitHub](https://github.com/zopefoundation/grok).

## Worth knowing

The project's own website is not reachable. The README links only an archived copy of it, and the documentation site named in the record is the only project site that still answers.
