React Icons supplies React components that draw SVG icons taken from many icon sets. Each set has its own import path, such as `react-icons/md` for Material Design icons, so a project imports only the icons it uses. The package is installed with npm and its README says it requires React.

## Worth knowing

The library code is MIT licensed, but the icons come from the other projects that publish each set. The README lists the license of every set, among them Creative Commons and Apache terms, and asks readers to check each one before using its icons.
