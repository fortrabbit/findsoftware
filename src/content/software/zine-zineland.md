Zine is a static site generator written in Rust that builds a magazine-style website from Markdown articles. The articles are flat files in a content directory, organized into issues. It supports internationalization and localization, and it is installed with `cargo install zine`. `zine serve` previews the site on the local computer, and `zine build` writes the static website, which can be hosted anywhere. The documentation site is built with Zine itself.

The [documentation](https://zineland.github.io/) pages carry a Zine Team byline.
