fast-check is a property-based testing library for JavaScript and TypeScript. A test states a property that should hold for every input that meets a precondition, and the library checks that property against many generated inputs.

A tutorial on the project's website covers the approach. The module is installed with npm, pnpm or yarn as a development dependency. The GitHub repository is a monorepo: beside the core package it holds integrations and a website.
