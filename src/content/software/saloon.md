Saloon is a PHP library for building API integrations and SDKs. It moves each API's requests into reusable connector and request classes, so the configuration for that API lives in one place. It is framework agnostic and works in any PHP application that uses Composer.

## Worth knowing

Caching, pagination, rate limits and Laravel support are installable plugins, added to the core library separately.
