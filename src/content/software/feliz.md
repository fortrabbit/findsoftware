Feliz is an F# library that exposes the React API to code compiled by Fable, so React components are written in F# and emitted as JavaScript. It ships Html and CSS helpers and React hooks, and the Getting Started page describes a .NET template that scaffolds a project using Vite and Tailwind CSS. The library is installed as a NuGet package, and the fable-hub organization on GitHub publishes it.

## Worth knowing

The Getting Started page lists the .NET SDK and Node.js with npm as prerequisites, so a build needs both toolchains.
