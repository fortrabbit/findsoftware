Mongoose is a networking library that a project compiles into its own C or C++ code. Building with it means compiling `mongoose.c` into the program, and the library then provides a TCP/IP stack, TLS, an HTTP and WebSocket server and MQTT. Cesanta Software Limited, based in Dublin, maintains it.

The homepage names device web dashboards and firmware updates among the library's uses.

## Worth knowing

The library is distributed under GPLv2 and under evaluation and commercial license terms. The licensing page says commercial projects can also use the GPLv2 license by releasing the source code of the end product under it.
