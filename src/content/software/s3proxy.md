S3Proxy implements the S3 API and forwards each request to another storage system, so an S3 client can read and write buckets held in AWS S3, Azure Blob Storage, Google Cloud Storage, OpenStack Swift, SFTP or the local filesystem. It is a Java program that runs as an executable jar or from a Docker image, and Java applications can embed it through a Maven artifact. The project is maintained by Andrew Gaul.
