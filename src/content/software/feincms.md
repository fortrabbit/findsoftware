FeinCMS is a content management system built on Django. It creates an admin interface for page content types that a project defines itself, and page content is stored in the Django database. The Python package is installed with pip.

The documentation covers a tree editor and an item editor in the admin, a page translations extension and an extension that limits pages to a site.

## Worth knowing

The project's README says that feincms3 is where current development happens and that FeinCMS is still maintained.
