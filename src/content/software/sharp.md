Sharp is a content management framework packaged for Laravel. It adds a content management section to a Laravel application, with lists, forms and the admin interface defined in code. Code 16, a web agency based in France, develops it. The package is unrelated to the libvips image library of the same name. The [installation guide](https://sharp.code16.fr/docs/10.x/guide/installation) covers setup.
