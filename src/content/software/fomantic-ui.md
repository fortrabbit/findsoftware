Fomantic-UI is a CSS and JavaScript framework that styles components through descriptive class names added to HTML elements, such as "ui primary button". It is a community fork of Semantic UI, created, as its README puts it, to continue active development of Semantic UI. The README states that the fork intends to merge back once that development can restart.

A project installs it with npm or loads it from a CDN provider, and the distribution files can also be hosted locally. The project publishes CSS-only and LESS packages next to the main one.

## Worth knowing

The getting-started guide says theming requires the npm install, because that is how a project gets the files needed to create and manage a theme. The README also says work on a version 3 has started, with its proposals tracked in a GitHub issue.
