freenginx is an HTTP and reverse proxy server written in C, which the project describes as an effort to preserve free and open development of nginx. Its source lives in a Mercurial repository, mirrored on GitHub, and the project publishes Windows binaries alongside the source. The server runs as a master process with worker processes, and support runs through mailing lists.

## Worth knowing

The project publishes its releases on its own news page rather than through GitHub releases, and it maintains a stable line alongside a mainline line.
