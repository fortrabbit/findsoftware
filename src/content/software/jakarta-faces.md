Eclipse Mojarra is Eclipse's implementation of the Jakarta Faces specification for building Java web user interfaces. Pages are written as Facelets files. Mojarra is added to a project either as a Maven dependency or as JAR files copied into the application, as the [README](https://github.com/eclipse-ee4j/mojarra/blob/main/README.md) describes. The Eclipse Foundation AISBL maintains it in the eclipse-ee4j GitHub organization.

## Worth knowing

The source is offered under the Eclipse Public License 2.0. The Maven pom also names GPL2 with the Classpath exception as a secondary license.
