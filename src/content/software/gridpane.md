GridPane is a hosted control panel for WordPress websites. It provisions servers and manages the sites on them from one panel. The panel is set up on a server by running GridPane's provisioning command as root. GridPane has built-in API support for DigitalOcean, Vultr, Linode, Amazon Lightsail and UpCloud, and can be used on custom servers elsewhere, such as Google Compute Engine, Hetzner or OVH. PeakFreq managed servers are provided by GridPane and Vultr together.

## Worth knowing

The Core plan is free and covers up to 25 websites. Paid plans are described on the [pricing page](https://gridpane.com/pricing). The software has no public repository.
