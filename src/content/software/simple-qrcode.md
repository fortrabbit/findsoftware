Simple QrCode generates QR codes for Laravel applications. Its README describes it as a wrapper for the Laravel framework, based on the BaconQrCode library.

## Worth knowing

The website that the project's metadata names no longer serves the software, so the repository's documentation is the reference. According to that documentation, the PNG format needs the imagick PHP extension.
