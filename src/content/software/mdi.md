Material Design Icons is an icon set of Material Design icons, provided as SVG files, as an icon font, and as JavaScript and React packages. The library is maintained by the Pictogrammers collective, and icons are managed on the Pictogrammers site and synced to the GitHub repository, which holds the SVG files and metadata. The npm package @mdi/font carries the webfont, and the [getting started guide](https://pictogrammers.com/docs/library/mdi/getting-started/getting-started/) explains how to use the icons.

## Worth knowing

The getting started guide discourages the webfont because of its performance and request size, and points to other ways of using the icons.
