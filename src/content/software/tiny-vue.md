TinyVue is an enterprise UI component library for Vue that supports both Vue 2 and Vue 3 and covers PC and mobile screens with one code base. A project installs the @opentiny/vue npm package, where the Vue 2 and Vue 3 lines are installed by version, and imports components by name from the package for use in templates. The library supports internationalization and theme customization.

The README credits Element as an influence at the start of the design and says TinyVue is compatible with Element's component API.
