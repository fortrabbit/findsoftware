Eloquent is the ActiveRecord-style ORM inside illuminate/database, a PHP database toolkit that also provides a query builder and a schema builder and serves as the database layer of Laravel. The package can also run outside the framework through its Capsule helper, which its readme describes. The [Eloquent documentation](https://laravel.com/framework/docs/eloquent) in the Laravel docs describes how the ORM behaves.
