Docker Desktop is the application through which developers run the Docker Engine, the Docker CLI and Docker Compose on their own machine. Docker, Inc. publishes it for macOS, Windows and Linux, and the [install guide for Mac](https://docs.docker.com/desktop/setup/install/mac-install/) describes it as a download with system requirements and installation steps. It runs on the developer's computer, not on a hosting service.

## Worth knowing

The proprietary [license agreement](https://docs.docker.com/subscription-billing/desktop-license/) decides who may use the application without payment. Small businesses, personal use, education and non-commercial open source projects may use it free, and professional use in larger organizations needs a paid Docker Pro, Team or Business subscription.
