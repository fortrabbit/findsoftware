Yii 1.1 is the 1.1 line of the Yii PHP framework, a component-based framework for web applications. The [installation guide](https://www.yiiframework.com/doc/guide/1.1/en/quickstart.installation) has users download the release archive and unpack it to a web-accessible directory. The [guide](https://www.yiiframework.com/doc/guide/1.1/en/index) is the documentation, and the source is on [GitHub](https://github.com/yiisoft/yii).

## Worth knowing

The project's README says Yii 1.1 has reached end of life and will only receive necessary security fixes and compatibility fixes. The Yii site's release announcement for the line describes it as in maintenance mode.
