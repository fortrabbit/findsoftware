Z-BlogPHP is a blog and content management program written in PHP, published by the Z-Blog community since 2005. It is installed by uploading the program files to a web directory and then running the browser-based installation wizard, which connects it to MySQL, MariaDB, SQLite or PostgreSQL. A back-end management interface is part of the program, and the project's [app center](https://app.zblogcn.com/) lists free and paid themes and plugins.

## Worth knowing

The [security policy](https://github.com/zblogcn/zblogphp/blob/master/SECURITY.md) places the project in limited maintenance mode.
