Lighthouse is a PHP framework that serves a GraphQL API from a Laravel application. It is added to an existing Laravel project and works with the models and features that project already has.

## Worth knowing

The README says the repository is planned to move to another organization. At the time of research that transfer had not happened, and the package is still published from the original repository. Only the current major version receives new features and bug fixes. The name Lighthouse is shared with an unrelated audit tool.
