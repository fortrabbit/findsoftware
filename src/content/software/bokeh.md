Bokeh is a Python library for interactive plots and data applications. Its output is HTML that a web browser runs, whether as static files, as embedded pages or in Jupyter notebooks, and the Bokeh server runs Python code in a server process that serves interactive applications to browsers. The library is installed with pip or conda.

The project's homepage describes it as a Python library for plots and data applications in modern web browsers. The project is fiscally sponsored by NumFOCUS.

## Worth knowing

A static Bokeh page needs only a web server that serves files. An application built on the Bokeh server needs a Python process that stays running, and the deployment guide describes running several server processes.
