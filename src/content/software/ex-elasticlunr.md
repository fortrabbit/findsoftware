Elasticlunr is a full-text search library for Elixir that indexes JSON documents and provides a search interface to retrieve them. It is installed as the Hex package elasticlunr, and its documentation is on hexdocs.pm. The package describes itself as a port of Elasticlunr.js with more improvements.

## Worth knowing

Indexes are written through a storage provider. The README lists disk and blackhole providers, with S3 as a separate package.
