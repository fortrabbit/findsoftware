Flask-RESTX is an extension for Flask that adds support for building REST APIs and documenting them with Swagger. It is a community-driven fork of Flask-RESTPlus, and projects add it to a Flask application with pip.

## Worth knowing

The documentation index gives the reason for the fork: the original author did not respond to the maintainers, and only that author had rights to publish releases on PyPI. The README and the installation page state a higher minimum Python version than the metadata of the latest release does.
