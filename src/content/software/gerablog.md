GeraBlog is a Ruby gem that generates a static blog from Markdown files. Its layout files are [Tenjin](https://github.com/paulohrpinheiro/gerablog/blob/master/README.md) templates, and the posts stay on disk as Markdown files in category subdirectories rather than in a database. The README says to copy the generated output directory to a server.

The author describes it as a blog generator and as his own static site generator.
