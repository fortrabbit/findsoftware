underblog is a Go command-line static blog generator. Its input is a folder of Markdown files and two HTML templates, for the index and single posts. The date and slug come from each filename, and there is no front matter. The tool is installed with Homebrew, Docker or a downloaded binary, as the [README](https://github.com/freetonik/underblog/blob/master/README.md) describes.

## Worth knowing

The project has no site of its own, and its documentation is the repository README.
