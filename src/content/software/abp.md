ABP Framework is an application framework for .NET that builds on ASP.NET Core. The ABP CLI or ABP Studio creates a solution from a startup template, which can be deployed to a cloud provider, a server, IIS or another web server. Entity Framework Core works with SQL Server (the default), MySQL, SQLite, Oracle and PostgreSQL, MongoDB is a supported database provider, and the framework includes multi-tenancy support. The pricing page offers Team, Business and Enterprise licenses with Pro startup templates and Pro modules. Its localization system builds on Microsoft.Extensions.Localization.

Volosoft Bilişim Anonim Şirketi, registered in Turkey, maintains ABP, which its own pages call the natural successor to ASP.NET Boilerplate.

## Worth knowing

Commercial modules, support and tooling tiers are sold beside the LGPL-licensed framework. The homepage lists Pro modules such as Identity and SSO, SaaS, Payment, Audit Logging, CMS Kit and GDPR.
