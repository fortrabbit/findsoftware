OpenUI5 is SAP's open source JavaScript UI framework for building enterprise web applications. It runs in the browser as a client-side HTML5 rendering library and provides an MVC architecture, data binding to JSON, XML and OData models, and a set of controls that adapt to different devices. The README offers three ways to get it: a download of the runtime and SDK, the UI5 CLI, which manages framework dependencies and builds application packages, and bootstrapping from a CDN as the homepage's example does.

The npm package for the core library is published by SAP SE.
