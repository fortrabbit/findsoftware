dotLottie Web plays Lottie JSON and dotLottie animation files in browsers and in Node.js environments. Its core is written in Rust and compiled to WebAssembly, and it renders through Canvas 2D, WebGL2 or WebGPU, with the backend chosen by the import path.

The core is framework-agnostic. LottieFiles publishes separate first-party packages for React, Vue, Svelte and Solid, and a Web Component.
