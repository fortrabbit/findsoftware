jQuery UI is a set of user interface interactions, effects, widgets and themes built on top of the jQuery library, and it runs in the browser. It is obtained from the project's download builder. Its API documentation is on the [API site](https://api.jqueryui.com), and questions go to the project's forum for jQuery UI users. The OpenJS Foundation maintains it, and the source is in the jquery organization on GitHub.

## Worth knowing

The README states that jQuery UI is in maintenance-only mode. The license has more than one part: the MIT terms cover the code, the sample code in the demos is waived to the CC0 terms, and the libraries kept in its external directories carry their own licenses.
