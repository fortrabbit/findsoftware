Easy Email is a React email editor that builds MJML email templates through drag-and-drop editing. The open-source editor is installed from three npm packages that the README names: easy-email-core, easy-email-editor and easy-email-extensions. The GitHub description says the project is based on React and MJML.

## Worth knowing

Easy Email Pro is a paid edition, sold as a self-hosted SDK. The README's comparison table lists the open-source version as supporting only Chrome, without responsive design or React 19 support, and Pro adds those with a file manager and professional technical support.
