zino is a Rust framework for composable applications, described in its README as spec-driven and strongly opinionated. Its ORM covers MySQL, PostgreSQL and SQLite.

Projects depend on the zino crate, with feature flags such as axum for the web layer, and the README's minimal application runs a server. The crate is published on crates.io and documented on docs.rs.
