Rowy is a web application that shows Firestore data in a spreadsheet-style table and describes itself as a low-code backend. It runs in the user's own Google Cloud or Firebase project: the guided setup deploys it there, and a manual install from the repository exists for developers who want to contribute. Permissions can be set per table and per field, and data can be imported from Airtable.

The project is maintained by Rowy Inc. The homepage promotes BuildShip, a separate product, and a waitlist for Rowy 2.0.

## Worth knowing

Rowy works with Firestore on Google Cloud or Firebase. The docs mention Rowy Pro features, but the pages read here do not say what they include. Some backend features need Rowy Run installed in the user's project.
