React Suite is a set of React components for building web applications. It is installed from npm, and its documentation site includes guides for Next.js, Create React App and Vite. The library includes built-in multi-language support.

## Worth knowing

The README says the 5.x line no longer receives new features, and that its security fixes last only until the 7.x line is in progress.
