Laminar is a Scala.js library for building web application interfaces, and it keeps the interface's state in sync with the application's state. Projects add it to an sbt build as a Scala.js dependency, and the compiled code runs in the browser. Nikita Gazarov maintains it.

## Worth knowing

The README states a minimum Scala.js version that the build must meet. Laminar depends on Airstream, a separate library in the same GitHub account.
