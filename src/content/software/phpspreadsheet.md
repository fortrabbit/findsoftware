PhpSpreadsheet is a library of PHP classes for reading and writing spreadsheet files, with support for Excel and LibreOffice Calc formats. Writing PDF goes through a separate PDF library installed beside it.

The README names the project the next version of PHPExcel, which it says is no longer maintained, and links an automated migration tool from PHPExcel.
