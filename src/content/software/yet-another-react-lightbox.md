Yet Another React Lightbox is a React component for showing images and video slides in a lightbox, written in TypeScript with its type definitions in the package. It is compatible with right-to-left layouts, and its UI labels can be translated. The plugins bundled in the package cover captions, a counter, downloads, fullscreen, inline mode, rotation, sharing, slideshows, thumbnails, video and zoom.

The plugins ship inside the package rather than as separate registry packages.
