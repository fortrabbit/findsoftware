tsdown is a bundler for TypeScript and JavaScript libraries, powered by Rolldown; its guide states that tsdown is built on top of Rolldown. It is added as a development dependency with npm, pnpm, yarn or bun and runs on the developer's machine. The guide states the Node.js versions it needs to run and says the bundled output can target older Node.js versions. The guide documents a migration from tsup.

## Worth knowing

The tsup README names tsdown as the replacement for the tsup project, which it states is no longer actively maintained.
