Rough.js is a JavaScript graphics library that draws in a sketchy, hand-drawn style. The README says it defines primitives for lines, curves, arcs, polygons, circles and ellipses, and that it also draws SVG paths. It works with both Canvas and SVG.

The repository moved from its original owner to the rough-stuff organization.
