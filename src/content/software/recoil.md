Recoil gives React apps shared state. The [documentation](https://recoiljs.org/docs/introduction/core-concepts) covers its core concepts. The package is installed from npm and also publishes a UMD build that loads with a script tag.

The repository on GitHub is archived, so the record is listed as discontinued.

## Worth knowing

The install page says Recoil builds are not transpiled to ES5, and that browsers without native ES6 support are not supported.
