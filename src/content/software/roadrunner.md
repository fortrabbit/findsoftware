RoadRunner is a PHP application server and process manager written in Go. The Go binary starts PHP worker processes and keeps them running, and the core is extended with plugins that the docs describe. The homepage names Spiral Scout, a company, as the project's sponsor.

## Worth knowing

The examples in the install guide need a PHP build with the sockets extension.
