Semantic UI is a UI framework designed for theming, with components distributed as CSS and JavaScript on npm. The [getting started guide](https://semantic-ui.com/introduction/getting-started.html) installs the package semantic-ui and runs Gulp build tasks, which compile the CSS and JavaScript for use in the project. The guide has the reader install Node.js for these build tasks. The guide also names the semantic-ui-css and semantic-ui-less repositories for a default theme and a zip download from GitHub.

## Worth knowing

The README and homepage do not say whether development continues; the homepage asks for donations under "Help Preserve This Project". The React integration is a separate project.
