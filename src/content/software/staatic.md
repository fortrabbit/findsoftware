Staatic is a WordPress plugin that crawls a WordPress site and publishes a static copy of it. Publishing runs from the WordPress admin, and the public site is a deployed set of static files, as the [plugin page](https://wordpress.org/plugins/staatic/) describes.

## Worth knowing

The plugin page lists forms integration, search integration, scheduled publications and change-based publications as Staatic Premium features.
