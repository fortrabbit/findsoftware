Simple-Jekyll-Search is a JavaScript library that adds search to a Jekyll blog and runs in the visitor's browser. The install docs name npm, and the library is recorded as a plugin of Jekyll.

The GitHub repository that the project names as its source is archived, which is the signal behind the discontinued status. The record is kept for its page and stays out of the register.

## Worth knowing

The archive is the only end signal found: the README and the homepage carry no end statement, and the npm package is not deprecated. The homepage is the project's example site for a Jekyll blog.
