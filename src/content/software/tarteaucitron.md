tarteaucitron.js is an open-source JavaScript cookie consent library. It shows a consent banner, and it keeps configured third-party services blocked until the visitor agrees. A site adds the library folder and a script tag, then calls an init function with its options. The library is published on GitHub and npm under the MIT license.

The author also sells a managed service, tarteaucitron.io Pro, with automatic detection of supported services, an online configuration dashboard and consent statistics.

## Worth knowing

Initializing the banner alone does not block scripts that the site already loads elsewhere, and using the library does not by itself make a website comply with the GDPR. The README states both points.
