Flowbite Svelte is a set of Svelte components styled with Tailwind CSS. Its introduction describes it as built on the core Flowbite components, with interactivity handled by Svelte itself. The quickstart sets up a SvelteKit or Vite project, then installs the package together with the flowbite package. The source lives in the themesberg organization on GitHub, and Shinichi Okada is named as its creator.
