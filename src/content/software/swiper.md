Swiper is a JavaScript slider library for carousels in websites and web apps, with modules for navigation, pagination and effects. The package exports only the core version by default, so the modules a slider uses are imported and configured separately.

The project's React and Vue bindings and its Swiper Element web components ship from the same project. The library does not require jQuery or any other JavaScript library, and it supports right-to-left layouts. The Swiper site has comparison pages against Embla Carousel, Flickity, Glide.js, Keen Slider, Owl Carousel, Slick and Splide.

## Worth knowing

Premium templates and plugins from UI Initiative are add-ons to the project. They are not an edition of Swiper.
