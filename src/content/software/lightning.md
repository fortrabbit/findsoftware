Lightning is an HTTP server and TCP client and server framework written in Swift. It is added to a project as a dependency of a Swift Package. The project was formerly named Edge.

## Worth knowing

The project has no stable release. Its GitHub releases are all marked as prereleases, and the newest one is a prerelease. The repository has no homepage of its own; its README links only to a chat invitation.
