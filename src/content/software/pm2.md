PM2 is a process manager for Node.js and Bun applications. It runs as a daemon process manager that keeps applications online and has a built-in load balancer. It is installed with npm or with Bun. The project is maintained by KEYMETRICS, a French company that also runs the PM2 Plus monitoring service.

## Worth knowing

The open source runtime is licensed under the GNU Affero General Public License 3.0, and the README says other licenses are available on request. PM2 Plus is a hosted monitoring dashboard with no free plan. The [pricing page](https://pm2.keymetrics.io/pricing/) also lists PM2 Enterprise, with advanced optimization and profiling features, offered after contact.
