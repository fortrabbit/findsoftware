Basscss is a low-level CSS toolkit of utility classes that the project describes as immutable, composable and responsive by default. The modules cover type scale, typography, layout, alignment, spacing, position, grid, flexbox, border and hiding, and the install line on the homepage offers npm or a CDN link.

## Worth knowing

The README says version 8 is the final version of Basscss: no major breaking changes will follow, while minor features and patches may still be added.
