React Storefront is a framework for building eCommerce progressive web apps, built on Next.js. It connects to commerce platforms through their APIs and renders pages on the server. A new app is created with an npm create command, and the framework is deployable to any environment that runs Node.js. The README names Layer0, a serverless platform, as the easiest place to deploy it.
