Microweber is a website builder and content management system built on the Laravel framework, with a drag-and-drop editor. Editors manage content in an admin panel and change text on the site itself in a live edit view. The project describes websites, blogs and online stores as its uses.

It is installed with Composer or from a downloaded archive, and the PHP process needs write access to the files the README names.
