HappyX is a Nim framework for full-stack web work, which its README describes as macro-oriented. The README describes it for single-page, static site and server-rendered applications. It is installed with `nimble install happyx`, and the MIT license is held by the HapticX organization, which publishes the framework on GitHub. The README sets HappyX against Jester and Karax, the two frameworks it names as alternatives.
