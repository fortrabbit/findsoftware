webmozart/assert is a PHP library of assertions for checking the input and output of methods. Each assertion throws an exception when it fails, and a custom message can use a placeholder for the tested value, with the same placeholder order for every assertion. The README says the library is heavily inspired by beberlei/assert and fixes a usability issue with that package's error messages.
