Aurora is a static site generator implemented in Python. Pages are written in Markdown, Jinja2 and HTML, and the build writes the finished site as static files. It installs with pip from the aurora-ssg package on PyPI.

## Worth knowing

The README states that as of August 29, 2026, Aurora is being archived and will soon no longer be maintained. The GitHub repository was not archived at the check date.
