Hypercorn is an ASGI and WSGI web server for Python applications, installed from PyPI with pip. Its docs describe it as based on the sans-io hyper library and its README says it supports HTTP/1, HTTP/2 and WebSockets, with optional HTTP/3 through an extra. It began as part of Quart and was forked from Quart 0.5.0. P G Jones maintains it under the MIT license, and the repository is on GitHub.

## Worth knowing

The current release requires a newer Python than the installation page of the docs states.
