feincms3 is a Django toolkit for building a content management system, published by the feincms organization. It is installed with pip and, per its docs, builds on Django, django-content-editor and django-tree-queries. Its docs call it a library.

The toolkit includes Django admin classes for tree-structured models, a multilingual sites guide and a multisite setup. Its docs list PostgreSQL, SQLite and MariaDB as the supported databases.
