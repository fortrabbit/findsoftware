GSAP animates web pages in the browser, and its plugins cover scroll, SVG, text and UI animation. The [installation guide](https://gsap.com/docs/v3/Installation) describes the core file and all the plugins as plain JavaScript files, installed with npm or Yarn or loaded with a script tag.

## Worth knowing

GSAP is free to use under the project's own "Standard No Charge" license, which has no SPDX identifier. The license bars use in tools that compete with Webflow's visual animation builder, and it names Webflow as the owner of the intellectual property.
