NVIDIA Elements is a design system and UI library of Web Components for interfaces in AI infrastructure, robotics and autonomous vehicle tools. Its homepage says the components run in React, Angular, Vue, Svelte, Lit and plain HTML. The core package is imported from npm as @nvidia-elements/core, and the [CDN guide](https://nvidia.github.io/elements/context/integrations/cdn.md) describes loading the packages from a CDN without a build step. A command-line tool, nve, installs from a script or from npm and creates a project.

## Worth knowing

The repository is a monorepo. Its themes, forms, lint and other packages are released separately, so only the core package's releases are counted here.
