RevoGrid is a JavaScript data grid component for showing and editing large tables. It is a web component built with StencilJS: a page places the element and sets its columns and rows. Framework wrappers for React, Angular, Svelte and Vue are built from the same repository. The component depends on browser APIs, so a server-rendered React page has to render it on the client.

## Worth knowing

A paid edition, RevoGrid Pro, adds modules such as pivot tables, charts, Gantt charts, a scheduler and kanban boards under its own license agreement, separate from the open library.
