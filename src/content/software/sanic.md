Sanic is an asynchronous web framework for Python, installed with `pip install sanic`. The [running guide](https://sanic.dev/en/guide/running/running.html) describes its own server, which starts several worker processes and routes traffic between them. The copyright line in its MIT license names the Sanic Community as the maintainer, and its extensions and testing tools are separate packages.

## Worth knowing

The minimum Python version is stated two ways: the package metadata and the README for the latest release require Python 3.10 or higher, while the getting-started page says Python 3.9 or higher.
