Semiotic is a React data visualization library for charts, network graphs and streaming data. Its chart components render SVG automatically in server environments, and the non-streaming ones can be imported into a Next.js Server Component.

The package also ships an MCP server and agent skill files for AI coding assistants, and its package description names deterministic chart validation. The README points readers to Recharts for a standard dashboard chart and to Apache ECharts for rendering very large data sets.

## Worth knowing

React is a peer dependency, so React must be installed beside the library.
