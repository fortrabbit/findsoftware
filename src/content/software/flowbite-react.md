Flowbite React is a set of React components styled with Tailwind CSS. It is built on the core Flowbite components. The project is installed through a scaffolding command that creates a new application, or through an init command that adds the components to an existing one. Bergside Inc. holds the copyright, and the source lives in the themesberg organization on GitHub. The package on npm is the core library the install docs name.

## Worth knowing

The README says the project is a pre-release and that its APIs may change before a final release.
