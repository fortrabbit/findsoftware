Odoo is a suite of web-based open source business apps, with a website builder and an e-commerce app among them. It is a Python application that keeps its data in PostgreSQL, and it runs as a server process started with odoo-bin, either from the source tree or from the packaged installers. Odoo S.A. maintains it.

## Worth knowing

The Community edition is licensed under LGPLv3, while Enterprise is offered as a paid subscription with extra apps, infrastructure and professional services. Odoo S.A. also hosts the software on a cloud platform, which its Enterprise subscription agreement covers.
