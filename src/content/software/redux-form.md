Redux Form connects the inputs of a React form to a Redux store, so the state of the form lives in the store. It works with React Redux.

## Worth knowing

The project's own homepage says not to begin a project with Redux Form and names React Final Form as the library to use instead. The README says the only good reason to use it is a need for tight coupling of form data with Redux, and links a migration guide for projects that already use it.
