compojure-api is a library on top of Compojure for building web APIs. It adds data coercion and Swagger API documentation to the routes that Compojure defines, and it is added as a Maven coordinate in a deps.edn or Leiningen project. It runs on the Java virtual machine, and the README states Java 1.8 as the requirement. The documentation is the project's GitHub wiki.

## Worth knowing

The README's first line asks anyone starting a new project to consider reitit. It does not say the project has ended.
