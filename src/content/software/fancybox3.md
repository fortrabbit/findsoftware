fancyBox 3 is a jQuery lightbox script that shows images, videos and other media in an overlay over the current page. The README's quick start loads jQuery, the downloaded Fancybox script and its stylesheet with tags on the page. The README describes the script as touch enabled, responsive and customizable.

The repository is archived. Its README says the project is now part of the fancyapps/ui repository, where the current Fancybox ships as part of Fancyapps UI. Fancyapps publishes the software, and its terms page names Jānis Skarnelis as the author.
