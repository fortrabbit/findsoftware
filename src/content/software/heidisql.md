HeidiSQL is a desktop client for managing MariaDB, MySQL, SQL Server, PostgreSQL, SQLite, Interbase and Firebird databases. Its homepage says that once connected, a user can edit data and structures in these databases. It runs on the user's own computer and connects to a server or SQLite file the user can reach, so it is not part of a website's own server. The homepage dates the project to 2002.

The download page lists Windows installers, portable archives, winget and Chocolatey packages, Debian and RPM packages, a Flatpak and a macOS app bundle. Ansgar Becker maintains the project, which is released under the GPL.

## Worth knowing

HeidiSQL does nothing on its own: it needs a database server or SQLite file to connect to.
