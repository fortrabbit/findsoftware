Spark Framework is a micro framework for web applications in Java and Kotlin. The library is published to Maven Central as `com.sparkjava:spark-core`, and the [documentation](https://sparkjava.com/documentation) covers routes, requests, responses, filters, sessions, static files and WebSockets. Per Wendel, the founder, is its main maintainer. Community wrapper libraries provide template engines, among them Velocity, Freemarker, Mustache, Handlebars, Jade, Thymeleaf and Jetbrick.

## Worth knowing

Standalone Spark runs on an embedded Jetty web server, so an application built with it runs as its own long-running process.
