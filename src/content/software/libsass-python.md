libsass-python is a Python binding for LibSass, the C/C++ implementation of Sass, which compiles Sass and SCSS to CSS from Python code. The binding is published on PyPI as libsass and installed with pip. Hong Minhee wrote the binding.

## Worth knowing

LibSass has reached its end of life and will receive no updates, and neither will its wrapper libraries. The README tells users to migrate to Dart Sass. The GitHub repository is archived.
