Puma is a threaded application server for Ruby and Rack applications, and Ruby on Rails uses it as its default server. The gem installs with gem install puma or with an entry in the Gemfile. The [project documentation](https://puma.io/puma/) is the README of the current release.

Evan Phoenix created Puma in 2011 as a derivative of Mongrel.
