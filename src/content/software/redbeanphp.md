RedBeanPHP is an object relational mapper for PHP that generates tables and columns on the fly as data is stored. The [homepage](https://www.redbeanphp.com) describes it as a zero-config ORM.

The recommended install is a download: a tarball holding the compiled rb.php script. Composer is also a route, which the install page marks as not recommended.

## Worth knowing

The [About page](https://www.redbeanphp.com/about) lists existing applications with a custom database as a less suitable project and names Propel to use instead.
