Flickity is a JavaScript library for touch-enabled, responsive, flickable carousels. The [README](https://github.com/metafizzy/flickity/blob/master/README.md) gives the install routes and points to the [documentation site](https://flickity.metafizzy.co) for complete docs and demos. It can be installed from npm or Bower, loaded from a CDN, or downloaded as files, and Metafizzy LLC maintains it.

## Worth knowing

The repository holds no LICENSE file. The open source option is GPLv3, and a project that keeps its source code proprietary needs the commercial license that the [license page](https://flickity.metafizzy.co/license.html) describes. The documentation and the CDN paths name a major line older than the newest package on npm.
