Capybara is a Ruby library that drives a web application the way a user would: it visits pages, clicks links and buttons, fills in forms and checks what is on the page. It plugs into RSpec, Cucumber, Minitest and Test::Unit, and Rails and Rack applications need no extra setup. The Rack::Test driver runs against a Rack application in the same process, and the Selenium driver runs the same tests in a real browser. WebKit is supported through an external gem. Installation is a Gemfile entry or a RubyGems install.
