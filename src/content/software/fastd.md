FastD is a PHP framework for API services, built on PSR standards and optionally on the Swoole extension. The README describes four run modes: a Swoole server that stays resident in memory, FastCGI for PHP-FPM deployments, a console runner and a multi-process runner.

The framework is organized around a PSR-11 container, PSR-14 events, PSR-7 messages and PSR-15 middleware.

## Worth knowing

The README is in Chinese; it links documentation in Chinese and in English.
