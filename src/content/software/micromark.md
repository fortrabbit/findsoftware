micromark is a markdown parser for JavaScript that follows CommonMark. It emits concrete tokens with positional information and compiles them to HTML, and other tools can build a syntax tree from the same tokens. GFM, MDX, math and frontmatter support come from extensions.

## Worth knowing

The package is ESM only, as its README states. The README calls the project a sibling of the Rust markdown-rs.
