Halfmoon is a CSS framework built to replace Bootstrap's stylesheet. It ships no JavaScript of its own: the [documentation](https://www.gethalfmoon.com/docs/) says it relies on Bootstrap's bootstrap.bundle.js instead. It comes with three built-in themes with dark mode, and installs from npm, yarn, a CDN or a download of the compiled CSS.

## Worth knowing

A page that uses Halfmoon's interactive components also loads Bootstrap's JavaScript bundle, since Halfmoon provides none.
