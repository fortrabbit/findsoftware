Faker is a Python package that generates fake data. It is installed with pip from PyPI, and its [extended docs](https://faker.readthedocs.io/en/stable/) list the bundled providers and the [community providers](https://faker.readthedocs.io/en/stable/communityproviders.html).

The LICENSE file names Daniele Faraglia as copyright holder, and the repository belongs to the joke2k account on GitHub.

## Worth knowing

The package was earlier published as fake-factory, which the README calls deprecated. The README asks that projects and their dependencies do not depend on the old package.
