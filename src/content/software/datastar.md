Datastar is a hypermedia framework in which the backend drives the frontend through HTML attributes. The getting started guide names a script tag that loads the framework from a CDN as the quickest way to use it, and recommends hosting the script file yourself. The guide says it needs no npm packages or other dependencies. The [Star Federation page](https://data-star.dev/star_federation) says the framework is backed by Star Federation, a 501(c)(3) nonprofit organization, and developed and maintained by a few core team members. The project publishes its code on GitHub.

## Worth knowing

Datastar Pro is a paid add-on under a commercial license. It adds functionality to the open source framework, and its pricing is on the [Pro page](https://data-star.dev/pro).
