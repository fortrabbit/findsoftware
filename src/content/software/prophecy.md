Prophecy is a PHP object mocking framework. It builds test doubles from predictions of how an object will behave. It was first written to serve phpspec2, and its README says it can be used inside any PHP testing framework. The README shows it under the development dependencies of a project.

## Worth knowing

The README FAQ says Prophecy does not support calling the original methods on a prophesized class.
