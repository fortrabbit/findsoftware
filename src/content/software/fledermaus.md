Fledermaus is a static site generator that renders JSX templates and Markdown sources into HTML files. It is added to a project as a development dependency, and the site is built by a script the project writes itself. The README describes a local server for previewing and uploading the built site to GitHub Pages.

## Worth knowing

The repository is archived.
