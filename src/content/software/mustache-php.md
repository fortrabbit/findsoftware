Mustache.php is a PHP implementation of the Mustache template syntax. An application creates a Mustache engine and renders a template against a context object. Documentation lives in the project's [wiki](https://github.com/bobthecow/mustache.php/wiki/Home).

## Worth knowing

The README says the newest major version changes some defaults, such as the strict callables option, and that configuration options restore the previous behavior.
