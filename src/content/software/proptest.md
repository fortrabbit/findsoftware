Proptest is a property-based testing library for Rust. It generates arbitrary inputs for a test and reduces a failing input to a minimal case that still fails. Its design is inspired by the Hypothesis framework for Python, and it belongs to the QuickCheck family of testing tools. Generation and shrinking are defined per value instead of per type.

## Worth knowing

The README says the crate is close to feature-complete and mainly sees passive maintenance.
