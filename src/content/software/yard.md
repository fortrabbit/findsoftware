YARD is a documentation generation tool for Ruby code. It is installed as a gem with `gem install yard`, and the `yardoc` command generates documentation from a project's source files, by default from `lib/**/*.rb`. The `yard server` command serves the generated documentation for a project or for installed gems, and reloads changed files while it runs.

## Worth knowing

The [README](https://github.com/lsegal/yard/blob/main/README.md) describes the server as a preview for a project under development. It does not describe publishing the generated output.
