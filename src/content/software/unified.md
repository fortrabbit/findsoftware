unified is the core package of a collective of packages that process content as syntax trees. It parses content into a tree, lets plugins inspect and transform the tree, and serializes the result back to text. The markdown, HTML and natural-language ecosystems built around it, remark, rehype and retext, are separate projects that connect to it.

## Worth knowing

The package is ESM only.
