Enhance is a web framework for multi-page web apps, built around HTML and Web Components. Apps and their elements are server-side rendered. Enhance is written in JavaScript and runs on Node.js. The GitHub organization Enhance maintains it.

## Worth knowing

The repository the record names holds a README and a license only. The framework's modules live in separate repositories that the README links, and this record does not cover them.
