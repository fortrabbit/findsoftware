XState is a JavaScript and TypeScript library for state management and orchestration. It models application logic as state machines, statecharts and actors.

The same repository holds the @xstate/store, @xstate/react, @xstate/vue, @xstate/svelte, @xstate/solid and @xstate/effect packages. Stately, the company founded by the library's creator, offers Stately Studio, a hosted visual editor that its docs describe with premium features, as a separate product.

## Worth knowing

The README and docs present a beta of the next major release as the install route, while the npm latest tag is the stable line.
