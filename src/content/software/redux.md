Redux is a JS library for global state management in applications. The core package is standalone: the README says it can be used with React or with any other view library, and that it helps applications run in client, server and native environments.

The Redux Toolkit package wraps the core and is the approach the README names as the official recommended way to write Redux logic. React bindings are a separate package, named on the installation page.
