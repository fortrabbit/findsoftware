Stenope is a static website generator for Symfony. It runs in a Symfony environment and is added to an existing Symfony application with Composer. The build step dumps every page of the application into a static HTML file. It provides a Twig extension for templates.

## Worth knowing

The README states that Stenope is not a ready-to-use blog system.
