uWSGI is an application server and process manager written in C. Its project describes a full stack for building hosting services, in which application servers for several languages and protocols sit beside proxies, process managers and monitors. It installs from distribution packages, from source with its own build script, with pip or with gem install. A master process respawns the worker processes when they die.

## Worth knowing

The project is in maintenance mode, which the documentation limits to bugfixes and updates for new language APIs. The documentation also says questions on GitHub issues and pull requests may take a long time to get an answer.
