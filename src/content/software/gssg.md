Generic Static Site Generator is a static site generator written in JavaScript. It is installed globally from npm as generic-static-site-generator, started with the `gssg` command, and configured through a `config.json` file. The README says it treats webpages as objects that can be evaluated.

## Worth knowing

The license is stated two ways: the LICENSE file and the README say MIT, and the package.json published to npm says ISC.
