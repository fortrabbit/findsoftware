Symfony Form is a PHP component for creating, processing and reusing HTML forms. In a Symfony application the framework creates and configures the form factory; in any other PHP application the application creates it. Twig is supported as a template engine through an integration.

The repository is a read-only split of the main Symfony repository, which takes the issues and pull requests.
