Netty is a Java framework for network applications. Its asynchronous, event-driven model lets a developer build protocol servers and clients, such as TCP and UDP socket servers, through one API. A project adds the netty-all artifact as a Maven dependency.

## Worth knowing

The downloads page marks the 5.x line as development and the 5.x user guide as abandoned and not supported, so a project on 5.x depends on a preview with no stable release behind it.
