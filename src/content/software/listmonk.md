listmonk is a newsletter and mailing list manager that ships as a single Go binary and needs a PostgreSQL database to run. The [installation guide](https://listmonk.app/docs/installation/) describes an install command that creates the tables in that database. The binary can be downloaded and run directly, or run as a container with Docker Compose. Kailash Nadh, an individual, maintains the project.
