Zensical is a static site generator for project documentation, written in Rust and Python and distributed as a Python package. It is built by the creators of Material for MkDocs, and its documentation includes a guide for moving an existing MkDocs project to it.

A project installs Zensical with pip, uv or conda-forge and builds the site with `zensical build`. The publishing guide describes the static site being automatically built and deployed.

## Worth knowing

Zensical Studio is a separate product, not part of the open source code. Its license page describes it as a commercial product under its own end user license agreement, and its pricing page lists a Pro edition that adds project-wide refactoring. The Zensical code itself is MIT-licensed.
