ReactPy is a Python library for building user interfaces out of components, without writing JavaScript. The [documentation](https://reactpy.dev/) describes its components as similar to those in ReactJS. It is installed with pip alongside one of its native backends: Starlette, FastAPI, Flask, Sanic or Tornado. Django, Jupyter and Plotly Dash are reached through separate packages.

## Worth knowing

The [running guide](https://reactpy.dev/docs/guides/getting-started/running-reactpy.html) says the development server started by `run()` suits testing, and that a production deployment runs the application under an ASGI or WSGI server from the command line. The server then stays running on the host.

The documentation site says it is still under construction.
