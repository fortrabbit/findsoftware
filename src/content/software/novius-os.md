Novius OS is a content management system designed as an application platform. A site is assembled from existing applications or from applications a team builds for its own content. It is built on the FuelPHP framework, and its installation guide describes an install script, a zip download or a git clone.

Multilingual and multisite content needs no extra plug-in.
