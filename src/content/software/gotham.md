Gotham is a web framework for Rust, published as the `gotham` crate on crates.io, with its API documentation on docs.rs. Applications are written in Rust and start a server from Rust code, as the homepage's hello-world example does.

The framework uses Tokio for async and Hyper as its HTTP server. The crate manifest lists Shaun Mangelsdorf first among its authors. The code is available under the MIT License or the Apache License, Version 2.0, at the user's option.
