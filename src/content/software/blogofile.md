Blogofile is a static website compiler and blog engine written in Python. It renders the whole site as static HTML, so any web server can host the output, and its templates use Mako or Jinja2. Posts are files written in reStructuredText, Markdown or Textile. It is installed with pip, and the migration guide names a converter for WordPress blogs.

## Worth knowing

The GitHub repository is archived, and the project's own domain no longer resolves, so the repository is the only place its documentation can be read. The LICENSE.txt says the author does not enforce violations of its MIT-style license.
