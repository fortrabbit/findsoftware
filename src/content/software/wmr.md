WMR is a development tool for web apps, distributed as the `wmr` npm package. A new project starts with `npm init wmr`, and an existing one adds the package with `npm i -D wmr`. Its development server can serve any directory like a static file server. The production build crawls and prerenders the app's pages to static HTML at build time.

## Worth knowing

The README says WMR is no longer maintained and recommends Vite with `@preactjs/preset-vite` instead.
