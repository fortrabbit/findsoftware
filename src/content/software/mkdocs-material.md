Material for MkDocs is a documentation framework built on MkDocs, a static site generator for project documentation. It turns a directory of Markdown files and a configuration file into a static documentation site, with search that runs in the visitor's browser, code annotations and generated social cards. The package is installed with pip, and an official Docker image is provided for local previewing only. The publishing guide describes building the site and deploying it to GitHub Pages or GitLab Pages. Martin Donath maintains the project.

## Worth knowing

The project is in maintenance mode. Critical maintenance continues through May 5, 2027, and the project names Zensical as its successor.
