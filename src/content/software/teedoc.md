teedoc is a documentation site and blog generator written in Python. It converts Markdown and Jupyter notebook sources into HTML pages, and the README says the generated static HTML files are copied to a server or another host. The README lists support for multiple documents in one site, plugin-provided themes and Jinja2 layout templates. The [official site](https://teedoc.neucrack.com) is the project's own documentation.

## Worth knowing

The PyPI package page links to a different GitHub account, Neutree/teedoc, than the README does.
