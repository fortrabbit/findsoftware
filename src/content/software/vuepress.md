VuePress is a Vue-powered static site generator for Markdown-based sites. Each page is pre-rendered as static HTML, and the page runs as a single-page app once it has loaded. Its content lives in Markdown files, and Vue components can be used inside Markdown. The project is maintained by the VuePress Community.

## Worth knowing

The repository README labels the project a release candidate. The npm latest release is an older line, while the [documentation](https://vuepress.vuejs.org) describes a newer line that is also a release candidate. The README points users of the older line to a migration guide on the documentation site.
