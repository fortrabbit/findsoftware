nivo is a set of React components that draw data visualization charts, built on top of d3 and React as its homepage states. It is a monorepo of scoped packages: the README says to install the core package and then the scoped packages for the charts a project uses. The [documentation](https://nivo.rocks/) is the project's own site.

## Worth knowing

The README lists server-side rendering among its features.
