Hot Chocolate is a GraphQL server for .NET that builds a GraphQL schema from C# classes. In implementation-first mode, a source generator turns attributed classes into schema types. In code-first mode, the schema is described with a fluent type descriptor API. The server runs on ASP.NET Core and returns results over HTTP, WebSocket and Server-Sent Events. The [getting-started guide](https://chillicream.com/docs/hotchocolate/get-started-with-graphql-in-net-core) creates a project from the Hot Chocolate templates. ChilliCream Inc. maintains it in the graphql-platform repository, alongside Strawberry Shake, Fusion, Nitro and Mocha.
