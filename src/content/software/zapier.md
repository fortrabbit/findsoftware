Zapier is a hosted no-code automation service that connects web apps and AI agents into workflows, built by Zapier, Inc. Its [Help Center](https://help.zapier.com) documents the service, and a [community forum](https://community.zapier.com) is linked from the site. Accounts support role-based access by role and workspace, and the security page lists SAML 2.0 and SCIM for sign-in and user provisioning.

## Worth knowing

The service runs in the cloud from the United States, and the pages read name no self-hosted version, so workflows run on Zapier's infrastructure.
