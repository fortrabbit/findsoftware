Capistrano is a deployment tool written in Ruby that connects to remote servers over SSH and runs the deployment tasks defined in a project. The `cap` command runs on the developer's machine after the Capistrano gem is installed, either as a standalone gem or through a Gemfile. The project's documentation lists third-party plugins on its own site, and the README describes the tool as built on Ruby, Rake and SSH.
