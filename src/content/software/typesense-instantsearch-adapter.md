The Typesense InstantSearch Adapter is a JavaScript library that lets a search interface built with InstantSearch.js query data held in a Typesense search server. Its README describes it as an adapter that uses InstantSearch.js with a Typesense search server, and it is installed with npm or yarn or loaded with a script tag. Typesense, Inc. maintains it, and the npm package carries the same name as the repository.

## Worth knowing

The project states its license two ways: the MIT license in the repository's LICENSE file, and Apache-2.0 in the npm package of the latest release.
