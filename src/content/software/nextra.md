Nextra is a framework on top of Next.js for building content-focused websites from Markdown and MDX. It is installed with npm into a Next.js project, alongside the nextra and nextra-theme-docs packages, and its homepage describes hybrid rendering with Server Components and Incremental Static Regeneration. Pages can be exported as static files, as described in the [static exports guide](https://nextra.site/docs/guide/static-exports). The project is maintained by The Nextra Project.

## Worth knowing

According to its [FAQ](https://nextra.site/docs), the current major version of Nextra works only with the Next.js app router, and only earlier major versions support the pages router.
