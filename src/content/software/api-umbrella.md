API Umbrella is an open-source API management platform that the project describes as a reverse proxy between API users and the APIs behind it. The [README](https://github.com/NatLabRockies/api-umbrella/blob/master/README.md) says the platform takes over access control, rate limiting and analytics, so API code does not need to change. The [documentation](https://api-umbrella.readthedocs.org/en/latest/) describes installation from binary packages and from source.

## Worth knowing

The installation pages describe an older release line than the newest tags in the repository, so the steps need checking against the current version.
