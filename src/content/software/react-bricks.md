React Bricks is a visual headless CMS for React and Next.js. Developers define content blocks as React components and choose which props editors may change, and editors compose pages on the site from those blocks. The frontend stays a React application the development team hosts, while the CMS backend is provided as a hosted service by F2 .net engineering s.r.l., based in Bergamo, Italy.

## Worth knowing

The features listed on the pricing page as SSO, custom roles and multilanguage content are plan rows, and the self-hosted backend is an enterprise option delivered as Docker images.
