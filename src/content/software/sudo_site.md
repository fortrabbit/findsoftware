sudo_site is a static site and blog generator written in C++. It is compiled with g++ from a clone of the repository, and running the compiled program inside the project directory generates the site. The README says the repository supplies all the libraries it uses, so no other dependency is installed.

A GitHub Actions workflow in the repository can build the site on GitHub and push it to another repository.
