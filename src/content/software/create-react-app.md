Create React App is a command-line tool that creates React single-page apps with a preconfigured build setup. It is started with `npx create-react-app`. The production build produces static HTML, JavaScript and CSS files, so Node.js is needed on the development machine and not on the server.

## Worth knowing

The project's site and its README both call it deprecated, and the README describes it as in long-term stasis.
