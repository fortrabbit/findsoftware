LinkFree Generator is a web form that produces a single `index.html` file, a link-in-bio page, which the README says can be uploaded to any hosting service. The README links guides for hosting that file on GitHub Pages, Netlify and Vercel, and describes the project as a graphical interface to generate your own LinkFree. The contributing guide says the project is written in PHP and works with PHP's built-in development server.
