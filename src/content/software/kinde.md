Kinde is a hosted service for authentication, user management and authorization. Web and mobile apps connect to it through SDKs and an API. The security page lists OAuth 2.0 among its protocols, a migration guide calls Kinde OAuth2/OIDC compatible, and the pricing page lists SAML single sign-on.

The docs index lists SDKs for server, front-end and native platforms, along with a Management API and an Account API. Migration guides cover moving users over from several other identity services.

## Worth knowing

Pricing is per monthly active user, and the free tier covers 10,500 monthly active users. Some plans also count monthly active organizations. The [supported data regions page](https://docs.kinde.com/get-started/learn-about-kinde/supported-data-regions/) lists Sydney, Oregon, Quebec, Dublin and London, and says the region cannot be changed once selected.
