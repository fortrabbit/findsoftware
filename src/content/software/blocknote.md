BlockNote is a block-based rich text editor for React, built on Tiptap. A project installs it with npm and renders the editor with the React components. The editor interface can be localized into multiple languages. The getting-started guide tells projects on Next.js or other server-side React frameworks to disable server-side rendering of the editor.

OpenBlocks B.V. maintains it. The [documentation](https://www.blocknotejs.org/docs) is on the project's site.

## Worth knowing

The core is licensed under MPL-2.0. The XL packages, which include AI integration and multi-column layouts, are licensed under GPL-3.0; closed-source applications that use them need a commercial license, sold as the Business tier on the [pricing page](https://www.blocknotejs.org/pricing).
