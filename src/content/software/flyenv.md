FlyEnv is a desktop application for Windows, macOS and Linux that sets up a local development environment on the host operating system. Its runtimes and services run directly on the machine, without a container layer. The project describes it as having local sites, HTTPS and an MCP server for AI coding agents. The application is built with Electron, according to its package manifest, and its source is on GitHub.

## Worth knowing

Premium features need a one-time paid license, which covers one device at a time. The repository holds two license statements: the README and the LICENSE file say BSD 3-Clause, and the package manifest says MIT.
