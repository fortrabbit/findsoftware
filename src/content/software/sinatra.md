Sinatra is a Ruby DSL for building web applications: routes are declared in blocks and the application runs as a Ruby program. It is installed as a gem next to a Rack server such as Puma, and its templates can be written in many engines, among them ERB, Haml, Slim, Liquid, Markdown and Builder. The MIT-licensed project is maintained by Blake Mizerany, Ryan Tomayko, Simon Rozet and Konstantin Haase.

## Worth knowing

The [README](https://github.com/sinatra/sinatra/blob/main/README.md) says code changes take effect only after the server restarts, so a Sinatra application is a running server process.
