Cucumber.js is the JavaScript implementation of Cucumber, a tool for running automated tests written in plain language. It is installed from npm as @cucumber/cucumber and runs on maintained versions of Node.js.

The package is licensed under MIT. The copyright line in the license names Julien Biezemans and contributors.

## Worth knowing

The install guide directs users away from the older cucumber npm package, which is deprecated, to @cucumber/cucumber.
