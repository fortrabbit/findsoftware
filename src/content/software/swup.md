swup is a page transition library for server-rendered websites. It intercepts link clicks, loads the next page in the background and animates between the old and new content, replacing only the content containers that are configured.

A site loads it through a bundler, or through a script tag from a CDN when it has no bundler. Extra behavior comes from plugins that the project lists in its plugin directory.
