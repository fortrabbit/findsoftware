Primer React is the React implementation of GitHub's Primer design system, published by GitHub, Inc. as the npm package `@primer/react`. It is installed with npm or yarn alongside its peer dependencies, and the [getting-started guide](https://primer.style/product/getting-started/react/) describes the install steps.

## Worth knowing

The documentation states browser support for the current versions of Chrome, Firefox, Safari and Microsoft Edge.
