Less is a backwards-compatible language extension for CSS. Its official page installs the npm package less, which provides the lessc command for Node.js, and it also shows loading Less in the browser through a stylesheet link and a script from jsDelivr. The project is a monorepo on GitHub maintained by Alexis Sellier and The Core Less Team.

## Worth knowing

A next major version is in alpha prereleases, and the record lists the stable release.
