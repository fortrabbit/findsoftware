axe-core is a JavaScript accessibility testing engine. Its rules cover the WCAG criteria at levels A, AA and AAA, plus best-practice checks, and the rule list is in the project's repository. A test includes the axe-core script in its fixtures or test system, and the engine reports violations and elements it could not decide. The [API reference](https://github.com/dequelabs/axe-core/blob/develop/doc/API.md) describes the options and result types. The package installs from npm or pnpm as a development dependency.

## Worth knowing

The README describes axe-core as built to integrate with existing test environments, and its install routes are development dependencies.

The Deque product page offers commercial tools built around the engine, such as a site-wide monitoring product and a manual auditing product. They are separate products from the open-source package.
