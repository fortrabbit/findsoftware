Silex is a visual website builder for static sites. Its editor is built on GrapesJS, and the sites it publishes are static HTML and CSS. Silex Labs, a non-profit organization based in Paris, France, maintains it and holds the copyright.

Silex can be self-hosted with Docker or run from source with Node.js. The Node.js server is a process that keeps running and serves the editor, while the published sites are static files that any web space can serve.

## Worth knowing

A hosted instance at v3.silex.me is also offered, and the README says it needs a GitLab account for storage. The self-hosting guide and the npm package state different minimum Node.js versions.
