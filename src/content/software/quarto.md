Quarto is an open-source scientific and technical publishing system built on Pandoc. Documents are written in Markdown with code from Python, R, Julia and Observable JavaScript, which the FAQ names as the principal supported languages. Quarto is installed from an installer for Windows, macOS or Linux.

Quarto websites can be published to any static hosting service or intranet web server. The [get started guide](https://quarto.org/docs/get-started/) covers installation and a first document.
