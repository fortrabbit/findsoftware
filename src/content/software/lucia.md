Lucia is a TypeScript authentication library for web apps, published on npm as lucia. Its README and homepage both say the maintainer deprecated it, and the npm package is marked deprecated.

The README points to `code/auth_session.ts` in the repository as a single-file replacement for the npm package.

## Worth knowing

Installing the npm package gives a deprecated release, and the README directs readers to the file in the repository instead.
