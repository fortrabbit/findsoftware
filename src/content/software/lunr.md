Lunr.js is a JavaScript full-text search library for indexing JSON documents and searching them. The [README](https://github.com/olivernn/lunr.js) describes it as a library for use in the browser, and the [homepage](https://lunrjs.com/) adds that it has no external dependencies and works on the server with Node.js.

The README gives two install routes: including the library's source file in a page, or installing the npm package.
