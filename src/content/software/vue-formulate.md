Vue Formulate is a form library for Vue. A single component creates every input, and the library includes validation rules, repeatable field groups, a plugin system and form generation from a JSON schema.

## Worth knowing

The installation guide says Vue Formulate is compatible with Vue 2 and that the next major version of Vue Formulate for Vue 3 is called FormKit.
