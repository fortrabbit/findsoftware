Dioxus is a Rust framework for building fullstack web, desktop and mobile apps from a single codebase. Its web apps can render on the server and hydrate in the browser, be generated as static HTML, or run as client-side apps with client-side routing. The project publishes its command-line tool through cargo, and its maintainer is Dioxus Labs.

## Worth knowing

The project is pre-1.0, and its next minor line has only alpha releases so far.
