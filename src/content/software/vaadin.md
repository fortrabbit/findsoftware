Vaadin is an open-source full-stack Java UI framework. In its Flow views the UI state lives on the server, while a React view runs in the browser. Vaadin Start and Spring Initializr create Spring Boot projects, which run as a Java application rather than in a servlet container.

## Worth knowing

The [licensing and maintenance page](https://vaadin.com/docs/latest/building-apps/architecture/licensing-and-maintenance) says commercial subscriptions add to the open source core. The Pro plan adds commercial components such as Charts, Dashboard, Map, CRUD and Grid Pro. The Enterprise Edition offers long-term maintenance per major release, and Copilot and the hosted MCP server are not open source.
