Minimal is a static personal website and blog generator for Go, Node.js and Python, with no external dependencies. A reader forks the repository, clones it locally and edits a content file, then runs a task script with the runtime to use, which builds the site and starts a local web server. The same script with a deploy command builds and deploys the site, and the [README](https://github.com/lutzroeder/minimal/blob/main/README.md) describes Netlify as a deploy target.

## Worth knowing

The repository has no release or tag. The npm package named minimal is an unrelated project.
