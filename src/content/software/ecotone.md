Ecotone is a PHP architecture layer that adds CQRS, event sourcing, sagas and asynchronous messaging to an existing Laravel, Symfony or Tempest application. It is installed with Composer, and handlers and messaging are declared with PHP attributes on the application's own classes. The project describes it as running on the framework the application already uses.

Ecotone is documented at [docs.ecotone.tech](https://docs.ecotone.tech) and maintained by Simply Coded Software. The Composer package is published from a read-only repository, while development takes place in a separate monorepo.

## Worth knowing

The core is open source. Enterprise features require a paid subscription and a license key, and the composer.json of the project lists a proprietary license next to Apache-2.0.
