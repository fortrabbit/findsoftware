Gotenberg is a Docker-based HTTP API that converts web pages and office documents to PDF. The [installation guide](https://gotenberg.dev/docs/getting-started/installation) starts the API as a container, and the image bundles Chromium, LibreOffice and PDF engines. Clients send files as multipart form data. The project describes the API as a standard HTTP API and publishes an official PHP client. The guide also covers Docker Compose, Kubernetes, Cloud Run and AWS Lambda. Julien Neuhart maintains the project.
