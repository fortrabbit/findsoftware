Noty is a dependency-free JavaScript notification library for alert, success, error, warning, information and confirmation messages. The library offers eleven layouts, a custom container for inline notifications, named queues, callbacks and progress bars for timed notifications.

## Worth knowing

The README opens with "DEPRECATED" and says the repository "is no longer supported, please consider using alternatives." npm also marks the package as deprecated.
