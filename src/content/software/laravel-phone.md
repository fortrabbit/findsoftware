Laravel Phone adds phone number handling to Laravel: a validation rule, Eloquent attribute casts and a PhoneNumber class for formatting and comparing numbers. The README says the package is based on the PHP port of libphonenumber by Google.

## Worth knowing

The README includes a section with suggestions for storing phone numbers in a database. It says these are thought starters and that support is not provided for them.
