SplitType is a JavaScript library that splits HTML text into lines, words and characters, so that each can be animated independently. The README says it was inspired by GSAP's SplitText plugin and can be used with any animation library.

## Worth knowing

The repository has no LICENSE file, so the ISC license comes from the npm package rather than from the repository.
