Orchard 1 is the first generation of Orchard, an open-source content management system built on the ASP.NET MVC platform. It runs on the .NET Framework and is extended with modules and themes, and the project keeps a community gallery for them. The installation guide for the 1.x line describes four routes: the Microsoft Web Platform Installer, WebMatrix, a zip file download, and a build from the source code. A site starts on a built-in database, and can be pointed at SQL Server or SQL Server Express instead.

## Worth knowing

The README says that anyone starting a new project should use Orchard Core, the ASP.NET Core generation, and also points developers maintaining a project built on Orchard 1 to it. The documentation for the 1.x line lives on a separate docs site with its own release notes.
