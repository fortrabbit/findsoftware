TuiCss is a CSS library for web applications whose interface is based on an ASCII table, in the text-based user interface style. The project names the Turbo Vision Framework as its base, and its README mentions curses, ncurses and Newt among the libraries it looked at for features.

A project either downloads the repository and imports the files from its `dist` folder, or installs the `tuicss` package from npm. The distribution also contains a JavaScript file for a chart component, so the CSS is not the only part a page loads.
