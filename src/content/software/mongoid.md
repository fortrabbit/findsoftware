Mongoid is an Object-Document Mapper framework for MongoDB in Ruby. A project adds it to its Gemfile to connect a Ruby application to a MongoDB database. The README says Mongoid is built on top of the Ruby driver for MongoDB, which has its own documentation. The [user documentation](https://www.mongodb.com/docs/mongoid/current/) lists Quick Start guides for setting up a runnable project.

## Worth knowing

The gem's metadata names a separate domain for the project. That domain did not answer when it was checked, so the MongoDB-hosted documentation is the project's site here. Issues go to the MONGOID project in MongoDB's JIRA, not to a repository tracker, and questions go to Stack Overflow or the MongoDB Community Forum.
