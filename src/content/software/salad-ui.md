SaladUI is a set of Phoenix LiveView components inspired by shadcn, published on Hex as salad_ui. A project can use the components straight from the dependency after running `mix salad.setup`, or run `mix salad.install` to copy the component files and JavaScript files into its own code under a module prefix chosen at install time. The setup task also configures Tailwind CSS and color schemes.
