Ratpack is a set of Java libraries for building HTTP applications on the JVM. It is built on the Netty event-driven networking engine. A Ratpack application starts an embedded server, which listens for HTTP traffic on a configured port. An application can be a single Groovy script or a Java project built with Gradle plugins, and the libraries are published to Maven Central under the io.ratpack group.

## Worth knowing

The homepage describes Ratpack as a foundation and not an all-encompassing framework. A later release line has so far been published only as release candidates.
