graphql-go is an implementation of GraphQL in Go that supports queries, mutations and subscriptions. Its README says it follows the official reference implementation, graphql-js. A project adds it as a Go module with go get.

The MIT license names Chris Ramón. The project has no website of its own; its README points to its godoc page for documentation.
