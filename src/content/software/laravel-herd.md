Laravel Herd is a desktop application for macOS and Windows that runs PHP and Laravel sites on the developer's own machine. The project describes it as a native PHP and Laravel stack for every project on that machine, and its services include MySQL and PostgreSQL. Beyond Code GmbH is the company behind the product, which the project describes as a product of Beyond Code in partnership with Laravel.

## Worth knowing

Herd is proprietary. Its end-user license agreement says the application is licensed, not sold, to the user. A free version is offered alongside Herd Pro, a paid tier that the homepage describes as adding managed services, deeper debugging and a direct line to the team behind Herd. The app is not available for Linux; the project says it is working on that.
