Apache PouchDB is a JavaScript database that runs in the browser, so an application can store its data locally while it is offline and synchronize it with CouchDB and compatible servers once the connection is back. The library is inspired by Apache CouchDB. It is an abstraction layer over other databases and uses IndexedDB in the browser and LevelDB in Node.js by default. The project's site says it is undergoing incubation at the Apache Software Foundation.

## Worth knowing

Synchronization needs a CouchDB or compatible server on the other end.
