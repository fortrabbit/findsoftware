baserCMS is an open-source content management system written in PHP on the CakePHP framework, for building and customizing websites. It has an admin interface in the application and can also serve as a headless CMS through its REST API. The project is Japanese, and most of its pages are in Japanese, while the README is in English. The project runs a forum and a marketplace for extensions.
