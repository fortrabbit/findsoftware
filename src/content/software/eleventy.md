Eleventy is a static site generator that turns a directory of templates into HTML. It accepts many template languages, including Markdown, Nunjucks, Liquid and JavaScript. The project was renamed Build Awesome in 2026 and has joined Font Awesome. The stable line still ships as `@11ty/eleventy`, with its docs at 11ty.dev. The official plugins cover images, RSS, syntax highlighting and internationalization. The output is plain static files, so any host that serves static files can run it, and the docs list many such hosts.

## Worth knowing

The next major line, documented on Build Awesome's site, is in alpha, so the stable docs and the Build Awesome docs describe different versions. Build Awesome Pro, a site builder that needs no installation, is announced as coming soon. Eleventy does not require it.
