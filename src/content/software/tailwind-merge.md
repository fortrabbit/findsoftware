tailwind-merge is a utility function that merges Tailwind CSS classes in JavaScript without style conflicts. It is written in TypeScript and maintained by Dany Castillo. The repository is a monorepo: the tailwind-merge package is the one this record describes, and the project has no website of its own, so its documentation sits in the repository.

## Worth knowing

The monorepo holds other packages that are unreleased or unpublished, so this record covers only the core package.
