Publii is a desktop CMS for Windows, macOS and Linux that builds static websites on the author's computer. The app is installed from a platform installer, and the author publishes the built files to a host of their choice. The homepage names GitHub Pages, Netlify, Amazon S3 and FTP as destinations.

Because the published output is static files, the live site has no server-side process to keep running. The [user documentation](https://getpublii.com/docs/) covers installation, creating a site and hosting.
