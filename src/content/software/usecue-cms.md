Usecue CMS is a hosted content management system for Hugo websites. Editors work in the browser on content that lives in the Git repository of the site, with side-by-side editing and instant publishing. Each commit records the author of the change, so editors appear in the Git history.

Sites are connected through a sign-up, when Usecue checks that the Hugo website is compatible with the CMS. The CMS supports multiple content directories for multilingual Hugo sites, and a user can be a member of several websites.

## Worth knowing

The CMS is operated by Usecue BV for its hosting customers, and the documentation describes no install outside that hosting. It is built for Hugo only.
