c15t is a consent manager for websites and web apps. It draws a cookie banner and a preferences dialog and holds scripts back until the visitor's choice allows them, and the consent logic runs in the visitor's browser. The package is installed from npm as `c15t`, with adapters for React, Next.js, Vue, Nuxt, Astro, TanStack Start and Svelte, and a script tag covers sites built with Webflow, WordPress, Framer or Squarespace. Consent policies and records are served by a backend. The operator can run that backend with the `@c15t/backend` package and a PostgreSQL, MySQL or SQLite database, or use the hosted service that Inth runs for the project's maintainer.

## Worth knowing

The [self-host guide](https://c15t.com/docs/self-host/quickstart) says that self-hosting means operating the service and its database yourself. The hosted service is named Inth, and the homepage says Inth hosts the backend, the policy rules and the IAB CMP ID.
