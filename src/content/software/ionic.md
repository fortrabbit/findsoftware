Ionic Framework is an open source UI toolkit for cross-platform mobile and web apps, used with React, Angular or Vue. Its components run in the browser and handle the frontend of an app: UI controls and their interaction. The documented installation is the Ionic CLI from npm. The project is part of OutSystems, as its [announcement](https://ionic.io/blog/important-announcement-the-future-of-ionics-commercial-products) states.

## Worth knowing

The same announcement says new customer sales of Ionic's commercial products, including Appflow, have been discontinued, and that the open source framework and Capacitor continue to be maintained. Those commercial products are separate from the framework.
