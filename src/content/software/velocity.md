Velocity is an animation library that its README calls a standalone alternative to jQuery's animate method. The README is titled as a beta, says the project website documents the earlier line, and points to the [wiki](https://github.com/julianshapiro/velocity/wiki) for current documentation.

## Worth knowing

The newest stable release is older than the newest beta, and the newer line is published only under the beta tag.
