Petal Components is a set of HEEx components for Phoenix LiveView apps, styled with Tailwind CSS. A project installs them from Hex with mix, and the Hex package is named petal_components.

## Worth knowing

Some components are marked as available only to Petal Pro members. Petal Pro is a separate paid product, and the license terms page puts it and the other Petal products under a separate license from the MIT-licensed components.
