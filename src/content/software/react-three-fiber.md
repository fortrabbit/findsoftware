React Three Fiber is a React renderer for three.js. A 3D scene is written declaratively as reusable React components that react to state, and the README says everything that works in three.js works through it.

## Worth knowing

The renderer must pair with a major version of React, as react-dom does, so the React version in a project has to match the renderer's release line. The older unscoped package under the name react-three-fiber is deprecated in favor of @react-three/fiber.
