Maz-UI is a library for Vue and Nuxt whose components, plugins, directives and composables can each be imported on their own. A Nuxt module, theming, icons, translations and other companion packages are separate npm packages that sit beside the core library. The core package installs with npm, and its codebase is written in TypeScript. The [getting started guide](https://maz-ui.com/guide/getting-started) describes the Vue and Nuxt setups.

## Worth knowing

The GitHub repository reports no license because its LICENSE file is missing at the default branch. The package manifest at the latest release tag and the npm package both state MIT.
