Valitron is a stand-alone PHP validation library with no dependencies. It checks an array of input against rules attached to field names: the README's examples use rules such as required, email and lengthMin, run them in one call, and read the messages back as errors. Dot notation reaches nested values, an asterisk applies a rule to each member of an array, custom rules can be added, and the language of the error messages can be set.

## Worth knowing

The README links a Tidelift subscription for supported use of the package.
