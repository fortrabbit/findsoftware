Fiction is a personal marketing platform for building personal websites, marketing funnels and newsletter emails, and its repository describes it as a CMS and application framework. The README installs it by cloning the repository and running pnpm install, and the editor is a drag-and-drop interface for website and content management. Supereon LLC, which does business as Fiction.com, is the company the project's terms name as the operator.

## Worth knowing

The www.fiction.com address now redirects to pagelines.com, which shows an unrelated AI agent product, and the docs and support paths redirect there as well, so the project's own site no longer shows the software. The record stays a stub until that is settled. The repository has no LICENSE file, and its README and package.json disagree on the license.
