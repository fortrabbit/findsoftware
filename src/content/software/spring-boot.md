Spring Boot is a Java framework for building stand-alone Spring applications. It auto-configures the Spring Framework and embeds a web server, so an application runs as one JVM process that listens on port 8080 by default. Applications can also be deployed to a compatible Servlet container, and container images are built with Dockerfiles or Cloud Native Buildpacks rather than an official image. Spring Initializr generates a project that builds with Maven or Gradle.

## Worth knowing

Commercial support comes from a Tanzu Spring subscription. For each release line, open-source support ends before commercial support does.
