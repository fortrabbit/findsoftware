idli.site is a Python script that builds a static website from a Google Doc. The build script fetches the document's published HTML and writes it into an index.html page, so the Google Doc is where the content is edited. The README describes forking or cloning the repository and running build.py. WIOS Designs holds the copyright under the MIT license.

## Worth knowing

The homepage the repository names does not resolve, so the project's own site could not be checked. The README offers paid setup and training from WIOS Designs.
