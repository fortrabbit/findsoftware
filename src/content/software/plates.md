Plates is a template system for PHP that renders HTML from plain PHP template files. Templates use native PHP with no template syntax of their own, and the system adds layouts, inheritance and escaping helpers. It is added to a project with Composer and used from inside a PHP application.

The project describes itself as inspired by Twig, and as designed for developers who prefer native PHP templates over compiled template languages such as Twig or Smarty.
