Farm is a web build tool written in Rust, which the project describes as Vite-compatible. The [quick-start guide](https://www.farmfe.org/docs/quick-start) creates a project with `npm create farm@latest`, starts it for development and builds production-ready static files. The core package is published on npm as `@farmfe/core`, and the project's source is on GitHub under the farm-fe organization.

## Worth knowing

The project publishes nightly versions alongside its releases, and its documentation says that nightly versions will continue to be released. The stable release line is the one the registry lists as latest.
