The Gutenberg block editor is the editor that WordPress uses for its content. Its @wordpress/block-editor npm package lets other applications create and use standalone block editors. The [Block Editor Handbook](https://developer.wordpress.org/block-editor/reference-guides/packages/packages-block-editor/) documents installing the package with npm.

The package is one of the packages in the Gutenberg monorepo, which also holds the Gutenberg plugin for WordPress sites. The package has its own version line, separate from the plugin's releases.

## Worth knowing

Stars and contributor counts describe the whole monorepo, not the package alone.
