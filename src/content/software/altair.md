Vega-Altair is a declarative visualization library for Python, built on the Vega-Lite grammar. The [installation guide](https://altair-viz.github.io/getting_started/installation.html) installs it with pip.

Saving a chart to an HTML file creates a page that loads Vega, Vega-Lite and vegaEmbed, and the chart renders when a browser opens that page. The project is maintained by Vega-Altair Developers.

## Worth knowing

The homepage states that the project is not affiliated with Altair Engineering, Inc., a separate company with a similar name.
