Attractions is a UI kit of components for Svelte, installed from npm or loaded from a CDN. Its maintainers deprecated it, and the [README](https://github.com/illright/attractions) now points readers to other projects for the same purpose.

## Worth knowing

The project is discontinued: the GitHub repository is archived, and npm marks its last version as no longer supported. The README says the kit was built for Svelte 3, and its npm peer range is for Svelte 3 as well.
