L7 is a geospatial visualization framework that renders data as layers on maps with WebGL, in 2D and 3D. Its base maps come from third-party map services, which the README names as Mapbox and Amap, and the package @antv/l7-maps supplies the map integration. The core is installed from npm or loaded from a CDN, and the repository is a monorepo of packages. The AntV team publishes it under the MIT license, and the site footer names Ant Group Co., Ltd. as copyright holder.

## Worth knowing

The base maps are served by third-party services, so the map provider sits outside the library.
