gulp-site-generator is a static site generator that runs as a set of Gulp tasks. It renders Markdown files kept in a site's content folders with Handlebars templates and partials, and it produces a build folder that a web server such as Nginx or Apache can serve. The generator is added to a site as a Git submodule or a plain checkout, and the site is set up with a node tools/install script.

## Worth knowing

The repository was archived on GitHub after its last push in 2017, and the project has no homepage.
