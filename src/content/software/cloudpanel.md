CloudPanel installs on a virtual machine and configures the server for PHP, Node.js, Python and static websites. It runs on Debian or Ubuntu, on x86 or ARM64, and the [technology stack page](https://www.cloudpanel.io/docs/v2/technology-stack/) states that it supports virtual machines only, with no Linux container support.

## Worth knowing

The pricing page lists the Community Edition as free to use for commercial and hobby sites. The [license terms](https://www.cloudpanel.io/license-terms/) forbid reselling the software. MGT-COMMERCE GmbH also offers a managed service.
