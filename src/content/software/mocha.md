Mocha is a JavaScript test framework. Tests are written as describe and it blocks in test files and run with the mocha command, which the getting started page installs as a development dependency and starts with npx. It runs on Node.js and in the browser. The same page shows a test script in package.json for starting it in a project.

## Worth knowing

The getting started page states a minimum Node.js version for the current major.
