Textpattern is a content management system written in PHP. Its templates are built from Textpattern tags, and content is kept in a MySQL database. Editing happens in browser-based administration panels, and the core interface is available in over 50 languages.

Installation means downloading the release package, uploading it to a web server and running the browser setup, which asks for the database details. The [system requirements](https://textpattern.com/about/system-requirements) name Apache or Nginx with PHP and MySQL.
