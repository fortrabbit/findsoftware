Retype is a static site generator that turns a folder of Markdown files into a documentation website. The content stays in plain Markdown files, and the build writes the static site files, which can be copied to any web server.

Retype installs through npm, yarn or the dotnet tool. A Pro edition adds features the free version does not include, and the [pricing page](https://retype.com/pro/) compares the editions.

## Worth knowing

Retype is distributed under its own license agreement, the Retype Software License Agreement. The free license may contain restricted functionality, and a Retype Key removes those restrictions. The repository holds the documentation site and its templates, not the Retype engine.
