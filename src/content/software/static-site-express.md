static-site-express is a Node.js static site generator that uses EJS templates and Markdown content. It is distributed as a GitHub template repository: the "Use this template" button creates a copy that the owner builds and deploys.

Content lives in Markdown files, and the README names Decap CMS for editing site content. The README says to deploy the built site to Netlify or another platform.

## Worth knowing

Search is optional and uses Algolia, an external service. The README links a project website that does not resolve; the recorded homepage is a different netlify.app address.
