Aimeos is an e-commerce and shop system written in PHP and built on Laravel. It installs as a standalone Composer project or as a package inside an existing Laravel application. Its releases use calendar versioning, so the year and month appear in each release number.

## Worth knowing

The license is stated two ways: MIT for the Laravel package repository and LGPL-3.0-or-later for the core library. The project does not explain the difference.
