Granim.js animates gradients in a page's canvas element: a script creates a Granim instance that points at the element. The instance takes named states, and each state lists gradients, each made of two colors.

The library installs from npm or Bower, or as a file downloaded from the project's releases page. The README links a demo site that shows the effects.
