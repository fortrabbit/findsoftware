WampServer is a web development environment for Windows. It installs Apache, PHP, MySQL and MariaDB on a developer's machine and lets the developer switch between their versions. The software is downloaded as a Windows installer from the project's SourceForge page.

## Worth knowing

The official website answers a "Site retired" page, while the SourceForge project is still active. Whether the project continues under a new site is not settled.
