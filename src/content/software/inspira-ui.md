Inspira UI is a collection of reusable Vue and Nuxt components built with shadcn-vue, motion-v and Tailwind CSS. The project describes itself as a curated collection rather than a traditional component library: a reader picks a component, copies its code and adapts it, and the component pages name a shadcn-vue registry command for the same step. The code is MIT-licensed and the author is Rahul Vashishtha.

## Worth knowing

The repository has no tagged release, so the code a reader copies is whatever the default branch holds on the day they copy it. A paid sibling product, Inspira UI Pro, sells premium components and templates for Nuxt and Vue.
