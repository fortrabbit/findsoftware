SUID is a component library for SolidJS whose components are ports of Material-UI's. The package @suid/material is installed from npm, and a create-suid scaffolder starts a new project with it. The repository is a monorepo, and the documentation is published at suid.dev. The maintainer is an individual named in the MIT license, while the repository belongs to the swordev organization.
