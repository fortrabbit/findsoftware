Commerce Layer is a hosted headless ecommerce platform provided by Commerce Layer, Inc. Its Core API is a set of REST endpoints for checkout, payments, inventory, orders and fulfillment, and the Commerce Layer Dashboard is where team members work with the platform's apps. The pricing page lists a distributed order management system, a promotion engine and a metrics dashboard as add-ons.

## Worth knowing

Commerce Layer is hosted only, and the docs describe no self-hosted install. The Metrics API, the Provisioning API, custom user roles and a custom identity provider are listed on the Enterprise plan. A Developer plan is listed as free.
