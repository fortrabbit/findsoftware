Fork CMS is a content management system written in PHP that stores its data in a MySQL database. The [installation page](https://docs.fork-cms.com/documentation/detail/installation/installation) describes installing it with Composer's create-project command, and the [minimum requirements page](https://docs.fork-cms.com/documentation/detail/installation/minimum-requirements) lists an Apache server with .htaccess and mod_rewrite. The installation page also notes that Fork cannot be installed in a subdirectory.
