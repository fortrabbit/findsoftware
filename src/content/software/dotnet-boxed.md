.NET Boxed is a set of helper NuGet packages for .NET projects. Its core package, Boxed.AspNetCore, provides ASP.NET Core middleware, MVC filters, extension methods and helper code for an ASP.NET Core project.

The repository ships five packages in total, including Swagger and tag helper packages, and the packages are installed from NuGet. The project templates that build new applications are in a separate repository.
