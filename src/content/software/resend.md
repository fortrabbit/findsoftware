Resend is a hosted email API for sending transactional and marketing email from applications. The [homepage](https://resend.com/) names REST and SMTP among its integration methods, and it lists SDKs for many languages. Its [documentation](https://resend.com/docs) describes the API as the email API for developers. The operator is Plus Five Five, Inc., which the privacy policy names. The company gives a San Francisco address.

Webhooks are offered, with the number of endpoints limited by plan. Single sign-on is an add-on on one plan and included on the top plan, and the pricing page says it works through the team's identity provider. The homepage also names react-email, a separate open source component library for building email templates.

## Worth knowing

Resend is offered only as a hosted service. Its security page states that stored data is held in the United States, and that the region chosen for a domain controls where email is sent from.
