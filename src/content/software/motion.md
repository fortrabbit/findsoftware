Motion is a JavaScript animation library. Its React package imports from `motion/react`, and the README notes that Framer Motion is now Motion. The docs say it runs animations natively in the browser. A separate package covers Vue and has its own record.

## Worth knowing

Motion+ is a paid plan that adds examples, tutorials and premium APIs such as Cursor and Ticker. The [Motion+ page](https://motion.dev/plus) says those APIs and examples are licensed under MIT.
