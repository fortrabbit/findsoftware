Prism is a JavaScript syntax highlighter for code shown in web pages. A page includes its CSS and JavaScript files, or loads them from a CDN, and Prism highlights the code elements that carry a language class. It can also be installed from npm for use with a bundler, and it can be used with Node.js.

## Worth knowing

The homepage lists two limitations: Prism is regex-based, so it fails on certain edge cases, and any pre-existing HTML inside the code is stripped off. The README says the maintainers accept only security-relevant pull requests for the time being while they work on a new major version.
