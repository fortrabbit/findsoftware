CMS.js is a client-side site generator written in JavaScript. It takes Markdown content, renders it in the browser, and delivers a complete website in single-page app fashion, without server-side scripting. In its GitHub mode it reads the content of a repository through the GitHub API, and the README's setup hosts the finished site on GitHub Pages. In server mode it asks a web server with directory indexing for the Markdown or HTML files in a folder. The starter repository gives a ready site to change, and the project also offers a script to load from the unpkg CDN. Posts and pages from a Jekyll project can be copied into its content folders. The author is Chris Diana.
