Sphinx is a Python application that reads reStructuredText sources and writes documentation as HTML, PDF, EPUB and other formats. The installation page lists the PyPI, conda, OS package manager and Docker routes. The HTML output is rendered with Jinja 2 templates.

The tutorial's deployment appendix says the HTML Sphinx generates is static, so any web hosting service can serve the result.
