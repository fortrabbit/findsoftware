Gridly is a hosted platform for localization and multilingual content, built around a spreadsheet-style interface for managing content. Its API is organized around REST and is documented by the vendor. The homepage names content management, translation management and computer-assisted translation as its capabilities, and the company, Gridly AB, is based in Sweden.

## Worth knowing

API requests are capped per month, and the cap depends on the plan the pricing page lists.
