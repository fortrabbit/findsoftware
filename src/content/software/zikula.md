Zikula is an application framework that extends Symfony with a modular system of bundles and a Twig-based theme system. The README says it can grow into a content management system with community modules. The project is installed by uploading the release archive to a web server, or with Composer for development. The Zikula Team maintains it.

## Worth knowing

The README describes the project as dormant, and says that the 3.x releases are no longer maintained. The repository is archived and the Packagist package is flagged abandoned. The address ziku.la redirects to the repository, and the documentation site does not answer, so the installation and requirements pages in the repository at the 3.1.0 tag were read instead.
