Starwind UI is a set of accessible Tailwind CSS components for Astro, React, Vue and Svelte. The Starwind CLI adds the components to a project as source code, so the code stays in the project and can be changed there. The components sit on a shared, framework-neutral runtime, and each framework adapter connects that runtime to the framework's own component markup. The CLI is run with npx, and the install commands are documented in the [installation guide](https://starwind.dev/docs/getting-started/installation/).

## Worth knowing

Starwind Pro is a separate paid library of Astro blocks, sold as a one-time purchase, next to the free components. The Vue and Svelte adapters are published as betas.
