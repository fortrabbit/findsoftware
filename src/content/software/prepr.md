Prepr is a hosted headless CMS made by Prepr B.V., a company in Utrecht, the Netherlands. Editors use a Visual Editor, and the docs describe previewing changes in a new tab or side by side inside Prepr. Sites read content through a GraphQL API, and the REST API handles content mutations.

Prepr combines content management with personalization and A/B testing, and it offers role-based access control, multi-language content and management of multiple websites. All Prepr data is stored and managed in the Netherlands.

## Worth knowing

Prepr is offered only as a hosted service, so a site depends on it to deliver content. Plan limits for locales, users and API requests, and single sign-on availability differ by plan, so check the [pricing page](https://prepr.io/pricing) before choosing one.
