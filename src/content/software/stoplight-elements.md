Stoplight Elements is a set of React components and web components that render API reference documentation from an OpenAPI document. A page loads the web component with a script tag and a stylesheet and points an element at the OpenAPI description. The React component takes the same description. The README describes both three-column and stacked layouts, the stacked one for sites that already have their own navigation. The homepage names ReDoc and Swagger UI as tools people move from.

## Worth knowing

Elements runs in the browser. The package sends anonymized installation analytics to Scarf during installation, and the README explains how to turn that off. The vendor's Stoplight Platform and Studio use Elements for hosted documentation; the open-source package does not include that service.
