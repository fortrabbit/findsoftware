shadcn-templ is a set of components for Go applications written with templ, the Go templating language. The [installation guide](https://shadcn-templ.com/docs/installation) describes a CLI that copies component source into the project, so the project owns and edits the code. Axel Adrian maintains the project.

## Worth knowing

A second route imports the module as a Go library without copying files. The [import workflow](https://shadcn-templ.com/docs/import-workflow) page calls that route experimental, and the CLI is the page's supported path.
