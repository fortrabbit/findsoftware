Wyam is a static content generator written in C# for .NET. Its README describes it as a set of chained, configurable modules, and it is installed as a .NET Core global tool with dotnet tool install. The generated output is static files.

## Worth knowing

The README says the project is essentially archived and that development moved to Statiq, a rebooted version under a new name. The homepage wyam.io no longer belongs to the project, so the README and the repository are the only sources.
