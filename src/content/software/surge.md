Surge is a command line tool that publishes a folder of static files, or a single HTML file, to the surge.sh hosting platform, which serves the files from a global network. The CLI is installed with npm and runs on Node.js. The project's [documentation](https://surge.sh/docs/) is on the same site as the platform.

## Worth knowing

The CLI is the open source part and surge.sh is the hosted service it publishes to. The service has publishing limits per domain and per account, listed on the [pricing page](https://surge.sh/pricing) with its free and paid plans.
