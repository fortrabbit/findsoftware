Front Matter is a Visual Studio Code extension that manages a static site's content from dashboards inside the editor. The dashboards cover content, data and media files, and a taxonomy dashboard manages tags and categories. The content stays in the folders the static site generator defines, and the extension is pointed at them by [registering content folders](https://frontmatter.codes/docs/content-creation/content-folders/). The extension also supports content in multiple languages. It is installed from the Visual Studio Code Marketplace, as the [getting-started guide](https://frontmatter.codes/docs/getting-started) describes, and it runs on the developer's machine within the editor.

The project is maintained by Elio Struyf and published under the MIT license.

## Worth knowing

The maintainer states that the project will continue to be maintained, that major changes depend on a personal reason, a company commitment or significant community support, and that feature requests may take longer to be addressed.
