Globalize is a Ruby gem that adds translated attribute values to ActiveRecord models, so user-generated content such as a blog post can carry several translations. It builds on the I18n API in Ruby on Rails.

## Worth knowing

The README says the gem is relatively feature complete and not very actively maintained, as none of its current maintainers actively use it, but that it should still work. It names Mobility as a natural successor to Globalize.
