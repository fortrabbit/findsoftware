Transifex is a hosted localization platform for software, websites and apps. Teams manage translation projects with roles and permissions for projects, teams and languages, and single sign-on comes through an existing identity provider. The security page places the platform's virtual machines on Amazon Web Services in Ireland. The developer hub describes an API built on JSON:API, and a community forum is linked from the homepage.

## Worth knowing

Transifex runs only as a hosted service, and no installable part was found, so it cannot be set up on a user's own server.
