Inputmask applies an input mask to a form field: a predefined format that the text a user types must follow, such as a date, a number or a phone number. It can run in memory without a DOM element, for example for use in Node.js, and it supports the dir="rtl" attribute for right-to-left input.

The core package is framework-agnostic and runs against vanilla JavaScript, jQuery and jqlite. First-party packages wrap it for React, Vue, Svelte, Angular and jQuery.

## Worth knowing

The README asks anyone using Inputmask in a commercial setting to make a small donation, and says the license stays permissive.
