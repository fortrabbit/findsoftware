Astryx is an open source design system from Meta, built on React and StyleX. The [getting-started guide](https://astryx.atmeta.com/docs/getting-started) installs a core package, a theme and a command-line tool, and the components can also be loaded from a CDN without a build step.

## Worth knowing

The homepage and README both describe Astryx as in beta.
