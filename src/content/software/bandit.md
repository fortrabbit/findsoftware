Bandit is an HTTP server for Plug and WebSock applications, written entirely in Elixir. The README says it is the default HTTP server for Phoenix, and it is installed by adding it to the dependencies in mix.exs. The project has no website of its own; its API documentation is published on bandit.hexdocs.pm, and the package is distributed through Hex.

## Worth knowing

Hex marks one older version, 1.10.0, as retired for an improper DEFLATE implementation.
