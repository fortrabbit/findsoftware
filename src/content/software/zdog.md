Zdog is a pseudo-3D engine for canvas and SVG that lets a page design and render simple 3D models. It is installed with npm, from a script tag on unpkg, as a downloaded file or with Bower. David DeSandro is the package author, and the repository belongs to the Metafizzy organization, which the README names as the maker.

## Worth knowing

The site calls the current release a beta and expects lots of changes in the next one. The repository has no LICENSE file; its MIT license is stated in the README and in the npm package.
