favicons is a Node.js module, installed from npm under the same name, that generates favicons and their associated icon and web app manifest files from a source image. Its README says it creates the icons locally with JavaScript and no external dependencies. The project has no website of its own; the source and README are on GitHub, and the package manifest names Hayden Bleasel as its author.

## Worth knowing

The README says the module was originally built for Google's Web Starter Kit and Catalyst, and that it is tested on an older Node.js release than the current package manifest requires.
