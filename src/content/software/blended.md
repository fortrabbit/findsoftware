Blended is a static website generator written in Python, with an HTML-based templating system. It is installed from PyPI with pip, and its README names importers for WordPress and Blogger. The setup script names John Roper as the author.

## Worth knowing

The GitHub repository is archived. Its GitHub releases end before the PyPI releases, so the PyPI package carries the newer versions of the software.
