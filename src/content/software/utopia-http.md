Utopia HTTP is a PHP MVC framework for HTTP routing and request handling. It relies on the separate Utopia DI package for dependency injection and ships two server adapters, one for PHP-FPM and one for Swoole.

## Worth knowing

The repository is a read-only mirror of a package in the appwrite/appwrite monorepo, where development happens, so issues and pull requests go there.
