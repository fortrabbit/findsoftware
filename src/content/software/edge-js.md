Edge is a template engine for Node.js, written in TypeScript and published on npm as `edge.js`. An application installs the package from npm and calls its render method with a template path and a data object; the [getting-started guide](https://edgejs.dev/docs/getting_started) shows this inside a Node.js HTTP server that renders a template for each request. The package is ESM-only, so the importing application must use ES modules. AdonisJS applications use Edge as their template engine, and the AdonisJS documentation covers it there. The MIT license names Harminder Virk as the copyright holder, with contributors.
