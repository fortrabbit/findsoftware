React Aria is a library of unstyled React components and hooks from Adobe, published as the react-aria-components npm package. The components come without styles, so the project supplies its own look, and the install guide adds the package with npm. A second route in the same guide is the shadcn CLI, which adds the components from the project's own registry.

## Worth knowing

React Aria lives in the adobe/react-spectrum repository with React Spectrum and other Adobe libraries. The figures on this record come from the react-aria-components package alone, and the repository's contributor and star counts cover the whole monorepo.
