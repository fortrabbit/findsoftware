Echo is a Go web framework built on the standard net/http package and interoperable with it. A project adds Echo with go get, creates an Echo instance, registers routes and middleware on it, and starts a server. The framework provides a radix-tree router, request binding with pluggable validation, centralized error handling, TLS support and template rendering with any Go template engine. LabStack LLC publishes it under the MIT license.
