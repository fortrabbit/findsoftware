Motion for Vue is an animation library for Vue. The docs say every feature of vanilla Motion is also compatible, and that it adds APIs tailored for Vue. The repository belongs to the same organization that publishes Motion.

## Worth knowing

Motion+ is a paid membership that adds examples and premium APIs such as Cursor and Ticker.
