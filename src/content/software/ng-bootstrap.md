ng-bootstrap is a set of Angular components styled with Bootstrap 5 CSS, published on npm as @ng-bootstrap/ng-bootstrap. The Angular CLI adds it to a project with an ng add command. The README names Angular, Bootstrap 5 CSS and Popper as its dependencies: Angular and Popper are peer dependencies, while Bootstrap is not listed as one because Bootstrap does not release its CSS separately. The Angular ng-bootstrap team maintains the project in the ng-bootstrap organization on GitHub.

## Worth knowing

The README table gives the Angular and Bootstrap CSS versions each release line is tested against.
