TW Elements is a component library of interactive components for Tailwind CSS. It is built on top of the Tailwind CSS framework and is included in a project as a plugin, registered in `tailwind.config.js`. A project installs the `tw-elements` package from npm, loads its CSS from a jsDelivr CDN, clones the repository, or downloads a zip package.

The documentation covers directional (RTL) classes, and an [internationalization guide](https://tw-elements.com/docs/standard/getting-started/internationalization/) describes integrating i18n with a project.

## Worth knowing

The free packages are under the MIT License. Premium Access features are a separate part of the product, covered by a recurring subscription under the project's End User License Agreement, and the [pricing page](https://tw-elements.com/pricing/) lists them.
