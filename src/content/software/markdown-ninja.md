Markdown Ninja is a Markdown-first CMS for publishing websites, blogs and newsletters. The code is written in Go and released under the AGPL, and the documentation is under CC BY-SA 4.0. Content is published with a command-line tool that sends it to the service at markdown.ninja with an API key, and a Docker image is provided for running that command.

The repository's developer notes describe a Docker setup with a TimescaleDB container, which is how the code is developed rather than how a site is run.

## Worth knowing

The sources read do not show whether a user can run the server on their own infrastructure, so the record is a stub until the operator documentation is read. The README links to a free trial of the hosted site.
