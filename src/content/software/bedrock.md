Bedrock is a project template, not a WordPress plugin: it sets up a new WordPress site with Composer. WordPress core, plugins and themes are installed as dependencies, in a directory layout meant to be kept in git, and configuration is read from environment variables. Roots, an independent open source organization, maintains the template. The [Bedrock page](https://roots.io/bedrock/) describes the layout.
