Poet is a blog engine for Node.js that renders posts written in Markdown or Pug into the routes of an Express app. Posts are files written in Markdown, Pug or another template language.

Poet is passed the Express app and its options, and it sets up the blog routes on that app when it initializes.

## Worth knowing

The README carries a request for maintenance help, linked to an issue on the repository.
