Tongs is a static site generator built on Laravel Zero, and its README calls it heavily based on Metalsmith. It runs source files through plugins for collections, drafts, Markdown and Blade views. The source and destination can each be a local directory or a Laravel filesystem, so the output can go straight to an S3 bucket. The [example site repository](https://github.com/datashaman/tongs-example) shows the setup with Composer.

## Worth knowing

The repository is archived and read only, and the README marks the project as work in progress. The Packagist record flags the package as abandoned. The README has no installation steps; the setup comes from the example repository.
