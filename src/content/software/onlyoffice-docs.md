ONLYOFFICE Docs is a document server. Web applications and platforms embed its online editors, and the server behind them handles the documents: a storage service keeps the files, an editing service serves the editors, a command service manages open documents and a conversion service converts between formats. The community edition runs on the operator's own server from a Docker image or a Debian, Ubuntu or Windows install.

Ascensio System SIA, a company in Riga, Latvia, builds the project.

## Worth knowing

The core components are open source under AGPLv3. Enterprise features, including the administration panel, come under commercial licenses, and the Developer Edition is a commercial edition for building the editor into an app under the builder's own brand.
