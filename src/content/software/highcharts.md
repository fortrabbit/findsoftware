Highcharts is a JavaScript charting library that draws charts with SVG, with some canvas and WebGL. All core functionality runs in the browser. The repository holds the library together with its Stock, Maps, Gantt, Dashboards and Grid packages. A page loads the npm package through a bundler, uses the Highsoft CDN, or serves files from a zip download. The [installation guide](https://www.highcharts.com/docs/getting-started/installation) describes each route.

Charts can be presented in any language through the lang options, and the documentation covers right-to-left text.

## Worth knowing

The repository's readme calls Highcharts a source available product. Two license agreements apply: the Standard License Agreement covers the commercial license types, and the End User License Agreement grants personal and educational use free of charge and requires a commercial license for other use. The CDN is meant for local development, product evaluation and other non-production use under its acceptable use policy.
