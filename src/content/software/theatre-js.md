Theatre.js is an animation library that changes JavaScript values over time, so a page can move HTML, SVG and Three.js objects, or any other variable, along a timeline. Animations can be built in code or in the Theatre.js studio, a visual editor that the README describes as a design and development tool. The core package is installed from npm and imported into a bundled project, or loaded from a CDN on a page that has no build step.

## Worth knowing

The README says development has temporarily moved to a private repository, so the public repository may not show the latest work. The studio is released under the AGPL and the core under the Apache License; the README says a project's final bundle includes only the core.
