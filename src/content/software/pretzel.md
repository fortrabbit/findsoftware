Pretzel is a site generation tool for .NET developers, written in C#, and based on Jekyll. Its [README](https://github.com/Code52/pretzel/blob/master/README.md) describes `pretzel bake` as generating a site from the contents of a folder, with Liquid or Razor templates, and `pretzel taste` as testing a site locally. It can import content from WordPress and Blogger.

It is installed as a single Pretzel.exe from the GitHub releases or from Chocolatey.

## Worth knowing

The README says the project was archived because its maintainers no longer had the time and will to work on it. The project's homepage does not answer over HTTPS, so no homepage is linked.
