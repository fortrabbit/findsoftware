Klaro is a consent manager that a site loads as a script with a config file. The config lists the third-party apps on the site, and Klaro keeps each one from running until the visitor consents. It installs from npm, from a CDN URL with a version in the path, or as compiled files downloaded from the dist folder, and it runs in the visitor's browser. KIProtect GmbH maintains the project and also offers a hosted version with paid plans; the documentation mostly describes the open-source version.
