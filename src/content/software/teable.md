Teable is an open source spreadsheet and database platform built on PostgreSQL. The README lists tables, views, permissions and an API on that database, and the record API lets applications create, read and update records over HTTP with a Bearer token. The [Docker guide](https://help.teable.ai/en/deploy/docker) describes a standalone instance started with Docker Compose. Teable's comparison pages name Baserow, NocoDB and n8n as products it is an alternative to.

The company also runs Teable Cloud, which the homepage offers with a free sign-up.

## Worth knowing

The repository is the Community Edition: the core applications are under AGPL-3.0 and the packages directory is under the MIT License. The official image ships the complete product, and paid plans unlock AI features and advanced enterprise capabilities there once a license key is activated.
