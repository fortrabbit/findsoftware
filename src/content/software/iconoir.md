Iconoir is an open source SVG icon set created by the designer Luca Burgio, who still leads the project, with help from open source contributors. The icons can be downloaded from the website, installed from npm as SVG files, or used through a CSS stylesheet loaded from a CDN. The [introduction](https://iconoir.com/docs/introduction) also lists separate packages for React, React Native, Vue and Flutter.
