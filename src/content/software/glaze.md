Glaze is a static site generator for PHP that takes content written in Djot and renders it through Sugar templates. It writes plain HTML files, so the built site is a folder that any web space can serve. Glaze is installed with Composer, as the [installation guide](https://josbeir.github.io/glaze/getting-started/installation/) describes.

The project was created by Jasper Smet. An optional Vite step adds CSS and JavaScript bundling.
