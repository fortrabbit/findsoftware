uFuzzy is a fuzzy search library that matches a short search phrase against a list of phrases, without building an index for the list. It is installed from npm and loaded in Node with require, or in the browser with a script tag that points at the built file in the repository's dist folder.

The repository is the project's only site. The copyright line in its license names Leon Sorokin, who is also the package's author.
