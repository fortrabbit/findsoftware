Highlight is a full-stack monitoring platform for error monitoring, session replay and logging, and its README describes both a hosted app and a self-hosted Docker setup. The README installs a hobby instance on Linux with a script in the repository's docker directory.

LaunchDarkly announced that Highlight is joining its team. The project's own homepage now redirects to LaunchDarkly's site.

## Worth knowing

The enterprise directory has its own license, which allows production use only for parties that have agreed to the vendor's terms. The rest of the repository is under the Apache license.
