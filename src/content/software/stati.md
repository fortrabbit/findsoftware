Stati is a static site generator written in PHP. Its stated end goal is to build any existing Jekyll site with the same results. The [install guide](https://stati.jfoucher.com) describes running `stati build` in the website directory to generate the site, and `stati serve` to serve it locally.

## Worth knowing

The README says Stati is not entirely compatible with Jekyll, most notably because of missing Liquid filters.
