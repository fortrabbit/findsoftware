Sequelize is an object-relational mapper for Node.js and TypeScript. It features transaction support, relations, eager and lazy loading and read replication, and connects to each database through a driver package the user installs next to it.

A next major version of the library is in alpha, and the stable line is the one the npm package named sequelize installs.
