React Datepicker is a date picker component for React, installed from npm. React and PropTypes are not included in the package and are installed separately. Display text is localized through date-fns locales, which are imported into the project and registered with the component.

## Worth knowing

The component works with native JavaScript Date objects and has no built-in timezone conversion. The README recommends date-fns-tz alongside it for that.
