SortableJS is a JavaScript library that makes HTML lists reorderable by drag and drop. Sortable.create attaches it to an element, and lists that share a group option can move items between each other. The README says it supports touch devices and needs no jQuery, with a separate jQuery binding available. The homepage compares it with jQuery UI and Dragula.

Bindings for Vue, React, Angular and other frameworks are separate repositories that the README and homepage link.
