drf-spectacular is a Python package that generates OpenAPI 3 schemas for Django REST framework APIs, with Swagger UI and Redoc views as options. It is installed with pip.

The README describes the code as a heavily modified fork of the OpenAPI generator in Django REST framework. An optional sidecar package ships the Swagger UI and Redoc static files for environments without access to a CDN.
