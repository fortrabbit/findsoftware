Brunch is a front-end build tool for web applications, with a declarative config and incremental compilation. The getting-started guide installs it with npm. The build runs on a developer's machine and produces static files.

## Worth knowing

The npm package named brunch is no longer the project. Its README says the package was transferred to a new owner for an unrelated project and will not receive further updates from the original author. The README names 4.0.2 as the last release from the original author, and the registry marks that version deprecated.
