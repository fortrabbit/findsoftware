GrazeDocs is a static site generator for .NET that builds documentation sites from Markdown files, one file per documentation page. It is installed as a global .NET tool with `dotnet tool install -g GrazeDocs`, and `GrazeDocs -p` publishes the complete site as HTML. Its themes are Razor based, and its live preview refreshes the site as the Markdown changes. The [quick start](https://github.com/mikoskinen/GrazeDocs/blob/master/docs/QuickStart.md) describes the install, init and publish steps.
