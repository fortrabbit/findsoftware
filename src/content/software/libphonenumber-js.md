libphonenumber-js parses, formats and validates personal phone numbers in JavaScript and TypeScript. It is a rewrite of Google's libphonenumber and reuses Google's metadata. The package ships several metadata sets, min, max, mobile and a custom one, so a project can choose the set that matches its bundle size and validation needs.

## Worth knowing

The primary repository is on GitLab, and the GitHub repository is a backup.
