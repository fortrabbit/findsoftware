NativeBase is a mobile-first component library for React and React Native, for apps that run on Android, iOS and the web. GeekyAnts builds and maintains it.

## Worth knowing

The project is discontinued. The README says NativeBase is entering maintenance mode, the installation page says its docs are not maintained anymore, and the project's homepage says NativeBase is now gluestack. The README recommends gluestack-ui for new projects.
