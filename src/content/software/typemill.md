Typemill is a PHP content management system that keeps pages in flat files and writes them in Markdown, aimed at documentation, manuals and handbooks. It can be installed from a ZIP archive, a Git clone or a Docker image. On Apache it relies on the bundled `.htaccess` file and `mod_rewrite`. The admin area is under `/tm/login` on the installed site. Sebastian Schürmanns, named as owner in the imprint, operates the project.

## Worth knowing

The core is MIT-licensed, while premium plugins and themes are sold under [MAKER and BUSINESS licenses](https://typemill.net/license/buy). Each license covers one Typemill instance for one year and renews automatically every 12 months.
