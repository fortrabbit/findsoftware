Vaadin Web Components is a set of web components for business web applications, published as one npm package per component. A project installs the package for each component it uses and imports it into its code. The [documentation and live examples](https://vaadin.com/docs/latest/components) cover the components, and the [forum](https://vaadin.com/forum/) takes support questions.

## Worth knowing

The repository holds two license tiers. The core components are under the Apache License 2.0, while the Pro components carry the Vaadin Commercial License and Service Terms and come with a Vaadin Pro subscription. A project that uses a Pro component needs that subscription, and the core components do not.
