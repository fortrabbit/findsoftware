Conform is a form validation library for HTML forms. Its React package, @conform-to/react, is the one published on npm and the one the installation page names, and it is a view adapter for React. Schemas from Zod, Valibot or Yup are checked through helper packages that the installation page lists next to it.

The overview says Conform gives full support to server frameworks such as Remix and Next.js, and the integration pages cover React Router and Next.js.

## Worth knowing

The React package lists React 18 or later and react-dom as peer dependencies, so the application has to provide them. The installation page says Conform is installed along with the schema library the application validates with.
