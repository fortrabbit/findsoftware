BigCommerce is a hosted commerce platform for online stores, offered by Commerce.com US, Inc. The [developer documentation](https://developer.bigcommerce.com/api-docs/) describes REST and GraphQL APIs for managing store data such as products and orders, which headless storefronts build on. The hosted control panel is how most brands interact with the platform, and one dashboard can manage several storefronts.

## Worth knowing

The service is run by the company and is not installed by the merchant. The Stencil CLI is a local tool for editing and previewing theme files; it does not host a store.
