Chai is an assertion library for Node.js and the browser. It offers three styles, assert, expect and should, and works with any JavaScript test framework. Plugins extend the assertions through a plugin API that the project documents.

The package is installed from npm as a development dependency. In a browser page, the index.js file from the same npm install loads as an ES module. The [documentation](https://www.chaijs.com/) covers the styles and the plugin guide.
