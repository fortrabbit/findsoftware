OpenACS is a toolkit for building community-oriented web applications, written in Tcl and published on GitHub under the GNU General Public License. The core packages live in the [openacs-core repository](https://github.com/openacs/openacs-core), whose install notes name Oracle or PostgreSQL as the database. The OpenACS community maintains the software.

It runs as a server process that a keepalive mechanism restarts when it halts, and it carries internationalization and localization for the user interface.
