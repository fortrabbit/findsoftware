HtmlBuilder is a generator of static HTML websites written in FreePascal and Lazarus. Its engine keeps content in an SQLite database. The README also describes a menu constructor, a built-in web server, and an Ollama client, and a way to commit the output to GitHub Pages. Translations cover English, Spanish, Chinese and Korean.

The README documents three ways to get the application: a Linux installer, a download of the pre-release from the releases page, and compiling the Lazarus project file in the Lazarus IDE. Server-side bridge endpoints for PHP, Node.js and Python are also described in the README, for uploading content to a server.

## Worth knowing

The repository has no stable release. Its only GitHub release is a prerelease, and the other version tags are not releases. The project's own homepage named in the README could not be read, so it is not linked.
