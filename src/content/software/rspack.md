Rspack is a bundler for the web written in Rust. It is installed with npm next to its CLI, which provides a dev server for local development and a build command. The project says it modernizes the webpack API to enable seamless replacement of webpack, and that its loaders are fully compatible with webpack loaders.

The quick start recommends Rsbuild for web applications.
