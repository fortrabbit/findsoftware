Whoosh Reloaded is a Python library for indexing text and searching it, implemented in pure Python so that it needs no compiled extensions. Applications import the library and build their own index and query code around it. It is installed from PyPI with pip under the name whoosh-reloaded, and the [documentation](https://whoosh-reloaded.readthedocs.io/en/latest/) covers the schema, indexing and searching APIs. The README credits Matt Chaput with creating Whoosh and names the Sygil-Dev Organization as the current maintainer.

## Worth knowing

The README opens with a notice that the repository is no longer maintained. The release fields on this record show the newest version published.
