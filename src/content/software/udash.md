Udash, written in Scala and compiled to JavaScript with Scala.js, builds the browser side of a web application. The framework adds a type-safe layer over HTML, CSS and JavaScript, with data bindings into the page, and the README says it does not influence the backend implementation. Translations can be served by the backend or compiled into the JavaScript. The [developer guide](https://guide.udash.io/) covers project setup, and the framework is installed by generating a project with sbt from the project's Giter8 template.
