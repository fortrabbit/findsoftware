corvu is a collection of unstyled UI primitives for SolidJS, built to be accessible and customizable, so the styling is left to the project using them. The [installation guide](https://corvu.dev/docs/installation/) says each primitive is its own npm package, so a project installs only the ones it needs, and the main corvu package installs all of them at once. The docs also describe a plugin for Tailwind CSS and a preset for UnoCSS.
