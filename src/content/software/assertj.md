AssertJ is a Java library of fluent, strongly typed assertions for unit tests, and it works with JUnit, TestNG or any other test framework. The core module is the one the install guide names, and the Maven and Gradle snippets add it as a dependency.

The repository also holds modules for Guava, Joda-Time, Neo4j, relational database tables and Swing user interfaces.

## Worth knowing

The guide lists Kotlin support and states that Android is compatible with exceptions: soft assertions and assumptions are not supported there, and Android is not an official target.
