Simply Static is a WordPress plugin that exports a WordPress site as a static HTML copy, so the public copy can sit on static hosting while WordPress stays private. Simply Static Studio is a hosted service for managing the static WordPress workflow.

## Worth knowing

The free plugin is the core. Pro is a paid plugin tier and Studio is a paid hosted tier; the [pricing page](https://simplystatic.com/pricing/) sets out the differences.
