Layui is a web UI component library for building web pages in the browser with plain HTML, CSS and JavaScript. The README describes it as developed with pure HTML, CSS and JavaScript, and it is installed from npm, loaded from a CDN or downloaded. The documentation and the website are in Chinese, and the README is also available in English. The copyright line under the MIT license names Layui contributors.

## Worth knowing

The README says the original website was taken down in 2021 and that development continued on GitHub and Gitee. A next major line, Layui 3, is in development and is published on GitHub only as alpha prereleases.
