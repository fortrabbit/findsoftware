Commento++ is a fork of Commento, a comment box that a static website embeds in place of Disqus. Its README says the fork came from fixing many bugs after the original maintainer seemingly disappeared, and it adds a comment moderation dashboard and wildcard domains. The widget attaches to a page with a script tag served from the instance's own server. The server needs a PostgreSQL database and can be run from a Dockerfile, a pre-compiled binary or a build from source, with deploy buttons for Heroku and Railway. Souradip Mookerjee, the fork's author, maintains it.

## Worth knowing

The homepage named in the candidate list does not resolve in DNS, so the record has no homepage and its status is stub. The LICENSE file keeps the copyright line of Commento, Inc., the upstream project.
