CodeceptJS is a testing framework for end-to-end tests of websites and web apps. Tests are written as scenarios of steps from a user's point of view, and the framework runs those steps through the browser and mobile drivers it supports.

CodeceptJS is the successor of Codeception, a testing framework for PHP. It runs on Node.js. The project publishes an official Docker image based on the Playwright image, and its documentation includes a migration guide for Cypress test suites. The maintainer is DavertMik.
