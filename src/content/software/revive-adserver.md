Revive Adserver is an ad serving system that a publisher installs on its own web server to serve banners, track campaigns and set delivery rules. It is written in PHP and stores its data in MySQL or PostgreSQL. The project publishes release archives on its download page, and the [installation guide](https://www.revive-adserver.com/how-to/install/) describes uploading the archive and running the web installer.

The project began in 2013, when the Revive Adserver team bought OpenX Source. Aqua Platform now looks after the project and also offers a hosted edition.

## Worth knowing

The hosted edition is a subscription service, and the self-hosted edition runs on a server the operator controls.
