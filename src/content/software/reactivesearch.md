ReactiveSearch is a UI components library for React that builds search interfaces over Elasticsearch, OpenSearch, Solr and MongoDB. The React package is published on npm as @appbaseio/reactivesearch, and the install step is a single npm command.

## Worth knowing

For version 4, the search query is generated by ReactiveSearch cloud, which the README says the library is designed to work with.
