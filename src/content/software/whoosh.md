Whoosh is a pure-Python library for full-text indexing and searching, installed with pip. Matt Chaput created and maintains it, and its documentation is hosted on Read the Docs. The project publishes releases to PyPI and tags them in its repository, which has no GitHub releases.

## Worth knowing

The latest release on PyPI dates from 2016, and the last commit on the default branch is from 2022. A community fork, whoosh-reloaded, is published under its own name. The project's README does not declare the project ended.
