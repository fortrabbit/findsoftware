CodeMirror is a code editor component for the web, maintained by Marijn Haverbeke. It can be used in websites to implement a text input field for code. The project is a set of packages installed from npm, and development takes place on the project's own forge. The GitHub copy of the repository is archived.

## Worth knowing

The packages are distributed as ES6 modules, and the guide says running the library without a bundler or module loader is not currently practical.

The project's homepage says that commercial users carry a social, but no legal, expectation to help fund its maintenance.
