c8 is a code-coverage tool for Node.js. It uses the coverage that Node.js collects with its built-in V8 support and writes reports in the formats of the Istanbul reporters.

Options can be set as command-line flags, in a package.json section, or in a JSON configuration file, as the [README](https://github.com/bcoe/c8/blob/main/README.md) describes. The package is published on npm under the name c8.
