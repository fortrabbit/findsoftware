Cirrus is an SCSS framework built for rapid prototyping, with pre-built components to start a project and utility classes to refine the final design. The README says its styles need no JavaScript for interactions such as modals and dropdowns, and that the stylesheet build can add components, remove utility classes and disable features. The setup page shows how to use it in plain HTML pages and in React, Vue, Svelte and Sass projects.

## Worth knowing

The glyphs need the Font Awesome library, which the setup page says requires signing up for a developer kit. The website's own text is licensed under CC BY-NC-SA 4.0, separately from the MIT license of the code.
