MyBatis is a Java persistence framework that couples Java objects with stored procedures or SQL statements, written in XML files or as annotations. It removes most of the JDBC code and manual parameter setting. An application builds a SqlSessionFactory from an XML configuration or from a Java configuration object. The getting-started guide names the MyBatis-Spring and MyBatis-Guice sub-projects for dependency injection frameworks. The [getting-started guide](https://mybatis.org/mybatis-3/getting-started.html) covers setup.
