MiniJinja is a Rust template engine that follows the syntax and behavior of Jinja2, the Python template engine it is based on. A program adds templates to an environment as text and renders them with a context of values, and templates can inherit from one another and apply filters. The crate is maintained by Armin Ronacher. The same repository holds a Go port, bindings for JavaScript, Python and C, and a command line tool, each as its own package. The [API documentation](https://docs.rs/minijinja/) is on docs.rs, and questions go to the repository's [GitHub Discussions](https://github.com/mitsuhiko/minijinja/discussions).
