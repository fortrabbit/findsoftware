Respect\Validation is a PHP validation library that checks values against chains of validator rules and reports failures as exceptions or results.

## Worth knowing

Translation is supported, but it is off by default, and the library ships no official translations other than English. The [translation page](https://github.com/Respect/Validation/blob/main/docs/messages/translation.md) describes supplying the messages through a translation contract.
