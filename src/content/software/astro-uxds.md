Astro UXDS is a design system from Rocket Communications for space application interfaces, published as web components built in Stencil with React and Angular wrappers. The [README](https://github.com/RocketCommunicationsInc/astro) describes the Web Component and CSS libraries as a starting point for in-browser space app experiences. The web components can be installed from npm or loaded from a CDN.

## Worth knowing

The README warns that documentation and code are not currently being actively maintained and may be outdated, and it points readers to Rocket Communications for support.

The license is stated two ways. The [LICENSE file](https://github.com/RocketCommunicationsInc/astro/blob/main/LICENSE) places the software in the public domain within the United States and grants a royalty-free license elsewhere with conditions, while the npm package reports MIT.
