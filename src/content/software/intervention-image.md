Intervention Image gives PHP code one API for creating, editing and composing images. The processing happens in a driver underneath, GD, Imagick or libvips, so the server needs one of them installed before any image work runs. The [installation guide](https://image.intervention.io/v4/getting-started/installation) explains the requirements for each driver. Oliver Vogel maintains the library.
