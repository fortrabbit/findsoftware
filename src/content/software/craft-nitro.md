Craft Nitro is a console tool that manages a Docker-based local PHP development environment for [Craft CMS](https://craftcms.com/) projects. Its command-line binary, written in Go, is installed with Homebrew, a shell script or a manual download, and the environment includes MySQL, MariaDB and PostgreSQL databases.

## Worth knowing

Pixel & Tonic, Inc. retired Craft Nitro and no longer supports it. Its [announcement](https://craftcms.com/blog/retiring-craft-nitro) points users to DDEV, and the repository is archived.
