OhMyForm is an open source form builder for forms, surveys and questionnaires. The README lists embeddable forms, a forms API and webhooks on submission, and says it runs on PostgreSQL or SQLite, with a Heroku button and a Docker image as the deployment routes.

## Worth knowing

The repository is archived, and its README opens with an end notice that names Formbricks as the project to move to.
