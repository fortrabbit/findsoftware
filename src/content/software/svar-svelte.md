SVAR Svelte Core is a library of more than thirty UI components for Svelte. It is installed from npm as @svar-ui/svelte-core. The package was published as wx-svelte-core until the core packages moved to the @svar-ui namespace, and the old name is deprecated on npm. The repository holds the core library only: its menu, toolbar, task list, comments and file uploader widgets are separate packages in separate repositories. XB Software Sp. z o.o., a company in Poland, maintains it.
