Amazon CloudSearch is a fully managed AWS service that sets up a search solution for a website or application, indexes structured data and text in it, and answers queries through its API. Amazon Web Services, Inc. runs it, and the AWS Management Console is the place to create a search domain. The [developer guide](https://docs.aws.amazon.com/cloudsearch/latest/developerguide/what-is-cloudsearch.html) documents the service.

## Worth knowing

AWS states that Amazon CloudSearch is no longer available to new customers, while existing customers can keep using it. AWS also says it continues to support the service, and it recommends that users explore Amazon OpenSearch Service for the latest search capabilities. The record is a stub until it is settled whether closure to new customers counts as an end.
