Sinuous is a low-level UI library written in JavaScript, with a tiny footprint. It is installed from npm or loaded from the jsDelivr CDN. The docs site names Wesley Luyten as its author and states that the source is MIT-licensed.

## Worth knowing

The repository has no license file, so the MIT license comes from the npm package and the docs site rather than from the repository. The most recent npm release is older than the last change to the repository.
