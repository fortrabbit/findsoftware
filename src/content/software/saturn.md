Saturn is a web framework written in F# that implements the server-side MVC pattern. The [overview page](https://saturnframework.org/explanations/overview.html) says it is built on top of ASP.NET Core and Giraffe.

New projects come from a dotnet template, installed with the dotnet CLI, and the [getting-started guide](https://saturnframework.org/tutorials/how-to-start.html) walks through creating a project and running it. The guide says the code generator uses only SQLite.
