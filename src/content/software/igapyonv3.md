igapyonv3 is a Java-based static site and blog generator that converts Markdown files into HTML. Its README calls it an open source diary system written in Java. It is installed as a Maven plugin and run from the diary directory with a Maven exec goal. Templates use FreeMarker, and the repository's docs folder holds the detailed behavior of the program. Toshiki Iga is the maintainer named on the GitHub profile.
