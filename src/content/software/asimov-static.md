Asimov is a static site generator that runs as a plugin of the asimov.js Node.js framework, together with asimov-server. Pages are files in a content folder, and a page can have localized versions. Templates are written in Handlebars. A prebuild step writes the whole site out as static files. Adam Renklint maintains it.

## Worth knowing

The GitHub repository is archived and described as deprecated. The asimov.js site that mentions the plugin describes asimov.js itself, whose repository is also archived.
