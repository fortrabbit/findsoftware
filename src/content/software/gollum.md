Gollum is a wiki that serves and edits the pages of a Git repository. A Gollum wiki is a git repository of a specific nature: its pages are files that can be edited in any editor and committed, or in the built-in web interface. The software ships with Markdown and RDoc support, and the [README](https://github.com/gollum/gollum/blob/master/README.md) names further markups that install as extra renderers. The server binds a port that a browser opens, and it can run alongside a CAS (Central Authentication Service) single sign-on server.
