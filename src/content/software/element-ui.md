Element, published on npm as element-ui, is a UI toolkit for Vue 2 web applications. It is installed from npm or loaded from a CDN, and its default language is Chinese, with other languages set through locale configuration.

## Worth knowing

The README says Element will stay with Vue 2.x and, for Vue 3, recommends Element Plus.
