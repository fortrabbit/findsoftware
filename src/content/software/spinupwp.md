SpinupWP is a hosted control panel for WordPress sites on cloud servers. It connects over SSH to a server the user runs and manages the WordPress sites on it, from a web dashboard, and installs MySQL on that server. Plans are listed on the [pricing page](https://spinupwp.com/pricing/). The company is SpinupWP Inc., based in Ontario, Canada, and its application and databases run on DigitalOcean servers in the United States.

## Worth knowing

The software is a service run by the vendor, not something installed from source. The community forum is open only to existing customers. Access for additional users can be limited to specific servers and permissions.
