rails-i18n is a Ruby gem that collects locale data for Ruby on Rails. The README says all of its modules (locales, pluralization, transliteration and ordinals) are enabled by default, and a Rails configuration setting restricts which ones load. The README also describes copying locale files into an application's config/locales directory instead of installing the gem.
