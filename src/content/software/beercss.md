Beer CSS is a CSS framework based on Material Design 3. Its README says it translates Material Design to semantic HTML, needs no build step or dependencies, and builds interfaces without custom CSS. It is organized as settings, elements and helpers, documented in markdown files in the repository. The README lists a default stylesheet, a scoped version that applies inside a container, a custom element version and a local copy of the CDN files for projects that host their own files. Its JavaScript file and a separate color package are optional, though some uses require them.
