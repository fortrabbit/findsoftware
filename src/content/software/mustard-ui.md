Mustard UI is a CSS framework that the project describes as a starter, with its source in modular SCSS. A project installs the compiled stylesheet from npm, loads it from a CDN or downloads it as a zip file. Kyle Logue maintains it.

## Worth knowing

The site states that Mustard does not include a CSS reset such as normalize.
