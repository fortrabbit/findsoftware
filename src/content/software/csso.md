CSSO is a CSS minifier that cleans, compresses and restructures stylesheets. It is installed from npm, and its bundles can also be loaded into a web page. The optimizer is based on CSSTree, a parser that turns CSS into a syntax tree.

Usage data is an optional input. When a project supplies it, the optimizer can merge rules across scopes that never appear together on one page.
