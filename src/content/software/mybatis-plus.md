MyBatis-Plus is an enhancement toolkit for MyBatis that adds features on top of it without changing the core framework. It provides a base mapper interface with ready-made database methods, a lambda-style query wrapper, an active record mode, automatic paging and a code generator for mapper, model, service and controller layers. The install guide names Spring Boot starters for each Spring Boot version, and plugins that parse SQL, such as pagination, need an optional parser module. The [documentation](https://baomidou.com/en/) covers the features and the supported databases.

## Worth knowing

The Baomidou site lists separate components next to the library, including an enterprise-level module, that this record does not cover.
