Loupe adds full-text search to a PHP application and keeps its index in SQLite, so the search needs no service beyond the application and its database file. The [Loupe documentation](https://loupe-php.github.io/loupe/) covers setup and indexing.

## Worth knowing

Loupe needs the pdo_sqlite PHP extension and a minimum SQLite release.
