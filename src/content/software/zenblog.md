Zenblog is a hosted headless CMS for blogs. Authors write posts in a hosted editor, and Zenblog hosts the images and videos that the posts use. A site reads the posts through a REST API or through the TypeScript client that the getting-started guide installs with npm. The guide lists posts, fetches one post by slug and renders its HTML in the site's own code.

One account can hold several blogs.

## Worth knowing

The posts live on Zenblog's hosted service, so a site cannot read them without the API. The free plan limits files, images, videos and API requests per month. The Pro plan names unlimited ones under a fair use policy.
