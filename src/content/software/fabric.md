Fabric is a Python library for running shell commands on remote hosts over SSH, returning the results as Python objects. Its README describes it as building on Invoke and Paramiko. It is installed with pip and documented on [the documentation site](https://docs.fabfile.org), which holds the usage and API reference.

The project describes its purpose as remote execution and deployment. Its maintainer, Jeff Forcier, is named in the LICENSE copyright line.
