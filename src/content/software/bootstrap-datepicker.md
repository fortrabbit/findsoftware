bootstrap-datepicker is a datepicker widget in the Bootstrap style, used from JavaScript through jQuery. The project site hosts an online demo and a sandbox where the options can be tried. The widget is loaded on a page from the cdnjs CDN, and the package is also published on npm. It supports translated month and weekday names.

## Worth knowing

The widget depends on Bootstrap's dropdown styles and sprites for some of its appearance, so a page that uses it loads Bootstrap and jQuery alongside it. The documentation names the versions it is tested against and says other versions are used at the user's own risk.
