SPIP is a publishing system for the Internet, written in PHP, aimed at multilingual sites and collaborative editing. It has a back-office, and it runs on a web server with PHP, using SQLite, MySQL or MariaDB as the database.

The [download page](https://www.spip.net/en_download) offers a loader file, a zipped archive for manual upload, and the source as a git clone from the project's forge.

## Worth knowing

The project's charter describes the SPIP community as independent of any association, foundation or company.
