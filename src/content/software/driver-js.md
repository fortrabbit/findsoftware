Driver.js is a JavaScript library for product tours, element highlights and feature hints on web pages. It is written in TypeScript and is installed with npm, or loaded from a CDN as a script tag. The homepage says it works with any framework or with plain JavaScript, so no framework is recorded as its base.

## Worth knowing

Hints and checklists are separate entry points in the package, which the docs give as their own files.
