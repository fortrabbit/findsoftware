PatternFly React is a React component library for the PatternFly design system, published to npm as a set of packages that the develop page says are maintained together. It installs with npm or Yarn from @patternfly/react-core, the core package the install docs name. The docs state that PatternFly supports the two most recent versions of React at a time.

The HTML and CSS library is a separate project, recorded as patternfly.
