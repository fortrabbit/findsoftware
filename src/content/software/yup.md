Yup is a schema builder for parsing and validating runtime values, with TypeScript types inferred from the same schema. The README describes validation on the server and in the browser, and a setLocale function that customizes error messages for multi-language support.

The project has no website of its own; the repository README is the documentation. Jason Quense maintains it.

## Worth knowing

The README has no installation section, so the npm registry is the install route recorded here. It documents the current major API and links to pre-v1 documentation.
