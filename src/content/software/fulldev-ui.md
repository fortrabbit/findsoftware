Fulldev UI is a component library and set of page blocks for content-driven websites, built for Astro and also offered for React and Shopify Liquid. It follows the shadcn/ui registry format, components are added with the shadcn CLI, and the code is copied into the project. Its install page is written for Astro.

## Worth knowing

The repository holds the Astro components, a React extension and a Shopify Liquid package. Components are installed from the registry at ui.full.dev, and the npm package fulldev-ui holds a versioned copy of that registry, so its download count measures the archive package rather than installs.
