Elder.js is a static site generator and web framework whose page templates are written in Svelte. The README describes it as supporting server-side rendering and static site generation, and the [documentation](https://elderguide.com/tech/elderjs/) lists two production paths: building HTML files, or running the server in SSR mode. The quickest start clones the Elder.js template with degit and installs its dependencies with npm.

## Worth knowing

The README says the ElderGuide.com team expects to maintain the project until 2023 to 2024.
