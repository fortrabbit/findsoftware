Sage is a WordPress starter theme that builds its templates with Laravel Blade, bundles assets with Vite and styles with Tailwind CSS. It runs as the theme of a WordPress site and is installed with Composer from the WordPress themes directory. Building its assets needs Node and npm in addition to PHP. Roots, which describes itself as an independent open source organization, maintains it.
