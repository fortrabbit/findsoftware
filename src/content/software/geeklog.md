Geeklog is a content management system and blog engine written in PHP. Its content is stored in a MySQL or PostgreSQL database. The [install guide](https://github.com/Geeklog-Core/geeklog/blob/v2.2.2/public_html/docs/english/install.html) describes installation: unpack the release tarball, create an empty database, and place the public_html directory in the web root. Geeklog runs under Apache or Microsoft IIS with PHP.
