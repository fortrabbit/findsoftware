Embla Carousel is a carousel library that runs in the visitor's browser, installed from npm or loaded with a CDN script. The [get started guide](https://www.embla-carousel.com/docs/get-started) covers plain JavaScript and bindings for React, Vue, Svelte and Solid. Server-rendered pages use the embla-carousel-ssr plugin and initialize the carousel on the client, and the docs list further plugins.
