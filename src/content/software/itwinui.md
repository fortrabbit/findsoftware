iTwinUI is a design system from Bentley Systems for web interfaces in Bentley and iTwin.js applications. It comes as three npm packages: CSS for every component, CSS variables for the design tokens, and a React component library that builds on the CSS. The documentation covers the React package, which is installed with npm.

## Worth knowing

The README says iTwinUI is in maintenance mode, with StrataKit replacing it as the primary design system. A migration guide and a theme bridge for running both libraries side by side are linked from the README.
