ArangoDB is a multi-model database for documents, graphs and key-value data, queried with the AQL query language. The server is a native C++ binary that starts as a server process, and the installation docs cover Linux packages, the official Docker image and source builds. Its HTTP API exposes RESTful integration endpoints.

## Worth knowing

The repository is under the Business Source License 1.1, which changes to Apache License 2.0 four years after each release's release date. The Community Edition is free for non-commercial use and datasets up to 100 GB. Arango also runs a managed cloud, Managed Cloud (AMP), fully managed by Arango in AWS or GCP.
