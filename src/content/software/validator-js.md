validator.js is a library of string validators and sanitizers for JavaScript. The README documents server-side and client-side usage, with validators such as isEmail, isDate and isCreditCard and sanitizers such as escape, ltrim and normalizeEmail. It validates and sanitizes strings only, so other input has to be converted to a string first. The README serves as its documentation, and it lists several maintainers under the validatorjs GitHub organization.

## Worth knowing

The README says XSS sanitization was removed from the library and points to other projects for that job.
