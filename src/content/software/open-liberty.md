Open Liberty is a Java application server runtime from IBM for building and running cloud-native Java microservices and Jakarta EE applications. It runs on a Java SE runtime, and the server is started by a command that runs it as a background process. Applications and the Liberty runtime are set up through the Maven or Gradle plugins, a zip download or a Docker image.

The project is an IBM open source project, and its copyright line gives IBM Corp. as the owner.
