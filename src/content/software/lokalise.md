Lokalise is a hosted localization platform for software, websites and mobile apps, with an API, a CLI and translation workflow management. Customer data is stored on Amazon Web Services infrastructure in EU regions. The pricing page says teams migrating from WorldServer, Trados or other legacy platforms can transfer translation memory, glossaries and project structures using standard exchange formats.

## Worth knowing

Lokalise is offered only as a hosted service: its security page states that on-premises and private cloud deployments are not supported. Single sign-on uses SAML 2.0 for enterprise teams.
