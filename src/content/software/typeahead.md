typeahead.js is a JavaScript autocomplete library with two parts that can be used separately or together. The suggestion engine, Bloodhound, computes suggestions for a query, and the UI view renders them and handles the interactions with the page.

The UI view is available as a jQuery plugin.

## Worth knowing

The suggestion engine also depends on jQuery, so using it on its own still puts jQuery on the page.
