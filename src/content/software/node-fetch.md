node-fetch brings the Fetch API to Node.js, so server-side code can make HTTP requests with the same `fetch` calls a browser uses. The project has no website of its own; the [README on GitHub](https://github.com/node-fetch/node-fetch/blob/v3.3.2/README.md) and the docs folder in the repository are its documentation.

## Worth knowing

The current major is an ES module and cannot be loaded with `require()`. The 2.x line stays available for CommonJS code.
