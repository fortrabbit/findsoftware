PhantomJS is a headless web browser that scripts written in JavaScript control, aimed at page automation. Its download builds are self-contained binaries. The [documentation](https://phantomjs.org/documentation/) covers the scripting API.

## Worth knowing

The README and homepage say development is suspended until further notice, and the GitHub repository is archived.
