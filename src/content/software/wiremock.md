WireMock is an open source tool for mocking HTTP APIs in tests and development environments. It runs as a library inside a Java test, as a standalone server, or in a Docker container, and mock APIs can be defined in code, through its REST API, or as JSON files. Responses can be generated with Handlebars templates, and the project has adapters for other languages.

## Worth knowing

A hosted version, [WireMock Cloud](https://wiremock.org/docs/commercial/), is offered as a managed service, and its team features are not part of the open source server.
