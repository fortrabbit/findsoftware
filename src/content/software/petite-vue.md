petite-vue is an alternative distribution of Vue with the same template syntax and reactivity mental model as standard Vue. It is optimized for sprinkling a small amount of interaction on an existing HTML page rendered by a server framework, and a page can use it without a build step by loading it from a CDN with a script tag. The repository sits under the vuejs organization on GitHub.

## Worth knowing

The README says petite-vue may have bugs and API changes, and that its issue list is disabled. It also says feature requests are unlikely to be accepted, because the scope is kept to a bare minimum.
