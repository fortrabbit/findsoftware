Froala Editor is a WYSIWYG HTML editor that a page loads as a JavaScript component. Froala Labs SA publishes it under a commercial license. The README points to online documentation, and it lists server-side SDKs for PHP, Node.js, .NET, Java and Python, which are separate packages from the editor.

## Worth knowing

Using the editor requires a purchased license. The license agreement has a trial section for evaluation software, which runs for a limited period. The LICENSE file names bundled third-party components that carry their own MIT licenses.
