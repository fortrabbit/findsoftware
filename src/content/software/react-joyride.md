React Joyride is a React component library that runs guided tours over the elements of an app. A tour is a list of steps, each pointing at an element of the page, and the library offers both a component API and a hook API over the same steps.

The docs also describe a controlled mode and tour events.

## Worth knowing

Projects still on the second major move to the third through the migration guide in the docs.
