JS Search is a client-side search library for JavaScript and JSON objects. It runs its index in the browser. Its README lists tokenizers, stemming through a third-party stemmer, stop-word filtering, TF-IDF ranking and index strategies for prefix, substring and exact-word matches. The README says it is compatible with ES5 and needs no jQuery. It began as an implementation of Lunr JS, according to the README, and has since expanded. It is installed from npm or Bower.
