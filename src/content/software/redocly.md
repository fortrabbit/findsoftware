Redoc generates interactive API reference documentation from OpenAPI, AsyncAPI and GraphQL definitions. The Redocly CLI, run with npx, writes a static HTML file from an OpenAPI file by default. Alternatively, an HTML element with a script tag can load the viewer from a CDN, or a React component can embed it. Redocly Inc. maintains it, and the README calls it Redocly's community-edition product.

## Worth knowing

Redoc collects anonymous usage and performance data, and an option or an attribute turns that off. Redocly also offers a hosted Redoc with a try-it panel, automated code samples, a mock server and role-based access control, which the README lists as additional features.
