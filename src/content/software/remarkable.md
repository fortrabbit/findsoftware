remarkable is a JavaScript markdown parser that supports the CommonMark spec and renders markdown to HTML. Footnotes, tables and strikethrough are enabled by default, and a preset switches the parser to strict CommonMark. The parser takes options, and syntax rules can be added or replaced.

It runs on Node.js and can also be loaded from a CDN in the browser.
