Superstruct validates JavaScript and TypeScript data against struct definitions. A struct describes the expected shape of a value, and structs can be composed into larger ones. The README says the library is designed for checking data at runtime, and that it throws or returns detailed errors for the code that receives the data.

The changelog says maintenance has moved to a volunteer team. The README names joi, express-validator, validator.js, yup, ajv and is-my-json-valid as existing validation libraries and gives its reasons for another one.

## Worth knowing

The changelog marks use with an older Node.js line as deprecated.
