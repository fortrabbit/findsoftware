Midway is a Node.js framework written in TypeScript that covers web, full-stack, microservice, RPC, socket and serverless applications. The [introduction](https://www.midwayjs.org/en/docs/intro) names the Alibaba-Taobao front-end architecture team as its developer. A project is created with `npm init midway`, which runs the create-midway scaffolder.

## Worth knowing

The documentation describes separate technology stacks: a pure Node.js project, a serverless project built on @midwayjs/faas, and an integrated front-end and back-end project built on @midwayjs/core/functional.
