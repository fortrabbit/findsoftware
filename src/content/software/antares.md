Antares SQL is a desktop SQL client built with Electron.js and Vue.js. It runs on the developer's own machine and connects to MySQL, MariaDB, PostgreSQL, SQLite and Firebird databases. The [README](https://github.com/antares-sql/antares/blob/master/README.md) lists an AppImage for Linux, packages on Flathub and the Snap Store, and the Microsoft Store for Windows as ways to install it.

## Worth knowing

The project describes itself as in development and in a beta phase, and the homepage lists SQL Server as coming.
