Saas UI is a design system and source component registry for SaaS products, built with Chakra UI. Its CLI copies editable component source into a project, and the project then owns the installed files. The README describes the project as moving from a bundled React component package to a preset and source-template model.

## Worth knowing

A Pro edition sells a premium catalog of editable application blocks under a separate commercial license. The Pro license governs the paid blocks.

The older `@saas-ui/react` package remains available during the transition, according to the README.
