Orejime is a consent manager for websites that loads third-party scripts and embeds only after the visitor agrees. Site owners declare the purposes they use and wrap each script or embed in a template tag that names its purpose, and Orejime leaves the wrapped code untouched until consent is given. It runs from standalone builds installed with npm or loaded from the jsDelivr CDN, and it is configured through a global configuration object. The project began as a fork of Klaro, and BOSCOP, a French cooperative, maintains it.
