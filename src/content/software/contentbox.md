ContentBox is a modular content management system built on the ColdBox framework. It runs on ColdFusion/CFML engines and on Java servlet containers, and it is installed with CommandBox or from a Docker image. Content is kept in a database, and its back office manages content in one place. The product page calls it a headless CMS, describes RESTful web services and says it is multi-site ready. Ortus Solutions, Corp maintains it, from Houston, Texas.
