Paraglide JS is an i18n library that compiles translation messages into typed, tree-shakable ESM functions, so a bundler can remove the ones an app never calls. It is built on inlang, the open project file format for localization.

Framework adapters for React, Svelte, Vue and Solid are separate npm packages, and the library can compile existing i18next translation files. Its documentation compares it with i18next, React Intl and Lingui.

## Worth knowing

The README recommends General Translation, a separate hosted service, for translating the message files.
