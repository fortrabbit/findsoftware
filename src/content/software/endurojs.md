Enduro.js is a Node.js content management system and static page generator. It is installed globally with npm, and `enduro create` sets up a project folder. Running `enduro` starts the project in development mode. An admin interface, a separate repository installed with Enduro, runs locally once an admin user is added from the command line. The project is maintained by Martin Gottweis.

## Worth knowing

The domain the repository lists as the homepage now serves an unrelated online gambling site, so the README in the GitHub repository is the documentation that remains. The README links its full documentation to that domain. The facts do not state whether the output is static files or what a live site needs from its host.
