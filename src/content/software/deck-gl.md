deck.gl is a GPU-powered framework for visual exploratory data analysis of large datasets, rendered with WebGL2 and WebGPU. Its JavaScript packages are published under the @deck.gl scope, and a standalone bundle can be included in a page with a script tag.

The repository is a monorepo: its stars and contributors cover every package in it, and it also holds the React binding. The project is a vis.gl project under the OpenJS Foundation, and its license names the vis.gl contributors.
