missing.css styles plain HTML without classes, so a page that only links the stylesheet takes on a base look. Its components follow well-known semantic markup patterns with ARIA where appropriate, and it adds utility classes on top of the base styles.

It is added with a link to the stylesheet on a CDN, or installed into an npm project. Its look can be changed through CSS variables.

## Worth knowing

The project says it is not designed to be a complete styling solution for large websites. It is meant to be complete enough for small sites, internal tools and personal projects.
