CSLA .NET is a software development framework for .NET that helps build the business layer of an application as object-oriented business objects. The homepage lists ASP.NET Core Blazor, Razor Pages and MVC among the supported platforms, so the business layer can sit behind a web front end. The framework is installed from the NuGet package Csla or from release binaries. The homepage says Rockford Lhotka created it, and the copyright belongs to Marimer LLC.

## Worth knowing

The homepage lists .NET Framework 4.6.2 and later next to .NET 8, 9 and 10. The project sells books and videos through a store; these are not editions of the software, and the record lists no paid edition.
