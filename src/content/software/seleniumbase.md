SeleniumBase is a Python framework for browser automation, testing and web scraping. It uses the Selenium WebDriver APIs and incorporates test runners such as pytest and behave.

The project documents migrating raw Selenium scripts to SeleniumBase with worked examples. Its README also describes a Chrome DevTools Protocol mode, a stealthy Playwright mode, CAPTCHA handling, a test dashboard and MasterQA, a hybrid of manual testing with automation.
