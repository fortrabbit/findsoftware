Laravel Echo is a JavaScript library that a web page loads to subscribe to channels and listen for events that a Laravel application broadcasts. It is installed from npm and runs inside the browser client, where it receives the events that a server-side broadcasting driver sends. The [Laravel documentation](https://laravel.com/docs/broadcasting) covers the server side and the client setup together.
