XP.css is a CSS library for building interfaces that look like the Windows XP desktop. It restyles semantic HTML elements, so a page keeps its own markup and gets the look from the stylesheet. The [documentation](https://botoxparty.github.io/XP.css/) lists its components, and the [README](https://github.com/botoxparty/XP.css/blob/main/README.md) describes it as an extension of 98.css. It ships no JavaScript, so it works alongside any frontend framework, and a page loads it either from unpkg or from npm.

## Worth knowing

Its latest release is several years old, and the record shows the date.
