Badaso is a Laravel-based API and admin platform. Its README describes it as built on Laravel, with a Vue single-page dashboard, role management, a CRUD generator, and REST and GraphQL APIs. A project is created with `composer create-project badaso/starter`, as the [installation guide](https://badaso-docs.uatech.co.id/getting-started/installation) describes. Uasoft, part of Uatech Group, maintains it.

## Worth knowing

The license is stated two ways: the LICENSE file and GitHub say MIT, while the composer.json of the latest stable release says proprietary.

Packagist lists the old package name uasoft-indonesia/badaso as abandoned, with badaso/core as its replacement, so the record follows badaso/core.
