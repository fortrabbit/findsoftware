Pico CSS is a CSS framework that styles semantic HTML elements directly. An optional class-less version is also published. The stylesheet is installed by linking it from a CDN, through npm or Composer, or by downloading the archive from GitHub.

## Worth knowing

The project is no longer maintained. Its README says the final release is the last one, the repositories are archived, and there will be no new issues, pull requests or releases. The project states that the npm package, the jsDelivr CDN and the website stay online.
