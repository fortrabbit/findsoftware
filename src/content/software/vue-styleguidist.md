Vue Styleguidist builds an isolated development environment and a living style guide for Vue components. The vue-styleguidist command line starts a development server for the style guide, or builds it as a static website. The repository description says it was created from react styleguidist.

## Worth knowing

The repository is archived, and the README on its default branch says the maintainer no longer works on the project and will hand it to a trusted maintainer. The same README lists Storybook Docs, Histoire and pure Astro websites as alternatives.
