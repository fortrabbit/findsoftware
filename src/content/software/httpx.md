HTTPX is an HTTP client library for Python 3 with synchronous and asynchronous APIs. It supports HTTP/1.1 and HTTP/2, and it includes a command-line client for sending requests from a terminal. Its API is broadly compatible with requests, and it can send requests directly to WSGI or ASGI applications.

The [project documentation](https://www.python-httpx.org/) covers a quickstart, advanced usage, async support and the HTTP/2 options.
