Compodoc is a documentation tool for Angular applications that generates static documentation from a project's source. It runs as a local tool: the project's homepage says no server is needed and no sources are uploaded online. A developer installs it from npm with the global install command. Its output is static, and the hosting guide gives GitHub Pages as an example of where it can be published.

## Worth knowing

The package was published under the name compodoc until it moved to @compodoc/compodoc, and the old name is deprecated with a notice pointing to the new one. The homepage names Nest and Stencil next to Angular, while the guides describe Angular projects only.
