AsgardCMS is a content management system built as a Laravel application, with features supplied as modules and multilingual content built in. The [installation page](https://github.com/AsgardCms/Documentation/blob/master/v3/getting-started/installation.md) in the project's documentation repository installs it with Composer or the AsgardCMS installer and keeps content in a MySQL database.

## Worth knowing

The README links its documentation to asgardcms.com, which no longer serves the project; the installation guide is in the documentation repository instead.
