CMS Made Simple is a content management system whose templates run on the Smarty engine. Editors maintain the site in a browser-based admin area, and content is kept in a MySQL database. The [quick install](https://docs.cmsmadesimple.org/installation/quick-install) uploads a single installer file to the host, which sets up the rest.

## Worth knowing

The About page links the word GPL to the GPL-2.0 text, while GitHub reports GPL-3.0 for the repository.
