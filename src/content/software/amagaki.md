Amagaki is a TypeScript static site generator for hand-coded marketing sites, largely maintained by Blinkk, a small web development studio. It supports several template languages, with Nunjucks as the default, and localization is a built-in feature. The README also names a plugin system.

## Worth knowing

The README describes Amagaki as rendering pages at request time, unlike generators that watch files and rebuild, while the same README and the project site call it a static site generator.
