critical extracts the critical-path CSS from HTML pages, inlines it in the head and defers the remaining stylesheets, so the first screen can paint without waiting for a full stylesheet. It is a Node.js module with a command-line interface, installed from npm as a development dependency. The [README](https://github.com/addyosmani/critical/blob/master/README.md) includes a recipe for running it in CI against a build directory.

The README lists Ben Zörb as primary maintainer and Addy Osmani as creator, and points to a separate comparison document that covers Beasties.
