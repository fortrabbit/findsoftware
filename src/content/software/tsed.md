Ts.ED is a server framework written in TypeScript that runs on top of Express.js, Koa.js or Fastify.js. A new project is created with the [CLI command](https://tsed.dev/introduction/getting-started.html) npx -p @tsed/cli tsed init, which prompts for the runtime.

The homepage names Node.js and Bun.js as runtimes, and the docs describe serverless platform adapters alongside the server platforms.

## Worth knowing

The CLI prompt marks the Bun.js runtime as experimental.
