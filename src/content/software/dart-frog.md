Dart Frog is a backend framework for Dart, built on top of shelf and mason. The dart_frog command-line tool, installed from pub.dev, creates a project, runs a development server and makes production builds. The [getting started guide](https://dart-frog.dev/getting-started/) describes the commands.

A production build includes a Dockerfile, so the app can be deployed wherever a container runs. The framework is maintained by Very Good Ventures, the name its LICENSE file carries.
