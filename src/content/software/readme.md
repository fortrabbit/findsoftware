ReadMe is a hosted developer documentation platform for API references and guides. Its open-source companion is `rdme`, ReadMe's official command-line interface, which is installed with npm and run on a developer's machine or in a CI pipeline. The repository holds the CLI only; the platform itself is hosted.

## Worth knowing

The docs say `rdme@10` serves projects on ReadMe Refactored and `rdme@9` serves projects not yet migrated, so the major version recorded applies to the Refactored platform.
