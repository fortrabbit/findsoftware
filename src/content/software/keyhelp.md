KeyHelp is a server control panel for Ubuntu and Debian, made by the hosting provider Keyweb AG in Erfurt, Germany. The basic version is free of charge. It manages domains, email mailboxes, FTP users and MySQL databases through its control panel, and its REST API lets other programs connect to a KeyHelp server.

The installer is a shell script that a root user runs on the server. It installs and configures the required services itself, and the project's install page states that it offers no uninstaller.

## Worth knowing

KeyHelp Pro is a paid licence for each Linux server, and it adds features to the basic version. The project's pages name no repository or source code, so the source cannot be checked from them.
