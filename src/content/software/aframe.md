A-Frame is a web framework for building browser-based 3D, AR and VR experiences. Scenes are written as HTML elements, and each element takes its behavior from the components attached to it, an entity-component structure the README describes as a layer on top of three.js.

A page gets A-Frame either from a script tag that points to the CDN build or from npm. The install page says most methods need no installation, because A-Frame is primarily HTML and JavaScript.
