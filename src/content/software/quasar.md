Quasar is a Vue.js framework with a set of UI components and a CLI that builds one codebase into several kinds of app: single-page, server-rendered and statically generated sites, PWAs, mobile and desktop apps and browser extensions.

What the host must provide depends on the build mode. SPA and PWA output can be served by a static web server. A server-rendered build includes a Node.js web server and requires a JavaScript runtime on the host.
