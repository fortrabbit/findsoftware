Choices.js is a select box and text input plugin written in JavaScript and built to work without jQuery. It is installed from npm for use with a bundler, or loaded as a built file from a CDN. The README lists right-to-left support among its features and asks for more active maintainers.

## Worth knowing

The README describes a build flag that allows loading Choices into a non-browser environment.
