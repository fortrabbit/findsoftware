Bootstrap Icons is an open source library of SVG icons, published as the official icon set for Bootstrap. The package ships individual SVG files, a combined sprite, an icon font, CSS and Sass, and it installs from npm. The icons can be used with or without Bootstrap, in any project. The Bootstrap Authors maintain it under the MIT license, and the [icon font guide](https://icons.getbootstrap.com/font/) describes the class names for the font.
