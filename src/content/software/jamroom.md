Jamroom is social networking software written in PHP, which runs on a web host with MySQL or MariaDB and either Apache or Nginx. The open source core is installed by uploading its files to a web hosting account and then running the installer. Modules and skins are added from the Jamroom marketplace, and the open source ones are free to install on any Jamroom site.

The [quick install guide](https://www.jamroom.net/the-jamroom-network/documentation/getting-started/4603/quick-install-guide) walks through the upload and the installer, and the [licensing page](https://www.jamroom.net/the-jamroom-network/documentation/jamroomnet/4863/jamroom-licensing) explains which items fall under which license.

## Worth knowing

Premium modules and skins are released under the Jamroom Commercial License and licensed per site, so each site that uses them needs its own license.
