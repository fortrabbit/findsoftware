swag is a Go command-line tool that generates Swagger 2.0 documentation from annotations written as comments in Go source code. The [getting started section](https://github.com/swaggo/swag#getting-started) starts by adding those comments to the API source code.

Integrations for several Go web frameworks are separate repositories, listed in the README under its supported frameworks.
