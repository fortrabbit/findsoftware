verless is a Go static site generator that reads Markdown files, applies HTML templates and renders them as a website. It is distributed as a binary and as a Docker image. The built site goes into a `target` directory by default. During development, verless serves the project with its own built-in server, so no separate web server is needed.

## Worth knowing

The repository is archived on GitHub, so the record is marked discontinued.
