HLEB is a PHP framework for websites and web applications, with a service container and an optional asynchronous mode. The documentation is available in English, Russian and Chinese. HLEB is installed with Composer and can run behind Nginx with PHP-FPM, or as a long-running process under RoadRunner, which reuses loaded configuration, classes, services and cached data between requests. Twig can be used in place of the standard templates.
