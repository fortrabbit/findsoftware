Keep React is a set of React components styled with Tailwind CSS. A project installs the keep-react npm package with phosphor-react, adds the Keep React preset to its Tailwind configuration and imports the keep-react CSS into its stylesheet. Components are imported by name from keep-react. The README gives setup steps for a Vite React application and for a Next.js application.

The [installation guide](https://keep-react-pi.vercel.app/docs/getting-started/installation) is on the project site. The source is in a public GitHub repository owned by the StaticMania organization.

## Worth knowing

The installation steps set up Tailwind CSS in the project and wrap its configuration with the keepTheme function from Keep React. The code is MIT licensed, but the name and logos are trademarks of StaticMania, which the README states separately.
