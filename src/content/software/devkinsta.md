DevKinsta is a desktop app from Kinsta for building WordPress sites on the developer's own machine. It requires Docker, which the app asks the user to install if Docker is missing, and it can push a local site to a Kinsta staging environment.

## Worth knowing

No open-source license is stated for the app, and Kinsta's terms of service list it among the services they cover. The app is free to use, according to its homepage.
