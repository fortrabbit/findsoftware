RxJS is a JavaScript library for composing asynchronous and event-based programs with Observable values. It is published on npm as rxjs, and its repository also holds sibling packages for an Observable polyfill, testing and migration.

## Worth knowing

The README says RxJS 7 remains the production line and continues to be maintained, while a next major version is in prerelease work.
