Bestatic is a static site generator written in Python and Jinja2 that builds websites and blogs from Markdown files. The site is configured with a `bestatic.yaml` file and themed with Jinja2 templates. The quickstart creates a site, builds it into `_output`, and runs a bundled server for local preview.

It is installed with graphical installers, or with Snap, Flatpak, Homebrew or pipx. The `_output` folder can be uploaded to any server, and the [deployment guide](https://www.bestaticpy.com/docs/deployment/) describes building in CI on GitHub Pages, GitLab Pages, Netlify or Cloudflare Pages.
