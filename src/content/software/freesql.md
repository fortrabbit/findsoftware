FreeSql is an object-relational mapper for .NET, written in C# and maintained under the dotnetcore organization on GitHub. The project's documentation is on freesql.net. Each database has its own provider package, so an application installs the provider for the database it uses. The README lists providers for MySQL, SQL Server, PostgreSQL, Oracle, SQLite, Firebird, ClickHouse and DuckDB, and further providers for other engines, several of them Chinese domestic databases.

## Worth knowing

The NuGet metadata links to an earlier repository URL that redirects to the dotnetcore repository. The README names QQ groups for discussion, and the project does not list a forum of its own.
