Bake is a templated blog generator written in C++. It is used in a make-like fashion: a directory holds a bakefile of rules, a template file and blog posts as Markdown files, and running bake writes the HTML output. The README says an earlier version was written in C. Bake is built from source with make install or with CMake.

## Worth knowing

The repository has no release or tag.
