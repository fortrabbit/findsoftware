Arco Design Vue is a Vue component library based on the Arco Design system. It is published as the @arco-design/web-vue npm package, and a project installs it with npm into a Vue 3 application. Component texts use Chinese by default, and other languages are set through the ConfigProvider component. The source sits in a monorepo, so the figures on this record are for the @arco-design/web-vue package alone.

## Worth knowing

The docs source gives a minimum Vue 3 version for the library and says it does not support Internet Explorer, since Vue 3 does not.
