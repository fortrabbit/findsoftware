BookGen is a command-line toolchain for writing books and documentation in Markdown. The [manual](https://github.com/webmaster442/BookGen/blob/master/Docs/manual.md) lists the build commands, which write a static website, an EPUB 3 file, printable HTML and XHTML, a WordPress export XML, or RSS and Atom feeds.

Page templates use mustache-style tags. The README names a Scripting API and Node.js and Python scripts as ways to extend the tool.

## Worth knowing

The README says it is designed to be cross platform, but the author mainly develops and tests it on Windows.
