Laravel Admin Panel is a Laravel web application with an admin panel, user access control and a Bootstrap front end. It is not installed as a package: the README has the user clone the repository and run composer install, and it also gives a Docker route based on docker-compose. The README says the project is based on the Rappasoft Laravel Boilerplate. The repository is published by the FTXInfotech GitHub organization.
