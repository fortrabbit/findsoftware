CS-Cart is commercial eCommerce software for building online stores and multi-vendor marketplaces, installed on the customer's own server. One administration panel manages several storefronts. Installation starts with uploading the archive to the server. The [installation guide](https://docs.cs-cart.com/latest/install/apache.html) covers an Apache server, and the [documentation](https://docs.cs-cart.com/latest/) covers the rest of the product.

## Worth knowing

CS-Cart is licensed per server and per year. A Full License covers one copy on one server for one year, and the license agreement treats the program source code as Confidential Information. A free trial is offered before purchase.
