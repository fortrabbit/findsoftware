Wt is a C++ library for building web applications. An application is written as C++ widgets, and the library renders them to HTML on the server, so the application code is written without JavaScript. The application is compiled to a binary, and the library includes a built-in HTTP and WebSockets server, libwthttp, which can run it as a single process or as several.

## Worth knowing

The library is offered under the GNU General Public License, version 2, with an OpenSSL exception, and under a commercial license. The commercial license does not require distributing the application's source code.
