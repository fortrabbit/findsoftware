Amplience is a hosted content operations platform for commerce, from Amplience UK Limited and Amplience Inc. Content is stored in hubs and repositories of the Amplience CMS and read through an HTTP Content Delivery API and a [GraphQL Content Delivery API](https://amplience.com/developers/docs/concepts/content-delivery/). Properties inside a content type can be localized, so each locale carries its own value.

Access is organized through user roles, and administrators can restrict access to hubs and repositories for each user. Unpublished content is available through virtual staging, which the docs say powers the platform's visualization and preview features. The docs also describe single sign-on configuration for accounts.

## Worth knowing

Amplience runs as a hosted service. The docs list API limits, among them a rate limit on the Content Management API.
