description: The five criteria a piece of software meets to be listed on FindSoftware.
lead: Five mechanical criteria, so no listing is a judgement call.
---

1. **Used to build, run or extend a website or web app.** It serves one, generates one, or is a library, plugin or tool added to one. Software built on other software, such as a WordPress plugin, gets its own record.
2. **Installable by the user.** Source code or a distributable is available. Software sold only as a hosted service is listed [beside the register](/hosted/).
3. **Documented installation or deployment.**
4. **A release in the last 24 months.**
5. **A signal of use.** A company behind it, or a public adoption figure such as GitHub stars or package downloads.

Candidates that are not clearly in or out are listed as [boundary cases](/boundary/) until that is settled.
